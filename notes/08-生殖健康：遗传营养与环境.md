# 08 生殖健康：遗传、营养与环境

> [!abstract] 本章要点
> 遗传病与出生缺陷；营养对男性、女性及孕期生殖健康的影响；环境污染物的类型与作用；内分泌干扰物（EDCs）与防控措施。

## 遗传与生殖健康

- 遗传物质载体：染色体、DNA；遗传物质决定性状的传递。
- **遗传病**类型：

| 类别 | 内容 |
| --- | --- |
| 染色体病 | 核型分析；数目畸变、结构畸变（缺失、重复、倒位、易位）；21 三体综合征（含罗伯逊易位）；性染色体病（先天性卵巢发育不全综合征） |
| 基因病 | 单基因遗传病：X 连锁、Y 连锁、常染色体显性、常染色体隐性；红绿色盲为 X 连锁隐性 |
| 分子病 | 由基因突变导致蛋白质结构异常引起的疾病 |

- 遗传因素对生殖的影响：出生缺陷、胚胎死亡（流产）。

## 营养与生殖健康

营养状况影响健康状况；营养物质分常量营养素与微量营养素，需关注营养价值与营养吸收。

### 营养与男性生殖健康

- 胆固醇 → 性激素；精氨酸 → 精子；锌 → 睾丸萎缩。
- 维生素 A：缺乏或过量均可致胎儿畸形；酒精性肝硬化可致睾丸生精功能障碍。
- 微量元素与不育：锌、铜、硒、钙、镁。

### 营养与女性生殖健康

- **体脂率**：脂肪组织将雄激素转化为雌激素，影响月经来潮和排卵周期；体脂异常可致排卵异常、卵巢早衰。
- **体重指数 BMI** = 体重 / 身高²；18.5–23.9 为健康；低于 19.1 不易受孕。
- 孕前：补充叶酸；孕前三个月合理膳食、保证营养供给、戒烟戒酒；肉类过多影响受孕。

### 孕期营养

- 分孕早期、孕中期、孕后期。
- 营养不足可致低出生体重、早产儿、先天性畸形（与叶酸、维生素 A、锌等相关）。
- 孕期进行营养检测与代谢功能监测：甲状腺功能筛查、糖尿病筛查。

## 环境与生殖健康

### 环境污染的类型

| 划分依据 | 类型 |
| --- | --- |
| 环境要素 | 大气、水体、土壤、噪音、农药、辐射、热污染 |
| 属性 | 显性污染、隐性污染 |
| 人类活动 | 工业、农业、城市污染 |
| 性质来源 | 化学、生物、物理污染 |

### 环境因素对生殖健康的影响

| 因素 | 代表物 | 主要影响 |
| --- | --- | --- |
| 化学因素 | 农药、重金属、工业化学物（塑化剂 DEHP、双酚 A/BPA） | 干扰内分泌、影响性腺发育 |
| 生物因素 | 细菌（革兰氏阳性/阴性菌、衣原体——女性输卵管堵塞、男性尿道）、支原体、病毒（乙型肝炎病毒）、真菌（OTA、ZEA 玉米赤霉烯酮） | ZEA 为类雌激素，与雌激素竞争、抑制内分泌，影响精卵发生、类固醇激素合成、生殖周期与排卵、胎儿性腺发育 |
| 物理因素 | 电离辐射、非电离辐射（激光、红外、紫外）、高温（睾丸生精障碍）、噪音、超声波、震动 | 损伤生殖细胞与内分泌功能 |

**ZEA 作用机制要点**：诱发前颗粒细胞凋亡 → 抑制原始卵泡形成 → 卵巢早衰；影响皮层颗粒释放；使颗粒细胞周期改变、凋亡、DNA 损伤且修复困难 → 卵泡闭锁。

### 环境内分泌干扰物（EDCs）

- 又称环境激素，是环境中能干扰动物内分泌的化学物质。
- 对男性生殖系统的影响：内分泌、生殖细胞发育、生殖系统肿瘤。

### 防控措施

- 环境质量控制：水源、大气、环境监控、劳动条件。
- 生理毒害研究：加强作用机制与风险评估研究。

> [!abstract] 考点速记
> 1. 染色体病（数目/结构畸变、21 三体、性染色体病）与基因病（四类单基因遗传）的分类。
> 2. 男性：胆固醇、精氨酸、锌、维生素 A、酒精；女性：体脂率、BMI 18.5–23.9、<19.1 不易受孕。
> 3. 孕期营养不足的三大后果：低出生重、早产、先天畸形；产检筛查甲状腺与糖尿病。
> 4. 环境污染物按要素/属性/活动/性质四种分类；化学、生物、物理因素的代表物与效应。
> 5. EDCs 定义及对男性生殖系统的三类影响；防控从质量控制与毒理研究入手。

<summary>参考答案</summary>

1. 导致出生缺陷与胚胎死亡（流产）；染色体病与基因病是主要遗传基础。

4. EDCs 是环境中干扰内分泌的化学物质，影响内分泌、生殖细胞发育并诱发肿瘤；防控包括水源大气等质量控制、环境监控、改善劳动条件与毒理机制研究。
