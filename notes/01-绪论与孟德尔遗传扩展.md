# 01 · 绪论与孟德尔遗传的扩展

> [!abstract] 一句话定位
> 遗传学从「性状如何传递」出发：孟德尔定律是骨架，**不完全显性、复等位基因、致死基因、基因互作、性连锁与表观遗传**是对骨架的补充和修正，使经典比例能解释真实世界。

## 1　遗传学的研究层次与发展脉络

### 1.1　不同水平的遗传

| 水平 | 主要特征 |
| :--- | :--- |
| 单细胞生物 | 以**无性繁殖**为主，遗传信息直接传给子代 |
| 多细胞生物 | 通过**单倍体有性配子**完成世代传递 |
| 群体 | 研究等位基因频率在世代间的变化（→ [[遗传学/05-专题遗传/02-数量性状与群体遗传\|群体遗传学]]） |

### 1.2　学科发展史

| 阶段 | 代表人物 / 事件 | 核心贡献 |
| :--- | :--- | :--- |
| 孟德尔前 | 希波克拉底 | 认为遗传物质通过**精液**传递 |
| | 亚里士多德 | 认为遗传具有**非连续性** |
| | 先成论与后成论 | 个体发育是预先形成还是逐步形成 |
| | 林奈 | 物种不变论；界门纲目科属种、双名法 |
| | 科尔鲁特 | 杂交育种（仍持神创论），培育出植物品种 |
| 进化论 | 达尔文 | 变异积累 → 生殖隔离 → 新物种；孟德尔为其提供变异来源 |
| 经典遗传学 | 孟德尔 | 豌豆杂交实验，建立遗传学基本定律 |
| | 孟德尔理论重新发现 | 遗传学成为独立学科 |
| | Sutton–Boveri | **染色体是遗传因子的载体** |
| | 摩尔根 | 基因在染色体上线性排列；提出连锁交换规律 |
| 分子遗传学 | 细菌转化实验、T2 噬菌体实验、DNA 双螺旋 | 把遗传因子落到分子层面 |
| 基因组学 | HGP（Human Genome Project） | 从单基因走向全基因组 |

## 2　孟德尔比例的修饰

> [!tip] 记忆抓手
> 孟德尔的 3∶1 与 9∶3∶3∶1 成立需要前提：**完全显性、等位基因只有两种、无致死、基因间独立、表型不受环境影响**。下面逐条拆解这些前提被打破时的表现。

### 2.1　显性关系的扩展

| 类型 | 定义 | 典型例子 |
| :--- | :--- | :--- |
| **不完全显性** | 亲本的相对性状在子代中表现为**中间表型** | 红花 × 白花 → 粉花 |
| **共显性** | 亲代双方的性状**同时、完整**地在子代出现 | ABO 血型中的 AB 型 |
| **复等位基因** | 群体中同一基因座存在**三个及以上**等位基因形式 | ABO 血型、孟买血型、果蝇复眼基因 |

**ABO 血型（$I^A/I^B/i$）**

- $I^A$：N-乙酰半乳糖胺转移酶，作用于 N-乙酰氨基葡萄糖（H 物质前体）。
- $I^B$：半乳糖基转移酶，作用于 N-乙酰半乳糖胺。
- $i$：假基因，无功能性转移酶；$I^A$、$I^B$ 对 $i$ 显性，彼此共显性。
- 凝集原即红细胞表面的糖链末端结构。

**孟买血型（$I^A/I^B/i$ + $H/h$）**

- 孟买 O 型：**缺少 H 底物**（$hh$），即使携带 $I^A$ 或 $I^B$ 也无法合成 A/B 抗原。
- 这是**上位效应**的经典例子：H 基因座对 ABO 基因座呈隐性上位。

### 2.2　致死等位基因

| 类型 | 定义 | 例子 |
| :--- | :--- | :--- |
| 隐性致死 | 纯合时致死 | 隐性纯合个体在后代中缺失，比例由 3∶1 变为 2∶1 |
| 显性致死 | 一个等位基因即可致死 | 亨廷顿病（Huntington disease） |

### 2.3　多基因效应与一因多效

- **多基因效应**：多个基因共同控制同一性状（→ [[遗传学/05-专题遗传/02-数量性状与群体遗传\|数量性状]]）。
- **一因多效**：一个基因影响多个性状。
  - 典型例：β-半乳糖苷酶基因同时影响三种酶的表达（→ [[遗传学/04-基因表达与调控/02-基因表达调控\|操纵子]]）；苯丙氨酸羟化酶缺陷同时导致智力损伤与色素缺乏（见第 3 节）。

### 2.4　基因相互作用

| 类型 | 含义 |
| :--- | :--- |
| **上位** | 一个基因影响另一个基因的表达；分为**隐性上位**（隐性纯合时抑制）与**显性上位**（单个显性基因即可抑制） |
| **互补** | 两个基因都是产生表型所必需的 |
| **抑制** | 一个基因抑制另一个基因的功能 |
| **重复基因** | 两个基因产生相同表型效应，功能冗余 |

**互补分析（顺反测验）**——判断两个表型相似的隐性突变是否属于同一基因：

1. 将两个突变纯合体杂交，观察 F1。
2. 若突变位于**不同基因**：彼此互补，F1 为野生型。
3. 若突变位于**同一基因**：不能互补，F1 仍为突变型。
4. **互补群**：一系列不能相互互补的突变，属于同一基因内部的不同位点。

### 2.5　性连锁与性别影响

| 概念 | 定义 |
| :--- | :--- |
| **X 连锁遗传** | 基因位于 X 染色体上；伴随交叉遗传特征 |
| **Y 连锁遗传** | 基因位于 Y 染色体上，只在男性中传递 |
| **限性遗传** | 性状只出现在某一性别（如仅雄性表达的性状） |
| **从性遗传** | 常染色体基因控制的性状在两性中均可出现，但显隐性关系受性别影响；例如 $Bb$ 在雄性表现显性、在雌性表现隐性 |

> [!note] 与性别决定的区别
> 本节讨论的是**基因位于何处、如何表达**；性染色体如何决定个体性别见 [[遗传学/05-专题遗传/01-性别决定与剂量补偿|性别决定与剂量补偿]]。

### 2.6　表型为何不完全由基因型决定

- 表型 = **基因型 + 环境**共同作用的结果。
- **外显率**：具有特定基因型的个体中，表现出相应表型的比例。
- **表现度不一**：同一基因型个体间表型严重程度存在差异。
- **遗传早现**：性状在世代传递中**发病越来越早、程度越来越重**。

### 2.7　表观遗传、印记与核外遗传

**表观遗传学**：DNA 序列不变，但基因表达模式改变并引起可遗传的表型变异。

| 机制 | 举例 |
| :--- | :--- |
| DNA 化学修饰 | 甲基化等 |
| 组蛋白化学修饰 | 乙酰化、甲基化、磷酸化（→ [[遗传学/02-染色体与基因组/01-染色体结构与基因组组织\|染色体重建]]） |
| 染色质结构改变 | 常染色质 / 异染色质状态转换 |

- **基因组印记**：子代表型取决于该基因来自父方还是母方。
- **母性影响**：母本基因型决定子代表型，源于基因表达的时间性与细胞质成分。
- **核外遗传（细胞器遗传）**：线粒体和叶绿体 DNA 控制的性状，详见 [[遗传学/02-染色体与基因组/01-染色体结构与基因组组织|染色体结构与基因组组织]]。

## 3　案例：苯丙氨酸代谢与先天代谢病

![[attachments/苯丙氨酸代谢途径.jpg|600]]

| 疾病 | 缺陷酶 | 代谢后果 | 遗传方式 / 表型 |
| :--- | :--- | :--- | :--- |
| **苯丙酮尿症（PKU）** | 苯丙氨酸羟化酶 | 苯丙氨酸 → **苯丙酮酸**积累，损伤大脑神经；同时酪氨酸、黑色素缺乏 | 智力损伤 + 肤色/发色变浅，体现**一因多效** |

## 4　考点速记

- 孟德尔比例成立的五个前提：完全显性、两种等位基因、无致死、基因间独立、环境不影响表型。
- ABO 血型：$I^A$ 与 $I^B$ 共显性，$i$ 为隐性；孟买型需同时考虑 $H/h$ 上位。
- 互补测验：**子代野生型 = 不同基因互补；子代突变型 = 同一基因不互补**。
- 限性遗传 vs 从性遗传：前者只在一个性别出现，后者两性均可出现但显隐性受性别影响。
- 外显率看「比例」，表现度看「程度」，遗传早现看「世代趋势」。

<details>
<summary><b>自测 1：孟买型个体携带 $I^A$ 却表现为 O 型，原因是什么？</b></summary>

其基因型为 $hh$，不能合成 H 物质（A/B 抗原的前体底物），因此即使存在 $I^A$ 转移酶也没有作用底物，无法生成 A 抗原。这是 $H/h$ 基因座对 ABO 基因座的**隐性上位**。
</details>

<details>
<summary><b>自测 2：如何用顺反测验判断两个隐性突变是否在同一基因？</b></summary>

将两突变纯合体杂交：F1 野生型说明两个突变位于不同基因、可相互互补；F1 仍为突变型说明位于同一基因、不能互补，二者属于同一互补群。
</details>
