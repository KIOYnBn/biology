# 04 · 器官发生总论与外胚层

> [!abstract] 本章速览
> 三胚层建立后进入器官发生：**形态发生与细胞分化同步进行**。外胚层主要产生神经系统、表皮及其衍生物。主线为"外胚层 → 神经板 → 神经管 → 脑 / 脊髓"与"神经嵴 → 周围神经系统 / 色素细胞 / 面部软骨等"两条并行路线。
>

## 4.1 器官发生总论

### 4.1.1 原肠胚特点

1. 细胞分裂速度减慢；
2. RNA 迅速转录，胚胎在分子水平上出现个体特征；
3. 细胞迁移，胚层形成。

### 4.1.2 器官发生的含义

- **定义**：细胞之间相互作用、重新排列，形成躯体及器官的过程。
- 包括**形态发生**（细胞或细胞群形态、空间排列变化）与**细胞分化**（细胞内部生成独有蛋白质、具备独特功能），二者同步进行。
- 原肠作用后形成外、中、内三胚层，是器官发生的基础。

![[attachments/器官发生总览.png]]

> [!note] 冯贝尔定律的延伸
> 胚胎中动物的一般特征比特化特征出现早；高等动物早期胚胎只与其他动物的**早期胚胎**相似，而非其成体。完整表述见 [[01-绪论与发育基本过程#1.3.3 冯贝尔法则（von Baer's laws）]]。

## 4.2 外胚层分化与神经管形成

**脊椎动物外胚层的三大分化方向**

| 方向 | 来源与命运 |
| --- | --- |
| **神经板** | 受索前板和脊索在原肠形成中的诱导；外胚层 → 神经板 →（内陷）神经管 → 脑、脊髓 |
| **表皮** | 弹性、防水、持续再生的屏障 |
| **神经嵴** | 位于表皮区室与中枢神经系统之间；形成周围神经系统等（见 4.2.4） |

### 4.2.1 神经胚形成

- **定义**：胚胎形成神经管的过程；正在形成神经管的胚胎称神经胚。
- **两种方式**

| 方式 | 过程 |
| --- | --- |
| **初级神经胚形成** | 脊索中胚层诱导其上外胚层细胞分裂、内陷，与表皮脱离形成中空神经管 |
| **次级神经胚形成** | 预定外胚层细胞形成间质细胞，进入表皮下方形成实心髓索，随后空洞化形成神经管 |

- **按神经管构建方式分类**：混合型（初级 + 次级并存：两栖类、爬行类、鸟类、哺乳类）与完全型。

### 4.2.2 初级神经胚形成的步骤

1. **神经板形成**：神经外胚层细胞纵向伸长、加厚。
2. **神经褶形成**：外胚层边缘变厚、向上运动；背部中胚层信号诱导边缘细胞变成"楔形"。
   - **神经沟**：神经褶聚合前，隆起神经褶与神经板中央形成的沟状结构。
   - **铰合点**：作为中枢轴引导周围细胞旋转。
     - **内侧铰合点 MHP**：神经板中线细胞形成，用于锚定其下的脊索。
     - **背外侧铰合点 DLHP**：由表面外胚层诱导形成，左右各一个。
     - 形成机制：**顶端收缩**——肌动蛋白顶端边缘局部收缩，使细胞顶部相对基部变小。
3. **铰合点的调控**
   - **BMP（骨形态发生蛋白）负调控**：调控细胞顶—基极性（稳定顶端 Par 复合物），促进均一上皮形态，即阻止 DLHP 形成。
   - **头蛋白（Noggin）**：拮抗 BMP。
   - 脊索与底板的 **Shh** 促使 MHP 形成。
4. **神经褶闭合**：表皮外层表面丝足生长，帮助 DLHP 弯曲、神经管闭合；神经褶顶部细胞迁移形成神经嵴细胞。
   - 神经嵴路径：在神经板边缘特化 → 定位于神经褶顶部 → 间质细胞化 → 迁移。
5. **神经管与表皮分离**：细胞黏附分子调节——神经管细胞从表达**上皮钙黏素**转为**神经钙黏素 + 神经细胞黏附因子**。

> [!important] 闭合顺序
> 神经管闭合具有**物种特异性**：鸟类沿体轴依次闭合；哺乳类同时开始。前端神经孔（前端开口）形成嗅窝，后端神经孔闭合。

### 4.2.3 神经嵴的形成与分化

- **来源**：外胚层；起源于**神经管最背部区域**。
- **分子机制**

| BMP / Wnt 状态 | 命运 |
| --- | --- |
| BMP、WNT 持续存在 | 表皮 |
| Wnt 诱导 BMP 后关闭 | 前部基板 |
| Wnt 诱导 BMP 后仍开启 | **神经嵴** |
| BMP 受抑制 | 神经组织 |

- **特点**：分化命运由**迁移位置**决定；迁移路径由**胞外基质**决定。
- **四大区域与衍生物**

| 区域 | 衍生物 |
| --- | --- |
| 颅内神经嵴 | 迁移到面部和咽弓，形成面部 / 颈部骨骼软骨、感觉神经元、胶质细胞 |
| 迷走神经嵴与骶神经嵴 | 肠的交感神经 |
| 心脏神经嵴 | 分隔主动脉和肺动脉 |
| 躯干神经嵴 | 交感神经元、色素细胞 |

- 神经嵴细胞在神经管闭合时于背侧中线迁移，形成**周围神经系统**：即除中枢神经系统外的所有神经元、神经胶质细胞、色素细胞、真皮等。

## 4.3 神经系统发育

- 早期发育：神经管、神经嵴形成；组成：**中枢神经系统 + 周围神经系统**。
- 神经管头部 → 脑，尾部 → 脊髓。

**脑的分化（五部分）**

| 脑区 | 主要结构与功能 |
| --- | --- |
| **端脑** | 嗅叶（嗅觉）、海马（记忆）、大脑 |
| **间脑** | 视泡（视网膜）、上丘脑（松果体）、丘脑（视听神经中枢）、下丘脑（温度、睡眠、呼吸调节） |
| **中脑** | 温度、运动调节 |
| **后脑** | 小脑、脑桥（连接大脑和小脑）、控制面部和颈部的神经 |
| **末脑** | 髓质——非自主反射中枢 |

**脑泡形成过程中的弯曲**

- 先出现的**背侧弯曲**：头曲（中脑曲，位于中脑）、颈曲（脑与脊髓之间）。
- 后出现的**凸向腹侧**：端脑曲、脑桥曲。

**脑室**

- 脑中的腔隙：两个侧脑室、第三脑室、第四脑室，彼此有孔道连接；内含脑脊液与脉络丛。
- **脉络丛**：产生脑脊液，含丰富血管，与内皮细胞相连形成**血脑屏障**，允许特定物质进入。

## 4.4 神经细胞的增殖与分化

- 神经管最初由单层**神经干细胞**组成。
- **神经上皮**：细胞核位于不同高度，呈**假复层上皮**。
- 神经干细胞始终位于神经管腔的基底层，沿垂直于神经管的方向迁移分化，先后分裂出成神经细胞与成神经胶质细胞；留下的神经干细胞转变为**放射状胶质细胞**，成体后变为室管膜细胞，失去干性。

### 4.4.1 神经元

- 神经系统结构与功能的基本单位；由**细胞体 + 细胞突起**组成。
  - **树突**：接受信号，一个或多个分支延伸。
  - **轴突**：细胞间传递兴奋，只有一个。
    - **髓鞘**：神经胶质细胞围绕轴突形成的多层膜结构，防止电脉冲损耗；中枢由**少突胶质细胞**形成，外周由**施旺细胞**形成。
  - **生长锥**：轴突或树突末端；感知信号引起定向运动，产生微刺并通过丝足运动。
  - 细胞体仅位于大脑、脊髓、神经节；细胞突起可延伸全身。
- **分类**
  - 按功能：感觉神经元、运动神经元、联络神经元。
    - 运动神经元：生长锥接触肌管 → 神经突触蛋白聚糖诱导乙酰胆碱受体成簇。
  - 按突起：假单极、双极、多极神经元。

### 4.4.2 神经胶质细胞

- 特点：不产生动作电位；支持、滋养神经元，吸收和调节某些活性物质；具有干细胞特性，可吞噬损伤神经元。

![[attachments/神经胶质细胞.png|500]]

- **放射状胶质细胞的分裂面决定命运**

| 分裂面 | 结果 |
| --- | --- |
| 垂直管腔 | 自我更新（保持干细胞） |
| 与管腔呈斜角 | 分化：接受**旧中心体**的子细胞为干细胞，接受**新中心体**的子细胞分化；顶端蛋白 Par-3 招募 Notch 信号蛋白，接收更多 Par-3 的细胞为干细胞 |

## 4.5 神经细胞迁移与中枢分化

- 由**放射状神经胶质细胞**引导迁移：
  - 室管膜区：增殖区；
  - 中间区（灰质）：成神经细胞、成神经胶质细胞；
  - 边缘区（白质）：神经轴索和胶质。

| 部位 | 分化要点 |
| --- | --- |
| **脊髓** | 邻近体节细胞形成脊柱；神经管分化为室管膜区、套区（灰质）、边缘区（白质）；功能上被界沟分为背部（接收信息）和腹部（投射运动神经元） |
| **大脑皮层** | 白质外的新皮质层（灰质），由成神经细胞组成 |
| **小脑皮层** | 室管膜层 → 套层 → 浦肯野细胞层 → 内颗粒层 → 外颗粒层；外颗粒层细胞向内迁移形成内颗粒层 |
| **周围神经系统** | 包括神经节、神经干、神经丛、神经终末装置，由神经元和神经胶质细胞组成；作用：身体与中枢神经系统的联络。按连接中枢位置分脑神经 / 脊神经，按分布对象分躯干神经 / 内脏神经 |

## 4.6 感觉器官发生

### 4.6.1 眼睛形成

1. 前脑腹侧**眼场**外翻形成视泡；
2. 视泡与外胚层预定晶状体接触 → 晶状体板增厚；视泡外壁内陷形成双层壁**视杯**；
3. 晶状体板内陷形成晶状体窝 → 脱离表皮形成**晶状体泡**；
4. 视杯外层细胞产生色素形成**色素视网膜**；内层形成光感受器、神经细胞等构成**神经视网膜**；
5. 视网膜与晶状体泡诱导覆盖的表皮形成透明**角膜**；
6. 视杯作用下，间充质积聚在视杯外表形成血管膜和巩膜；
7. 神经节细胞轴突在视乳突集中，经**视柄（视神经）**连接间脑枕叶；与视神经相连的脑组织：哺乳类为侧膝状核和上丘，两栖类与鸟类为视顶盖。

### 4.6.2 耳

| 部分 | 结构 |
| --- | --- |
| 外耳 | 耳廓、外耳道、鼓膜 |
| 中耳 | 鼓膜、听小骨 |
| 内耳 | 耳蜗、前庭 |

- **内耳**：菱脑两侧体表外胚层形成听基板 → 内陷形成听泡 → 产生内耳感觉上皮、听神经节和前庭神经节神经元。
- **中耳**：第一咽囊向背侧拓展，远侧盲端膨大成鼓室，近端为咽鼓管；外胚层第一鳃沟背侧壁与内胚层第一咽囊外侧壁融合形成鼓膜；鼓室上方间充质形成听小骨。
- **外耳**：第一鳃沟内陷形成漏斗状管道，其外胚层形成外耳道内侧段。

### 4.6.3 嗅觉与面部异常

- 胚胎最前端形成嗅上皮。
- **异常类型**：唇裂（上颌隆起与内侧隆起未愈合）、腭裂（正中腭凸与外侧腭凸未愈合或左右侧腭未愈合）、面斜裂（上颌隆起与外侧隆起未愈合）。

### 4.6.4 皮肤

| 层次 | 要点 |
| --- | --- |
| **表皮** | 角质层、颗粒层、棘皮层、基底层（基底细胞分泌 Notch 诱导子细胞分化）、基底膜（分隔表皮与真皮） |
| **真皮** | 分泌因子促进基底膜表皮细胞增殖 |
| **黑素细胞** | 神经嵴来源，位于基底表皮和毛囊 |

**表皮形成**（胚胎外胚层 → BMP、WNT 调控）

1. 一层细胞；
2. 双层细胞：外侧为周皮（临时结构），内侧为基底层 / 生发层（含表皮干细胞）；
3. 表皮不对称分裂、沿基底膜垂直分裂，离开的成为角质形成细胞，到达角质层后为死细胞。
