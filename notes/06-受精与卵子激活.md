# 06 受精与卵子激活

> [!abstract] 本章要点
> 受精的概念、类型与过程；海胆体外受精模式；哺乳动物体内受精与获能；顶体反应、透明带反应与皮质反应；卵子激活的钙信号；卵胞质重排。

## 概念与作用

**受精**：单倍体的精子和卵子相互结合、融合形成双倍体合子的过程，是有性生殖生物发育的起点。

作用：

1. 保证双亲的遗传作用（性状稳定）。
2. 恢复染色体数目，是发育的开端。
3. 继承个体发生中产生的变异，保证物种多样性。

### 受精类型

| 划分依据 | 类型 | 说明 |
| --- | --- | --- |
| 受精地点 | 体内受精 / 体外受精 | 体内：精子从雄体传到雌体抵达受精部位（爬行类、鸟类、哺乳类）；体外：精卵同时排出体外（鱼类、部分两栖类） |
| 个体来源 | 自体受精 / 异体受精 | 自体：雌雄同体同一个体精卵融合；异体：两个不同个体的精卵融合 |
| 入卵精子数 | 单精受精 / 多精受精 | 单精：只有一个精子入卵（胎盘类哺乳类）；多精：多个精子入卵形成多个雄原核，只有一个与雌原核结合（昆虫、鸟类、软体动物） |

### 一般过程

1. 精子穿越卵丘细胞（放射冠）。
2. 精子接触并穿越透明带。
3. 精子与卵子质膜融合，精子入卵。
4. 诱发皮质反应，阻止多精受精。
5. 雌雄原核形成与融合：精核去浓缩（清除鱼精蛋白二硫键，被组蛋白取代），卵母细胞恢复减数分裂，雄原核较大，配子融合时核仁核膜消失、原核收缩融合形成合子。
6. 重要事件：精卵接触与识别、精子入卵、遗传物质融合、卵子激活与发育。

## 体外受精：海胆模式

海胆属棘皮动物，是体外受精的模式生物。

### 精卵识别

- 卵母细胞分泌趋化因子形成微环境吸引精子；海胆趋化因子为呼吸活化肽。
- 卵有两层膜：卵黄膜（与卵膜相连，纤维物质，可与精子顶体融合）；卵胶膜（透明，主要成分为糖蛋白/呼吸活化肽）。卵排出后胶膜缓慢溶于水，引起精子趋化并诱发顶体反应。

### 顶体反应

接触卵胶膜 → 精子膜与顶体膜融合 → 顶体下腔肌动蛋白聚合形成微丝 → 顶体伸长（未发生反应时肌动蛋白以颗粒形式存在）。

### 精卵融合

- 卵黄膜精子受体识别顶体结合素，使精子与卵黄膜结合。
- 顶体延伸的机械力 + 水解酶使精子穿过卵黄膜。
- 卵表面微绒毛伸长形成受精锥包裹精子，将精子拖入卵内，随后受精锥消失。

### 阻断多精入卵

- **膜电位快速变化**：精卵融合后发生动作电位。
- **皮层反应**：皮层颗粒膜与卵膜融合释放皮层颗粒 → 卵黄膜硬化成为受精膜；受精膜从精子入卵位置形成并扩散。
  - 皮层颗粒成分：过氧化物酶（交联蛋白质酪氨酸残基使膜变硬）、多糖（进入卵周隙吸水膨胀顶起卵黄膜）、蛋白水解酶（使卵黄膜与卵膜分离，剪除卵膜结合素受体及结合的精子）。
  - 机制：精卵融合释放 Ca²⁺ 波使卵胞质 Ca²⁺ 升高，诱发皮层反应；皮层反应后线粒体吸收 Ca²⁺ 并转移给内质网。

### 受精卵发育

- 早期反应（精卵接触至皮层反应）：Ca²⁺ 波解除母源 mRNA 及其翻译的抑制，促进 DNA 复制与蛋白质合成。
- 晚期反应（受精后数分钟）：pH 升高（Na⁺ 内流、H⁺ 排出），激活 DNA 和蛋白质合成。
- 雌雄原核形成：精子线粒体和鞭毛降解，留下精核和中心体；卵子中心体降解，精子中心体成为合子中心体，作为微管组织中心形成星体，牵拉雌雄原核靠近融合。

## 体内受精：哺乳动物

### 精子与卵子运行

精子活力、子宫肌收缩、精子趋流性（逆向液体流向）；卵子由输卵管伞捕获并在壶腹停留。

### 精子获能

**精子获能**：精子在子宫和输卵管中接受雌性分泌物质发生生理变化，获得受精能力的过程。获能前以氧化磷酸化为主，获能后转为糖酵解与有氧氧化。

| 变化类别 | 具体内容 |
| --- | --- |
| 运动能力 | 增强，游动方式改变（超激活） |
| 代谢 | 增强，糖酵解和有氧氧化 |
| 膜结构 | 膜筏重排、流动性增强；表面蛋白质或糖类（去获能因子）脱落；质膜胆固醇与磷脂比例下降；表面电荷降低 |
| 离子 | K⁺ 外流、Ca²⁺ 内流，促进顶体反应膜融合 |
| 信号 | 蛋白质酪氨酸磷酸化；cAMP 浓度增高 |

- 机制：HCO₃⁻ 升高 → 激活精子腺苷酸环化酶 → cAMP-PKA 通路。
- 其他诱导因素：孕酮可诱导顶体反应；低剂量活性氧促进获能（激活腺苷酸环化酶、酪氨酸磷酸化），高剂量有害；精胺低浓度促进（促进 Ca²⁺ 吸收）、高浓度抑制。
- 获能可逆：与精浆或附睾液接触可去获能，再进入雌性生殖道可重新获能（详见 [[04-精子发生与睾丸结构]]）。

### 精卵识别与顶体反应

透明带由生长期卵母细胞分泌，为非细胞成分，由 ZP1–ZP3 糖蛋白组成；作用是保护卵子、阻止异种精子进入，是阻止种间受精的主要屏障。

- **初级识别**：未发生顶体反应的精子与 ZP3 结合；半乳糖基转移酶与 ZP3 的 N-乙酰葡糖胺结合，激活 G 蛋白诱导顶体反应；SP56 与 ZP3 的半乳糖端结合（小鼠精子顶体完整时表达，顶体反应后消失）；透明带受体激酶 p95 为受体酪氨酸激酶，抑制其活性可阻断顶体反应。
- **次级识别**：顶体反应后精子与 ZP2 结合并穿过透明带；ZP2 与 ZP3 形成异二聚体，ZP1 连接异二聚体。
- **卵子结合蛋白**：初级位于精子顶体质膜（半乳糖苷转移酶、p95、sp56），次级位于顶体内膜（顶体素——胰蛋白酶样酶活性并具凝集素样碳水化合物结合活性；精子黏合素）；ph-20 位于顶体后区与顶体内膜。
- **顶体反应机制**：
  - Ca²⁺：IP₃ + PKA 打开顶体外膜 Ca²⁺ 通道。
  - G 蛋白：ZP3 激活 Gi 蛋白；白喉素可抑制 ZP 引发的顶体反应。
  - Rab3A：顶体膜上的小 GTPase，Ca²⁺ 作用下转为结合 GTP 的活性形式，促进 Ca²⁺ 释放。
  - PLC → PIP₂ → DAG + IP₃：DAG 提高膜流动性，IP₃ 促进 Ca²⁺ 释放。
  - 蛋白激酶参与调控。
- **融合**：顶体反应使顶体膜内侧向外暴露；Izumo 蛋白由顶体颗粒外膜转位至精子表面，与卵膜蛋白 Juno 结合，拉近并促进精卵膜融合。COC（卵母卵丘复合体）由卵母细胞及外围卵丘细胞层构成，保护卵母细胞成熟发育。

### 融合后事件与阻止多精入卵

融合后：精核去致密化与雄原核形成；卵子减数分裂完成与雌原核形成；雌雄原核融合。

阻止多精入卵：

1. 卵膜 Juno 脱落。
2. 皮层颗粒反应：锌金属蛋白酶切割 ZP2；TGM1 交联 ZP3 及其他 ZP 蛋白使透明带变硬。
3. 透明带结合阻断：ZP3 构象改变无法识别；N-乙酰葡糖胺苷酶切除 ZP3 末端，静电排斥增强。

> [!note] 与海胆的区别
> 哺乳动物没有顶体突起，不是垂直入卵；皮层反应不形成受精膜，主要修饰透明带中的精子受体，又称透明带反应。海胆形成受精膜，见前文。

## 卵子激活

- 未受精卵母细胞被细胞静止因子（CSF）阻止在减Ⅱ中期；精子入卵后 CSF 激活 APC（后期促进复合体）。
- **卵子激活**：精子入卵使卵子复苏，启动一系列生化事件、完成减数分裂、形成新个体的过程。

### 生理变化

| 类别 | 内容 |
| --- | --- |
| 质膜 | 去极化 |
| Ca²⁺ | Ca 波（受精后第一次 Ca²⁺ 升高，始于精子入卵处，以波形式传遍卵子，来自胞内钙库）；Ca 震荡（持续数小时、反复短暂升高，胞外高浓度 Ca²⁺ 必需） |
| pH | 升高，促进 DNA 复制转录、蛋白质合成与糖原利用、精核染色质去浓缩与原核形成 |
| 代谢 | 氧气吸收、能量代谢、DNA 复制 |
| 基因活动 | 母源 mRNA → 合子 mRNA；启动 DNA 复制、RNA 转录与蛋白质合成 |
| 酶活性 | 多种酶活性变化 |

### 总结与模型

- 精子进入后第一个反应是卵内 Ca²⁺ 瞬间升高，先出现在融合处，再以波形式传至对侧，随后出现重复 Ca 震荡。
- Ca²⁺ 变化的作用：引起皮层颗粒释放、阻断多精受精；触发第二次减数分裂重启与第二极体排出。
- 1997 年英国科学家 Swann 和 Lai 发现震荡蛋白，与 Ca 震荡同步出现；免疫分析显示其位于精卵最先融合处。
- **受体假说**：精卵表面受体相互作用 → G 蛋白/酪氨酸蛋白激酶 → PLC → IP₃ → Ca²⁺。
- **精子因子假说**：精子胞质信号分子在膜融合时进入卵胞质，激活 Ca²⁺ 释放。

> [!note] 其他相关术语
> 胚泡附植见 [[07-早期胚胎发育与干细胞]]；卵黄膜是一种原生质膜；精子在获能中膜流动性、酪氨酸磷酸化、cAMP、表面电荷与胆固醇/磷脂比的变化见本节表格。

## 卵胞质重排

- 低等动物：由形态发生决定物决定。
- 高等动物：由精子进入位置决定。
  - **两栖类灰色新月区**：胞质不同层次相对运动，在精子进入点对面形成新月形灰色区域，确定原肠部位与胚胎形态发育方向。
  - **被囊动物黄色新月区**：受精前黄色皮质胞质包裹内部胞质；受精后黄色皮质胞质与透明胞质（卵子核分解释放）向植物极精子方向收缩；黄色细胞质区域标志尾部肌肉形成位置。

> [!abstract] 考点速记
> 1. 受精概念、作用与三种分类；一般过程六步。
> 2. 获能的定义、变化与 HCO₃⁻-cAMP-PKA 机制；可逆性。
> 3. ZP3 初级识别、ZP2 次级识别；Izumo-Juno 融合；p95、sp56、顶体素、精子黏合素、ph-20、Rab3A。
> 4. 阻断多精：海胆膜电位 + 受精膜；哺乳类 Juno 脱落 + ZP2 切割 + ZP3 修饰。
> 5. Ca 波与 Ca 震荡、CSF-APC、母源 mRNA 向合子 mRNA 转换；两种激活模型。

<details>
<summary>参考答案</summary>

1. 海胆靠快速膜电位变化与皮层颗粒形成受精膜；哺乳类靠 Juno 脱落、锌金属蛋白酶切 ZP2、TGM1 交联及 ZP3 构象改变阻断结合，不形成受精膜。
2. ZP3 与未顶体反应精子初级识别并诱导顶体反应；ZP2 与顶体反应后精子次级识别，助其穿过透明带。
3. 运动增强、代谢转换、膜流动性增强与去获能因子脱落、离子流动、蛋白磷酸化；可逆说明获能是雌性生殖道内可调的生理状态。
4. Ca 波从入卵点传播，触发皮层反应与多精阻断；持续 Ca 震荡重启减数分裂并促进原核形成与发育启动。
