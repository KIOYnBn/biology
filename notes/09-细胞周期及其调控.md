# 09 细胞周期及其调控

> 返回 [[00-总览]] ｜ 配套总结：[章节总结-细胞周期与分裂](attachments/章节总结-细胞周期与分裂.pdf)

## 1. 细胞周期概述

- **定义**：由一次细胞分裂结束到下一次细胞分裂结束的过程。
- 时相：
  - **G1 期**：细胞生长。
  - **S 期**：DNA 与组蛋白合成。
  - **G2 期**：细胞继续生长，为分裂做准备。
  - **M 期**：细胞分裂（见 [[10-细胞分裂]]）。
- **检查点（checkpoint）**：作用于细胞周期转换时序的调控信号通路；当特殊事件出现差错时，通过反馈机制暂停周期，等待条件成熟。

### 细胞类型

| 类型 | 特征 |
|---|---|
| 周期细胞（cycling cells） | 持续分裂 |
| G0 期细胞 | 暂不分裂，条件合适时可重新进入周期（停留在 G1 期） |
| 终末分化细胞 | 高度分化，不再分裂 |

- 早期卵母细胞（早期胚胎细胞）的细胞周期最短，几乎没有 G1 和 G2 期。

### 细胞所处时相的测定

- 显微镜观察。
- 流式细胞仪测定 DNA 含量：用 DNA 特异性荧光染料处理细胞后分析（见 [[02-细胞生物学的研究方法]]）。

## 2. 核心调控因子

- **MPF（成熟促进因子 / 有丝分裂促进因子）**：
  - 调节亚基：周期蛋白 **cyclin（Cyclin B）**。
  - 催化亚基：周期蛋白依赖性激酶 **CDK（cdc2 / CDK1）**。
  - 具激酶活性；活化涉及 Wee1 抑制性磷酸化、Cak 激酶和 Cdc25 磷酸酶去磷酸化。
  - 作用：磷酸化染色体凝缩蛋白、核膜崩解蛋白、纺锤体装配蛋白等，推动 M 期事件。
- **cdc 基因**：细胞周期基因；**cyclin**：周期蛋白。
- **PCC（早熟凝集染色体，prematurely condensed chromosome）**：细胞提前进入 M 期导致的染色体异常凝缩。
  - G1 期：单线丝状；S 期：粉末状；G2 期：双线丝状。

### 各时期 Cyclin-CDK 复合物与代表底物

| 时期 | Cyclin-CDK | 代表底物 |
|---|---|---|
| G1 | Cyclin D – CDK4/6 | Rb |
| S | Cyclin E – CDK2；Cyclin A – CDK2 | p107 |
| G2 | Cyclin A – CDK1 | p107 |
| M | Cyclin B – CDK1 | H1、Lamins、GM130 |

> 注：Cyclin 的泛素化降解由 SCF、APC 等 E3 连接酶复合体介导，保证周期单向推进。

## 3. 检查点调控

### 3.1 G1/S 检查点（限制点）

- 限制因素：单细胞为营养条件；多细胞为促分裂原信号。
- 信号通路：
  1. 促分裂原信号 → 激活 SOS → 激活 Ras → MAPK 通路活化。
  2. 活化的 G1-CDK 磷酸化 **Rb 蛋白** → 转录因子 **E2F** 游离。
  3. E2F 转录 Cyclin A/E → CDK 活化 → 激活 DNA 合成相关蛋白，细胞进入 S 期。
- **Rb 基因突变**会导致该检查点失控，引发肿瘤。
- G0 期细胞即停留在 G1 期的细胞。

### 3.2 S 期检查点（DNA 损伤检查点）

- DNA 损伤识别：
  - 单链损伤 → ATM 激酶 → Chk2 激酶。
  - 双链损伤 → ATR 激酶 → Chk1 激酶。
- 两条阻滞通路：
  1. Cdc25A 被磷酸化后经蛋白酶体降解，CDK 无法活化。
  2. p53 磷酸化后与 Mdm2 解离，作为转录因子促进 **p21** 表达；p21 结合 CDK-Cyclin 复合物并抑制其活性。
- DNA 无法修复时：p53 介导细胞凋亡；**p53 基因突变**与细胞癌变密切相关（见 [[11-细胞衰老与死亡]]）。

### 3.3 G2/M 检查点

- 核心为 **MPF（Cyclin B-CDK1）** 的活化：
  - Cyclin B 积累并与 CDK1 结合。
  - Wee1 激酶与 Cak 激酶参与调节，Cdc25 磷酸酶去除抑制性磷酸基团后 MPF 活化。
  - 活化的 MPF 磷酸化多种底物，引发染色体凝缩、核膜崩解、高尔基体与内质网破裂、纺锤体形成。

### 3.4 中期/后期检查点（纺锤体组装检查点，SAC）

- **后期促进复合体 APC（APC/C）**：泛素连接酶；与 M 期 CDK 及 Cdc20 结合后活化。
- **Mad2 / Bub 蛋白**：纺锤体组装检查点调控因子。
  - 未被微管捕捉或错误捕捉的动粒募集 Mad2，Mad2 与 Cdc20 结合，抑制 APC，使细胞暂停在有丝分裂期。
  - 微管正确连接动粒后 Mad/Bub 消失，APC 被激活。
- APC 的作用：降解保护蛋白 **securin** → 释放**分离酶 separase** → 裂解**黏连蛋白 cohesin** → 姐妹染色单体分离；同时降解 Cyclin B，促使退出 M 期。

## 4. 细胞同步化

- **定义**：人为处理使细胞周期进入同一时相。
- 类型：
  - 自然同步化：如早期卵母细胞。
  - 人工选择同步化：M 期细胞分离、离心分离。
  - 药物同步化：
    - **TdR（胸腺嘧啶脱氧核苷）双阻断法**：TdR → 正常培养基 → TdR，阻断 DNA 合成。
    - **秋水仙素**：阻断细胞于中期，影响纺锤体形成。

## 5. 特殊的细胞周期

| 细胞/生物 | 特征 |
|---|---|
| 早期卵母细胞（早期胚胎） | 无 G1、G2 期，S 期短；几乎不生长，除 DNA 外几乎不合成其他组分 |
| 芽殖酵母 | 核膜不崩解，在核内完成分裂 |
| 裂殖酵母 | G2 期长 |
| 植物细胞 | 成膜体（phragmoplast）→ 细胞板 → 细胞壁；有胞间连丝 |
| 细菌 | 环状 DNA；DNA 复制与分裂同时进行 |
