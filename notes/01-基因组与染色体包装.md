# 01 · 基因组与染色体包装

> [!abstract] 一句话定位
> 信息要**装得下**（压缩 10⁴ 倍）、**分得准**（复制与分离）、**调得动**（可及性调控）——核小体与染色体结构同时解决这三件事。

## 1　基因组序列

### 1.1　原核生物基因组特征

1. **高度紧凑**：绝大多数序列为编码序列。
2. **调控序列精简**：一个启动子/转录起始位点可调控多个基因（**操纵子**结构）。
3. **功能元件极少**：复制起点是少数非编码功能元件之一，仅占几百个碱基对。
4. **基因密度极高**。

### 1.2　基因组大小与生物复杂度

1. 大体上：基因组越大，生物越复杂。
2. 修正后：**基因数量**决定生物复杂度。
3. 复杂度相近的生物之间基因组大小差异巨大 → 原因在于**基因密度**（单位长度 DNA 所含基因数）：
   - 生物复杂度与基因密度大致呈**负相关**。
   - 真核生物基因密度小于原核生物。

### 1.3　基因密度降低的原因

1. **内含子**存在大幅增加 DNA 长度。
2. **基因间序列增加**
   - 单拷贝序列：调控序列、无功能序列（突变基因/假基因）、未知功能序列。
     - **假基因**：由 mRNA 逆转录形成。
   - **重复序列**：大部分基因间序列由重复序列组成。
     - **微卫星 DNA**：非常短的串联重复序列。
     - **转座序列**：均为转座元件，即能在基因组中自主移动位置的 DNA 序列，通常转座后在原位置留下拷贝。

> 转座机制详见 [[分子生物学/02-基因组维持/04-重组与转座|重组与转座]]。

## 2　染色体与染色质

| 概念 | 定义 |
| :--- | :--- |
| **染色体** | 细胞中携带遗传信息的 DNA-蛋白质复合物，线性或棒状，由染色质高度螺旋化凝缩形成 |
| **染色质** | 由 DNA、组蛋白、非组蛋白、RNA 组成的 DNA-蛋白质复合物 |
| **同源染色体** | 同一条染色体的两份拷贝 |

### 2.1　DNA 包装成染色体的意义

1. 适应细胞大小。
2. 保护 DNA 免受损伤。
3. 便于复制时 DNA 分发到子代细胞。
4. 便于 DNA 调控。

### 2.2　染色体/染色质中蛋白组分的功能

1. 调控 DNA 复制、转录、重组、修复。
2. 压缩 DNA。

### 2.3　染色体多样性

1. 原核生物大多为**环状**染色体（也有线性），真核生物为**线性**染色体。
2. 原核染色体位于**拟核**，真核位于**细胞核**。
3. 面临的问题不同：环状染色体需拓扑异构酶分离子代；线性染色体需端粒酶保护末端（见 [[分子生物学/02-基因组维持/02-DNA复制|DNA 复制]]）。

## 3　染色体复制与分离

### 3.1　三大功能元件

| 元件 | 功能 |
| :--- | :--- |
| **复制起点** | 复制机器组装并启动复制的地点；原核生物染色体通常只有一个 |
| **着丝粒** | 指导**动粒**合成，动粒结合微管蛋白丝 |
| **端粒** | 线性染色体末端；富含 TG，部分为单链 |

端粒结合蛋白的两项功能
1. **区分端粒与断裂处**，避免 DNA 被当作损伤降解。
2. 作为**特殊的复制起点**，招募端粒酶复制染色体末端。

### 3.2　细胞周期

- **S 期**：染色体复制。
  - **染色单体**：染色体复制后成对染色体中的一条。
  - **姐妹染色单体**：成对染色单体互称。
- **M 期**
  1. **前期**：染色体凝缩、核膜破裂。凝缩蛋白与 Ⅱ 型拓扑异构酶（解开缠住的染色体）使染色体高度凝缩。
  2. **中期**：纺锤体组装、双极附着，染色体排列在**赤道板**。
     - 纺锤体由微管组成，微管与动粒结合。
     - **单极附着**：两个动粒结合同一微管组织中心的微管，或只有一个动粒结合了微管。减数第一次分裂为单极附着，靠同源染色体间的物理连接 + 姐妹染色单体臂部黏连对抗牵拉张力。
     - 微管附着于两个微管组织中心（动物为中心体，酵母为纺锤极体）。
     - 黏连蛋白与微管相互作用使染色体排列在赤道。
  3. **后期**：黏连蛋白被降解，染色单体分离。
  4. **末期**：染色体去凝缩、核膜重建、胞质分裂。
- **检查点**：G1/S、G2/M。
- 真核细胞染色体的复制与分离**不同时发生**；原核生物**同时发生**。

### 3.3　SMC 蛋白（染色体结构维持蛋白）

| 蛋白 | 结构 | 功能 |
| :--- | :--- | :--- |
| **黏连蛋白** | 环状 | 连接姐妹染色单体 |
| **凝缩蛋白** | 环状 | M 前期连接染色体不同部位，缩短染色体 |

> **有丝分裂**：子代细胞染色体数目与亲代相同的分裂方式。

## 4　核小体

### 4.1　组成与基本参数

- 核小体 = **八个核心组蛋白** + **核心 DNA**。
  - **核心 DNA**：与组蛋白结合最紧密的 DNA，**147 bp，缠绕 1.65 圈**。
  - **连接 DNA**：核小体之间的 DNA，一般 **20–80 bp**。
- 形成核小体是 DNA 压缩的第一步，形成 **10 nm 串珠状**结构，DNA 被压缩约 **6 倍**。
- 形成核小体**限制可接近性**；通过修饰或移动核小体暴露特定区域，使其与其他蛋白相互作用。
- **未被包装为核小体的 DNA 区段**通常是正在表达、复制或重组的位点。

### 4.2　核小体组装

1. 未结合 DNA 时：形成 **H3-H4 四聚体**与 **H2A·H2B 二聚体**。
   - 组蛋白通过**组蛋白折叠结构域**（三个 α 螺旋 + 分隔螺旋的两段短无序环）组装。
2. 结合 DNA 时：**H3-H4 四聚体先结合**，随后 H2A·H2B 二聚体结合。
3. 依赖**组蛋白伴侣**将组蛋白运送到组装部位：

| 组蛋白伴侣 | 负责 |
| :--- | :--- |
| CAF-1 | H3、H4 四聚体 |
| NAP-I | H2A、H2B 二聚体 |
| PCNF-ring | 协助 CAF-1 与 DNA 结合 |

### 4.3　负超螺旋的储存位置（重要对照）

- 组蛋白尾巴引导 DNA 以**左手螺旋**缠绕组蛋白，从而引入**负超螺旋**。
- **真核生物**：负超螺旋主要储存在**核小体结构**中。
- **原核生物**：无核小体，全基因组直接维持负超螺旋状态。
  - 向松弛 DNA 引入负超螺旋是**耗能**反应：旋转酶（促旋酶，拓扑异构酶）需消耗 ATP；无 ATP 时只能松弛 DNA。
  - 高温环境生物需要**反旋酶**引入正超螺旋以对抗高温解链。
- 细胞内很多过程都需要驱动 DNA 解旋：复制起始、转录起始、同源重组等。
- DNA 拓扑基础见 [[分子生物学/01-结构基础/02-DNA结构与拓扑|DNA 结构与拓扑]]。

## 5　组蛋白

> [!note] 定义
> 真核生物中**富含碱性氨基酸**的小分子蛋白，功能为 **DNA 包装 + 表达调控**。

### 5.1　类型与结构

1. **核心组蛋白**：H2A、H2B、H3、H4。
   - H3、H4 与核心 DNA **中段**结合；H2A、H2B 与**两端**结合。
   - H3、H4 结合使 DNA 发生大幅弯曲。
2. **连接组蛋白**：H1。
   - 同时结合**连接 DNA** 与**核心 DNA 中央部分**，将二者拉近，使核小体 DNA 呈**锯齿状**。
   - 作用：促进 DNA 更紧密包裹核小体；保护连接 DNA 避免被降解。
   - 由**微球菌核酸酶消化实验**验证。
3. 核心组蛋白八聚体具有**二重对称性**。
4. 四种核心组蛋白含量相等；**H1 含量仅为其他组蛋白的一半**。

### 5.2　组蛋白与 DNA 的相互作用

1. 形成大量**氢键**：主要是小沟中磷酸骨架的氧与蛋白形成，少部分来自碱基。
2. 组蛋白富含**正电氨基酸**，与 DNA 磷酸骨架的负电结合；电荷抵消减少骨架间斥力。
3. **结构匹配**：组蛋白 α 螺旋与小沟结构匹配。
4. 相互作用导致 DNA 弯曲。
5. **所有接触位点都位于小沟或磷酸骨架上**——不读取碱基序列，因此无序列特异性。

### 5.3　组蛋白尾巴

- 核心组蛋白的**氨基末端延伸**；胰蛋白酶可特异性切割带正电氨基酸后的肽键，切割后不影响 DNA 与组蛋白结合。
- 功能
  1. **远端**有大量修饰位点，可改变核小体功能。
  2. **近端**参与形成组蛋白-DNA 氢键，稳定 DNA 缠绕状态。
  3. 引导 DNA 以左手螺旋缠绕，引入负超螺旋。

### 5.4　组蛋白变体

| 变体 | 说明 |
| :--- | :--- |
| **H2A.X** | H2A 变体。DNA 双链断裂时，断裂附近的 H2A.X 上一个特有丝氨酸被磷酸化，被 DNA 修复酶特异性识别，引导其定位到损伤位点 |
| **CENP-A** | H3 变体，与含着丝粒 DNA 的核小体结合；具有延长的氨基末端尾巴，是动粒蛋白组分 CENP-C 的结合位点 |

## 6　高级染色质结构

1. **常染色质 vs 异染色质**
   - **异染色质**：更凝缩、染色深、几乎不表达基因；富集于着丝粒和端粒区域。
   - **常染色质**：结构更松散、染色浅。
2. **30 nm 结构**
   - **螺线管**：核小体沿侧边堆叠盘绕成超螺旋，每圈 6 个核小体（DNA 较短时形成）。
   - **锯齿型（之字型）**：DNA 较长时形成。
   - 稳定依赖 **H1** 与核心组蛋白的氨基端尾巴；缺乏组蛋白尾巴则无法形成 30 nm 结构。
3. **放射环**：30 nm 结构进一步压缩成环，环根部是**核骨架**，由 SMC 蛋白和 Ⅱ 型拓扑异构酶稳定。

## 7　染色质结构的调控

### 7.1　核小体重塑复合物

- **功能**：利用 **ATP 水解**能量，改变核小体位置或调整核小体与 DNA 的结合状态；可识别被修饰的组蛋白。
- 三种移动方式
  1. **滑动**：核小体沿 DNA 滑动。
  2. **移除**：组蛋白八聚体完全解离或在 DNA 间转移。
  3. **异构体置换**：组蛋白二聚体与变体组蛋白交换。
- 整个重塑过程中，**大部分组蛋白-DNA 相互作用得以维持**。

![[attachments/染色体重塑.jpg|500]]

### 7.2　核小体定位

> **定义**：核小体在 DNA 上占据特定位置的现象。目的通常是腾出**无核小体区域**，让调控蛋白能结合连接 DNA；无核小体区域常见于活跃基因转录起始位点上游。

- **机制一：蛋白介导（竞争与锚定）**
  - **竞争排斥**：DNA 结合蛋白先结合，空间阻碍组蛋白结合；两个蛋白位点间距小于约 150 bp 时，中间维持无核小体状态。
  - **边界锚定**：某些 DNA 结合蛋白与邻近核小体紧密互作，使核小体倾向紧挨其组装，形成定位边界。
- **机制二：DNA 序列介导**
  - 核小体组装要求 DNA 弯曲，组蛋白对易弯曲 DNA 有内在偏好。
  - 富 **A:T** 的 DNA 易弯向小沟，倾向出现在小沟面向八聚体的位置；富 **G:C** 则相反。核小体自动寻找并最大化这种排列。
- **生物学意义**
  - 双重作用：可**暴露**（定位在结合位点旁）也可**遮蔽**（覆盖结合位点）特定序列。
  - 分布：紧密定位的核小体最常见于转录起始位点附近，但基因组中许多核小体定位并不紧密。
  - 动态性：重塑复合物与转录因子可移动已定位的核小体。

### 7.3　组蛋白修饰

| 修饰 | 位点 | 主要效应 |
| :--- | :--- | :--- |
| **乙酰化** | 赖氨酸 | 转录激活；新合成 DNA 的组蛋白募集 |
| **甲基化** | 赖氨酸、精氨酸 | 转录激活或抑制（上下文依赖） |
| **磷酸化** | 丝氨酸、苏氨酸、酪氨酸 | 有丝分裂、DNA 复制/修复 |
| 其他 | — | ADP-核糖化、泛素化、SUMO 化 |

- **组蛋白密码假说**：特定的修饰组合与不同细胞事件相关。
- **作用机制**
  1. **改变电荷**：乙酰化与磷酸化中和组蛋白尾巴正电荷，减弱与带负电 DNA 骨架的亲和力，使染色质趋于开放。
  2. **调控高级结构形成**：组蛋白尾巴对形成抑制性 30 nm 纤维至关重要。
- **生物学意义**
  1. **传播与维持修饰状态**：许多修饰酶含识别结构域，可结合已乙酰化核小体并修饰相邻核小体。
  2. 被修饰的尾巴可**招募特定蛋白质**到染色质上。
- **识别修饰的结构域**

| 结构域 | 识别对象 |
| :--- | :--- |
| 溴结构域 | 乙酰化的组蛋白尾巴 |
| 罗莫结构域、TUDOR 结构域、PHD 指 | 甲基化的组蛋白尾巴 |
| SANT 结构域 | 未被修饰的组蛋白尾巴 |

- **修饰酶**：组蛋白乙酰化酶（HAT）、组蛋白去乙酰化酶（HDAC）、组蛋白甲基化酶等。
- 氨基端尾巴修饰与核小体重塑结合，可极大改变 DNA 可及性。

- [ ] 组蛋白与 DNA 形成的键型、发生位置（小沟/磷酸骨架）、有无序列特异性及原因
- [ ] 组蛋白变体 H2A.X、CENP-A 的功能
- [ ] H1 与 30 nm 结构、常/异染色质

- [ ] 组蛋白分子伴侣（CAF-1 / NAP-I / PCNF）功能

<details>
<summary><b>自测 1：生物复杂度相近时，基因组大小为何差异巨大？</b></summary>

基因密度不同。内含子与基因间序列（重复序列、假基因等）大量增加 DNA 长度，但基因数量变化不大；复杂度主要由基因数量决定。
</details>

<details>
<summary><b>自测 2：为何真核每条染色体有多个复制起点却只有一个着丝粒？</b></summary>

真核基因组大、线型染色体长，需要多个复制起点才能在 S 期内完成复制；而分离时只需一个动粒组装位点（着丝粒）与纺锤体微管建立双极附着，保证姐妹染色单体准确分向两极。多个着丝粒会导致断裂或分离错误。
</details>

<details>
<summary><b>自测 3：组蛋白与 DNA 之间形成哪些键？发生在哪？有序列特异性吗？</b></summary>

主要是**氢键**（小沟中磷酸骨架的氧，少量碱基）与**静电作用**（组蛋白正电氨基酸与 DNA 负电磷酸骨架），并伴结构匹配与 DNA 弯曲。所有接触位点都在**小沟或磷酸骨架**上，不接触碱基特异基团，因此**无序列特异性**。
</details>

<details>
<summary><b>自测 4：组蛋白乙酰化为何通常激活转录？</b></summary>

乙酰化中和赖氨酸正电荷，减弱尾巴与带负电 DNA 骨架的静电吸引，染色质趋于开放；同时乙酰化尾巴可被含溴结构域的蛋白识别，招募转录机器与重塑复合物。
</details>
