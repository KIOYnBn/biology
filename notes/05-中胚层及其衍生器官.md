# 05 · 中胚层及其衍生器官

> [!abstract] 本章速览
> 中胚层分四条主线：**脊索中胚层**（诱导）、**轴旁中胚层**（体节 → 骨骼肌 / 椎骨 / 真皮）、**间介中胚层**（泌尿生殖）、**侧板中胚层**（循环系统 / 体腔衬里 / 四肢）。本章把原笔记中重复的"造血""泌尿生殖嵴""肾单位"各整合为一处。

## 5.1 中胚层分化谱系总览

> **脊索是中胚层分化的启动者和组织者。**

![[attachments/中胚层分化.png|700]]

| 中胚层分区 | 主要衍生物 |
| --- | --- |
| **脊索中胚层** | 脊索（诱导神经管、提供体轴），后退化为椎间盘髓核 |
| **轴旁中胚层** | 体节 → 椎骨、肋骨、软骨、肌肉、真皮 |
| **间介中胚层** | 泌尿系统、生殖系统 |
| **侧板中胚层** | 体壁 / 脏壁中胚层、体腔衬里、循环系统、胚外膜、四肢骨骼 |

### 5.1.1 脊索中胚层

- **形成**：原肠运动中原结头突下的细胞增殖，沿胚体纵轴延伸形成脊索。
- **功能**：诱导背部神经管形成；为早期胚胎提供完整体轴。
- **命运**：体节形成生骨节后，椎骨之间的脊索细胞形成**椎间盘髓核组织**，大多数死亡。

### 5.1.2 轴旁中胚层与体节

- 脊索两侧加厚的中胚层带；随原条退化与神经褶合拢形成**体节**。
- 体节是**临时性结构**，分化成脊椎、肋骨、软骨、肌肉、真皮等。
- 同一物种体节形成速度一致：**前端先形成，后端延伸**；体节刚形成时各部位细胞发育潜能一致。

**Hox 基因（同源异形基因）调控**

- 调控胚胎发育的轴向形态发生；产物为 **HD 蛋白**（转录因子），调控基因表达。
- **Hox 基因决定形成的椎骨类型**；染色体排列顺序与作用顺序一致。
- **后端优势**：所有基因在后端均有表达，但后端基因对前端基因表达有抑制作用。

**体节分化**

- 受神经管底板与脊索分泌的 **SHH 蛋白**诱导，体节腹中部细胞脱离形成间充质细胞 → **生骨节**。
- 生骨节最背侧细胞 → **生腱节 → 肌腱**。
- 生骨节背层中央为**生肌节区域** → 骨骼肌前体细胞；两侧为**生皮节** → 背部真皮。
  - 近轴生皮肌节唇（靠近神经管）→ 横跨脊椎的肌肉；
  - 远轴生皮肌节唇（远离神经管）→ 四肢和体壁的肌肉。
- 未分化成间充质细胞的上皮细胞形成**生皮肌节**。
- **生骨节分节形成椎骨**：生骨节分为前端节与尾段节；前端节和上一个生骨节的尾段节共同形成椎骨原基。

### 5.1.3 间介中胚层（泌尿生殖原基）

- 形成泌尿和生殖系统。
- 间介中胚层增生与体节分离，向胚内体腔凸出形成**尿生殖嵴**——肾脏、生殖腺、生殖道的原基。
- 向腹侧移动形成两条纵行细胞索，即**生肾索**；其头部分节状为**生肾节**（形成前肾）。
- 尿生殖嵴中部出现纵沟，分成**中肾嵴**与**生殖嵴**。

### 5.1.4 侧板中胚层

- 分化为**体壁中胚层**与**脏壁中胚层**，二者之间为**体腔**。
- 功能：① 体腔衬里；② 形成循环系统（心脏、血管、血细胞）；③ 形成除肌肉外的所有中胚层成分（骨骼、软骨、真皮）；④ 形成胚外膜（卵黄囊、尿囊、羊膜、绒毛膜）。

## 5.2 循环系统

- 由侧板中胚层形成。
- **起源**：卵黄囊的胚外中胚层形成**血岛**（早期造血中心）——中央细胞形成造血干细胞，周边细胞形成扁平内皮细胞构成毛细血管，最终形成原始心血管系统。
- **早期胚胎三套循环**：胚体循环、卵黄囊循环、脐循环。

### 5.2.1 血细胞生成（整合版）

- **造血**：血细胞生成过程。
- **分化层级**：造血干细胞 → 定向祖细胞（分化方向确定）→ 前体细胞（形态可辨认）→ 终末分化细胞（具特殊功能）。
- **造血中心转移**（时间线考点）

| 时期 | 造血部位 |
| --- | --- |
| 胚胎早期 | 卵黄囊 |
| 胚胎第二个月后 | 肝、脾 |
| 胚胎中期 | 骨髓 |
| 出生后 | 完全依赖骨髓 |

### 5.2.2 心脏的发生

**① 原始心管**

- 心脏发生于**生心区**（口咽膜前的中胚层）。
- 生心区出现围心腔，其腹侧中胚层弥散形成左右一对长索为**生心板**，板中央变空形成**心管**。
- 位置变化：神经板发育较快，使心管与围心腔到达咽腹侧，心管位于围心腔背侧。

**② 心脏外形的建立**

1. 左右心管融合；
2. 动脉端出现动脉干，静脉端出现静脉窦；
3. 心球和心室扭曲成 U 型——**球室袢**；
4. 进一步扭曲成 S 型。

- 原始血流：**静脉 → 静脉窦 → 窦房瓣 → 心房 → 心室 → 动脉**。

**③ 心脏内部的分隔**

1. 房室间形成狭窄通道——**房室管**；
2. 背侧和腹侧形成隆起——**心内膜垫**；
3. 腹、背心内膜垫融合；
4. 房室管分成左、右房室孔；
5. 左右房室孔间充质增生 → 二尖瓣、三尖瓣；
6. 心房顶壁出现半月形隔膜——**原发房间隔**；与心内膜垫之间为**原发房间孔**；
7. 原发房间隔上部出现小穿孔——**继发房间孔**；
8. 原发房间孔闭合，小穿孔融合成大孔；心房顶壁出现新月形隔膜——**继发房间隔**；
9. 继发房间隔逐渐覆盖继发房间孔，与心内膜垫之间留卵圆形孔——**卵圆孔**；覆盖卵圆孔的原发房间隔部分为**卵圆孔瓣**；
10. 心室底壁出现肌性嵴——**室间隔肌部**；
11. 肌部向上生长，与心内膜垫间形成**室间孔**；
12. 肌部与心内膜垫间形成隔膜——**室间隔膜部**；
13. 膜部与肌部融合形成完整室间隔，室间孔关闭，左右心室完全分隔。

![[attachments/出生前血流.png|700]]

![[attachments/出生前血回流.png|700]]

**④ 出生后变化**

| 结构 | 出生后结局 | 完成时间 |
| --- | --- | --- |
| 胎盘血循环 | 停止，肺呼吸开始 | — |
| 脐静脉 | 闭锁 → 肝圆韧带 | — |
| 脐动脉 | 闭锁 → 脐外侧韧带 | — |
| 静脉导管 | 闭锁 → 静脉韧带 | — |
| 动脉导管 | 闭锁 → 动脉韧带 | 2–3 个月 |
| 卵圆孔 | 关闭 | 约 1 年 |

## 5.3 泌尿系统发生

### 5.3.1 肾的三代发生

| 阶段 | 结构 | 要点 |
| --- | --- | --- |
| **前肾** | 前肾管 + 前肾小管 | 生肾节形成前肾小管（内侧开口于胚内体腔，外侧向尾延伸成前肾管）；**无泌尿功能**；小管随后退化，前肾管延伸至泄殖腔 |
| **中肾** | 中肾管 + 中肾小管 | 前肾小管退化后发生；中肾嵴内形成横行小管并汇入前肾管形成中肾管；小管不断死亡新生，保持约 30 个；中肾小管变形形成肾小囊，加上背主动脉起源的毛细血管球形成原肾小体；随后大部分退化——男性尾部小管及中肾管形成附睾及生殖道，女性形成卵巢冠 |
| **后肾** | 输尿管芽 + 生后肾原基 | 见下 |

**后肾的起源**

- **输尿管芽**：中肾管泄殖腔端伸出的盲管，进入中肾嵴尾端中胚层并多级分支；主干形成输尿管，分支形成肾盂、肾大盏、肾小盏、集合小管（聚合形成集合管）。
- **生后肾原基**：中肾嵴尾端中胚层，在输尿管芽诱导下形成肾小囊、肾小管并连通集合管；加上肾小球（毛细血管球）形成**肾单位**；外周部分形成肾被膜。
- 新形成的肾单位位于皮质方向；集合小管不断诱导生后肾组织形成肾单位；**出生后肾单位不再发生，集合小管也不生长**。

### 5.3.2 肾单位：结构与功能（整合版）

- **结构**：肾小体（肾小球 + 肾小囊）+ 肾小管。
- **形成**：集合小管盲端处，生后肾组织内部细胞团演化为"S"形肾小管——一端与集合小管盲端接通，另一端膨大凹陷形成肾小囊；毛细血管伸入肾小囊形成肾小球（血管球）；肾小管逐渐弯曲增长，分化为近端小管、髓袢、远端小管，具重吸收与排泌作用。
- **功能**
  1. 血液经肾小球 / 肾小囊过滤形成**原尿**（含葡萄糖、无机盐、水、尿酸、尿素）；
  2. 肾小管重吸收葡萄糖、大部分水和无机盐 → 形成**尿液**；
  3. 尿液 → 肾小盏 → 肾盂 → 输尿管 → 膀胱。

### 5.3.3 后肾发育的诱导与肾上升

- **相互诱导**：输尿管芽进入后肾间充质 → 间充质诱导输尿管芽多级分支；输尿管芽诱导间充质成腔形成肾小囊；间充质降解输尿管芽基底膜并与其连接。
- **起源**：间介中胚层。
- **诱导因子**：RA（视黄酸）、WNT、FGF；RA 作用下中肾管表达 GDNF-受体 RET 蛋白，生后肾间充质分泌 GDNF，使 RET 高表达的中肾管细胞迁移形成输尿管芽。
- **肾上升**：肾初始位于盆腔，随输尿管伸长到达腰部。

### 5.3.4 膀胱与尿道发生

- **泄殖腔**：后肠末端膨大，被尿直肠隔分为背侧原始直肠与腹侧尿生殖窦。
- 随膀胱扩大，一部分中肾管并入膀胱，开口下移到尿道起始部。
- **尿生殖窦分化**

| 节段 | 男性 | 女性 |
| --- | --- | --- |
| 上段 | 膀胱（与脐之间尿囊收缩形成脐尿管） | 膀胱 |
| 中段 | 前列腺、膜部 | 大部分尿道、阴道 |
| 下段 | 海绵体 | 阴道前庭 |

## 5.4 生殖系统发生

### 5.4.1 性别决定

- **定义**：生物体发育过程中性别确定的过程。
- **类型**：性染色体决定（XY 哺乳动物、ZW 鸟类、XO 昆虫）与环境因素决定。

**哺乳动物的两级决定**

| 层级 | 内容 |
| --- | --- |
| **初级性别决定** | 生殖腺决定：Y 染色体上的 **SRY** 基因在生殖腺发育期将生殖腺分化为睾丸 |
| **次级性别决定** | 生殖腺产生的激素决定表型 |

**SRY → SOX9 通路**

- SRY 与支持细胞前体细胞的 SF1 激活 *Sox9* → 成纤维细胞合成 Fgf9 → 促进 Sox9 进一步合成。
- **SOX9 蛋白作用**：① 激活自身启动子维持转录；② 抑制 β-联蛋白，抑制卵巢形成；③ 促进 *Fgf9* 表达。
- 若 Sox9 不表达，则走向卵巢发育通路。

### 5.4.2 生殖腺发生

- **原始生殖细胞（PGC）**：卵黄囊后壁近尿囊处形成，经背肠系膜进入生殖嵴初级性索。
- **初级性索**：生殖嵴表面上皮伸入间充质形成上皮细胞索（由间充质细胞组成）。
- **睾丸方向**：围绕 PGC 的生殖嵴细胞向支持细胞分化，分泌**抗苗勒氏管激素（AMH）**使苗勒氏管（中肾旁管）退化，并促进原始间充质细胞分化为睾丸间质细胞；初级性索 → 睾丸索 → 睾丸网；残留中肾小管形成睾丸输出小管并与睾丸网相连；中肾管分化为附睾和输精管。
- **卵巢方向**：**WNT4 + RSPO1 → β-catenin → 抑制 Sox9**，激活促卵泡激素抑制释素 → 卵巢上皮形成卵泡；生殖腺中心初级性索退化 → 卵巢髓质（基质 + 血管）；表面上皮增殖形成次级性索 → 卵巢皮质，表面上皮下间充质形成白膜；次级性索断裂形成细胞团 → 原始卵泡（卵原细胞 + 前颗粒细胞），其他间质细胞形成卵泡膜细胞。

![[attachments/生殖嵴性别分化.png|700]]

- **下降**：卵巢停留在盆腔；睾丸下降到阴囊。

### 5.4.3 生殖管道与外生殖器

- **中肾旁管**：体腔上皮内卷闭合形成，开口于泄殖腔；下端突入尿生殖窦形成窦结节。
- **男性**：AMH 使中肾旁管退化；中肾小管 → 睾丸输出小管；中肾管 → 附睾、输精管、精囊腺、射精管。
- **女性**：中肾管退化；中肾旁管头部 → 输卵管漏斗部，上段 / 中段 → 输卵管，下段 → 子宫与阴道上部；窦结节 → 阴道。
- **外生殖器**：泄殖腔两侧间充质形成尿生殖隆起，外侧形成阴道阴唇隆起。

### 5.4.4 相关异常与剂量补偿

| 主题 | 要点 |
| --- | --- |
| 假两性畸形 | 身体只有一种类型生殖腺，第二性征与生殖腺性别不同；雄激素不敏感综合征（雄激素受体缺失）、雌性假两性畸形（雄激素过量） |
| 剂量补偿（哺乳动物） | 两条 X 染色体中一条异质化，使雌雄基因产物剂量平衡 |
| 剂量补偿（果蝇） | 调整 X 染色体转录速率：雄性 X 转录速率是雌性的两倍 |
