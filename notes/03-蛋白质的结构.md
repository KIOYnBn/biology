# 03 蛋白质的结构

天然蛋白质处于有功能的折叠构象。本篇从化学组成与结构层次出发，说明各种作用力如何稳定结构、二级与高级结构如何组织，以及结构如何被测定、如何折叠与变性。

## 一、蛋白质的化学组成与结构层次

### 1. 化学组成与分类

- 蛋白质平均含氮量 **16%**，这是凯氏定氮法的原理：蛋白质含量 = 蛋白氮 × 6.25。
- **简单蛋白质**：仅由氨基酸组成，按溶解性分类。

  ![[attachments/简单蛋白质分类.png|600]]

- **缀合蛋白质**：含有非蛋白成分作为永久性结构，按辅基成分分类。
  - **辅基/配体**：非蛋白质成分；辅基通过共价键与脱辅基蛋白结合。
  - **脱辅基蛋白（Apoprotein）**：除去非共价结合的辅基后剩余的蛋白质部分。
  - **全蛋白（Holoprotein）**：含有辅基部分的整体蛋白。

  ![[attachments/缀合蛋白质分类.png|600]]

- 按**形状和溶解度**分类：
  - **纤维状蛋白**：细棒或纤维状，多数不溶于水和稀盐，主要起结构作用。
  - **球状蛋白质**：球形或椭球形，水溶性好（疏水侧链在内、亲水侧链在外）。
  - **膜蛋白**：不溶于水，溶于去污剂（疏水氨基酸位于外部）。

### 2. 结构层次

| 层次 | 定义 |
| --- | --- |
| 一级结构（共价结构） | 氨基酸序列 |
| 二级结构 | 肽链主链借助氢键形成的周期性结构 |
| 三级结构 | 多肽链通过非共价力折叠形成的实体 |
| 四级结构 | 亚基的组织方式（见本篇第六节） |

蛋白质序列数据库：PIR、GenBank、EMBL。

## 二、稳定蛋白质结构的相互作用

构象熵以及肽链基团与水的氢键倾向于维持**解折叠态**；二硫键和非共价弱相互作用倾向于维持**功能折叠态**。具有最低自由能的构象通常是弱相互作用数目达到最大的构象。

### 1. 二硫键

- 细胞内蛋白质大多没有二硫键：细胞内还原剂（如谷胱甘肽）浓度高，巯基保持还原态。
- 二硫键主要存在于分泌的胞外蛋白质（如胰岛素）。
- 嗜热菌及古菌大多含有二硫键，可能是对高温环境的适应。

### 2. 氢键

- 分子内氢键的形成驱动力来源于**水熵增的热力学驱动**；单个氢键贡献的净稳定性接近于零。
  - 极性基团能与水形成氢键，但形成氢键数目少于纯水，因此也会形成溶剂化层；形成分子内氢键时引起水环境熵增。
  - 折叠时每形成一个氢键，就要断裂一个同样强度的「基团–水」氢键。
- 作用：
  1. **保证结构稳定**：疏水核中未配对的氢键键合基团会引起不稳定，其配对形成的自由能变化远大于折叠态与去折叠态之间的自由能变化。
  2. **引导折叠**：依靠氢键的协同性。

### 3. 疏水相互作用

- **对蛋白质稳定性贡献最大**。
- 水围绕疏水分子时，氢键的最适排列使水形成笼型壳，水分子有序度增加、熵减；非极性基团聚集后溶剂化层面积减少，造成**熵增**。
- 因此疏水基团聚集是热力学驱动的自发过程。

### 4. 范德华力与盐桥

- **范德华力**：包括永久偶极、诱导偶极、瞬时偶极；蛋白质中主要指瞬时偶极，作用范围 0.3~0.6 nm。
- **离子间相互作用（盐桥）**：带正电与带负电的氨基酸靠静电吸引。
  - 作用是两面的：折叠态时两异性电荷相互吸引，去折叠时带电基团与水分子和盐离子相互作用，因此形成盐桥的稳定性要扣除「失去水中相互作用」的部分。
  - 盐桥在低介电常数环境（如疏水环境）中作用增强，位于蛋白质内部时有助于稳定结构——这也是嗜盐菌的生存策略。

## 三、肽键的几何约束与空间位阻

### 1. 肽平面与二面角

- 肽平面的羧基氧与酰胺氢呈反式；主链构象由三个二面角决定：
  1. $\phi$ 角（绕 $N-C_\alpha$）：$C-N-C_\alpha$ 与 $N-C_\alpha-C$ 两个平面的二面角。
  2. $\psi$ 角（绕 $C_\alpha-C$）：$N-C_\alpha-C$ 与 $C_\alpha-C-N$ 两个平面的二面角。
  3. $\omega$ 角（绕 $C-N$）：$C_\alpha-C-N$ 与 $C-N-C_\alpha$ 两个平面的二面角。
- 注意：$\phi$ 和 $\psi$ 不能同时为 0；$\omega$ 几乎不为 0（顺式构象很少见）。

### 2. 拉氏图（Ramachandran plot）

- **最小接触距离（允许距离）**：非共价键合原子之间的最小接触距离，即范德华半径之和。
- 拉氏图以 $\phi$ 为横坐标、$\psi$ 为纵坐标，表示立体结构允许的构象：
  - 允许区：原子距离大于允许距离，构象稳定。
  - 不完全允许区：原子距离小于允许距离但大于极限距离，构象不稳定。
  - 不允许区：不存在的构象。

## 四、蛋白质三级结构的测定方法

### 1. X 射线衍射（X-ray diffraction）

- 原理：光线投射到物体上发生散射，物体每一部分作为新光源，散射波含有物体构造的全部信息。
- 光学显微镜用透镜重组散射波成像；X 射线无法用透镜直接成像，先得到**衍射图**，再用数学方法绘制**电子密度图**。
- 需从各角度观测；X 射线会破坏蛋白质，因此需高浓度蛋白溶液样品并制备晶体。
- 衍射线的**方向**确定晶体大小和形状，衍射**强度**确定原子排布。

### 2. 核磁共振（NMR）

- 原理：
  1. 外磁场下不同原子核吸收不同射频能量。
  2. 核自旋磁矩分为与外场平行（低能态）和反平行（高能态）两个能级。
  3. 吸收直角方向射入的合适电磁脉冲能量后跃迁，产生核磁共振波谱。
     $\Delta E = hv = \dfrac{h\gamma}{2\pi}H_0$，其中 $\gamma$ 为旋磁比；外磁场一定时共振频率 $v$ 一定。
- 原子核周围电子云产生小磁场，实际磁场强度 $H_{eff} = H_0 - H_{loc}$，因此不同化学环境的核共振频率不同。
- **等效质子**：化学与磁场环境相同的同类核，显示单一吸收峰。
- **化学位移** $\delta$：共振频率相对标准值的偏移，通常以四甲基硅烷（TMS）为参考。
  $\delta = \dfrac{\text{偏离 TMS 的 Hz 数}}{\text{波谱仪工作频率（MHz）}}$
- **自旋–自旋分裂**：单一吸收峰因邻近不等效核自旋的相互作用（偶合）而分裂为几个峰。

![[attachments/NMR谱示例.png|600]]

- 一维 NMR 无法解析蛋白质结构：上百个氢原子的化学环境差异很小，峰密集难以归属；需使用二维 NMR。

## 五、二级结构

**二级结构**是由氢键稳定的有规则构象。

### 1. α-螺旋

- 一个螺圈含 **3.6 个氨基酸残基**，螺距 0.54 nm。
- 相邻螺圈之间形成氢键，氢键方向几乎与螺旋轴平行：由每个肽基的 C=O 与 C 端第 4 个肽基的 N—H 形成。

  ![[attachments/α螺旋的氢键.png|400]]

- 螺旋头 4 个酰胺氢与最后 4 个羰基氧不参与内部氢键，可与溶剂水形成氢键，称为**加帽**。
- α-螺旋能最大程度利用内部氢键；标准二面角 $\phi=-57^\circ$、$\psi=-47^\circ$，实际蛋白质中可能有所偏移。
- **手性**：左手螺旋能量高、不稳定。判断方法：右手握拳、拇指与螺距平行，若螺线按其余四指弯曲方向旋转并沿拇指方向前进，则为右手螺旋。

| 对比项目 | α-螺旋 | $3_{10}$-螺旋 | π-螺旋 |
| --- | --- | --- | --- |
| 每圈残基数 | 3.6 | 3.0 | 4.4 |
| 氢键模式（n → 第几个残基） | n→n+4 | n→n+3 | n→n+5 |
| 螺距 | 5.4 Å | 6.0 Å | 4.7 Å |
| 每残基上升高度 | 1.5 Å | 2.0 Å | 1.1 Å |
| 形态 | 最规整、最稳定 | 更紧致、细、陡 | 更宽松、粗、扁 |
| 二面角 $(\phi,\psi)$ | −57°, −47° | −49°, −26° | −57°, −70° |
| 出现频率 | 极高，最主要二级结构 | 较低，多在螺旋末端、转角 | 极低，多为短片段 |
| 氢键环原子数 | 13 元环 | 10 元环 | 16 元环 |
| 稳定性 | 热力学最稳定 | 弱于 α-螺旋 | 张力大，最不稳定 |

**影响 α-螺旋稳定性的因素**：
1. 不同氨基酸形成 α-螺旋的固有倾向。
2. R 基之间（尤其相隔 3/4 个残基）的相互作用。
3. 相连 R 基的体积。
4. Pro、Gly 限制螺旋形成。
5. 末端残基与螺旋电偶极的相互作用：螺旋 N 端带部分正电、C 端带部分负电，荷负电残基在 N 端、荷正电残基在 C 端有利于稳定。

### 2. β-结构

- 多肽链骨架呈**锯齿状**；β-折叠片中的每条肽链称 **β-股（β-折叠股）**。
- $C_\alpha$ 位于折叠线上，R 基垂直于折叠片平面；氢键主要在股间形成。
- 类型：
  - **平行**：相邻肽链同向。
  - **反平行**：相邻肽链反向，常由多个残基组成，疏水侧链通常位于同侧。

### 3. 转角与无规则卷曲

- **β-转角**：反向平行折叠片相邻肽段末端呈 180° 转折的结构，涉及 4 个氨基酸；第 1 个残基的 C=O 与第 4 个残基的 N—H 形成氢键。Gly 和 Pro 常见于 β-转角；β-转角多位于蛋白质表面，便于中间两个残基与水形成氢键。
- **Ω-转角**：可看作 β-转角的延伸，一般不超过 16 个残基，多为 6–8（常见 8）个残基；改变肽链走向，使环首尾残基间距小于 1 nm。
- **无规则卷曲**：无法纳入上述结构的肽段，常构成蛋白质功能位点。

## 六、纤维状蛋白质（了解）

一般由单一类型的二级结构组成，内部和表面具有高浓度疏水残基。

- 不溶性：角蛋白、胶原蛋白、弹性蛋白。
- 可溶性：血纤维蛋白原、肌球蛋白、原肌球蛋白。

### 1. α-角蛋白

- 作为结构蛋白，构成发、毛、甲、爪、蹄，属于中间丝蛋白质家族；主要为卷曲螺旋。
- 通过大量二硫键增强强度，二硫键越多刚性越强，据此分为硬角蛋白和软角蛋白。
- 伸缩性能好：湿热时 α 构象破坏形成 β 构象，冷却干燥后可恢复（依赖二硫键）。烫发原理即用还原剂破坏二硫键后重新形成。

### 2. 其他纤维状蛋白

- β-折叠片蛋白：丝心蛋白、β-角蛋白。
- 三股螺旋蛋白：胶原蛋白。
- 弹性蛋白、血纤维蛋白原。

## 七、超二级结构与结构域

### 1. 超二级结构（结构模体 motif）

多个二级结构及其连接部件的组合。

| 类型 | 结构要点 |
| --- | --- |
| $\alpha\alpha$（α-螺旋束） | 卷曲螺旋：两股平行或反平行的右手螺旋左手缠绕；可为三股或四股。球状蛋白中由同一条链上邻近螺旋形成，纤维状蛋白中由不同链上的螺旋形成。特征为七残基重复序列 a-b-c-d-e-f-g：a、d 为疏水残基，e、g 为极性残基，b、c、f 为荷电残基 |
| $\beta\alpha\beta$ | 两段平行 β-折叠股和作为连接链的 α-螺旋组成，连接链多为右手交叉；Rossman 折叠为 $\beta\alpha\beta\alpha\beta$ |
| $\beta\beta$ | 即 β-折叠片；球状蛋白中由一条链上的折叠股形成，最简单为 β-发夹结构，是 β-曲折和希腊钥匙拓扑结构的基础 |

### 2. 结构域

- 定义：三级结构的局部折叠区；对单结构域蛋白，结构域通常与三级结构等价。
- 序列长度一般在 40–400 残基，多为 100–200。
- 有时也称**功能域**：蛋白质中独立存在的功能单位，可由一个结构域或多个结构域组成。
- **铰链区**：连接结构域的部分，通常是酶活性位点。
- 类型：全 α、全 β、$\alpha/\beta$（α 与 β 相互掺杂）、$\alpha+\beta$（α 与 β 部分相互分开）。

## 八、球状蛋白与膜蛋白的结构

### 1. 球状蛋白的三级结构特征

1. 球状蛋白及某些膜蛋白通常具有多种二级结构（纤维状蛋白通常只有单一二级结构）。
2. α-螺旋常为**两性螺旋**：一面暴露于溶剂、一面面向疏水内部；平行 β-折叠片通常位于疏水内部，反平行折叠片与 α-螺旋类似。
3. 球状蛋白表面通常有一个空穴，用于结合底物。

### 2. 三级结构分类

| 类型 | 特征 |
| --- | --- |
| 全 α 蛋白 | α-螺旋 > 15%，β-片 < 10%；主要由反向平行 αα 螺旋束组成 |
| 全 β 蛋白 | β-折叠股 > 15%，α-螺旋 < 10%；少部分只含 β-折叠股并以反平行 β-片存在 |
| $\alpha/\beta$ 蛋白 | α-螺旋与 β-折叠股交替出现，二者各自含量 > 10% |
| $\alpha+\beta$ 蛋白 | 分子表面一侧为 β-片、另一侧为 α-螺旋；β-折叠 > 15%，α-螺旋 > 10% |
| 富含金属或二硫键的蛋白质 | 金属配体或二硫键对构象起稳定作用 |

### 3. 膜蛋白的结构

| 类型 | 与膜结合方式 |
| --- | --- |
| 膜周边蛋白 | 可溶性球蛋白，分布在磷脂双层表面，通过静电相互作用和氢键与膜结合 |
| 膜内在蛋白（膜整合蛋白） | 埋入或横跨磷脂双层，通过疏水相互作用与膜缔合 |
| 脂锚定蛋白 | 通过共价连接的脂锚与膜缔合，与膜可逆结合 |

- **膜内在蛋白**：
  1. 大部分位于水环境中，通过疏水肽链（通常是 α-螺旋）锚定膜。
  2. 大部分埋藏在膜中：一条多肽链来回跨膜折叠形成多个反向平行 α-螺旋，或通过 β-折叠片跨膜。
- **脂锚定方式**：酰胺连接、硫酯连接、硫醚连接、糖基磷脂酰肌醇连接。

## 九、四级结构

- **定义**：亚基的组织方式。亚基是具三级结构的多肽链；组织依靠结构互补与弱相互作用。
- **单体蛋白质**：仅由一条多肽链构成；**寡聚/多聚蛋白质**：由两条或多条多肽链构成，每条链为一个亚基，亚基间通过非共价力缔合。
  - 同多聚蛋白质：亚基相同；异多聚蛋白质：由多种亚基组成。
- **驱动力**：主要是疏水相互作用和二硫键，范德华力贡献不大——溶剂从蛋白质表面离开形成亚基接触时，丢失和形成的范德华力几乎一样多。
- **优越性**：结构稳定性、遗传效率、功能效率、协同和别构效应。

## 十、蛋白质的变性与折叠

### 1. 变性

- **变性不涉及共价键的断开**。
- 影响：
  1. 生物活性丧失。
  2. 部分侧链基团暴露。
  3. 物理化学性质改变（如等电点时溶解）。
  4. 更易受蛋白酶分解。
- 机制：变性剂通过与蛋白质**竞争氢键**或**破坏疏水作用**发挥作用。

### 2. 折叠的热力学

$\Delta G_{总} = \Delta H_{链} + \Delta H_{溶剂} - T\Delta S_{链} - T\Delta S_{溶剂}$，其中：

- $\Delta H_{链} > 0$（吸热，不利于折叠）
- $\Delta H_{溶剂} < 0$（放热，有利于折叠）
- $\Delta S_{链} < 0$（熵减，不利于折叠）
- $\Delta S_{溶剂} > 0$（熵增，有利于折叠）

> [!note] 为什么 $\Delta S_{溶剂}$ 是主要贡献（原「知识块」合并）
> **疏水侧链**：解折叠态时，疏水侧链周围的水被「锁」成有序笼状结构，熵很小；折叠后疏水侧链藏入内部，水恢复自由无序状态，熵大幅增加，故 $\Delta S_{溶剂} > 0$。同时，强的「水–疏水相互作用」被弱的「疏水–疏水相互作用」取代，$\Delta H_{链} > 0$；水从不利的水–疏水作用恢复为有利的水–水氢键，$\Delta H_{溶剂} < 0$。
> **极性侧链**：$\Delta H_{链}$ 仍为正、$\Delta H_{溶剂}$ 仍为负，但因极性侧链本身亲水、不使水形成高度有序的笼状结构，$\Delta S_{溶剂}$ 只是很小的正值。因此疏水侧链的溶剂熵增是折叠的主要驱动力。

### 3. 折叠的动力学

1. 多肽链折叠不是通过随机搜索最低自由能构象完成的（随机搜索耗时太长，机制尚未完全解决）。
2. 折叠分步骤进行：局部二级结构 → 初始结构域 → 超二级结构 → 结构域构象调整。
3. 有**异构酶**和**分子伴侣**参与。
