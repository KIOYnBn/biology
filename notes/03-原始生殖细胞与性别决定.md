# 03 原始生殖细胞与性别决定

> [!abstract] 本章要点
> PGC 的概念、来源与跨物种迁移路线；表观遗传重编程；性别决定方式；SRY 等性别决定因子网络；性腺分化与性反转。

## 原始生殖细胞（PGCs）

**原始生殖细胞**（Primordial Germ Cells, PGCs）：性别分化以前的生殖细胞，具有双潜性（可分化为精子或卵子），迁移到生殖嵴（生殖腺原基）后分化为生殖细胞。体积大，碱性磷酸酶（可用于细胞追踪与染色）、酯酶、糖原均为阳性。

### 生殖质与 PGC 来源

| 动物 | 生殖质/PGC 来源 | 特点 |
| --- | --- | --- |
| 两栖类 | 卵中特殊细胞质，由蛋白质和 RNA 组成；爪蟾生殖质呈小岛状靠近植物极 | 含生殖质的子代细胞发育为 PGC；果蝇卵尾部细胞质移植实验可证明 |
| 线虫 | P 颗粒（线虫的生殖质） | 含 P 颗粒的细胞为 P 细胞 |
| 果蝇 | 极质（生殖质）；极粒为极质中的致密小体，由核糖核蛋白（mRNA + 蛋白质）构成 | 含极质的细胞为极细胞 |
| 斑马鱼 | 生殖质位于受精卵多个位置，随卵裂向分裂沟聚集，定位于分裂沟远端（未来生殖嵴原基） | 体节期 PGC 在躯干两侧形成细胞系，经 SDF1a 趋化到达生殖嵴 |
| 鸟类 | PGC 起源于胚盘上胚层明区中央 | 原条期明区前缘形成生殖新月区 → 形成血管 → PGC 入血 → 血液循环 → 生殖嵴 |
| 哺乳动物 | 卵裂期胚胎无生殖质，PGC 来源于原肠期上胚层；小鼠可用碱性磷酸酶阳性鉴别 | 胚胎后端 → 后肠内卷进入后肠内胚层 → 主动迁移到生殖嵴，途中增殖 |

### PGC 的迁移路线

- **两栖类**：植物极 → 囊胚腔底部 → 内胚层表面 → 肠后部聚集 → 中肠上部生殖嵴。囊胚期 PGC 位于囊胚腔底部；有些两栖类无明确生殖质。
- **果蝇**：胚胎后端极细胞 → 原肠作用 → 中肠后部 → 穿过肠壁和中胚层 → 生殖腺。
- **鸟类**：生殖新月区 → 血管 → 血液循环 → 生殖嵴。
- **哺乳动物**：后肠形成前被动迁移（形态发生运动），后肠到生殖嵴为主动迁移（伪足）。

### PGC 迁移机制与影响因素

- PGC 的运动能力是固有属性（伪足等），但具有时效性。
- 生殖嵴释放趋化因子引导 PGC；TGF-β1 参与引导。
- 细胞间形成伪足网络连接，引导后出发的细胞移动。
- 迁移途中形成纤连蛋白受体附着于体细胞；细胞外基质（ECM）接触引导，成分包括层黏连蛋白、纤黏连蛋白、肌腱蛋白、Ⅳ型胶原、硫酸软骨素蛋白多糖。
- SCF（干细胞生长因子）在迁移途中表达量最高，PGC 表达其受体 c-kit。
- 信号调控：BMP、SMAD 信号通路。
- **凋亡与存活**：未进入生殖嵴的 PGC 凋亡，未退化可引发外周肿瘤；生殖嵴内 PGC 也有部分凋亡。Nanos3 是迁移中的抗凋亡信号，抵抗 Bax 的促凋亡信号。

### 进入生殖嵴后的命运分歧

PGCs 进入生殖嵴后先进行有丝分裂，随后依性别进入不同阶段：

- 雌性：出生前进入双线期停滞，性成熟时继续减数分裂（详见 [[05-卵子发生与卵泡发育]]）。
- 雄性：出生前停滞于 G1 期，性成熟后部分进行有丝分裂、部分进入减数分裂（详见 [[04-精子发生与睾丸结构]]）。

## 表观遗传重编程

**表观遗传学**：基因序列不改变的情况下，基因表达（基因活性调控）发生可遗传的变化。内容包括 DNA 甲基化、基因组印记、母体效应、基因沉默。

- **DNA 甲基化**：DNA 序列中胞嘧啶的甲基化修饰，可通过检测细胞 5mC 水平判断甲基化水平。
- 定位到生殖嵴的 PGCs 会进行染色体重建与 DNA 印记去除，然后重新甲基化。
- 雌性 PGC 在减数分裂前进行 X 染色体激活，需要生殖嵴的体细胞环境。
- X 基因沉默机制：Xist（非翻译 RNA）与 Tist（抑制 Xist）。
- 基因印迹：印记基因用于判断基因的父源/母源，雌雄原核表达模式不同；机制包括双启动子甲基化与绝缘子甲基化；性别分化后印迹在生殖系删除，故子代的印迹来自父代而非祖代。

> [!note] 分工说明
> 基因印迹在配子发生中的表现见 [[05-卵子发生与卵泡发育]]，在胚胎发育中的作用见 [[07-早期胚胎发育与干细胞]]；此处只讲 PGC 中的重编程。

## 性别形成与性别分化

- **性别决定**：胚胎发育早期性腺发育为睾丸或卵巢的选择过程。
  - 初级性别决定：受遗传因子与环境因素影响。
  - 次级性别决定：睾丸或卵巢分泌的性激素影响生殖系统与性别表型发育。
- **遗传型性别决定**：
  - XY 型。
  - ZW 型（鸟类、鳞翅目、部分爬行类和两栖类）：雄性 ZZ，雌性 ZW。
  - XO 型（直翅目昆虫等）：雌性 XX，雄性 XO。
- **温度依赖性性别决定**：常见于爬行类和两栖类。
- **位置依赖性性别决定**：海肠子（后螠）在海底、海滩发育为雌性，在雌虫子宫内发育为雄性。

## 性别决定因子

- **SRY**：Y 染色体性别决定区，在 Sertoli 前体细胞表达，诱导睾丸分化。特点：无内含子；有多聚腺苷酸位点；两个转录起始位点，其间为一个开放阅读框（ORF）。于人 11–13 dpc 发挥作用。
- **睾丸决定因子 TDF**：位于人 Y 染色体短臂。
- **AMH**（抗缪勒氏管激素，又名 MIS、MRF）：编码糖蛋白，属 TGF-β 超家族；促进雄性副中肾管退化、上皮细胞凋亡。
- **Sox 家族**：HMG box 中与 SRY 相似度 60% 以上；Sox9 与 CD 综合症相关；Sox3 位于 X 染色体，参与胚胎中枢神经系统发育与未分化性腺。
- **SF-1**：与 Sox9 共同激活 Amh 基因。
- **DAX1**：抑制 SF-1 与 WT1，阻止生殖嵴向雄性分化，被 SRY 抑制。
- **WT1**：激活 SRY 与 SF-1，间接调节性腺形成；活化 DAX1 启动子，WT1-DAX1 途径是性别决定早期事件。
- **Fol2**：抑制 Sox9 表达，促进卵巢形成。

## 原始生殖细胞的性别分化

- 定位于生殖嵴后才启动性别分化，其性别取决于周围体细胞的性别类型。
- 雌性标志：减数分裂；标志分子 Stra8、Dmc1、Oct4。
- 雄性标志：有丝分裂停止（随后重新启动有丝分裂）。

## 性腺发育

- 生殖嵴原基：中肾腹内侧的两条生殖嵴；成分为体腔上皮、间充质组织、原始生殖细胞。
- 默认发育为卵巢；睾丸下降受促性腺激素与性激素影响。
- **睾丸分化**：Sertoli 细胞来源于体腔上皮，表达 SRY 指导细胞分化与睾丸形成；管周肌细胞中肾迁移而来，围绕 Sertoli 细胞，参与精索与精子运输；Leydig 细胞部分来自中肾迁移，出生后来自间充质前体细胞，分泌睾酮。
- **卵巢分化**：germ cell cyst → ovigerous cord → 原始卵泡（16.5 dpc → 出生后 3 天）；Theca cell（卵泡膜细胞）出生后形成。

## 性反转与胚胎发育差异

- **性反转**：染色体不变而性表征翻转；哺乳类未曾发现具功能的性反转；可见 46,XX 男性综合征、46,XY 女性综合征；XXY 发育为睾丸，XO 发育为卵巢。
- 体外培养时雄性胚胎发育比雌性快，胎儿较重较大；体内一般相同。高浓度葡萄糖加速雄性胚胎发育、减慢雌性胚胎发育。

> 1. PGC 的定义、双潜性、迁移路线与关键分子（SCF/c-kit、SDF1a、TGF-β1、BMP/SMAD、Nanos3）。
> 2. 性别决定的定义与时期；初级 vs 次级性别决定；遗传型 / 温度依赖 / 位置依赖三类方式。
> 3. SRY（11–13 dpc、Sertoli 前体）→ Sox9/SF-1/AMH 通路与 DAX1、WT1、Fol2 的拮抗关系。
> 4. PGC 的性别取决于周围体细胞；雌性标志 Stra8/Dmc1/Oct4，雄性为有丝分裂停止。

<details>
<summary>参考答案</summary>

1. 果蝇：极细胞经原肠作用到中肠后部，穿肠壁与中胚层到生殖腺；鸟类：生殖新月区形成血管，PGC 经血液循环到生殖嵴；哺乳动物：先被动随形态发生运动，后主动以伪足迁移，经后肠到生殖嵴。
2. SRY 无内含子、有多聚腺苷酸位点、两个转录起始位点夹一个 ORF；下游激活 Sox9、SF-1，共同激活 Amh 使副中肾管退化，同时SRY抑制 DAX1。
3. PGC 定位于生殖嵴后才启动性别分化，其分化方向由周围体细胞（如 Sertoli 前体是否表达 SRY）决定。
4. 染色体重建、DNA 印记去除后重新甲基化；雌性 PGC 减数分裂前发生 X 染色体激活，依赖生殖嵴体细胞环境。
