# 01 · DNA 复制

> [!abstract] 一句话定位
> DNA 复制采取**半保留**方式：先解旋、再按碱基互补配对、最后重新螺旋；原核单起点环状染色体，真核多起点线性染色体，二者在引物去除、冈崎片段长度和末端复制问题上各有对策。

## 1　复制的基本模式

- **复制模式**：**半保留复制**——每个子代 DNA 分子保留一条亲代链、合成一条新链。
- **复制过程**：解螺旋 → 碱基配对 → 再螺旋。

**实验证据**

| 生物 | 实验方法 |
| :--- | :--- |
| 原核生物 | $^{15}\mathrm{N}$ / $^{14}\mathrm{N}$ 同位素密度梯度实验 |
| 真核生物 | 放射性同位素 $^3\mathrm{H}$ 标记实验 |

**起始方式对照**

| 项目 | 原核生物 | 真核生物 |
| :--- | :--- | :--- |
| 复制起点 | **单个**复制起点 | **多个**复制起点 |
| 染色体形态 | 环状染色体 | 线性染色体 |
| 复制方向 | 有的单向、有的双向；双向时两边速度可能一致也可能不一致 | **双向** |

## 2　细菌 DNA 合成

### 2.1　聚合酶与原料

**DNA 聚合酶所需材料**

| 成分 | 说明 |
| :--- | :--- |
| Template | DNA 模板链 |
| Primer | 引物 |
| 底物 | dNTPs |
| 延伸方向 | $5' \rightarrow 3'$ |
| 校对活性 | $3' \rightarrow 5'$ 外切酶活性 |

### 2.2　复制起点与解旋

**复制起点（oriC）特点**

- 长度约 **245 bp**。
- 碱基组成特征：含**重复序列**、**富含 AT**、含**回文序列**。

**解旋相关蛋白**

| 蛋白 | 作用 |
| :--- | :--- |
| DnaA | 弯曲 DNA，打开起始区 |
| DnaB、DnaC | 解旋、断开氢键 |
| SSBPs（单链结合蛋白） | 稳定已解开的单链 |

**消除超螺旋张力**

- 基本方法：**断开双链**释放张力。
- 旋转酶（DNA 拓扑异构酶Ⅱ）：执行剪切与重接。

### 2.3　引发与延伸

- **引发**：引发酶（primase）被 DnaB 招募，合成 **5～10 nt** 的 RNA 引物。
- **延伸**：主要由 **DNA POL Ⅲ** 承担。

| 模板链 | 合成方式 | 特点 |
| :--- | :--- | :--- |
| 前导链（leading strand） | 连续合成 | 与复制叉前进方向一致 |
| 后滞链（lagging strand） | 不连续合成 | 速度较慢，产生**冈崎片段** |

**长号模型（trombone model）**：两条链同方向复制——后滞链发生弯曲，使两个聚合酶形成二聚体协同前进，后滞链以间断方式合成。

### 2.4　引物去除、连接与校对

1. **去除 RNA 引物**：DNA POL Ⅰ 利用 $5' \rightarrow 3'$ 外切酶活性切除引物。
2. **填补缺口**：DNA POL Ⅰ 以 $5' \rightarrow 3'$ 聚合酶活性补上 DNA，连接酶封口，将冈崎片段连成完整链。
3. **校对**：$3' \rightarrow 5'$ 外切酶活性切掉错配核苷酸。

### 2.5　复制终止

- **终止子序列**：复制终止的信号序列。
- **Tus 结合蛋白**：与终止子结合后阻止 DnaB 解旋酶前进。
  - Tus 有两个面：
    - **permissive face（允许面）**：DnaB 可以通过。
    - **nonpermissive face（阻止面）**：DnaB 不能通过。

## 3　真核生物的 DNA 复制

### 3.1　与原核生物的区别

| 项目 | 真核生物的特点 |
| :--- | :--- |
| 复制起点 | 多起点 |
| 复制速度 | 较慢 |
| 冈崎片段 | 较短 |
| 引物去除 | 由 **RNase、FEN1** 完成 |
| 染色体形态 | 线性 DNA |
| 缺口填补 | 由 **POL δ** 完成 |
| 核小体 | 复制时核小体整体分裂为两块，通过后重新组装 |

### 3.2　末端复制问题与端粒

- **问题**：线性染色体复制时，由于 RNA 引物的存在，每次复制都会导致末端 DNA 缩短。
- **解决**：**端粒酶**在模板 DNA 末端加长重复序列。

| 端粒酶组分 | 作用 |
| :--- | :--- |
| RNA 组分 **TERC** | 作为逆转录的模板 |
| 反转录酶 **TERT** | 以 TERC 为模板延伸端粒 |

> [!note] 交叉索引
> 端粒的短顺接重复、富含 TG 的序列特征见 [[遗传学/02-染色体与基因组/01-染色体结构与基因组组织|染色体结构与基因组组织]]；复制错误的来源与修复见 [[遗传学/03-遗传信息的维持与变异/02-基因突变与修复|基因突变与修复]]。

## 4　考点速记

- 半保留复制三大实验证据：$^ {15}\mathrm{N}/^{14}\mathrm{N}$（原核）、$^3\mathrm{H}$（真核）。
- 原核：单起点、环状、DnaA 弯曲 DNA、DnaB/C 解旋、SSB 稳定、旋转酶解张力、DnaB 招募引物酶。
- 冈崎片段：后滞链不连续合成的产物；POL Ⅲ 延伸，POL Ⅰ 去引物并填补，连接酶封口。
- 校对靠 $3' \rightarrow 5'$ 外切酶；去引物靠 $5' \rightarrow 3'$ 外切酶。
- 终止：终止子序列 + Tus 蛋白的允许面 / 阻止面。
- 真核差异：多起点、慢、短冈崎片段、RNase/FEN1 去引物、POL δ 填补、端粒酶（TERC + TERT）解决末端缩短。

<details>
<summary><b>自测 1：原核复制起点有哪些序列特征？</b></summary>

约 245 bp，含重复序列、富含 AT（易解旋）、含回文序列（易形成可被起始蛋白识别的结构）。
</details>

<details>
<summary><b>自测 2：为什么后滞链合成较慢，需要长号模型？</b></summary>

后滞链必须以 RNA 引物起始、分段合成冈崎片段，且合成方向与复制叉前进方向相反。长号模型使后滞链模板弯曲成环，让前导链与后滞链的聚合酶形成二聚体同向协同前进，从而提高整体效率。
</details>
