# 04 精子发生与睾丸结构

> [!abstract] 本章要点
> 精子发生的概念与意义；睾丸组成与免疫豁免；精原细胞类型；减数分裂与精子形成；精子结构；精子成熟与获能；精子发生的内外源调控。

## 概念与研究意义

**精子发生**：精子在睾丸内产生的全过程，即精原细胞经精母细胞到精子细胞的发育过程和精子形成过程；也定义为原始生殖细胞形成精原细胞到精子并排出体外的过程。

- 过程：精原细胞增殖 → 精母细胞减数分裂 → 精子变形（塑形）。
- **男性不育症**类型：无精子、少精子、弱精子、精子无力、精子数正常性不育。
- **研究意义**：阐明精子发生机制；研究生殖健康障碍；辅助生殖；提高男性生殖能力。

## 睾丸

- 功能：产生精子，分泌雄激素。
- 来源：生殖嵴 → 雄性生殖腺（睾丸）→ 精子发生场所。

### 曲细精管（生精小管）

- 生精小管是睾丸实质部分，周围为结缔组织薄层（弹性纤维和平滑肌细胞）；管壁从内到外为支持细胞和生精细胞。
- 生精上皮 = 生精细胞 + 支持细胞，按发育阶段排列成多层。
- 分层：
  - 基底膜：肌样细胞 + 成纤维细胞 + 胶原纤维。
  - 基底室：精原细胞、细线期前的精母细胞。
  - 近腔室：细线期后的初级精母细胞、次级精母细胞、精细胞、精子。

### 细胞类型

| 细胞 | 形态与位置 | 功能 |
| --- | --- | --- |
| 支持细胞（Sertoli） | 不规则形、核仁明显、附着于基底膜、顶端直达管腔；富含内质网、溶酶体、脂肪滴、致密小体（吸收的残余体）、高尔基体 | 提供营养与微环境；参与血睾屏障；支持生精细胞；合成分泌雄激素结合蛋白（ABP）；吞噬凋亡生精细胞胞质 |
| 管周肌样细胞 | 包裹曲细精管一层 | 收缩；分泌细胞因子作用于支持细胞；与支持细胞共同分泌基膜成分 |
| 间质细胞（Leydig） | 体积大、圆形/多边形、胞质嗜酸性，位于生精小管间 | 分泌睾酮；参与免疫豁免 |
| 生精细胞 | 精原细胞、初级/次级精母细胞、精子细胞、精子 | 各级生殖细胞 |

- **血睾屏障**：支持细胞相互连接形成，将生精上皮分为基底室与管腔室；细线期细胞穿过屏障进入管腔室继续发育。

### 睾丸免疫豁免

睾酮 → 免疫抑制 → 抑制支持细胞、管周肌样细胞、Leydig 细胞表达免疫调节因子 → 形成免疫豁免环境。

表征：

1. 生精细胞表达自身抗原，但不诱导免疫反应。
2. 其他组织移植到睾丸，免疫排斥弱。
3. 睾丸抑制到其他组织，耐受免疫排斥。

睾丸天然免疫系统：PRR（模式识别受体）。

## 精原细胞与生精上皮动态

### 精原细胞类型

| 类型 | 形态与染色 | 行为 |
| --- | --- | --- |
| Ad 型（黑色型 / A 型） | 染色深、PAS 阳性、核卵圆或椭球盘状；最外层 | 精原干细胞；通过不完全分裂产生一个 Ad（自我更新）和一个 Ap |
| Ap 型（浅色型） | 染色浅、PAS 阴性、椭圆形 | 分化为 B 型 |
| 中间型 | 圆形 | 过渡阶段 |
| B 型 | 脱离基底膜，有丝分裂停滞 | 分化为精母细胞 |

- **细胞质桥**：Ad 型精原细胞分裂开始即为不完全分裂，细胞间通过细胞质桥连接形成合胞体，进行物质与信息交流，实现每群细胞同步成熟。
- **生精上皮周期**：两次分化程度相同的细胞群相继出现的时间间隔。
- **生精上皮波**：生精细胞群沿生精管长轴的有序组织排列。

## 减数分裂

初级精母细胞经历：细线期 → 偶线期 → 粗线期 → 双线期 → 终变期。精母细胞尾部富含线粒体和高尔基体；可分为圆形精母细胞与浓缩型精母细胞。

> [!note] 与卵母细胞减数分裂的差异
> 卵母细胞存在两次阻滞（双线期与 MⅡ 期），详见 [[05-卵子发生与卵泡发育]]。

## 精子形成（塑形）

- **顶体形成**：高尔基体形成顶体泡 → 顶体泡融合形成顶体囊 → 内含顶体颗粒 → 排出水分形成双层膜、内含水解酶；顶体面向管壁；大型哺乳动物卵圆形，小鼠大鼠镰刀形。
- **鞭毛形成**：中心粒微管延长形成轴丝，外周有致密纤维和纤维鞘；线粒体伸长、迁移到中段，围绕中央轴丝螺旋排列形成线粒体鞘。
- **体形变小**：多余胞质丢弃形成残体（残余体，由支持细胞吞噬）；染色体凝缩，鱼精蛋白（核精蛋白）大量非全部替代核小体与 DNA 结合，形成精子头；精膜上卵子结合蛋白合成。
- 精子离开睾丸生精小管后，形态结构在附睾继续成熟，至附睾尾具有受精和定向运动能力。

## 精子结构

| 部位 | 结构 |
| --- | --- |
| 头部 | 扁卵圆形；由细胞核、顶体、顶体后区组成；顶体为膜的囊状结构，顶体后区为细胞质特化的环状致密带 |
| 颈部 | 连接头和尾；近端中心粒变成基板，远端中心粒变成基体 |
| 尾部 | 代谢和运动；中段 = 轴丝 + 致密纤维 + 线粒体鞘；主段 = 轴丝 + 致密纤维；末段 = 轴丝（9+2 型） |

精核致密、基因不表达，几乎看不到染色质丝和核仁。无鞭毛型精子见于水生无脊椎动物。

> [!note] 顶体反应
> 顶体释放透明质酸酶（分散颗粒细胞）、顶体素（丝氨酸蛋白酶/胰蛋白样蛋白酶，溶解透明带）、脂酶等，详见 [[06-受精与卵子激活]]。

## 精子成熟与获能

- 精子在附睾尾获得受精与定向运动能力。
- **精子获能**：精子在子宫和输卵管中接受雌性分泌物发生生理变化、获得受精能力的过程；膜结构改变、顶体凝集素结合区域改变，可识别精子受体。
- 获能**可逆**：与精浆或附睾液接触可去获能（去获能因子为糖蛋白），再进入雌性生殖道可重新获能。
- 获能的分子变化与机制（HCO₃⁻ → cAMP-PKA 等）见 [[06-受精与卵子激活]]。

## 精子发生的调控

按调节途径分为外源调节因素与内源调节因素。

### 外源调节

- **激素**：
  - LH → 间质细胞 → 睾酮；睾酮经支持细胞或管周肌样细胞间接作用于生殖细胞，进入生精小管后与支持细胞合成的 ABP 结合。没有睾酮无法完成精子发生；肾上腺也能产生少量睾酮。
  - FSH → 支持细胞表面受体 → 腺苷酸环化酶信号通路 → 诱导 ABP 等蛋白合成，为生殖细胞输送营养；合成抑制素与睾酮进行负反馈调节。
- **旁分泌因子**：
  - IGF-1：促进 LH 与间质细胞结合、睾酮分泌、生精细胞 DNA 合成。
  - TGF-α：主要在间质细胞表达；在支持细胞过量表达导致生精障碍。
  - EGF：位于支持细胞和生精细胞，低表达有利于维持精子发生。
  - NGF：位于生精细胞，与减数分裂启动、DNA 合成有关。
  - 抑制素（支持细胞）：抑制精原细胞和早期精母细胞 DNA 合成。
  - 视黄酸（RA）：调控减数分裂通路。

### 内源调节

- **精原干细胞与精原细胞增殖分化**：SCF（干细胞因子）促进精原细胞分化扩增；c-kit（原癌基因）是精原细胞分化启动子（如 A → B）；GDNF（Sertoli 细胞分泌的神经营养因子）促进精原细胞扩增。
- **染色体动力学调控**：SCP3（联会复合体蛋白）失活导致生精细胞凋亡、不育；MSH4/5（生精细胞特异性 DNA 错配修复蛋白）参与染色体联会，失活导致停滞在粗线期、不育。
- **蛋白活性与稳定性调控**：泛素标记蛋白被 26S 蛋白酶体降解。

> [!abstract] 考点速记
> 1. 精子发生三阶段：精原细胞增殖 → 精母细胞减数分裂 → 精子变形。
> 2. 支持细胞（血睾屏障、ABP、营养）与 Leydig 细胞（睾酮）的功能分工。
> 3. Ad/Ap/B 型精原细胞的关系；细胞质桥实现同步成熟。
> 4. 精子形成三件事：顶体、鞭毛、核凝缩（鱼精蛋白）与残体。
> 5. 睾酮、FSH、抑制素、RA、SCF/c-kit、GDNF 的调控位置。

<details>
<summary>自测题</summary>

1. 血睾屏障由哪种细胞形成？它将生精上皮分成哪两个室？
2. 精子形成过程中顶体、鞭毛和精子头分别如何产生？
3. FSH 与 LH 分别作用于哪种细胞？二者如何协同支持精子发生？
4. 什么是生精上皮周期和生精上皮波？

<details>
<summary>参考答案</summary>

1. 支持细胞相互连接形成血睾屏障，分为基底室与管腔室（近腔室）。
2. 高尔基体形成顶体泡并融合成顶体囊，含水解酶；中心粒微管延长成轴丝、线粒体螺旋排列成线粒体鞘；染色体凝缩、鱼精蛋白替代核小体形成精子头。
3. FSH 作用于支持细胞，诱导 ABP 等蛋白合成并分泌抑制素；LH 作用于间质细胞分泌睾酮，睾酮与支持细胞 ABP 结合后间接作用于生殖细胞。
4. 周期是两次分化程度相同的细胞群相继出现的时间间隔；波是生精细胞群沿生精管长轴的有序排列。
