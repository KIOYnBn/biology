# 01 · 原核转录调控

> [!abstract] 一句话定位
> 原核调控的核心是**操纵子**：调控蛋白通过招募、变构、空间位阻和 DNA 成环影响 RNA 聚合酶；**能量效率最高的控制点是转录起始**。

## 1　转录调控原理

### 1.1　基本概念

| 概念 | 定义 |
| :--- | :--- |
| **操纵子（operon）** | 被同时转录到一条 mRNA 的一簇基因，转录成**多顺反子 mRNA**；由**结构基因**与**调控基因**组成 |
| 结构基因 | 编码蛋白质；转录产物之间具有功能相关性 |
| **本底表达水平** | 未受任何特定刺激、诱导或处理时，某基因/蛋白本来就有的基础表达量 |
| 调控蛋白 | **激活子**与**抑制子（阻遏子）** |

- **表达调控核心**：调控蛋白影响 **RNA 聚合酶的活性**。
- **大部分激活/抑制蛋白在转录起始阶段发挥作用**：① 调控更容易；② 能量利用效率高。

### 1.2　激活与抑制的机制

#### 激活机制

| 机制 | 说明 |
| :--- | :--- |
| **招募机制**（结合步骤） | 激活子同时结合 DNA 与聚合酶，将酶"招募"到启动子上，增强结合 |
| **变构机制**（构象变化步骤） | 调控蛋白结合后诱导聚合酶或 DNA 构象改变，推进受阻步骤；如刺激"闭合→开放"转变或帮助聚合酶逃离启动子 |

#### 抑制机制

| 机制 | 说明 |
| :--- | :--- |
| **空间位阻** | 抑制子结合在启动子或附近的**操纵基因**上，直接阻断聚合酶结合 |

#### DNA 成环机制（远距离作用）

结合在相隔较远 DNA 位点上的调控蛋白，通过促使中间 DNA 弯曲成环，使蛋白彼此靠近并相互作用，从而调控转录。

### 1.3　抑制子作用的多种方式

1. **位点竞争**：与启动子重叠，物理阻挡聚合酶结合（如 Lac 抑制子）。
2. **构象锁定**：把启动子 DNA 锁定在聚合酶无法起始转录的构象。
3. **抑制聚合酶构象转变**：结合在旁边与聚合酶互作，阻止闭合→开放转变（如 Gal 抑制子）。
4. **过度稳定导致抑制**：强启动子上激活子提供过强结合能，使聚合酶无法完成**启动子逃逸**，停滞在启动子上。

> [!question] 为什么调控主要发生在转录起始阶段？
> 因为这是**最有效也最节能**的控制点：在此处阻断可避免浪费核苷酸和能量去合成、加工最终不会翻译的 mRNA；同时能根据外界信号第一时间开启或关闭基因，实现快速响应。

## 2　乳糖操纵子（lac operon）

### 2.1　组成

**Lac I — Lac P — Lac O — Lac Z — Lac Y — Lac A**

| 类型 | 元件 | 产物 / 功能 |
| :--- | :--- | :--- |
| 结构基因 | **Lac Z** | β-半乳糖苷酶 |
| | **Lac Y** | 透性酶（位于细胞膜，运输 β-半乳糖苷） |
| | **Lac A** | 转乙酰酶 |
| 调控基因 | **Lac I** | 抑制基因，产生蛋白抑制物抑制转录 |
| | **Lac P** | 启动子 |
| | **Lac O** | 操纵区，RNA Pol 与抑制子的结合位点 |

- Lac O 区域结构：$LacI - O_3 - CAP - RNA\ POL - LacO - O_2$

### 2.2　正负调控

#### Lac I 抑制子（负调控）

- 响应**别乳糖（异乳糖）**。
- **无别乳糖**：结合操纵基因，靠**空间位阻**阻遏转录（结合位点与启动子重叠）。
- **有别乳糖**：别乳糖结合使阻遏蛋白变构失活，从操纵基因解离，解除阻遏。

#### CAP（正调控）

- **CAP** = 分解代谢激活蛋白，响应**葡萄糖**，需 **cAMP** 结合才能与 DNA 结合；二聚体，识别**回文序列**。
- 作用
  1. 使 DNA 弯曲 **94°**，识别部位紧贴 CAP 结合区，提供转录起始动力。
  2. 与 RNA 聚合酶 **α 亚基 CTD** 直接互作，帮助聚合酶稳定结合。
- **无葡萄糖** → cAMP 升高 → CAP 结合 CAP 位点 → 促进转录。
- **有葡萄糖** → cAMP 低 → CAP 失活 → 无法激活。

#### 葡萄糖抑制乳糖操纵子的分子机制

1. 抑制透性酶，抑制乳糖进入细胞。
2. **EⅡA**（Enzyme Ⅱ A）转运葡萄糖：胞内葡萄糖多时 EⅡA 去磷酸化，抑制透性酶。
3. 葡萄糖抑制腺苷酸环化酶 → **抑制 cAMP 形成**。

### 2.3　净结果

> 基因仅在 **"有乳糖且无葡萄糖"** 时才会**高效表达**。

| 乳糖 | 葡萄糖 | lacZ 表达 |
| :--- | :--- | :--- |
| 无 | 有 | 阻遏 |
| 有 | 有 | **基础水平**（解除阻遏但无 CAP 激活） |
| 无 | 无 | 阻遏（CAP 已激活但 LacI 仍结合） |
| 有 | 无 | **激活水平** |

### 2.4　突变型

| 基因型 | 表型 |
| :--- | :--- |
| $LacI^+$ | 需要乳糖诱导（野生型） |
| $LacI^-$ | 不需要乳糖诱导（组成型表达） |
| $LacI^S$ | 抑制物不能与乳糖结合（超阻遏，永不诱导） |
| $LacO^C$ | 操纵区 DNA 变异，不能与抑制物结合（顺式组成型） |

## 3　三个变构调控实例

1. **Lac 阻遏蛋白**：结合诱导物**异乳糖**后构象变化，无法再结合 lac 操纵基因。
2. **Trp 阻遏蛋白**：结合辅阻遏物**色氨酸**后构象变化，得以结合 trp 操纵基因，阻断转录。
3. **CAP**：结合 **cAMP** 后构象改变，特异性结合 DNA 并激活转录。

---

## 4　替代性 σ 因子

- 能识别**特定的启动子序列**，引导核心 RNA 聚合酶在特定环境条件下或针对特定基因群开启转录。
- 通过替换核心酶中的常规 σ（如 σ⁷⁰），细胞可全局性响应压力信号（如热休克时的 **σ³²**），协调大量下游基因表达。

## 5　自测题（含答案）

<details>
<summary><b>1. 基因表达最常见的调控发生在转录起始阶段。请解释原因。</b></summary>

转录起始是基因表达调控中最有效和最节能的控制点。将调控作用在此处，可防止细胞浪费资源（核苷酸、能量）去合成并加工那些最终不会翻译成蛋白质的 mRNA。同时这种快速响应机制允许细胞根据外界环境信号，第一时间决定是否开启或关闭特定基因的表达。
</details>

<details>
<summary><b>2. 请从本章内容中提供三个变构调控的例子。</b></summary>

① lac 阻遏蛋白结合异乳糖后变构，无法再结合操纵基因；② trp 阻遏蛋白结合辅阻遏物色氨酸后变构，得以结合操纵基因阻断转录；③ CAP 结合 cAMP 后构象改变，特异性结合 DNA 并激活转录。
</details>

<details>
<summary><b>3. lac 操纵子的去阻遏需要 β-半乳糖苷酶（lacZ 编码）。</b></summary>

**(a) β-半乳糖苷酶的作用**：它具有把乳糖转化为**异乳糖**的副反应活性。异乳糖是 lac 操纵子的真正诱导物，结合阻遏蛋白使其变构、从操纵基因解离，解除阻遏、开启转录。

**(b) 无葡萄糖且操纵子处于阻遏状态时，只有 β-半乳糖苷酶能否终止阻遏？** 不能。产生异乳糖必须有底物乳糖；环境中无乳糖时，即使有 β-半乳糖苷酶也无法合成诱导物，阻遏蛋白仍牢固结合操纵基因，维持阻遏。
</details>

<details>
<summary><b>4. 预测突变体在不同条件下的 lacZ 表达（不表达 / 基础水平 / 激活水平）。</b></summary>

**A. 操纵基因突变，阻遏蛋白无法结合**（$LacO^C$）
- a. 有葡萄糖、无乳糖 → **基础水平表达**
- b. 有葡萄糖、有乳糖 → **基础水平表达**
- c. 无葡萄糖、无乳糖 → **激活水平表达**
- d. 无葡萄糖、有乳糖 → **激活水平表达**

**B. 启动子突变，RNA 聚合酶无法结合**
- 无论 a–d 何种环境条件，**转录都无法启动，不表达**。
</details>

<details>
<summary><b>5. 列举原核生物中转录阻遏的三个机制，并各举一个蛋白例子。</b></summary>

① **空间位阻**：阻遏蛋白直接结合操纵基因，物理阻断 RNA 聚合酶与启动子结合——lac 阻遏蛋白。② **DNA 成环**：阻遏蛋白结合距启动子较远的多个位点，促使 DNA 弯曲成环，困住 RNA 聚合酶或阻断其逃逸。③ **与 RNA 聚合酶直接结合/干扰**：阻遏蛋白与聚合酶互作，阻止其向前移动——某些噬菌体阻遏蛋白。
</details>

<details>
<summary><b>6. 设计两个实验支持或反驳 ZntR 使用类似 MerR 的机制激活 zntA 转录。</b></summary>

**实验 1：EMSA（电泳迁移率变动分析）**。在有/无 Zn(Ⅱ) 条件下，测试纯化 ZntR 是否能与含 zntA 启动子的 DNA 探针结合——MerR 家族的典型特征是金属响应并结合启动子区域。

**实验 2：体外转录实验或 DNaseⅠ 足迹分析**。测试 ZntR 是否与 RNA 聚合酶协同，并在结合 Zn(Ⅱ) 时诱导 DNA 螺旋扭曲/空间重排，把 -10 与 -35 区的空间距离调整到适合 RNA 聚合酶启动转录的位置（MerR 家族典型机制）。
</details>

<details>
<summary><b>7. 设计体外实验确定阻遏蛋白结合的 DNA 特定区域。</b></summary>

进行 **DNaseⅠ 足迹分析**：将阻遏蛋白与含可能结合位点的放射性标记 DNA 片段混合孵育，随后加入 DNaseⅠ 有限消化。DNaseⅠ 能切割裸露 DNA，但蛋白结合区域被保护。凝胶电泳分离后，在测序胶上观察到缺乏切割条带的"空白区域"（足迹），即可精准定位结合序列。
</details>

<details>
<summary><b>8. 描述替代性 σ 因子在原核转录调控中的作用。</b></summary>

替代性 σ 因子识别特定启动子序列，引导核心 RNA 聚合酶在特定环境或针对特定基因群开启转录。通过替换常规 σ⁷⁰，细胞可全局响应压力信号（如热休克的 σ³²），协调大量下游基因表达。
</details>
