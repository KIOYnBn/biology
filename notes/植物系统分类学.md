## 0. 考前速记卡（先看这一页）

| 易混点 | 一句话区分 |
|---|---|
| 有胚 / 无胚 | 有无**多细胞胚**：有胚＝苔藓＋维管植物；无胚＝藻类 |
| 维管 / 非维管 | 有无**木质部＋韧皮部**：蕨类和种子植物是维管植物 |
| 显花 / 隐花 | 有无**花**：裸子＋被子显花；藻类、苔藓、蕨类隐花 |
| 种子 / 孢子 | 繁殖体是**种子**还是**孢子** |
| 单系 / 并系 / 多系 | 单系＝祖先＋**全部**后裔；并系＝祖先＋**部分**后裔；多系＝**不包含最近共同祖先** |
| 定距式 / 平行式检索表 | 定距式＝阶梯缩进、成对特征纵向对齐；平行式＝并列、成对特征横向相邻 |
| 配子体优势 / 孢子体优势 | 苔藓：配子体发达、孢子体寄生；蕨类：两者均独立；种子植物：孢子体发达、配子体寄生 |
| 双受精 | **被子植物特有**：1 精子＋卵→胚（2n），1 精子＋极核→胚乳（3n） |
| 裸子 vs 被子 | 胚珠裸露／包被于子房；无导管（买麻藤纲除外）／有导管；无果实／有果实 |

**演化主线**：藻类 → 苔藓（登陆、胚、颈卵器）→ 蕨类（维管组织、根、孢子体优势）→ 裸子植物（花粉管、种子，摆脱水依赖）→ 被子植物（花、双受精、果实、导管）。

**中柱演化**：原生中柱 → 管状中柱（出现髓）→ 网状／真中柱 → 散生中柱。

## 一、总论：概念与框架

### 1.1 植物关键类群

| 类群 | 核心特征 | 包括 |
|---|---|---|
| 有胚植物 | 具有多细胞胚结构的陆生植物 | 苔藓植物＋维管植物 |
| 无胚植物 | 无胚结构、形态未分化的原始类群 | 藻类 |
| 维管植物 | 具木质部和韧皮部组成的维管系统 | 蕨类植物＋种子植物 |
| 种子植物 | 通过种子繁殖的维管植物 | 裸子植物＋被子植物 |
| 孢子植物 | 通过孢子繁殖，不产生种子 | 苔藓、蕨类、藻类、真菌 |
| 显花植物 | 能开花并产生种子，花粉与胚珠结合形成种子 | 裸子植物＋被子植物 |
| 隐花植物 | 无花结构，不产生种子，依赖孢子繁殖 | 藻类、蕨类、苔藓 |

### 1.2 名词解释

- **维管组织**：维管植物中由木质部和韧皮部组成的复合输导结构，呈束状排列（维管束），贯穿根、茎、叶，承担水分与养分运输及机械支持功能。
- **单子叶植物**：被子植物门的一纲，胚具 1 片子叶，多为草本，稀木本（如龙血树）。
- **双子叶植物**：传统分类中被子植物门的另一纲，胚具 2 片子叶，包括草本（如向日葵）和木本。

### 1.3 维管植物

**主要特征**：具维管组织，高效运输并支撑植物体；世代交替中孢子体发达、能独立生存。

**起源证据**：莱尼燧石化石群——二叉分枝茎、无叶、顶生孢子囊。

**维管组织的意义**

- 植物登陆，摆脱对水的依赖；支持结构强化。
- **木质部**：运输水分和无机盐；**韧皮部**：运输糖类、氨基酸等有机物。
- 薄壁组织贮藏；形成层活动使茎干增粗。

**中柱类型**

| 类型 | 结构要点 | 适应意义 | 代表 |
|---|---|---|---|
| 原生中柱 | 中央无髓、木质部实心，外围筒状韧皮部；含单中柱、星状中柱、编织中柱 | 支撑力强但输导效率低，适合早期矮小陆生植物与湿润环境 | 裸蕨、石松类幼茎或根 |
| 管状中柱 | 木质部围绕中央髓形成圆筒；分外韧、双韧 | 髓增强储水与抗折能力，缓冲干旱 | 水龙骨属（外韧）、木贼属（双韧） |
| 网状中柱 | 管状中柱被叶隙分割成多个离散维管束，横切面呈网状 | 支持更复杂的枝叶系统，适应强光竞争 | 真蕨类 |
| 真中柱 | 维管束并列成环状／束状，木质部与韧皮部并生 | 同网状中柱 | 双子叶植物 |
| 散生中柱 | 维管束散生于基本组织，无环状结构 | 避免局部应力集中，适应风雨侵袭与快速生长 | 单子叶植物（玉米、水稻） |

> **演化**：原生中柱 → 管状中柱（髓形成）→ 网状／真中柱 → 散生中柱。

### 1.4 有胚植物与生活史

**生活史通式**：合子 → 胚 → 孢子体 → 孢子 → 配子体 → 配子。

**三大类群世代交替对比**

| 类群 | 配子体 | 孢子体 | 对水的依赖 |
|---|---|---|---|
| 苔藓植物 | 发达、独立生活；具根状物与茎叶分化 | 简单，寄生在配子体上；由基足、蒴柄、孢蒴组成，不能独立生活 | 精子游动需水 |
| 蕨类植物 | 原叶体，绿色，能光合作用，独立生活 | 独立生活，有根、茎、叶和维管组织 | 精子具鞭毛，受精需水 |
| 种子植物 | 高度退化，寄生在孢子体上 | 高度发达 | 花粉管输送精子，摆脱水依赖 |

**配子体演化趋势**

| 特征 | 苔藓植物 | 蕨类植物 | 裸子植物 | 被子植物 |
|---|---|---|---|---|
| 配子体独立性 | 独立、占优势 | 独立但微小 | 完全依赖孢子体 | 完全依赖孢子体 |
| 精子传递方式 | 需水 | 需水 | 花粉管输送 | 花粉管输送 |
| 结构复杂度 | 简单颈卵器 | 颈卵器简化 | 多颈卵器 | 无颈卵器 |
| 受精类型 | 单受精 | 单受精 | 单受精 | 双受精 |

**陆生植物的关键进化特征及意义**

| 类群 | 关键创新 | 意义 |
|---|---|---|
| 苔藓植物 | 假根固着并吸收水分养分；叶状体光合作用；颈卵器与精子器包裹配子 | 减少配子干燥风险 |
| 蕨类植物 | 根；维管组织；叶片高效光合作用 | 高效吸收与运输，适应陆生 |
| 裸子植物 | 花粉管；种子休眠；种皮保护；胚乳供营养；变态叶 | 彻底摆脱受精对水的依赖，应对环境波动，减少蒸腾 |
| 被子植物 | 花器官分化；双受精；导管 | 吸引传粉者、协同进化；增强后代适应性；提高水分运输效率 |

**繁殖与生活史术语**

- **世代交替**：生活史中配子体世代与孢子体世代循环交替。
  - 同形世代交替：配子体与孢子体形态构造基本相同——石莼。
  - 异形世代交替：两者形态结构不同——海带。
  - 配子体世代（有性世代）：从孢子开始，到配子结合前。
  - 孢子体世代（无性世代）：从合子开始，到减数分裂产生孢子前。
- **生殖器官**：配子体为单倍体植物体，由减数分裂产生的孢子发育，经有丝分裂产生配子；孢子体为二倍体植物体，由合子发育，经减数分裂产生孢子。
- **生殖方式**：有性生殖（同配、异配、卵配）；无性生殖（孢子直接萌发成新个体）；营养繁殖（细胞分裂、藻体断裂、繁殖小枝）。

### 1.5 种子植物

**种子的组成**：种皮＋胚＋胚乳。

**种子的意义**

- 让幼小孢子体得到营养和保护。
- 有利于传播和抵抗逆境。
- 适应陆生生境。

**主要特征**

- 孢子体发达，配子体退化且不能独立生活。
- 孢子体上产生小孢子囊（花粉囊）和大孢子囊（胚珠）。
- 雄配子体为三核或双核花粉粒，雌配子体为胚囊；颈卵器退化或消失。

### 1.6 系统发育与分类原理

**植物类型的层次**

| 层次 | 定义 |
|---|---|
| 泛植物（古质体类） | 经历初次内共生、具有质体的真核生物 |
| 绿色植物 | 光合色素为叶绿素 a、b，光合产物为淀粉的古质体类植物 |
| 成膜体植物 | 细胞分裂时产生成膜体的绿色植物 |
| 有胚植物 | 有性生殖过程中具胚、适应陆地生活的成膜体植物（部分水生） |

**个体发育 vs 系统发育**

| 概念 | 含义 |
|---|---|
| 个体发育 | 生物个体从受精卵开始，经细胞分裂、组织分化和器官形成，发育为性成熟个体并再次繁殖的过程 |
| 系统发育 | 类群由祖先发展分化的过程 |

**命名规则**

| 项目 | 要点 |
|---|---|
| 命名原则 | 优先权、唯一性、双名法、拉丁化 |
| 名称规定 | 合法名称（符合各项规定）；正确名称（规定的合法名称）；异名（曾经的正确名称） |
| 命名模式 | 科及以下的命名需要命名模式；科名由代表属的属名加 `-aceae` |
| 双名法 | 属名（单数名词）＋种加词（形容词／名词）＋命名人缩写。例：*Rosa chinensis* Jacq.、*Triticum aestivum* L. |
| 模式标本 | 主模式（命名人指定一份）；等模式（主模式的复制标本）；合模式（未指定主模式时引用多份）；后选模式（原标本损坏）；副模式（主、等、合模式以外引用的标本）；新模式（其他模式均有错误时重新选定） |
| 种名的转移 | 发生名称变化时，将原命名人放入括号内 |

**种及种下等级**

| 概念 | 含义 |
|---|---|
| 物种（生物学） | 在自然界占有特定生境的种群生殖群体，与其他群体生殖隔离 |
| 物种（分类学） | 具有一定形态构造、生理特征和分布区的类群 |
| 复合种 | 形态相似、亲缘相近、难以分类的物种群，常由杂交和基因交流导致难以区分 |
| 姊妹种（隐种） | 形态上难以区分的物种 |
| 亚种 | 占据次级地理区，表型相似 |
| 变种 | 具有稳定的形态差异 |
| 变型 | 具有少量稳定差异 |

**植物分类学宏观概念**

- 特点：无限综合性、实践性。
- 意义：探寻生命演化规律；具有应用价值。

**分类系统类型**

| 类型 | 依据 |
|---|---|
| 人为分类系统 | 根据心皮、雄蕊等少数特征 |
| 自然分类系统 | 根据表观特征，将物种视为不变的实体 |
| 系统发育分类系统 | 反映演化关系，如恩格勒分类系统 |

**分类单位**：纲（cl）、目（ord）、科（fam）、族（tf）、属（gen）。

**分类群（taxon）**：指任意等级的分类单元。

| 类型 | 定义 | 举例 |
|---|---|---|
| 单系 | 一个祖先及其**全部**后裔 | 被子植物、单子叶植物、苔藓植物；禾本科、菊科、豆科 |
| 并系 | 只包含祖先的**部分**后裔 | 裸子植物、藻类、双子叶植物、藓类、蕨类植物 |
| 多系 | 不包含成员最近共同祖先的类型 | 多肉植物、风媒花植物、C4 植物、寄生植物、水生植物 |

> **原则**：尽可能单系，避免并系，杜绝多系。
> **分类方法**：相似性比较。

**常见分类系统**

| 系统 | 划分 |
|---|---|
| 二界（林奈） | 植物界、动物界 |
| 三界（海克尔） | 植物界、动物界、原生界 |
| 四界（利戴尔） | 植物界、动物界、真菌界、原核界 |
| 五界（惠特克） | 植物界、动物界、原生界、真菌界、原核生物界 |
| 六界（陈世骧） | 植物界、动物界、原生界、真菌界、原核界、非细胞生物界 |
| 三域六界 | 古菌域（古细菌界）；细菌域（真细菌界）；真核生物域（原生生物、真菌、植物、动物） |

**五界系统详解**

| 界 | 主要特征 | 类别 | 代表生物 | 作用 |
|---|---|---|---|---|
| 原核生物界 | 无明显细胞核，无膜包被细胞器，微小单细胞 | 古细菌、细菌、蓝细菌 | 大肠杆菌、螺旋藻 | 有机物降解；自养／异养；工业发酵；水体污染与致病；提供单细胞蛋白及生物工程材料 |
| 原生生物界 | 真核细胞，单细胞或多细胞体，多水生 | 原生动物、真核藻类、黏菌 | 草履虫、小球藻 | 部分进行光合作用，是原初生产者；部分是古代石油来源 |
| 真菌界 | 真核细胞，无叶绿素，不能光合作用，腐食营养 | 霉菌、子囊菌、担子菌 | 青霉、木耳、猴头菇 | 降解有机物；致病与作物病害；制药；食品 |
| 植物界 | 真核、多细胞，具根茎叶和繁殖器官分化，光合自养 | 苔藓、蕨类、裸子、被子 | 各种植物 | 吸收 CO₂、释放 O₂；与人类衣食住行相关 |
| 动物界 | 真核、多细胞、异养、无细胞壁，组织器官发达，能运动 | 海绵、腔肠、环节、软体、节肢、脊椎动物 | 各种动物 | 吸收 O₂、释放 CO₂；部分为高蛋白食物来源 |

**分类的理论依据**：达尔文进化论——①共同祖先；②自然分类应当是单系的。

**分类证据**：形态学、解剖学、胚胎学、孢粉学、古植物学、植物地理学、植物化学、细胞学（染色体）、分子生物学。

**检索表类型**

| 类型 | 排版结构 | 特征排列 | 篇幅效率 | 使用难度 | 修改灵活性 |
|---|---|---|---|---|---|
| 定距式 | 阶梯式缩进 | 成对特征纵向对齐 | 低 | 低 | 低 |
| 平行式 | 并列 | 成对特征横向相邻 | 高 | 中 | 高 |

**性状**：植物的特征；**性状状态**：性状的表现形式。

**演化理论**

| 学派 | 核心观点 | 主要困难 |
|---|---|---|
| 进化学派 | 对独有特征加权；分类不仅表现分支，还表示趋异现象 | 趋同现象；进化极性判定 |
| 支序分类学派 | 二叉分支，每个分支处祖先消失、分化成两个子代种 | 分支不一定是二叉；分支后原种未必消失 |
| 表征学派 | 所有性状同等对待，数量化、计算机处理求相似性 | 复杂性状难以量化 |

### 1.7 花的起源与结构

| 主题 | 要点 |
|---|---|
| 心皮的起源 | 具孢子囊的变形叶 |
| 雄蕊的起源 | 与雌蕊同源，叶片部分退化后留下小孢子囊 |
| 假花学说 | 被子植物的花与裸子植物球花相同，雄蕊、心皮是极端退化的雄花和雌花。演化：单性孢子叶球 → 单性花花序 → 花序退化成单性花 → 雌雄蕊 → 两性花。雄蕊、心皮都有茎起源部分，胚珠为茎生构造 |
| 真花学说 | 被子植物的花由两性孢子叶球演化而来，起源于苏铁目。演化：两性孢子叶球 → 两性花 → 单性花。雄蕊和雌蕊无茎起源部分；离生心皮是原始类群 |
| 胚珠（顶枝学说） | 胚珠可能是茎起源；可育孢子囊生于枝条顶端，环绕的其他孢子囊变为不育并融合成内珠被，外珠被与叶同源 |

**被丝杯**：花萼、花冠、雄蕊花丝下半部分合生形成的杯状结构。

### 1.8 内共生

| 类型 | 被吞噬者 → 结果 | 关键特征与意义 |
|---|---|---|
| 第一次内共生 | 厌氧古菌吞噬 α-变形菌（好氧细菌），后者演化为线粒体 | 为真核细胞提供高效能量（ATP），是所有真核生物诞生的基础 |
| 初次内共生 | 真核细胞吞噬蓝细菌，产生质体 | 演化出灰藻、红藻、绿藻三支，质体均为双层膜；赋予光合能力 |
| 绿藻型二次内共生 | 吞噬绿藻 | 裸藻、网裸藻、部分甲藻；叶绿体 3–4 层膜；叶绿素 a/b |
| 红藻型二次内共生 | 吞噬红藻 | 隐藻、硅藻、褐藻、金藻、部分甲藻；叶绿体 3–4 层膜；叶绿素 a/c |
| 其他内共生 | 贝氏布拉藻与 UCYN-A | UCYN-A 由独立生物变为宿主不可分割的固氮器官，依赖宿主基因表达维持功能 |

**判断一个结构是否为细胞器**

- 能否通过宿主细胞传给子代。
- 该结构是否依赖宿主细胞提供的蛋白质。

### 1.9 植物多样性的保护与利用

**保护**

- 就地保护优化：建立生态廊道，促进种群间基因交流。
- 迁地保护：建立种子库、离体培养库，保护珍稀种质资源。
- 人工合成高价值化合物（如紫杉醇），降低对物种的砍伐。
- 生境修复：针对退化生境采取特征修复方式，加速生态功能恢复。
- 入侵物种防控。
- 政策：制定实施植物保护法和生物安全法。
- 记录物种信息，建立数据库，进行针对性保护。

**利用**

- 建立植物基因信息数据库和蛋白质数据库，为科学研究提供信息。
- 整合基因信息与表型信息，优化分类系统。
- 天然物质的人工合成。

### 1.10 生物经济：各类植物的价值

**广义藻类**：固氮（固氮蓝藻将 N₂ 转为氨，提升土壤肥力）；防风固沙（鞘丝藻等形成生物结皮，减少风蚀）；工业原料（褐藻藻胶酸用于人造纤维、医药辅料）；生物燃料（微藻含油量高，可生产柴油）；食用（海带、紫菜）；食品添加剂（海藻酸钠作增稠剂）；药物（褐藻提取碘、微藻 β-胡萝卜素）；医疗器械（硅藻土用于牙科模具）；水质净化；固碳。

**苔藓植物**：水土保持（吸附雨水，减少水土流失）；污染治理（环境质量生物指示器）；工业原料（泥炭藓形成泥炭可作燃料）；农业保水材料（包裹苗木运输）；药用（大叶藓治冠心病）；绿化。

**蕨类植物**：医药（黄酮类、萜类化合物抗癌抗炎）；食用（蕨菜）；工业（石松孢子作点火燃料）；农业（满江红与蓝藻共生固氮）；水质净化（水蕨吸收氮磷）；土壤指示（铁线蕨指示强钙性土壤）；固碳；观赏（铁线蕨）。

**裸子植物**：固碳；水土保持（麻黄科防风固沙）；空气净化（针叶林吸收 SO₂）；工业（松树松香用于橡胶工业）；药用（红豆杉紫杉醇抗癌）；食用（松子）；绿化（银杏）。

**被子植物**：主要粮食作物；饲料（玉米）；医药（长春花碱治白血病）；木材（橡树）；工业（棉花为纺织业核心原料）；碳汇；水土保持；维持生物多样性；花卉产业（玫瑰）；绿化。

## 二、广义藻类

### 2.1 蓝藻

**繁殖**

- 营养繁殖：细胞分裂、藻体断裂、藻殖段。
- 无性生殖：厚壁孢子、外生孢子、内生孢子、异形胞。

**生活史类型**

- 合子减数分裂：衣藻、团藻。
- 配子减数分裂：硅藻、鹿角菜。
- 孢子减数分裂：石莼、紫菜。

**细胞特征**

| 项目 | 特征 |
|---|---|
| 细胞 | 原核，无细胞核和组蛋白，环状 DNA |
| 细胞壁 | 成分为肽聚糖，外有胶质鞘（果胶酸＋黏多糖） |
| 光合作用 | 在类囊体膜上进行，藻胆蛋白向膜表面叶绿素 a 传递光能；羧酶体固定 CO₂；光合产物为蓝藻淀粉、蓝藻颗粒体 |

**常见属**

| 属 | 表型与鉴别 | 生殖 | 代表种／作用 |
|---|---|---|---|
| 念珠藻属 | 丝状体念珠状，公共胶质鞘形成片状体；细胞圆球形，具异形细胞和厚壁孢子 | 藻殖段 | 地木耳、发菜 |
| 鱼腥藻属 | 无公共胶质鞘，其余与念珠藻属类似 | — | 满江红鱼腥藻、固氮蓝藻 |
| 颤藻属 | 丝状体、无分支，胶质鞘无或不明显，可伸缩或摆动；区别于席藻属（有明显胶质鞘） | — | 生于有机质丰富处 |
| 螺旋藻属 | — | — | 减轻癌症放化疗副作用，提高免疫功能 |
| 微囊藻属 | 球形或椭圆形细胞组成 | — | 含藻毒素（肝毒素、神经毒素），形成水华 |
| 原绿藻 | 含叶绿素 a、b；细胞壁由肽聚糖组成 | 细胞分裂 | — |

### 2.2 真核藻类

**红藻门 Rhodophyta（植物界）**

- 藻体多为丝状、片状、树状，少数单细胞。
- 光合色素：叶绿素 a/d、胡萝卜素、藻红素、藻蓝素；**藻红素占优势，植物体呈红色**。
- 贮藏物质：红藻淀粉（干糖类多糖，存于细胞质）；KI 处理呈黄褐 → 葡萄红 → 紫色。
- 生殖：细胞裂殖、无性或有性生殖；**性细胞无鞭毛**；部分种类出现同形世代交替，有细胞分化。

**褐藻门（不等鞭毛类，SAR 界的 S）**

- 多细胞，带状或分枝丝状，有细胞分化；3 类囊体一束。
- 光合色素：叶绿素 a/c、胡萝卜素；**墨角藻黄素占优势，呈褐色或橄榄色**。
- 贮藏物质：褐藻淀粉（β-1,3-葡聚糖）、甘露糖、褐藻胶、碘。
- 生殖：无性／有性；性细胞具两条不等长鞭毛（茸鞭型向前较长，尾鞭型向后较长）；具同形或异形世代交替。
- 代表：
  - **海带**：带状褐色，基部固着器附着岩石。生活史：合子 → 孢子体 → 孢子囊 → 游动孢子 → 雌雄配子体 → 精子、卵子。
  - **裙带菜**。

**硅藻门（不等鞭毛类，SAR 界的 S）**

- 营养体无游动细胞；细胞壁成分为硅酸，由两个套合半片（瓣）组成：外瓣为上壳、里瓣为下壳，顶面和底面为壳面，套合面为环面。
- 光合色素：叶绿素 a/c；贮藏物质：金藻昆布糖和油滴。
- 生殖：精子具鞭毛；有性生殖产生复大孢子。细胞分裂时子代各获母细胞一个瓣片：获得上瓣片者与母细胞等大，另一者变小；变小到一定程度经减数分裂恢复大小。

**绿藻门**

- 多为草绿色；细胞壁成分为纤维素；光合色素为叶绿素 a、b；具蛋白核，贮藏物质为淀粉。

## 三、苔藓植物

**系统位置**：有胚植物（苔藓植物＋维管植物）。

**主要特征**

- 配子体发达，孢子体寄生在配子体上。
- 有组织分化，但无维管组织、无真正的根茎叶；具假根（固着，无输导组织）。
- 有原丝体阶段。
- 以孢子繁殖／无性繁殖。

**为什么苔藓植物是高等植物**

| 角度 | 依据 |
|---|---|
| 形态结构 | 陆生适应结构：假根固着，叶状体光合作用；多细胞生殖器官（精子器和颈卵器）保护配子发育 |
| 生活史 | 受精卵在颈卵器内发育成多细胞胚；配子体占优势，执行营养和生殖功能；孢子体寄生——以配子体为主导是早期陆生植物的保守策略 |
| 地质年代 | 4.3 亿年前已存在，与早期维管植物并存 |

**生态系统中的功能**

| 功能 | 说明 |
|---|---|
| 生态恢复先锋植物 | 常集群呈毡垫状，减缓地表径流、防止风蚀和水土流失；耐旱 |
| 健康与森林类型指示植物 | 对环境变化敏感 |
| 蓄水保土 | 阻断降雨对土壤的直接冲击；饱和蓄水量达干重 3–5 倍；可向土壤释放水分维持湿润 |
| 气候变化指示植物 | 对环境变化敏感 |
| 初级生产者 | 含不饱和脂肪酸，是部分动物食物；驯鹿食用苔藓获取花生四烯酸提高御寒能力 |
| 生态系统关键植物 | 为一些树木种子萌发提供有利条件 |

## 四、蕨类植物

**系统位置**：维管植物。

**主要特征**

- 细胞壁木质化。
- 维管植物中唯一以孢子繁殖的类群（也是孢子植物中唯一具维管组织者）。
- 孢子体优势的世代交替，孢子体和配子体均可独立生存。
- 孢子体有根、茎、叶分化。
- 生殖器官为精子器、颈卵器，精子具鞭毛，有性生殖需要水参与。

**主要类群**

**石松科**
- 生境：土生；维管组织为原生中柱或片状中柱。
- 茎：主茎匍匐、攀援或短直立；侧枝二叉分枝或近合轴分枝，稀单轴分枝。
- 叶：单型单叶，仅具中脉，螺旋状排列，钻形、线形、披针形。
- 生殖：孢子穗圆柱状或柔荑花序状，孢子枝顶生或侧生；孢子叶单型、有锯齿、膜质；孢子囊无柄、腋生、肾形、二瓣开裂；孢子同型，球状四面形，具网状纹饰。

**卷柏科**
- 多年生草本，土生或石生，常绿；原生中柱或管状中柱。
- 叶螺旋排列，单叶，具叶舌。

**木贼科**
- 生境：土生、湿生、浅水生。
- 茎分节，节上生根，具绒毛；地上枝直立圆柱形，有节、中空，可轮生分枝，节间有脊和沟。
- 叶鳞片状、轮生，形成叶鞘，鞘齿明显。
- 生殖：孢子囊穗顶生，圆柱形或椭圆形；孢子叶轮生、盾状，孢子叶下生 5–10 个孢子囊；孢子同型，具弹丝，无裂缝，颗粒状纹饰，薄透明壁。
- 代表：**问荆**——春枝（繁殖枝）、夏枝（营养枝），具节中柱。

**松叶蕨科**
- 附生或土生；原生中柱或管状中柱。
- 根茎粗、褐色，有假根；地上茎绿色，多回二叉分枝。
- 叶小型，仅中脉，散生，二型：营养叶钻状、鳞片状或披针形；孢子叶二叉型或分枝，无叶脉。
- 代表：松叶蕨。

**水龙骨亚纲**
- 孢子体陆生或附生，少水生；常绿多年生草本，少藤本或树形。
- 茎不发达，多地下生，为根状茎，单轴分枝。
- 叶大型，幼时拳卷，长大展开。
- 生殖：孢子叶穗生于茎或枝顶端或侧生小枝，四棱形、扁形或圆柱形；孢子囊腋生，二型；孢子表面具纹饰。

**石松科的进化地位**

- 现生维管植物的基部类群。
- 二叉分枝、小型叶、原生中柱。
- 顶生孢子叶穗，孢子同型或异型。
- 孢子体发达，各自独立生活；配子体常在孢子壁内发育。
- 木本石松有次生生长。

**裸蕨**：真叶植物（狭义蕨类植物＋种子植物）的姊妹群。

**分类系统**

## 五、裸子植物

| 珠鳞 | 松柏 | — |

**主要类群**

**苏铁纲**
- 叶集中于茎顶，二型（鳞叶和营养叶）；雌雄异株；孢子叶球顶生。
- 生活史：种子 → 孢子体 → 大小孢子叶球 → 大小孢子叶 → 雌雄配子体 → 雌雄配子 → 种子。

**银杏纲**
- 乔木，雌雄异株；维管组织为管胞；单叶扇形。
- 雄球花穗状下垂，雌球花二叉分枝；每个大孢子叶球仅一枚胚珠发育成种子。
- 直生胚珠，具传粉滴；珠心中间凹陷成贮粉室；大孢子叶特化成珠领。
- 种子：三层种皮——外种皮肉质，含油脂及芳香物质；中种皮骨质、黄白色、具纵脊；内种皮纸质、白色（未成熟时透明）；胚乳肉质；核果状，表面有白粉。

**松柏纲**
- 木本；次生木质部发达，无导管，具树脂道。
- 叶条形、钻形、针形、鳞形、刺形或披针形。
- 小孢子叶具类似花药的形态分化，花粉具气囊，精子无鞭毛。
- 大孢子叶为珠鳞、套被或珠托；种子生于珠鳞腋部，或由套被、珠托发育成的假种皮包裹。

**松柏纲分科**

| 类群 | 叶 | 生殖器官／果实 |
|---|---|---|
| 松科 | 针形或线形 | 种鳞具两粒种子 |
| 松属 | 二型：长枝具膜质鳞叶；短枝生绿色针叶，多针一束，顶生 | 孢子叶球单性同株 |
| 落叶松属 | 条形扁平 | 孢子叶单生枝顶，球果直立 |
| 杉木属／柏科 | 叶和孢子叶螺旋排列；叶背有两条白色气孔带 | 小孢子叶有三个孢子囊；传粉滴；珠鳞与苞鳞半愈合 |
| 罗汉松科 | — | 种子由套被发育成的假种皮包裹 |
| 红豆杉科 | — | 种子坚果状，包裹在珠托发育成的假种皮内；外种皮骨质，内种皮膜质；含紫杉醇，具抗癌活性 |

**买麻藤纲**
- 有导管。
- 孢子叶球有盖被（类似花被）；除麻黄类外不具颈卵器；双受精，但形成的是双合子。

**买麻藤纲分科**

|---|---|

| 花（花序） | 穗状花序、聚伞花序、伞形花序、伞房花序、头状花序、轮伞花序、总状花序 |
| 生殖器官 | 雄蕊：全着药、基着药、丁字药；横裂、纵裂、瓣裂；聚药雄蕊、二体雄蕊、单体雄蕊、二强雄蕊、四强雄蕊。雌蕊：上位、下位、周位子房；横生、倒生、弯生、直生胚珠 |

### 6.2 核心特征与常见问答

**三大特征**

- 具有真正的花。
- 胚珠包在子房内，发育成种子和果实。
- 双受精，胚乳染色体为 3n。

**双子叶 vs 单子叶**

| 项目 | 双子叶植物 | 单子叶植物 |
|---|---|---|
| 子叶 | 2 枚 | 1 枚 |
| 生活型 | 草本／木本 | 多为草本 |
| 叶脉 | 网状脉／羽状脉 | 平行脉／弧形脉 |
| 花基数 | 4 或 5 | 3 |
| 花粉 | 三沟花粉 | 单沟花粉 |

**为什么被子植物是最进化的植物**

| 方面 | 依据 |
|---|---|
| 繁殖器官 | 真正的花：花色香气吸引动物传粉，形成协同进化；子房与果实：保护种子、助力扩散、避免失水与外界伤害；双受精：形成胚和胚乳，为胚胎提供营养，提高后代抗逆性和适应性 |
| 营养结构 | 输导组织具导管、筛管和伴胞，加速水分和养分运输；生境多样；配子体完全依赖孢子体，缩短繁殖周期，提高效率 |

### 6.4 类群详述

#### 6.4.1 基部类群（无油樟目、睡莲目、木兰藤目）

**无油樟目——无油樟（单物种）**：灌木或小乔木；维管组织无导管、只有管胞；雌雄异株。

**睡莲目**

- **独蕊草科·独蕊草属**：水生草本。
- **莼菜科·水盾草属／莼菜属**：水生草本；水中根状茎。
- **睡莲科**：水生草本，茎内有通气组织、地下茎发达；叶和花伸出水面，花单生、双被，花被到雌蕊逐渐过渡，螺旋状排列；雄蕊花丝扁平，花药条形；子房下位，心皮多数合生，弥漫性胎座；浆果。模式属：睡莲属。

**睡莲科 vs 莲科**

| 项目 | 睡莲科 | 莲科 |
|---|---|---|
| 地下茎 | 块茎 | 根状茎 |
| 叶片 | 浮水为主 | 挺水 |
| 心皮 | 合生 | 离生 |
| 胚珠与胎座 | 胚珠多数，弥漫性胎座 | 胚珠单生，顶生胎座 |
| 果实 | 浆果 | 坚果，生于碗状花托内 |
| 系统位置 | 早期被子植物：睡莲目 | 真双子叶：山龙眼目 |

**木兰藤目**

- **木兰藤科**：木质缠绕藤本，喜湿喜温；叶常绿、革质、对生，产生挥发性昆士兰樟；雌雄同株。
- **苞被木科**：乔木、灌木或藤木；叶对生、全缘；总状／聚伞／圆锥花序。
- **五味子科**：相关类群为八角科、五味子科。

#### 6.4.2 木兰类
![image 3.png](attachments/木兰类演化图.png)

**白樟目·林仙科**：小乔木或灌木；单叶互生、螺旋状、全缘，具透明腺点；聚伞花序顶生或腋生，或单花；花萼囊状、开花时破裂，花瓣 2 至多数、离生或外轮合生；雄蕊 3 至多数、离生，心皮 1 至多数；聚合浆果。

**胡椒目**

- **胡椒科**：草本、灌木、攀援藤本，稀乔木，具香气；单叶互生，稀对生或轮生，掌状脉或羽状脉；穗状花序，稀总状；两性或单性异株，苞片盾状或杯状，无花被；雄蕊 1–10，子房上位，1 室，柱头 1–5；浆果核果状或坚果。
- **马兜铃科**：灌木、草本、革质或攀援藤本、乔木或寄生草本；单叶互生，有柄或无柄；花单生或簇生，3 数，两性或单性，花被合生 1–2 轮，辐射或两侧对称；雄蕊 6 至多数，心皮 3–5、合生，子房下位；蒴果蓇葖状、长角果状或浆果状。

**木兰目**

- **肉豆蔻科**：乔木或灌木，具香气；叶互生、全缘、螺旋状，无托叶；花腋生，圆锥／总状，稀头状或聚伞，单性，被片常 3 裂；雄蕊 2 至多数，花丝合生，柱顶盘状，子房上位、1 室；蒴果，果皮肉质或近木质、2 开裂，种子肉质。
- **木兰科**：木本；单叶互生，具托叶、早落；花单生，花被 3 基数、花瓣状；雌雄蕊多数、分离、螺旋排列；聚合蓇葖果。
- **番荔枝科**：乔木或攀援灌木，木质部有香气；单叶互生、全缘、羽状脉，有叶柄和托叶；花单生或圆锥／聚伞花序，两性、辐射对称，萼片 3、离生或基部合生，花瓣 6、2 轮；雄蕊多数，花药 2 室、纵裂，心皮 1 至多数、离生；聚合浆果，有柄，具假种皮和胚乳。

**樟目**

- **蜡梅科**：灌木；花两性、辐射对称，单生侧枝顶端或腋生，具香气，先叶开放；花被片多数、未分化、螺旋排列；雄蕊两轮，螺旋于花托顶端；心皮多数、离生，着生于花托内面，每心皮 2 胚珠；聚合瘦果。
- **樟科**：乔木或灌木，稀藤本，具芳香；叶互生／对生／轮生，革质、全缘；圆锥／总状／伞形花序，末端分枝为聚伞花序，辐射对称，3 或 2 基数，花被裂片排成 2 轮；雄蕊四轮，花药 4 或 2 室、瓣裂，花丝具腺体；子房上位，心皮 1，1 室，1 枚倒生胚珠；浆果，1 种子，有时核果状。

#### 6.4.3 单子叶植物

**百合目·百合科**：草本，常具根状茎或鳞茎；单叶互生或轮生；花两性、辐射对称、虫媒花，常 3 基数，花被花瓣状、裂片 6、排成两轮；雄蕊 6、2 轮，花丝分离或联合；子房上位，3 室中轴胎座；蒴果或浆果。

**天门冬目**

- **兰科**：地生、附生或腐生草本，稀攀援藤本，具块茎、根状茎或假鳞茎；叶基生或茎生；花序顶生或侧生，总状或圆锥花序，单花或多花，花梗和子房常扭转；花两性、两侧对称，花被片 6、2 轮、离生或部分合生，具距或囊，中央花瓣特化为唇瓣；具蕊柱／蕊喙，花粉黏合成团块；子房下位，1 室、侧膜胎座，稀 3 室中轴胎座；蒴果，种子多、粉尘状、无胚乳、具翅。
- **石蒜科**：多年生草本，具鳞茎，稀根状茎；叶基生、带状；伞形花序生于花葶顶端，花 1 至多数，开放前被膜质佛焰苞状总苞包裹，两侧对称或辐射对称，花被片和雄蕊各 6、2 轮；子房上位（百子莲亚科、葱亚科）或下位（石蒜亚科），3 室中轴胎座；蒴果。

**鸭跖草超目**

- 鸭跖草目：鸭跖草。
- 禾本目·禾本科：草本或木本；地上茎称秆，圆柱形，有明显节与节间，节间中空；单叶互生，2 列，每叶分叶鞘和叶片，叶鞘包秆、一侧开裂，叶舌位于叶片与叶鞘连接处内侧（膜质／具毛／退化），叶鞘顶端两侧耳状突起为叶耳；花序以小穗为基本单位，小穗轴基部具一对颖片（内颖、外颖）；小穗轴上生 1 至多小花，苞片 2（内稃、外稃），外稃顶端或背部具芒，子房基部有 2–3 枚透明肉质小鳞片（浆片）；雄蕊 3，花药丁字形着生于花丝顶端；雌蕊 1，2–3 心皮，子房上位、1 室、1 胚珠，花柱 2；颖果。
- **小麦**：穗状花序直立无柄，互生于穗轴各节，3–6 朵花；内外颖具芒；外稃长芒，浆片薄膜状；果皮膜质，种皮绿色，种皮与果皮可分离。

#### 6.4.4 真双子叶

**特征**：子叶两枚，有木质茎，花基数 4–5，3 孔花粉。

**毛茛超目**

- **罂粟科**：直立草本，具乳汁；单叶或复叶、互生；花两性，聚伞／总状／圆锥花序，基数 2，有花萼花冠分化，两侧对称或辐射对称；雄蕊 6 至多数，心皮 2 至多数，子房上位；蒴果。
- **木通科**：木质藤本；花单性、辐射对称，萼片花瓣状、6 片 2 轮，花瓣 6、蜜腺状；雄花雄蕊 6、退化心皮 3，雌花退化雄蕊 6、心皮 3、上位、离生，胚珠多数或 1；蓇葖果或浆果。
- **小檗科**：草本或灌木；单叶或复叶、互生、无托叶；花两性、辐射对称，单生／簇生／穗状或圆锥花序，萼片与花瓣相似、多轮、每轮 3 片，花瓣有蜜腺；雄蕊 3–9、与花瓣对生，花药瓣裂或纵裂；子房上位，1 心皮 1 室，柱头短、盾形，胚珠 1 至多数；浆果或蒴果。
- **毛茛科**：草本；叶互生；花两性、5 基数；雄蕊和雌蕊多数、离生、螺旋排列；聚合瘦果或蓇葖果。

**其余列名类群**：山龙眼目、昆栏树超目、黄杨超目。
