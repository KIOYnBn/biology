# 02 · 数量性状与群体遗传

> [!abstract] 一句话定位
> **数量性状**由多基因加性控制、受环境影响，用**方差分解与遗传力**描述；**群体遗传学**研究等位基因频率在世代中的变化，以**遗传平衡**为零点，分析选择、突变、迁移、漂变和非随机交配五大因素。

## 1　数量性状遗传

### 1.1　变异类型对照

| 连续变异（数量性状） | 不连续变异 |
| :--- | :--- |
| 变异不容易区分 | 变异容易区分 |
| 变异多 | 变异少 |
| 差异小 | 差异大 |

- **数量性状 QTL**：可进行连续变异。
- **$F_2$ 的变异范围大于 $F_1$**。

### 1.2　多因子假说

1. 数量性状由**多个基因**控制。
2. 基因之间**自由组合**。
3. 存在**加性基因**。
4. 每个加性基因的贡献**类似**。
5. 各基因效应**累加**。
6. 表型 = **遗传 + 环境**。

### 1.3　数量性状杂交实验

| 世代 | 表现 |
| :--- | :--- |
| 亲本（P） | 极端类型杂交 |
| $F_1$ | 中间长度，**无亲本型**，变异少 |
| $F_2$ | 大部分为中等长度，变异多，少数亲本型，呈**正态分布** |

**解释**：涉及两对基因，效应累加，符合孟德尔式**分离与自由组合**，由加性基因控制。

> [!warning] 易错点
> **多基因性状 $\neq$ 连续变异**：多基因控制是数量基础，但是否表现为连续变异还受环境影响和性状本身性质制约。

### 1.4　数量性状的类型

| 类型 | 定义 |
| :--- | :--- |
| **可数的数量性状** | 只能用**整数**描述的数量性状 |
| **阈值性状** | 只有**少数几种表型**的数量性状 |

### 1.5　遗传力与方差分解

**遗传力**：群体中某一表型的**全部变异中由遗传因子引起的比例**。

| 方差符号 | 含义 |
| :--- | :--- |
| $V_P$ | 表型方差 |
| $V_G$ | 遗传方差 |
| $V_A$ | 加性方差——加性基因引起的表型方差 |
| $V_D$ | 显性方差——加性基因的显性作用引起的方差 |
| $V_I$ | 互作方差——加性基因间相互作用引起的方差 |
| $V_E$ | 环境方差 |
| $V_{G \times E}$ | 遗传–环境互作方差 |

| 遗传力 | 公式 |
| :--- | :--- |
| **广义遗传力** | $H^2 = V_G / V_P$ |
| **狭义遗传力** | $h^2 = V_A / V_P$ |

> [!tip] 狭义遗传力为何更常用于育种
> 只有**加性方差**能稳定遗传给后代，显性方差和互作方差随基因组合拆散而改变，因此 $h^2$ 更能预测选择响应。

## 2　群体遗传学

### 2.1　群体与基因库

- **群体**：生活在**同一地理区域**、属于**同一物种**、具有**杂交能力**的一群个体。
- **基因库**：群体中具有生殖能力的个体的**所有等位基因总和**。

### 2.2　遗传平衡与频率计算

- **遗传平衡**：在没有外力作用时，基因频率与基因型频率**世代保持不变**。
- 基本关系：$p + q = 1$，$(p+q)^2 = 1$。
- **判断平衡**：用**卡方检验**（注意自由度）。
- **应用**：① 判断群体是否达到遗传平衡；② 根据表现型频率推算等位基因频率。
- **X 连锁基因**：只需计算**雄性**的基因频率即可（雄性只有一条 X）。

> [!note] 已合并的重复内容
> 原文末段「遗传平衡」条目与本节公式重复，已统一在此处表述，不再另列。

### 2.3　改变基因频率的五大因素

**(1) 自然选择**

| 概念 | 定义 |
| :--- | :--- |
| 适合度 $w$ | 对后代的遗传贡献 |
| 选择系数 $s$ | $s = 1 - w$ |

| 情形 | 频率变化 |
| :--- | :--- |
| 显性基因 | $\Delta p = p' - p = \dfrac{-sp(1-p)^2}{1-sp(2-p)}$ |
| 隐性基因 | $\Delta q = q' - q = \dfrac{-sq^2(1-q)}{1-sq^2}$ |
| 隐性致死 | $q_g = \dfrac{q_0}{1+gq_0}$（$g$ 为世代数） |

**(2) 突变**

- 突变是 DNA 或染色体发生改变、产生新基因的过程。
- 突变对进化中等位基因频率的影响**不显著**。
- **突变率**：某基因位点或群体中发生突变的概率。
- 单向突变 $\mu: A \rightarrow a$ 时：$p_{g+1} = p_g - \mu p_g$。

**(3) 基因流（迁移）**

- 个体从一个群体迁移到另一个群体，带入或带走等位基因。
- 频率变化：$p_{i+1} = (1-m)p_i + mP_m$，其中 $m$ 为迁移率，$P_m$ 为迁入群体的等位基因频率。

**(4) 遗传漂变（抽样误差）**

- **群体越小，基因频率波动越剧烈**。
- 对杂合子的影响：

| 群体 | 杂合度 |
| :--- | :--- |
| 无限大群体 | $H = 2pq$ |
| 小群体（一代） | $H' = \left(1 - \dfrac{1}{2N}\right)H$ |
| $t$ 代以后 | $H_t = \left(1 - \dfrac{1}{2N}\right)^t H$ |

**(5) 不随机交配——近交**

- **近交**：亲缘关系较近的个体交配，导致**杂合子减少**。
- 自交 $n$ 代后后代比例：

| 基因型 | 比例 |
| :--- | :--- |
| $AA$ | $\dfrac{1 - 1/2^n}{2}$ |
| $Aa$ | $\dfrac{1}{2^n}$ |
| $aa$ | $\dfrac{1 - 1/2^n}{2}$ |

- **近交系数 $F$**：二倍体的两个等位基因来自**同一共同祖先**的概率。
  - $F = 1$：群体中个体均为纯合体。
- **近交衰退**：近交群体**适合度降低**的现象。

## 3　考点速记

- 数量性状：连续变异、变异多、差异小；由多基因加性控制，受环境影响。
- 多因子假说六条：多基因、自由组合、加性基因、贡献相似、累加效应、遗传+环境。
- $F_1$ 中间型、$F_2$ 正态分布且变异范围更大。
- $H^2 = V_G/V_P$，$h^2 = V_A/V_P$；育种上更看重狭义遗传力。
- 遗传平衡：$p+q=1$、$(p+q)^2=1$，卡方检验判断。
- 漂变使杂合度按 $(1-1/2N)^t$ 递减；近交系数 $F$ 表示等位基因同祖概率。

<details>
<summary><b>自测 1：为什么 $F_2$ 的变异范围大于 $F_1$？</b></summary>

$F_1$ 为杂合的中间型，基因型较一致；$F_2$ 经减数分裂发生分离与自由组合，出现从极端到中间多种基因型组合，加上环境差异，表型变异范围更大并近似正态分布。
</details>

<details>
<summary><b>自测 2：遗传漂变与近交对杂合度的影响有何共同点与区别？</b></summary>

共同点：都使杂合子比例下降。区别：漂变源于**小群体抽样误差**，杂合度按 $H_t=(1-1/2N)^tH$ 递减，群体越小越快；近交源于**亲缘个体交配**，可用近交系数 $F$ 度量两个等位基因同祖的概率，并导致近交衰退。
</details>
