# 动物生理学

## 一、绪论

### 1.1 研究对象与任务

- **对象**：个体生命活动。
- **目标**：揭示生理活动的规律。
- **任务**：阐明生理活动的机制、条件和影响因素。
- **十大系统**：循环、免疫、排泄、呼吸、消化、皮肤、运动、生殖、内分泌、神经。
- **研究层次**：整体与环境 → 器官与系统 → 细胞与分子。

### 1.2 生命活动的基本特征

新陈代谢；兴奋性与适应性；生长、发育与生殖；遗传性。

**生命活动的最小结构和功能单位是细胞**，细胞的生命活动随内外环境变化而改变。

### 1.3 生理功能的调节方式

| 方式 | 要点 | 特点 |
| --- | --- | --- |
| 神经调节 | 神经系统通过反射活动调节；基本活动方式为反射，结构基础为反射弧（感受器、传入神经、中枢、传出神经、效应器五部分） | 迅速、短暂、准确 |
| 体液调节 | 即激素调节；细胞分泌化学物质，经血液运输作用于靶细胞；包括自分泌、旁分泌、内分泌 | 范围广、缓慢、持久 |
| 自身调节 | 组织、细胞对刺激的适应性反应 | 范围局限 |
| 神经-体液调节 | 内分泌腺受神经系统调节，如体温调节 | 兼具两者特点 |

- 反射分非条件反射与条件反射。
- 常见腺体：垂体、胸腺、性腺、泪腺、皮脂腺；胰腺位于腹腔，胰岛 A 细胞分泌胰高血糖素、B 细胞分泌胰岛素。

### 1.4 内环境与稳态

- **内环境**：细胞外液，包括组织液、血浆、淋巴液（及脑脊液）。
- **稳态**：内环境中各种成分和理化性质保持相对稳定的状态。

### 1.5 生理功能的控制系统

- **非自动控制系统**：单向控制，不受反馈影响。
- **反馈控制系统**
  - 正反馈：反馈信息加强控制部分活动（如排尿、血液凝固）。
  - 负反馈：反馈信息减弱控制部分活动，维持稳态（如体温、血压调节）。
- **前馈控制系统**：在干扰出现前预先发出控制指令，具有预见性（如进食前胃液分泌）。

## 二、细胞的基本功能

### 2.1 细胞膜的结构

- **半透膜**：通透性指物质通过膜的难易程度。
- **液态镶嵌模型**
  - 脂质双分子层：以磷脂为主，其次为胆固醇、鞘磷脂；磷脂一端亲水、一端疏水；脂质熔点低，具有流动性；胆固醇多则流动性小。
  - 膜蛋白：表面蛋白（通过带电残基与脂质极性基团结合）、结合蛋白（肽链贯穿脂质双分子层），主要以 α 螺旋或球形存在。
  - 糖类：寡糖和多糖链，以共价键与脂质、蛋白结合成糖脂、糖蛋白；位于膜外侧；特异性由单糖排列顺序决定。

### 2.2 跨膜物质转运

**扩散**：溶质由高浓度向低浓度移动；影响因素为温度、浓度差；通量为每秒每平方厘米通过的摩尔数，与浓度差成正比，离子还受电场力影响。

| 类型 | 要点 |
| --- | --- |
| 单纯扩散 | 脂溶性小分子顺浓度差移动，如气体、尿素、乙醇 |
| 易化扩散（载体介导） | 载体蛋白选择性结合 → 变构 → 释放；特征为特异性、饱和性、竞争性抑制；转运葡萄糖、氨基酸、核苷酸 |
| 易化扩散（通道介导） | 带电离子经通道蛋白快速顺浓度移动；特点为变化迅速、选择性、门控 |
| 原发性主动转运 | 能量由 ATP 直接提供；钠泵（钠钾泵）形成细胞内高 K⁺、建立势能储备，是生物电现象基础，同时维持渗透压与 pH |
| 继发性主动转运 | 利用其他物质的势能储备逆浓度转运，如小肠吸收葡萄糖 |
| 出胞与入胞 | 大分子或团块；出胞经内质网合成 → 高尔基体成囊泡 → 移向质膜 → 融合释放；入胞分受体介导与非受体介导 |

![离子通道功能](attachments/离子通道功能.png)

### 2.3 跨膜信号转导

**定义**：外界刺激作用于受体，将信号传递到膜内，引起细胞内功能改变。

| 类型 | 要点 |
| --- | --- |
| 离子通道介导 | 化学门控通道（如 N 型 ACh 受体，5 聚体蛋白，2α、β、γ、δ 亚基，梅花状，两个 α 亚基结合 ACh，激活后 Na⁺ 内流、K⁺ 外流形成终板电位）；电压门控通道（膜电位改变控制开放，见于肌细胞、神经细胞）；机械门控通道；细胞间通道（直径约 2 nm，常见于肝细胞、心肌细胞、肠平滑肌、晶状体细胞、神经细胞，与细胞同步性相关） |
| G 蛋白偶联受体介导 | G 蛋白由 α、β、γ 三亚基组成，α 亚基起催化作用；受体 7 次跨膜，N 端连接胞外信号、C 端连接 G 蛋白；第二信使为 cAMP、IP₃、DG |
| 酶联受体介导 | 酪氨酸激酶受体 TKR：第一信使为生长因子、肽类激素（胰岛素、生长素），N 端识别、C 端具酪氨酸激酶活性；鸟苷酸环化酶受体 GCR：第一信使为心房钠尿肽、NO，经 GTP 生成 cGMP，激活 PKG |

## 三、细胞生物电与兴奋传导

### 3.1 兴奋与刺激条件

- **动作电位**：受刺激时细胞膜两侧的电位变化，包括锋电位（脉冲样变化）与后电位（负后电位、正后电位）。
- **兴奋性**：细胞受刺激时产生动作电位的能力；受离子成分、酸碱度、温度、特殊药物影响。
- **兴奋条件**：刺激强度、持续时间及强度-时间变化率；兴奋所需最小强度与持续时间呈反比。
- **阈强度**：引起动作电位的最小刺激强度；**阈电位**：引发动作电位的临界膜电位。
- **相对不应期**：需超过阈强度才能兴奋；**绝对不应期**：任何刺激无效，兴奋性降为 0，受代谢与温度影响。
- 阈下刺激虽不引起兴奋，但仍对细胞产生影响。

### 3.2 静息电位与动作电位

| 概念 | 含义 |
| --- | --- |
| 静息电位 | 细胞未受刺激时膜内外电位差，膜内相对膜外为负 |
| 极化 | 膜两侧保持内负外正 |
| 超极化 | 膜内负值增大 |
| 去极化 | 膜内电位向负值减小方向变化 |
| 复极化 | 去极化后恢复到静息电位 |

**产生机制**

- 带电离子在膜两侧不均衡分布，及膜对离子通透性的改变。
- 静息状态下膜对 K⁺ 有通透性，是静息电位的基础；静息电位小于理论 K⁺ 平衡电位，是因为膜对其他离子也有通透性。
- 静息电位的维持：离子移动量很小，钠泵建立 Na⁺、K⁺ 的不均衡分布。
- 动作电位产生：刺激使膜对 Na⁺ 通透性增大 → Na⁺ 内流 → 膜负电位消失并继续内移 → Na⁺ 通透性消失、K⁺ 通透性增大 → 复极。
- **单一细胞动作电位特点**：全或无；沿细胞膜扩散；传播范围与距离和刺激强弱无关。

### 3.3 局部兴奋与传导

- 小于阈电位的去极化也引起 Na⁺ 内流，但此时膜对 K⁺ 通透性大于 Na⁺，刺激局限于受刺激部位，形成**局部兴奋**。
- 局部兴奋特征：非全或无；不能远距离传播，随距离增大而减弱；可以叠加。
- 达到阈电位后，去极化与 Na⁺ 内流互相促进；去极化速度取决于静息电位和膜内外 Na⁺ 浓度差，与刺激大小无关。
- **传导机制**：已兴奋部位通过局部电流刺激未兴奋部位。
- **跳跃式传导**：有髓神经纤维，速度快、节能（跨膜离子运动少）。

### 3.4 细胞间兴奋传递

**神经-骨骼肌接头**

- 囊泡储存的 ACh 经出胞释放；终板膜无电压门控通道，不能产生动作电位，只产生局部电位。
- 终板电位以电紧张性扩布使邻近肌细胞产生动作电位；ACh 引起的终板电位超过阈值 3～4 倍，保证收缩。
- **ACh 清除**：胆碱酯酶。抑制清除的物质包括肌肉松弛素、美洲箭毒、α-银环蛇毒（结合 ACh 受体）、有机磷农药；新斯的明抑制胆碱酯酶。

**三种传递方式比较**

| 项目 | 经典突触 | 神经-骨骼肌接头 | 神经-平滑肌接头 |
| --- | --- | --- | --- |
| 位置 | 神经元-神经元 | 运动神经元-骨骼肌细胞 | 自主神经节后纤维-平滑肌或心肌 |
| 结构组成 | 突触前膜 / 间隙 / 后膜 | 接头前膜 / 间隙 / 终板膜 | 曲张体 |
| 结构特点 | 递质小泡，后膜有受体簇 | 终板膜皱褶表面积大，含 ACh 受体与胆碱酯酶，1:1 传递 | 无突触结构，递质从曲张体弥散，作用范围广 |
| 信号传递 | 电-化学-电 | 电-化学-电 | 非突触性化学传递，激活 G 蛋白偶联通路 |
| 递质清除 | 酶解或重吸收 | 胆碱酯酶 | 扩散或血循环清除 |

**共同特点**：单向传递、易受环境影响、有时间延迟、易疲劳。神经-平滑肌接头传递时间长、作用范围大。

## 四、肌细胞收缩

### 4.1 概述与神经-肌接头

- 骨骼肌由成束肌纤维（肌细胞）组成，两端通过肌腱附着于骨；每个肌细胞是独立的结构和功能单位，至少接受一个运动神经末梢支配。
- 终板电位通过电紧张性扩布引发肌细胞动作电位，再经兴奋-收缩耦联引起机械收缩。

### 4.2 肌细胞的微细结构

| 结构 | 说明 |
| --- | --- |
| 明带（I 带） | 仅含细肌丝 |
| 暗带（A 带） | 含粗肌丝和部分细肌丝 |
| H 带 | 暗带中央，仅含粗肌丝 |
| M 线 | H 带中央，锚定粗肌丝 |
| Z 线 | 明带中央，锚定细肌丝 |
| 肌节 | 相邻 Z 线之间，含中间暗带和两侧各 1/2 明带，是肌纤维收缩的基本功能单位 |

**肌管系统**

- **横管系统（T 管）**：肌细胞膜内凹形成，走向与肌原纤维垂直，在 Z 线环绕肌原纤维并与细胞外液相通；作用是将膜的电变化传入细胞内部。
- **肌浆网（L 管，纵管系统）**：走向与肌小节平行；终末池位于肌小节两端，通过 Ca²⁺ 的贮存与释放触发收缩与舒张。
- **三联管**：横管及其两侧的纵管终末池，将肌细胞膜电变化与收缩过程耦联。

![横管与纵管比较](attachments/横管与纵管比较.png)

### 4.3 收缩机制与兴奋-收缩耦联

**滑行理论**：粗、细肌丝相互滑行引起肌肉收缩。

- 粗肌丝：肌球蛋白；细肌丝：肌动蛋白、原肌球蛋白、肌钙蛋白；能量来自 ATP。
- 横桥：粗肌丝伸出，一个粗肌丝周围有 6 个细肌丝；横桥与细肌丝相互作用是肌丝滑行的必要条件。
- 过程：动作电位 → 肌浆 Ca²⁺ 升高 → Ca²⁺ 与肌钙蛋白结合并改变构象 → 原肌球蛋白构象改变 → 肌动蛋白与横桥结合。
- 横桥循环非同步，使肌肉产生恒定张力和连续缩短；参与循环的横桥数目和速率决定收缩程度、速度与张力。

![兴奋收缩耦联示意图](attachments/兴奋收缩耦联示意图.png)

**兴奋-收缩耦联**：将兴奋过程与肌丝收缩联系起来的中介过程。

1. 电兴奋经横管传入肌细胞深处：Na⁺ 内流产生动作电位，沿横管膜传播至三联管。
2. 三联管处信息传递：某种因子将横管膜变化传递给肌浆网 Ca²⁺ 通道，Ca²⁺ 易化扩散进入肌浆。
3. 肌浆网对 Ca²⁺ 释放与再积聚：钙泵（Ca²⁺ 依赖性 ATP 酶）将 Ca²⁺ 转运回肌浆网；肌浆 Ca²⁺ 降低 → 肌钙蛋白与 Ca²⁺ 解离 → 肌肉舒张。

### 4.4 收缩的力学分析

| 类型 | 说明 |
| --- | --- |
| 等长收缩 | 只增加张力，不缩短长度 |
| 等张收缩 | 长度缩短，张力几乎不变 |
| 单收缩 | 一次有效刺激产生一次收缩，分潜伏期、缩短期、舒张期 |
| 不完全强直收缩 | 强直刺激频率较低，收缩有部分舒张 |
| 完全强直收缩 | 肌肉未舒张即再次收缩 |

- 收缩具有空间总和效应：幅度与刺激强度有关，超过最大刺激不能再增大。
- 强直收缩：一系列间隔很短的刺激使肌肉保持缩短状态。

### 4.5 平滑肌

有些平滑肌具有自动节律性，收缩缓慢。

## 五、血液

### 5.1 血液组成与理化特性

- **体液**分细胞内液与细胞外液；细胞外液包括组织液、血浆、淋巴液、脑脊液。
- **血液对内环境稳定的作用**：运输；缓冲 pH 与体热；机体防御；生理凝血与抗凝；维持渗透压稳定。
- **血量**：血浆量与血细胞量之和，血细胞主要是红细胞；两者均可用稀释原理测定（如 T1824 标记血浆蛋白测血浆总量）。

![血液组成图解](attachments/血液组成图解.png)

**血浆**

- 电解质作用：稳定 pH、稳定渗透压、作为电生理现象载体、参与信号转导和传递。
- 血浆蛋白浓度是血浆与组织液的主要区别，因分子大不能透过毛细血管壁；盐析法分为白蛋白、球蛋白、纤维蛋白原。
- 功能：营养、运输（亲脂性结合位点）、形成胶体渗透压、免疫、凝血与抗凝。

**理化特性**

- 比重与粘滞性：血液与红细胞成正比，血浆与蛋白质成正比。
- 血浆渗透压：晶体渗透压（主要来自电解质，血浆与组织液浓度几乎相同）与胶体渗透压（主要来自白蛋白）。
- 血浆 pH：依靠缓冲对维持。

### 5.2 血细胞生理

**造血**

- 胚胎早期卵黄囊造血 → 胚胎第二个月肝、脾造血 → 出生后完全依赖骨髓。
- 阶段：造血干细胞 → 定向祖细胞（红系、粒-单系、巨核系、淋巴系）→ 前体细胞 → 终末血细胞。

**红细胞**

- 双凹圆碟形，含血红蛋白；尿素可自由透过，负离子易通过、正离子难通过。
- 悬浮稳定性：红细胞沉降率以 1 小时内下沉距离表示；叠连使表面积/容积比减小、下沉加快；白蛋白减慢沉降，球蛋白和纤维蛋白原促进叠连。
- 脆性：机械脆性与渗透脆性；溶血指红细胞破裂、血红蛋白释放；功能是运输 O₂ 和 CO₂。
- 合成：维生素 B₁₂（含钴）与叶酸作为辅酶辅助 DNA 合成；内因子由胃腺壁细胞分泌，含两个活性部位（结合维生素 B₁₂、结合回肠上皮受体），保护其不被小肠蛋白酶破坏。胃切除或内因子抗体可致巨幼红细胞性贫血；叶酸缺乏同样致病。Fe 是合成血红蛋白的原料，以再利用为主，供应不足致小细胞性贫血。
- 调节：爆式促进因子作用于早期红系祖细胞；促红细胞生成素（肾组织产生）作用于晚期红系祖细胞；甲状腺激素与生长素促进其合成，雌激素抑制红细胞生成。
- 破坏：溶血后血红蛋白与触珠蛋白结合被肝摄取，铁以铁黄素形式储存；未结合者经肾排出。

**白细胞**：参与机体防御，具有变形、游走、趋化和吞噬作用。

- 中性粒细胞：又称多形核白细胞。
- 嗜碱性粒细胞：颗粒含肝素与组织胺；肝素与脂肪代谢有关，组织胺与过敏反应有关，并释放嗜酸性粒细胞趋化因子。
- 嗜酸性粒细胞：明显昼夜波动；限制嗜碱性粒细胞过敏反应（趋化聚集、产生前列腺素 E 抑制其生物合成与释放、吞噬其颗粒、释放组织胺酶）；参与对蠕虫的免疫（表面有 IgE Fc 段与补体 C3 受体，经溶酶体过氧化物酶破坏蠕虫）。
- 单核细胞：骨髓发育，未成熟即入血，含较多脂酶，进入组织后成为巨噬细胞。
- 淋巴细胞：T 淋巴细胞与 B 淋巴细胞，可增殖分化。

**血小板**：骨髓成熟巨核细胞胞浆裂解脱落的小块胞质；维护血管壁完整性，可融入血管内皮细胞；过少时微小创伤即引起瘀点或紫癜。血管损伤时由静止转为激活，释放止血物质。

### 5.3 生理止血

**生理止血**：血管损伤引起的血液流出自动停止；出血时间为血液流出到停止的时间。

**过程**

1. 血管收缩，损伤不大时可封闭血管。
2. 血管内膜损伤激活血小板与血浆凝血系统。
3. 血凝块出现：可溶性纤维蛋白原变为不溶性纤维蛋白多聚体，交织成网包裹血细胞，与血小板形成止血栓。
4. 血浆出现抗凝活动，防止凝血蔓延。

**血液凝固**：血液离开血管后由流动的溶胶变为不流动的胶冻状态。

- 凝血因子共 13 种；另有前激肽释放酶、高分子激肽原、血小板磷脂。
- 除磷脂和因子Ⅳ（Ca²⁺）外均为蛋白质，多为无活性酶原，需水解激活；活性形式加 a 标记（如 Ⅱa）。
- 关键因子：Ⅰ 纤维蛋白原、Ⅱ 凝血酶原；凝血酶使纤维蛋白原变为纤维蛋白。
- 途径：均通过激活因子Ⅹ（Stuart-Prower 因子）。内源性途径由血管内膜损伤启动，血浆内因子逐步激活Ⅹ；外源性途径由血管外组织释放因子Ⅲ（TF，组织凝血激酶）激活，如创伤出血。

![凝血过程示意图](attachments/凝血过程示意图.png)

**抗凝物质**

- 抗凝血酶Ⅲ：丝氨酸蛋白酶抑制剂，以精氨酸残基结合凝血因子活性中心的丝氨酸残基。
- 肝素：酸性多糖，由肥大细胞与嗜碱性细胞产生；增强抗凝血酶Ⅲ活性、促使血管内皮释放凝血抑制物和纤溶酶原激活物、激活血浆脂酶加速乳糜微粒清除。
- 蛋白质 C：灭活因子Ⅴ、Ⅷ；限制因子Ⅹ与血小板结合；增强纤维蛋白溶解。
- 体外因素：低温延缓凝血；光滑表面减少血小板聚集与解体；去除 Ca²⁺ 抗凝。

**纤维蛋白溶解**：纤溶系统包括纤溶酶原、纤溶酶、纤溶酶原激活物与纤溶抑制物。

- 激活物：血管激活物（内皮细胞释放）、组织激活物（血管外促进纤溶）、依赖因子Ⅻ的激活物（如前激肽释放酶）。
- 纤溶酶水解肽链的赖氨酸-精氨酸键；抑制物为抗纤溶酶。

**血小板止血功能**

- 松软止血栓：血小板黏附成团；损伤暴露的胶原纤维通过 vWF 与血小板膜糖蛋白Ⅰ结合。
- 坚实止血栓：血小板由圆盘形变球形、伸出伪足，释放 ADP 与 5-羟色胺；提供磷脂表面促进凝血因子激活，避免抗凝血酶Ⅲ与肝素的抑制。

### 5.4 血型与输血

- **凝集**：血细胞聚集成簇，可伴溶血；阻塞毛细血管并损伤肾小管；机制为抗原-抗体反应。
- **凝集原**：起抗原作用的糖蛋白；**凝集素**：与凝集原反应的抗体，为 γ-球蛋白，溶于血浆，每个凝集素可结合多个红细胞。
- **血型**：红细胞上的抗原类型；不同血型血清中不含抗自身凝集原的凝集素。

| 系统 | 抗体 | 依据 | 要点 |
| --- | --- | --- | --- |
| ABO | IgM | 凝集原 A、B | A 型含 A 凝集原/抗 B 凝集素；B 型含 B 凝集原/抗 A；O 型两者皆无/抗 AB；检测用抗 A、抗 B、抗 AB 血清分别与红细胞悬液反应 |
| Rh | IgG（可通过胎盘） | D 抗原 | Rh 阳性含 D 抗原；阴性母亲怀阳性胎儿时，胎儿红细胞进入母体产生抗体，再入胎儿可引起新生儿溶血性贫血；首次输注反应不明显，多次输血可产生凝集 |

**输血原则**：交叉配血试验。主侧为受者血清与供者红细胞配合，次侧为受者红细胞与供者血清配合；主侧凝集不能输血，次侧凝集仅在应急下输血。可分为输全血与成分输血。

## 六、血液循环

### 6.1 心脏泵血功能

- **心动周期**：心脏一次收缩和舒张；成年人约 0.8 s。
- **全心舒张期**：心房与心室同时处于舒张期。

![心动周期时序图](attachments/心动周期时序图.png)

**左心室心动周期分期**：心房收缩期（房内压 > 室内压）→ 等容收缩期（室内压上升）→ 快速射血期（室内压 > 主动脉压，达峰值）→ 减慢射血期（室内压与主动脉压下降）→ 等容舒张期（室内压下降）→ 快速充盈期（室内压 < 房内压）→ 减慢充盈期（房室压差下降）。

**泵血指标**

| 指标 | 定义 |
| --- | --- |
| 每搏输出量 | 一次心跳一侧心室射出的血液量 |
| 每分输出量 | 每分钟射出的血液量 |
| 心指数 | 按单位体表面积计算的心输出量；静息心指数指安静空腹状态 |
| 射血分数 | 搏出量占心室舒张末期容积的百分比 |
| 心室容积 | 舒张末期容积最大，收缩末期容积最小，二者之差即搏出量 |

### 6.2 心肌生物电现象

**心肌组织特性**：兴奋性、自律性、传导性、收缩性。

- 自律细胞：P 细胞、浦肯野细胞，无收缩性。
- 工作细胞：心房肌、心室肌，无节律性、传导性差。
- 节区传导细胞：无收缩性、无自律性、低传导性。

**心脏特殊传导系统**

- 窦房结：位于心房与上腔静脉连接处，含 P 细胞和过渡细胞。
- 房室交界：心房与心室间兴奋传导通道。
- 房室束：位于室间隔，主要为浦肯野细胞，分左右两支（左支分支多、分布左心室，右支分支少）。
- 浦肯野纤维网：位于心内膜，垂直向心外膜延伸，与普通心室肌细胞相连。

**心室肌细胞动作电位**：复极过程复杂、持续时间长。

| 分期 | 离子机制 |
| --- | --- |
| 0 期去极 | Na⁺ 内流 |
| 1 期复极 | K⁺ 外流，钠通道失活；0 期与 1 期合称锋电位 |
| 2 期平台期 | K⁺ 外流与 Ca²⁺ 内流并存，膜两侧近等电位 |
| 3 期快速复极末期 | Ca²⁺ 通道关闭，膜内越负 K⁺ 外流越强 |
| 4 期静息期 | 复极完毕，排 Na⁺、Ca²⁺，摄入 K⁺ |

**自律细胞**：3 期复极末达到最大复极电位，4 期自动去极至阈电位后产生新动作电位。

- 浦肯野细胞（快反应）：4 期内向起搏电流主要为 Na⁺；复极到 −60 mV 激活，去极到 −50 mV 失活。
- 窦房结细胞（慢反应）：最大复极电位与阈电位较高；无明显极化倒转；去极幅度小、时间长；无明显 1 期与平台期；4 期自动去极较快；0 期由 Ca²⁺ 内流引起；4 期涉及 Iₖ 衰减、I_f（Na⁺ 内流）与 Ca²⁺ 通道开放。

## 七、呼吸

### 7.1 肺通气

**定义**：肺与外界环境的气体交换过程。

**器官**

- 呼吸道：沟通肺泡与外界；上呼吸道（鼻、咽、喉）与下呼吸道（气管、支气管及其肺内分支）；作用是调节气道阻力，并对气体加温、湿润、过滤、清洁及防御反射。
- 肺泡：肺泡气与血液气体交换场所。
- 胸廓：节律性呼吸运动是肺通气的动力。

**动力**

- 肺本身无收缩能力，靠胸廓扩大与回缩张缩；呼吸肌引起胸廓运动。
- 吸气肌：膈肌、肋间外肌；吸气为主动过程。膈肌收缩使胸腔和肺容积增大、中心下移；肋间外肌收缩使肋骨和胸骨上提，增大胸腔前后径与左右径。腹式呼吸以膈肌运动为主，胸式呼吸以肋间肌运动为主。
- 呼气肌：肋间内肌、腹壁肌；平静呼气主要由膈肌和肋间外肌舒张、肺弹性回位完成，用力呼吸时呼气肌才参与。

**阻力**

- 弹性阻力：弹性组织对抗变形与回位的倾向。肺充血、肺纤维化或肺泡表面活性物质减少时阻力增大、吸气困难；肺气肿时弹性成分破坏、回缩力减小、呼气困难。
- 肺泡表面活性物质：二棕榈酰卵磷脂，一端疏水、一端亲水，可减小表面张力、增加顺应性；密度随肺泡半径增大而减小，使表面张力增大，防止肺泡进一步增大；肺炎、肺血栓时减少可致肺不张。
- Laplace 公式：P = 2T / r（P 为肺泡内压、T 为表面张力、r 为肺泡半径）。
- 非弹性阻力：主要为气道阻力，排痰、清除异物、减轻黏膜肿胀可降低阻力。

**肺通气量**

| 指标 | 计算 |
| --- | --- |
| 每分通气量 | 呼吸频率 × 潮气量 |
| 肺泡通气量 | （潮气量 − 无效腔量）× 呼吸频率 |
| 解剖无效腔 | 上呼吸道至呼吸性细支气管间，气体不参与交换 |
| 肺泡无效腔 | 肺泡中未参与交换的容量 |
| 生理无效腔 | 肺泡无效腔 + 解剖无效腔；健康人平卧时接近解剖无效腔 |

- 从气体交换角度看，浅而快的呼吸不利。

### 7.2 气体交换

**影响扩散的因素**：扩散面积、气体分压差、温度、溶解度、分子量、距离。

**肺换气**：肺泡气与肺泡毛细血管血液间的气体交换。

- 呼吸膜厚度：扩散量与厚度成反比；肺纤维化、肺水肿使膜增厚。
- 呼吸膜面积：扩散量与面积成正比；运动时毛细血管开放增多使面积增大；肺不张、肺实变、肺气肿、毛细血管阻塞使面积减少。
- 通气/血流比值：肺通气量与肺血流量之比。

**组织换气**：细胞与组织毛细血管血液间的气体交换，使动脉血变为静脉血；受组织细胞代谢强度与血液供应影响。

### 7.3 气体在血液中的运输

**存在形式**：物理溶解与化学结合。

**氧的运输**

- 血红蛋白由 1 个珠蛋白与 4 个血红素组成，每个血红素由 4 个吡咯基与 1 个 Fe 组成。
- Hb 与 O₂ 结合特征：反应快、可逆、不需酶、受氧分压影响；结合形式为氧合而非氧化（Fe 仍为二价）；1 分子 Hb 结合 4 分子 O₂；结合与解离曲线呈 S 型。
- 影响因素：pH 与 CO₂ 分压（**波尔效应**：酸度影响 Hb 氧亲和力，促进肺部氧合与组织处氧释放）；温度升高促进氧释放；2,3-二磷酸甘油酸升高降低亲和力；CO 与氧竞争。

**二氧化碳的运输**：溶解与化学结合（碳酸氢盐、氨基甲酸血红蛋白）；CO₂ 解离曲线；**何尔登效应**：氧与 Hb 结合促进 CO₂ 释放。

### 7.4 呼吸运动的调节

- **神经调节**：呼吸中枢分布于大脑皮层、间脑、脑桥、延髓、脊髓。脊髓联系上位脑与呼吸肌；脑桥与延髓产生呼吸节律；大脑皮层实现随意控制。
- **化学因素调节**：动脉血或脑脊液中的 O₂、CO₂、H⁺。
  - 外周化学感受器：颈动脉体、主动脉体，传入延髓，促进呼吸加深加快；氧分压降低或 CO₂、H⁺ 浓度升高时受刺激。
  - 中枢化学感受器：延髓腹外侧浅表部位，感受脑脊液与局部细胞外液的 H⁺。

## 八、消化与吸收

### 8.1 概述

- **消化**：食物在消化管被分解为小分子的过程；**吸收**：消化后的小分子、水、无机盐、维生素等通过消化管黏膜进入血液和淋巴的过程。
- **消化管**：口腔、咽、食管、小肠（十二指肠、空肠、回肠）、大肠（盲肠、结肠、直肠、肛管）。上消化道为口腔至十二指肠，下消化道为空肠以下。
- **消化腺**：小消化腺与大消化腺（三对唾液腺：腮腺、下颌下腺、舌下腺；肝；胰）。
- **功能**：食物的消化吸收、内分泌、免疫。
- **消化方式**：机械消化（消化道运动）、化学消化（消化酶）、生物消化（微生物酶）。
- 除口、咽、食管上端、肛门外括约肌为骨骼肌外，其余消化道为平滑肌。

**消化道平滑肌**

- 一般特性：兴奋性低；节律不规则、收缩缓慢；有伸展性；紧张性（持续收缩维持形态与位置）；对电刺激不敏感，对化学和机械刺激敏感。
- 电生理：静息膜电位（近 K⁺ 平衡电位，不稳定、波动大）；慢波电位（节律性自发去极化，反映兴奋性周期变化）；动作电位（Ca²⁺ 内流引起去极，K⁺ 外流复极）。

**消化液功能**：分解食物；为消化酶提供 pH 环境；稀释食物使渗透压接近血浆；保护消化管黏膜。

**胃肠神经支配**：内在神经系统（胃肠壁内，可独立于中枢完成反射）与外来神经系统（交感与副交感神经）。

**胃肠激素**：胃肠黏膜分泌的肽类化学信使。

- 分泌方式：内分泌、旁分泌、神经分泌、自分泌、腔分泌。
- 作用：调节消化腺分泌与消化道运动；调节其他激素释放；营养作用（促进代谢与生长）；调节食欲。

### 8.2 口腔内消化

- 三对主要唾液腺：腮腺、颌下腺、舌下腺；唾液接近中性。
- 唾液作用：湿润和溶解食物引起味觉；清洁与保护（清除残渣、冲淡中和有害物质）；灭菌杀毒（溶菌酶、免疫球蛋白）；唾液淀粉酶分解淀粉为麦芽糖。分泌调节为神经反射性。
- 咀嚼：咀嚼肌按顺序收缩，由口腔感受器与咀嚼肌本体感受器调控；作用是切碎食物并与唾液混合成食团、进行初步消化、刺激胃胰等器官活动加强。
- 吞咽：口腔至咽（舌尖与舌后部上举将食团挤入咽）→ 咽至食管（软腭上升、咽后壁前突、鼻咽通道关闭、呼吸暂停、食管括约肌舒张、咽与气管通路关闭）→ 食管至胃（食管蠕动，平滑肌顺序收缩形成向前推进的波形运动）。

### 8.3 胃内消化

- 胃暂时贮存食物，通过胃液和胃壁肌肉消化；仅吸收酒精和少量水分。

![胃粘膜外分泌腺](attachments/胃粘膜外分泌腺.png)

**胃液**

- 盐酸：壁细胞逆浓度分泌，食物促进其分泌。作用：灭菌；激活胃蛋白酶原；进入小肠促进促胰液素释放；促进铁和钙吸收；分解结缔组织与肌纤维使蛋白质变性。
- 胃蛋白酶：泌酸腺主细胞胞吐分泌胃蛋白酶原，酸性条件下活化为胃蛋白酶。
- 粘液与碳酸氢盐：粘液由表面上皮细胞、颈粘液细胞、贲门腺、幽门腺分泌，主要为糖蛋白，减少机械损伤；粘液与 HCO₃⁻ 形成屏障保护胃黏膜，形成 pH 梯度使胃蛋白酶在 pH > 5 时失活。
- 内因子：结合维生素 B₁₂。

**胃液分泌调节**

- 促进因素：乙酰胆碱（副交感神经释放，促进盐酸分泌）；促胃液素（胃窦 G 细胞分泌）；组织胺（肥大细胞产生）；生长抑素抑制胃泌素与组织胺分泌。
- 分泌时相：头期（眼、耳、鼻等头部感受器引起条件与非条件反射）；胃期（胃底感受器经迷走神经长反射与壁内神经丛短反射，胃幽门部 G 细胞释放胃泌素，食物化学成分直接刺激 G 细胞）；肠期（食物进入小肠后仍刺激胃液分泌）。
- 抑制因素：盐酸、脂肪、高张溶液，经负反馈调节。

### 8.4 小肠内消化

**胰液**：碱性。

- 无机物主要为碳酸氢盐，由胰腺小导管上皮细胞分泌；有机物主要为消化酶（胰淀粉酶、胰脂肪酶、蛋白水解酶），由腺泡细胞分泌。
- 调节：神经调节为迷走神经；体液调节为胃泌素、促胰液素、胆囊收缩素。

**胆汁**：肝细胞分泌，非消化时贮存于胆囊，无消化酶。

- 胆盐：胆汁酸与甘氨酸或牛磺酸结合形成的钠盐或钾盐，是参与消化的主要成分。
- 胆色素：血红蛋白分解产物，包括胆红素及其氧化物胆绿素。
- 作用：乳化脂肪（减小表面张力）；促进脂肪吸收（形成微胶粒）；促进脂溶性维生素 A、D、E、K 吸收。

**小肠液**

- 十二指肠腺分泌黏稠碱性液体；小肠腺分泌水、无机盐、肠激酶、黏蛋白，是小肠液主要部分。
- 小肠液弱碱性，消化酶仅肠激酶一种，含免疫球蛋白。

**小肠运动**：外层纵行肌、内层环行肌；形式有紧张性收缩、分节运动、蠕动。调节：内在神经丛接受肠壁感受器；副交感促进、交感抑制；乙酰胆碱与去甲肾上腺素促进肠运动。

### 8.5 大肠内消化

- 功能：吸收水和电解质；吸收结肠微生物产生的维生素 B、K；加工食物残渣形成并贮存粪便。
- 大肠液：由黏膜柱状上皮细胞和杯状细胞分泌，含黏液与碳酸氢盐；黏液蛋白保护肠黏膜、润滑粪便。
- 细菌活动：分解食物残渣；糖和脂肪发酵产生乳酸、醋酸、沼气；蛋白质腐败产生氨、组织胺等，有毒物质经肠壁吸收至肝解毒；细菌能合成维生素 B、K。
- 运动：袋状往返运动、分节运动、蠕动。

### 8.6 吸收

**小肠是吸收的主要部位**：十二指肠和空肠吸收糖类、蛋白质、脂肪的消化产物；回肠吸收胆盐和维生素 B₁₂。

**有利条件**：食物在小肠内已消化成可吸收物质；吸收面积大；小肠绒毛；食物停留时间长。

**途径**：跨细胞途径、细胞旁途径。**机制**：被动转运、主动转运、出入胞。

| 物质 | 吸收要点 |
| --- | --- |
| 水 | 被动转运 |
| Na⁺ | 主要为空肠，主动吸收 |
| Fe | 亚铁形式，主动吸收，十二指肠与空肠 |
| Ca²⁺ | 可溶性钙才能吸收，主要在十二指肠，主动；受维生素 D 与机体需要影响 |
| 糖 | 单糖才能吸收，主动，能量来自钠钾泵，属继发性主动转运 |
| 蛋白质 | 分解为氨基酸后主动吸收 |
| 脂肪 | 与胆盐形成微胶粒；长链脂肪酸及甘油一酯在内质网合成甘油三酯，与载脂蛋白形成乳糜微粒，经高尔基体形成囊泡释放入淋巴；中短链脂肪酸与甘油一酯水溶性高，直接进入肝门静脉 |
| 胆固醇 | 来自食物与胆汁；脂肪酸和脂肪促进吸收，植物固醇抑制吸收 |

- 动植物油中长链脂肪酸多，脂肪吸收仍以淋巴为主。

## 九、能量代谢与体温

### 9.1 能量代谢

**定义**：物质代谢过程中能量的贮存、释放、转移与利用。

**来源**

- 糖：主要供能物质。
- 脂肪：组织脂质（胆固醇、磷脂，为组成成分，不供能）与贮存脂质（脂肪，人体主要供能和能量贮存形式，分解为甘油和脂肪酸氧化释放能量）。
- 蛋白质：原笔记记为「不供能」，但氨基酸可转变为脂肪。
  - 【待核对】蛋白质在体内也可氧化供能，此表述需结合教材复核。

**去路**：大部分转化为热能，其余储存于 ATP。

**测定**：机体消耗的能量除肌肉收缩的机械外功外最终都转化为热能，故可计算安静状态下单位时间释放的总热量。

- 直接测热法：密闭空间，用水吸收热量。
- 间接测热法：测定耗氧量与 CO₂ 产生量。

### 9.2 热价、氧热价与呼吸商

| 概念 | 定义 |
| --- | --- |
| 热价 | 1 g 物质体内氧化或体外燃烧释放的热量 |
| 物理热价 | 体外燃烧释放的热量 |
| 生物热价 | 体内氧化释放的热量；蛋白质体内氧化不彻底，二者不等 |
| 氧热价 | 物质每消耗 1 L 氧产生的热量 |
| 呼吸商 | 物质氧化分解时 CO₂ 产生量与 O₂ 消耗量之比 |

- 呼吸商接近 1：主要以糖供能；接近 0.71：主要以脂肪供能（糖尿病患者）；约 0.80：以蛋白质供能；混合膳食约 0.85。
- 每 6.25 g 蛋白质分解产生 1 g 尿氮。

![能量代谢计算题](attachments/能量代谢计算题.png)

### 9.3 影响因素与基础代谢

- **影响因素**：肌肉活动（最显著）、精神活动、食物动力作用（摄入食物导致的额外能耗）、环境温度（低温和高温均促进代谢）。
- **基础状态**：清晨、清醒、静卧、肌肉放松、空腹、环境温度 20～25 ℃、无精神紧张。
- **基础代谢**：基础状态下的能量代谢；**基础代谢率**：单位时间内的基础代谢。

### 9.4 体温与产热散热

**体温**

- 体表温度：人体表层（如皮肤）温度，不稳定。
- 深部温度（体核温度）：心、肺、脑、腹腔等深部组织的平均温度；因血液循环进行热量交换，体内温度差异不大，常用口腔、腋窝测量。
- 变化：昼夜节律；青春期后女子体温比男子高约 0.3 ℃；儿童体温较高、老年人较低；肌肉活动与精神活动可使其升高。

**体热平衡**：产热与散热处于动态平衡。

**产热**

- 器官：肝脏、骨骼肌。
- 形式：战栗产热（骨骼肌节律性收缩，不做功）；代谢产热（褐色脂肪组织）。
- 调节：肾上腺素与去甲肾上腺素促进迅速产热、持续时间短；甲状腺激素促进缓慢产热、持续时间长。寒冷刺激使交感神经兴奋，肾上腺髓质分泌髓质激素，增强糖与脂肪氧化分解。

**散热**

- 途径：皮肤、呼吸道、消化道、泌尿道。
- 方式：辐射散热（外界温度超过皮肤温度时皮肤吸收热射线能量）；传导散热（直接传给接触的冷物体）；对流散热（气体流动）；蒸发散热（水分蒸发）。

### 9.5 体温调节

- **自主性体温调节**：体温调节中枢根据环境变化调节，使产热量与散热量保持平衡。
- **行为性体温调节**：通过改变姿势或行为保暖或散热。
- **温度感受器**：外周（皮肤、内脏，分冷觉与温觉感受器）；中枢（脊髓、延髓、脑干、下丘脑）。
- **体温调节中枢**：下丘脑。
- **调定点学说**：细菌感染时改变热敏神经元阈值，使调定点上移，散热减弱，体温升高。

## 十、排泄与渗透压

### 10.1 肾的功能解剖与肾血流量

**肾的功能**：排出代谢产物和异物；调节细胞外液量和渗透压；排出 H⁺ 维持酸碱平衡。

**肾单位**是肾的基本功能单位，与集合管共同完成泌尿功能。

- 肾小体：肾小球、肾小囊。
- 滤过膜：肾小球毛细血管内皮细胞、基膜、肾小囊脏层上皮细胞。
- 肾小管：近球小管、髓袢、远曲小管。
- 球旁器（近球小体）：颗粒细胞（入球小动脉上皮样细胞，含肾素分泌颗粒）；球外系膜细胞（具吞噬功能）；致密斑（远曲小管起始部，感受管液中 NaCl 变化并调节肾素释放）。

**神经支配**：肾交感神经来自胸 12 至腰 2 脊髓，支配肾动脉平滑肌、肾小管与颗粒细胞；末梢释放去甲肾上腺素，调节血流量、滤过率、重吸收与肾素释放。

**肾血液循环特征**

- 血流量大。
- 两套毛细血管网：肾小球毛细血管网血压高，利于滤过；肾小管周围毛细血管网血压低，利于重吸收。
- 肾血流量调节：
  - 自身调节（不依赖肾外神经，一定血压范围内血流量保持稳定）：肌源学说（灌注压增高使平滑肌紧张性增加、血管收缩）与球-管反馈（致密斑小管液流量变化影响肾血流量与滤过率）。
  - 神经体液调节：交感神经兴奋使血管收缩；紧急情况下血液重新分配，集中供应脑、心等重要器官。

### 10.2 肾小球滤过

- **肾小球滤过率**：单位时间内两肾形成的超滤液量。
- **滤过分数**：肾小球滤过率与肾血浆流量的比值。
- 滤过率取决于滤过系数（滤过膜面积与通透性）和有效滤过压。急性肾小球肾炎时毛细血管腔变窄、滤过面积减少，出现少尿；正电荷物质易通过滤过膜。
- **有效滤过压** = 肾小球毛细血管压 + 囊内胶体渗透压 −（血浆胶体渗透压 + 肾小囊内压）。
- **滤过平衡**：有效滤过压为零时滤过停止。入球端滤过率低，出球端滤过率高。

### 10.3 肾小管与集合管的转运

- 近球小管：Na⁺、Cl⁻、K⁺ 主动重吸收，大部分水重吸收；HCO₃⁻ 以 CO₂ 形式重吸收；葡萄糖（继发性主动转运）与氨基酸全部被重吸收。相关概念：肾糖阈（尿中不出现葡萄糖时的最高血糖浓度）、葡萄糖转运极限量；H⁺ 分泌入小管；动力为钠泵。
- 髓袢：升支粗段重吸收 Na⁺、Cl⁻、K⁺、Ca²⁺、HCO₃⁻、Mg²⁺；降支细段重吸收水。
- 远曲小管与集合管：主细胞重吸收 Na⁺、水并分泌 K⁺；闰细胞分泌 H⁺；水重吸收受抗利尿激素调节，Na⁺、K⁺ 转运受醛固酮调节。

### 10.4 尿液的浓缩与稀释

- 稀释：髓袢升支粗段溶质被重吸收而水不被重吸收。
- 浓缩：水重吸收的动力来自肾髓质渗透梯度。

### 10.5 尿生成的调节

**自身调节**：溶质浓度；球管平衡（近球小管按比例重吸收）；球管反馈（致密斑-肾素）。

**神经-体液调节**

- 交感神经：入球与出球小动脉收缩；颗粒细胞释放肾素；增强近球小管和髓袢对 Na⁺、Cl⁻ 和水的重吸收。
- 抗利尿激素：提高远曲小管和集合管对水的重吸收。
- 肾素-血管紧张素-醛固酮系统：肾素（颗粒细胞释放的蛋白水解酶）使血管紧张素原变为血管紧张素Ⅰ；转化酶使其变为Ⅱ；血管紧张素Ⅱ刺激醛固酮合成与释放、促进近球小管重吸收 NaCl、刺激抗利尿激素释放；醛固酮促进远曲小管和集合管重吸收 Na⁺、排出 K⁺。
- 心房利尿钠肽：抑制集合管对 NaCl 的重吸收；舒张出球与入球小动脉、增强滤过率；抑制肾素、醛固酮与抗利尿激素分泌。

## 十一、内分泌

### 11.1 激素总论

- **内分泌系统**由内分泌腺和内分泌细胞组成。
- **激素**：由内分泌腺或细胞分泌的高效能生物活性物质，经血液和组织液运输，调节组织细胞和器官功能。

**信息传递方式**：远距分泌（血液运输）、旁分泌（组织液扩散至邻近组织）、自分泌（局部扩散返作用于该细胞）、神经分泌（神经细胞合成的激素经轴浆运输进入血液）。

**分类**：含氮激素；类固醇激素（皮质醇、雌激素、雄激素，可口服）；固醇激素；脂肪酸激素（前列腺素）。

**作用机制**

- 含氮激素：第二信使学说（激素结合受体 → 激活 G 蛋白 → 激活效应酶 → 产生第二信使）。
- 类固醇激素：基因调节学说（脂溶性激素进入细胞 → 与胞浆受体结合 → 入核与核受体结合 → 启动 DNA 转录）。

**作用特征**：特异性、信息传递作用、高效性；激素间有协同、拮抗、允许作用。

**分泌调节**：激素以出胞方式分泌；主要受负反馈调节。

### 11.2 下丘脑与垂体

**下丘脑-腺垂体系统**

- 下丘脑基部促垂体区包括正中隆起、弓状核、视交叉上核、腹内侧核、室旁核；产生的激素经正中隆起弥散入局部血管，通过垂体门静脉到达腺垂体。

![下丘脑调节肽表](attachments/下丘脑调节肽表.png)

- 腺垂体激素：TSH（促甲状腺激素）、ACTH（促肾上腺皮质激素）、FSH（卵泡刺激素）、LH（黄体生成素）、GH（生长素）、PRL（催乳素）、MSH（促黑激素）。
  - **生长素**：促进生长（过少致侏儒症、过多致巨人症）；促进代谢（促进蛋白质合成、升高血糖、促进脂肪分解与脂肪酸氧化）。
  - **催乳素**：促进乳腺发育与泌乳；男性促进前列腺和精囊腺生长、促进睾酮合成；女性促进雌激素与孕激素分泌；应激时促进肾上腺皮质激素和生长素分泌。
- 分泌调节：下丘脑调节性多肽、外周靶腺激素负反馈、反射性调节。

**下丘脑-神经垂体系统**

- 视上核与室旁核细胞轴突下行至神经垂体形成下丘脑-垂体束；激素经轴浆运输至神经垂体储存并释放。
- 视上核合成血管升压素（抗利尿激素）：抗利尿；大出血时浓度升高，收缩血管维持血压。
- 室旁核合成催产素：促进乳腺腺泡周围肌上皮细胞收缩排乳；促进子宫平滑肌收缩；吸吮乳头与分娩时宫颈阴道扩张可促进其分泌释放。

### 11.3 甲状腺

- 人体最大的内分泌腺，由甲状腺腺泡组成，激素储存于腺泡腔；腺泡旁细胞（C 细胞）合成降钙素。
- **激素类型**：T₄（四碘甲腺原氨酸，量多）；T₃（三碘甲腺原氨酸，活性大，为主要作用形式）。
- **合成**：原料为碘（食物）和酪氨酸（腺泡上皮细胞合成的甲状腺球蛋白）。过程：碘吸收（以 I⁻ 形式经主动运输进入腺泡细胞）→ 碘活化（过氧化酶作用）→ 酪氨酸碘化（形成 MIT、DIT，MIT + DIT 形成 T₃，两个 DIT 形成 T₄）。
- **储存与释放**：以甲状腺球蛋白形式存于腺泡腔；经入胞吞入后由蛋白水解酶作用释放 T₃、T₄ 入血；运输时与血浆蛋白结合。
- **作用**
  - 代谢：促进线粒体生物氧化、增加耗氧量（产热）。
  - 物质代谢：促进蛋白质合成（过量则促进分解）；促进糖吸收、糖原分解、糖异生、升高血糖，同时增强糖利用（甲亢患者进食后血糖迅速升高又迅速降低）；促进脂肪酸氧化与胆固醇降解，降低胆固醇。
  - 生长发育：不足致呆小症。
  - 神经系统：提高兴奋性。
  - 心血管：心率加快、心输出量增加、外周血管舒张。
- **调节**：下丘脑-腺垂体-甲状腺轴（TRH、TSH）；冷刺激促进 T₃、T₄ 增加；负反馈调节；交感神经促进合成、副交感神经抑制合成。

### 11.4 甲状旁腺与甲状腺 C 细胞

| 激素 | 来源 | 作用 | 调节 |
| --- | --- | --- | --- |
| 甲状旁腺素 PTH | 甲状旁腺主细胞 | 升高血钙、降低血磷（血钙过低可致抽搐死亡）；促进骨钙进入细胞外液；抑制近球小管重吸收磷酸盐、促进远曲小管重吸收钙；促进肠道吸收钙 | 血钙、血磷负反馈 |
| 降钙素 CT | 甲状腺 C 细胞（腺泡旁细胞） | 降低血钙和血磷；促进骨盐沉积；抑制肾对钙磷钠氯的重吸收 | 血钙负反馈 |

### 11.5 肾上腺

由皮质和髓质组成，二者是独立的内分泌腺。

**肾上腺皮质**（由外向内）

- 球状带：盐皮质激素，如醛固酮。
- 束状带：糖皮质激素，如皮质醇。
  - 作用：糖代谢（促进糖异生、升高血糖、抑制糖利用）；蛋白质代谢（促进肝外组织蛋白质分解、氨基酸入肝生成肝糖原）；脂肪代谢（促进脂肪分解）；应激反应（非特异性反应，促进糖皮质激素分泌）；血细胞（红细胞、血小板、中性粒细胞增多，淋巴细胞与嗜酸性粒细胞减少）；循环系统（维持血容量和血压）；消化系统（促进胃酸与胃蛋白酶原增多）；神经系统（提高中枢兴奋性）。
  - 调节：下丘脑-腺垂体-肾上腺皮质轴（CRH → ACTH），负反馈。
- 网状带：性激素，如雌二醇。

**肾上腺髓质**：分泌肾上腺素和去甲肾上腺素，属儿茶酚胺类。

- 应急反应：中枢兴奋性增强、心率加快、呼吸加快、糖原和脂肪分解供能增多。
- 代谢：糖原分解、脂肪分解、促进乳酸合成糖原、抑制胰岛素分泌、增加耗氧量与产热量。
- 调节：受交感神经节前纤维支配（交感-肾上腺髓质系统），负反馈。

### 11.6 胰岛

- **细胞组成**：A 细胞分泌胰高血糖素；B 细胞分泌胰岛素；D 细胞分泌生长抑素（GIH）；PP 细胞分泌胰多肽；D₁ 细胞分泌血管活性肠肽。
- **胰高血糖素**：在肝脏降解，作用与胰岛素相反；受血糖负反馈、交感神经促进、迷走神经抑制调节；胰岛素间接刺激、直接抑制邻近细胞分泌。
- **胰岛素**：蛋白质；促进糖原合成、降低血糖；促进脂肪合成、抑制脂肪分解；促进蛋白质与核酸合成。受血糖负反馈、胰高血糖素及神经调节（迷走促进、交感抑制）。

### 11.7 松果体

分泌褪黑激素 MLT；抑制性腺轴和甲状腺轴活动；切除幼年松果体出现性早熟。

## 十二、感觉器官

### 12.1 感受器总论

- **感受器**：体表或组织内部感受体内外环境变化的结构，如感觉神经末梢（痛觉感受器）、肌梭、感受细胞（视网膜感光细胞）。
- 生理特性：适宜刺激（最敏感的刺激形式）；换能作用（将刺激转为动作电位，非全或无）；编码作用（将刺激信息转移到动作电位序列）；适应现象（恒定刺激持续作用下动作电位频率逐渐下降）。
- **感受器官**：感受细胞连通非神经组织；人体主要感觉器官为眼、耳、鼻、舌。

### 12.2 视觉器官

**结构**

- 折光系统：角膜、房水、晶状体、玻璃体。
- 视网膜：感光细胞、双极细胞、视神经细胞。

**调节**

- 晶状体调节（反射）：模糊视觉图像 → 视觉皮层 → 锥体束-皮层中脑束 → 中脑正中核 → 动眼神经缩瞳核 → 动眼神经副交感节前纤维 → 睫状短神经 → 睫状肌环形肌收缩 → 晶状体形状改变。
- 瞳孔调节：由光线亮度决定，保护视网膜并保证视觉成像；强光 → 视网膜 → 视神经 → 中脑顶盖前区换元 → 双侧动眼神经缩瞳核 → 副交感纤维 → 瞳孔括约肌收缩 → 瞳孔缩小。
- 双眼球会聚：注视由远移近的物体时视轴向鼻侧汇聚。

**折光异常**

| 类型 | 原因 | 矫正 |
| --- | --- | --- |
| 近视 | 眼球前后径过长（轴性）或折光能力过强（屈光性） | 凹透镜 |
| 远视 | 眼球前后径过短（轴性）或折光能力过弱（屈光性） | 凸透镜 |
| 散光 | 与角膜弧度有关 | 圆柱镜 |

**感光换能**

- 感光细胞（视杆、视锥）含感光色素，结构分外段、内段、胞体、终足；外段集中感光色素。
- 盲点：视神经乳头，位于视网膜黄斑鼻侧约 3 mm 处。

| 系统 | 组成与特点 | 机制 |
| --- | --- | --- |
| 视杆系统（晚光觉） | 视杆细胞及其双极细胞、神经节细胞；对光敏感度高、无色觉、精确度差、区分轮廓 | 感光色素为视紫红质（视蛋白 + 视黄醛，视黄醛来自维生素 A）；光照时视紫红质分解，暗处重新合成；过程为吸收光量子 → 视蛋白变构 → 激活 Gt 蛋白 → 激活磷酸二酯酶 → cGMP 分解 → Na⁺ 通道开放减少 → 超极化 |
| 视锥系统（昼光觉） | 视锥细胞及其传递细胞；对光敏感度差，强光下被刺激，辨别颜色，分辨率高 | 含三种感光色素，对应红、蓝、绿 |

- 视网膜信息处理：感光细胞、双极细胞、水平细胞不产生动作电位，通过慢电位积累传至神经节细胞产生动作电位。
- 依据：感光细胞分布不均（中心视杆少、视锥多，黄斑中心全为视锥细胞）；信号通路不同（视锥会聚程度低、视杆高，中央凹处一个视锥细胞只联系一个双极细胞）；与动物活动相关（白昼活动动物只有视锥细胞，夜行动物只有视杆细胞）；感光色素不同。

**视觉现象**：视力；明适应（暗处到亮处）；暗适应（亮处到暗处）；视野（单眼固定注视前方一点能看到的范围，范围按白色 > 蓝色 > 红色 > 绿色）；复视（光线未在两侧视网膜相称点成像）。

### 12.3 听觉器官

- **听觉器官**：耳（外耳、中耳、内耳耳蜗）；**听觉感受器**：耳蜗螺旋器（柯蒂器）。
- **听阈**：能引起听觉的最小振动强度；**最大可听阈**：引起鼓膜疼痛的振动强度。

**外耳**：耳廓（收集声波、判断声源方向）、外耳道（声波传导，作为共鸣腔，充气管道可与 4 倍于管长的声波产生共振）。

**中耳**：鼓膜、鼓室、听骨链、中耳小肌、咽鼓管。

- 增压作用：鼓膜与卵圆窗膜面积不同使压强增大；听骨链杠杆长臂与短臂不等使短臂侧增压；中耳肌肉在强声或气流时收缩使鼓膜紧张、传音减弱（保护作用）。
- 咽鼓管连通鼓室与鼻咽部，平衡压力差、维持鼓膜位置。

**耳蜗**：将机械振动转为听神经冲动。

- 骨质管道围绕锥形骨；横截面有前庭膜与基底膜，将管道分为前庭阶、鼓阶、蜗管。
- 前庭阶连卵圆窗膜，鼓阶连圆窗膜，二者经蜗孔相通（充满外淋巴）；蜗管为充满内淋巴的盲管。
- 螺旋器位于基底膜，含毛细胞；毛细胞顶部与内淋巴接触、基部与外淋巴接触，顶部有听毛、底部有听神经末梢。
- 过程：声波经听骨链传至卵圆窗 → 压力变化传给耳蜗液体和膜性结构 → 卵圆窗膜内移 → 前庭膜与基底膜下移 → 鼓阶外淋巴压迫圆窗膜外移；卵圆窗膜外移时反之，形成振动，引起听毛变形产生电位并传至神经纤维。
- 听神经动作电位为复合动作电位。

### 12.4 前庭、嗅觉与味觉

**平衡器官**：前庭器官为内耳迷路中的三个半规管、椭圆囊和球囊；三个半规管相互垂直，感受各方向运动；是机体对运动状态和空间位置的感受器。毛细胞为感受细胞，最长的毛称动毛，其余为静毛。

**嗅觉**：感受器为上鼻道的嗅上皮，含主细胞（嗅细胞）、支持细胞、基底细胞；嗅细胞圆瓶状，顶端有嗅纤毛，底部有嗅丝穿过筛骨连接嗅球；纤毛受空气分子刺激产生神经冲动传入嗅球和高级嗅觉中枢。

**味觉**：感受器为味蕾，分布于舌背表面、舌缘及口腔咽部黏膜；由味觉细胞和支持细胞组成，味觉细胞顶端有味毛伸出味蕾表面。

- 原笔记：舌尖对酸味敏感、舌两侧对咸味敏感、软腭和舌根对苦味敏感。
  - 【待核对】常见教材表述为舌尖对甜、舌两侧前部对咸、舌两侧后部对酸、舌根对苦，建议复核。

## 十三、神经系统

### 13.1 神经元与神经胶质细胞

**神经元**：神经系统结构和功能的基本单位。

- 组成：胞体、树突（多个，树状分支，接受传入信息）、轴突（由胞丘发出，距胞体一段后获得髓鞘成为神经纤维，传递信息）。
- 功能：接受、整合、传递信息。

**神经纤维**：轴索（轴突或感觉神经元的长树突）外包髓鞘或神经膜。

- 兴奋传导特征：生理完整性、绝缘性、双向性、相对不疲劳性、不衰减性。
- 传导速度影响因素：纤维直径（粗则快）、有无髓鞘（有则快）、髓鞘厚度、温度（高则快）。
- 轴浆运输：轴浆在胞体与末梢间双向流动，实现物质运输与交换；快速运输膜性细胞器（如囊泡），慢速运输细胞骨架及其蛋白。
- 营养作用：释放物质调节支配组织的代谢活动。

**神经胶质细胞**：施万细胞、卫星细胞、星形胶质细胞、少突胶质细胞、小胶质细胞、室管膜细胞。

- 功能：支持；修复与再生（终生可分裂，可转变为巨噬细胞）；物质代谢与营养（血管周足在神经元与毛细血管间进行物质交换）；绝缘与屏障（髓鞘防止电流扩散，参与血-脑屏障；周围神经髓鞘由施万细胞形成，中枢由少突胶质细胞形成）；维持细胞外合适离子浓度（转运神经元活动产生的 K⁺）；摄取和释放神经递质。

### 13.2 神经元间的信息传递

**方式**：突触性（化学突触、电突触）与非突触性。

**突触**：神经元间相互接触并具有信息传递的部位。

- 类型：轴-体、轴-树、轴-轴突触；兴奋性突触与抑制性突触。
- 结构：突触前膜（突触小体含大量线粒体与递质囊泡）、突触间隙（含粘多糖和糖蛋白）、突触后膜（胞体或树突表面，有特异性受体或化学门控离子通道）；前后膜均增厚。
- 传递过程：前膜去极化 → Ca²⁺ 通道开放、Ca²⁺ 内流 → 轴浆粘度降低、囊泡位移融合释放递质 → 间隙扩散 → 后膜产生突触后电位。
  - 兴奋性突触后电位：递质增大后膜对 Na⁺ 的通透性，Na⁺ 内流产生局部去极化，累积至阈值在轴突触发动作电位。
  - 抑制性突触后电位：提高 Cl⁻ 通透性，Cl⁻ 内流产生超极化。
- 非突触性化学传递：轴突末梢分支的念珠状曲张体释放递质。
- 电突触传递：双向，经细胞间通道，促进神经元同步活动。

### 13.3 神经递质与受体

**神经递质**：突触前神经元合成、在突触末梢释放、在神经元间传递信息的化学物质；神经调质由神经元产生，调节信息传递效率。

- 分类（按部位）：外周神经递质与中枢神经递质。
- 中枢神经递质举例：乙酰胆碱（髓质、丘脑、脑干、纹状体；参与感觉、运动、学习记忆）；单胺类（多巴胺、去甲肾上腺素、肾上腺素、5-羟色胺——肾上腺素与去甲肾上腺素在延脑与低位脑干，参与觉醒、睡眠、情绪；多巴胺在中脑黑质，破坏致震颤麻痹；5-羟色胺在低位脑干，参与内分泌、体温调节、心血管、情绪）；氨基酸类；肽类（部分下丘脑神经激素也有递质作用）。
- 特点：神经元能合成；储存于突触小泡；突触后膜有受体；有回收途径；可用受体阻断剂加强或阻断传递。

**受体调节**：亲和力与数量变化；脱敏现象（长时间暴露于配体后失去反应性）。

**配体**：激动剂（结合受体产生效应）与拮抗剂（结合受体但不产生效应）；结合特点为特异性、饱和性、可逆性。

| 受体 | 分布与效应 | 阻断剂 |
| --- | --- | --- |
| 毒蕈碱受体 M | 副交感神经节后纤维支配的效应细胞 | 阿托品 |
| 烟碱型受体 N | 交感和副交感神经节元突触后膜、终板膜；分 N₁、N₂ 亚型 | 筒箭毒（N₁、N₂）、六羟季铵（N₁）、十羟季胺（N₂） |
| α 肾上腺素能受体 | 平滑肌兴奋、血管收缩、子宫收缩 | 酚妥拉明 |
| β 肾上腺素能受体 | 平滑肌抑制、血管舒张、子宫舒张 | 普洛萘尔 |

- 去甲肾上腺素对 α 受体作用强、对 β 受体作用弱。

### 13.4 反射弧中枢的活动

- **反射**：神经系统活动的基本方式。
- **中枢神经元联系方式**：辐射式（一个轴突联系多个神经元）、聚合式（多个轴突联系一个神经元）、链锁式（侧支传递）、环状（多个神经元形成环）。
- **中枢突触传递特点**：单向传递、突触延搁、总和、兴奋节律改变、后发放、对内环境变化敏感和易疲劳。
- **中枢抑制**：突触后抑制（传入侧支性抑制、回返性抑制）；突触前抑制。
- **中枢易化**：突触后易化、突触前易化。

### 13.5 神经系统的感觉分析功能

**感觉传导路径**：感受器神经冲动 → 脊髓后根 → 脊髓 → 上行传导路径 → 大脑皮层。

- 浅感觉（温度觉、痛觉、轻触觉）：后根细纤维 → 脊髓后角换元 → 中央管交叉到对侧 → 丘脑；**先交叉再上行**。
- 深感觉（肌肉本体感觉、深部压觉、位置觉、运动觉）：后根粗纤维 → 同侧后索上行 → 延髓交叉到对侧 → 丘脑；**先上行再交叉**。

**丘脑及感觉投射系统**

- 丘脑是感觉传导换元部位，对信号进行粗略分析综合。
- 细胞群：感觉接替核（后腹核、内侧膝状体—听觉、外侧膝状体—视觉，点对点投射至皮层特定感觉区）；联络核（丘脑前核、外侧腹核、丘脑枕）；髓板内核群（中央中核、束旁核、中央外侧核，维持大脑皮层兴奋，弥散投射）。
- 投射系统：特异投射系统（第一类细胞群，点对点）；非特异投射系统（第三类细胞群，弥散投射）。

**大脑皮层的感觉分析功能**：感觉分析的最高中枢。

- 皮层分层：内侧皮层为分子层、锥体细胞层、多形细胞层；外侧皮层为分子层、外颗粒层、外锥体细胞层、内颗粒层、内锥体细胞层、多形细胞层。
- 感觉柱：皮层基本功能单位；感觉信号经第四层 → 第二层 → 第三层 → 第五层 → 第六层离开皮层；第三层细胞可抑制相邻细胞柱。
- 代表区：体表感觉在中央后回（交叉投射、投射区大小决定灵敏度、排列倒置）；本体感觉在中央前回；内脏感觉区面积小且不集中；视觉在枕叶（一侧皮层接受两侧信号）；听觉在颞叶（双侧）。

**痛觉**

- 皮肤痛觉：快痛（定位明确）、慢痛（定位不明确，如灼烧）。
- 内脏痛：缓慢、时间长、定位不准确；对牵拉、缺血、炎症和化学刺激敏感，对切割、灼烧不敏感。
- 牵涉痛：内脏病变引起的体表疼痛。

### 13.6 神经系统对躯体运动的调节

**脊髓**

- 运动单位：一个 α 运动神经元及其支配的全部肌纤维；大小取决于轴突末梢分支数目；运动单位之间可交叉分布。
- 骨骼肌牵张反射：
  - 腱反射：快速牵拉肌腱引起，肌肉迅速明显缩短，受高位中枢下行调控。
  - 肌紧张：缓慢持续牵拉引起，产生紧张性收缩阻止肌肉被拉长，不表现明显动作，维持身体姿势。
  - 反射弧感受器：肌梭（感受肌肉长度变化，兴奋 α 运动神经元使梭外肌收缩）；腱器官（位于肌腱胶原纤维，感受张力变化，抑制 α 运动神经元）。
- 脊休克：脊髓与高位中枢离断后，离断面以下脊髓暂时失去反应能力；表现为躯体反射消失、肌紧张消失、血压下降等。
- 屈肌反射与侧伸肌反射；节间反射（如搔爬反射）。

**脑干对肌紧张的调节**：去大脑僵直（中脑上下叠体间切断脑干，伸肌紧张亢进、四肢伸直、头尾昂起）；抑制区位于延髓网状结构腹内侧；易化区位于脑干中央（延髓网状结构背外侧、脑桥被盖、中脑中央灰质及被盖）。

**脑干对姿势的调节**：姿势反射包括状态反射（迷路紧张反射、颈紧张反射）、翻正反射、直线与旋转加速度反射。

**小脑**

- 前庭小脑（绒球小结叶）：与身体平衡有关。
- 脊髓小脑（旁中央小叶）：接受脊髓小脑束投射，与精巧动作有关。
- 皮层小脑（后叶外侧部）：只接受大脑皮层信号。

**基底神经节**：尾核、壳核、苍白球统称纹状体；调节躯体运动，损伤可引起肌紧张异常（亢进或减退）。

**大脑皮层**

- 皮质脊髓束：至脊髓灰质前角运动神经元；皮质脊髓侧束（对侧，与精确运动有关）、皮质脊髓前束（同侧前索，与粗大运动有关）。
- 皮质脑干束：至脑干神经运动核，支配面部肌肉。
- 顶盖脊髓束、网状脊髓束、前庭脊髓束：与皮质脊髓束相似。

### 13.7 神经系统对内脏活动的调节

**自主神经系统**（内脏神经系统、植物性神经系统）包括交感和副交感神经系统。

- 节前与节后纤维：交感节前短、节后长，副交感相反；交感节前纤维连接多个节后神经元、反应分散，副交感连接较少、反应局限。
- 双重神经支配：大部分器官同时接受交感和副交感支配。
- 功能拮抗：二者作用往往相反。
- 紧张性作用：自主神经持续发放冲动，使效应器维持一定活动状态。
- 作用受效应器本身状态影响。

**各级中枢**

| 中枢 | 功能 |
| --- | --- |
| 脊髓 | 初级中枢 |
| 低位脑干 | 延髓为生命中枢（心血管运动、呼吸运动、胃肠运动等基本反射中枢），还有呼吸调节中枢与角膜反射中枢 |
| 下丘脑 | 较高级中枢，联系内脏活动与其他生理活动；调节体温、摄食行为、水平衡（有渗透压感受器）、腺垂体激素分泌、情绪反射、生物节律（控制中心在视交叉上核；分高频、中频、低频节律） |
| 大脑皮层 | 最高级调节和整合中枢 |

### 13.8 脑的高级功能

**脑电活动**：无外界刺激时的自发节律性电位变化称自发脑电活动；受刺激时固定区域的固定电位变化称皮层诱发电位；脑电图记录这些电位变化。

**觉醒**：脑电觉醒（脑电波呈快波）与行为觉醒（清醒状态）。黑质多巴胺系统维持行为觉醒（破坏后行为上不表现觉醒），蓝斑去甲肾上腺素递质系统也参与。

**睡眠**

| 时相 | 特点 |
| --- | --- |
| 慢波睡眠 | 脑电同步化慢波；感觉功能衰退，骨骼肌反射和肌紧张减退，自主神经功能减退，胃液分泌与发汗增强，生长素分泌增多；有助于生长与体力恢复 |
| 快波睡眠 | 又称异相睡眠、去同步化睡眠、快动眼睡眠；脑电低振幅去同步化快波；感觉与躯体运动功能衰退，出现眼球快速运动、肢体抽动、心率变快、血压升高、呼吸加快；脑蛋白合成与新突触建立，有助于神经系统发育、学习记忆与精力恢复；做梦是其特征 |

- 产生机制：脑干尾端睡眠中枢发出上行抑制系统，与上行激动系统拮抗；慢波睡眠与脑干 5-羟色胺有关；快波睡眠与去甲肾上腺素、5-羟色胺、乙酰胆碱等有关。

**学习与记忆**

- 学习：人和动物通过神经系统接受外界环境信息影响自身行为的过程。
  - 非联合型学习：不建立条件反射。
  - 联合型学习：建立条件反射，包括经典条件反射（无关刺激与非条件刺激在时间上结合，可发生条件反射消退）与操作式条件反射（第一信号系统、第二信号系统）。
- 记忆：获得的信息或经验的存储和读取的神经活动过程。
