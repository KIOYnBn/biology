# 02 · RNA 加工、剪接与编辑

> [!abstract] 一句话定位
> 真核 pre-mRNA 要过三关：**5′ 加帽 → 剪接去内含子 → 3′ 加 poly(A)**；剪接靠**两次转酯反应**与剪接体完成，可变剪接与 RNA 编辑让一个基因产生多种蛋白。

**导航**：[[分子生物学/03-基因组表达/01-转录|← 转录]] · [[分子生物学/00-复习总览|复习总览]] · [[分子生物学/03-基因组表达/03-翻译|翻译 →]]

---

## 0　总览

成熟 mRNA 的结构：**Cap — 5′ UTR — CDS — 3′ UTR — poly(A)**

| 加工步骤 | 核心事件 | 主责因子 |
| :--- | :--- | :--- |
| 5′ 加帽 | 添加 m⁷G | 加帽酶（被 Ser5-P CTD 招募） |
| 剪接 | 两次转酯，去除内含子、连接外显子 | 剪接体（snRNP） |
| 3′ 加尾 | 切割 + 加约 250 个 A | CPSF / CstF / PAP |
| RNA 编辑 | 转录后改变个别碱基 | 脱氨酶 / gRNA 系统 |
| 运输 | 经核孔复合体出核 | SR 蛋白、EJC |

> 与转录的偶联机制（CTD 密码）见 [[分子生物学/03-基因组表达/01-转录|转录]]。

---

## 1　5′ 帽（Cap）

- **添加 7-甲基鸟嘌呤（m⁷G）**：鸟嘌呤的三磷酸替代 RNA 5′ 端的三磷酸，随后甲基化。
- **反应过程**
  1. $Gppp \rightarrow Gp + pp$
  2. $pppNp \rightarrow p + ppNp$
  3. $Gp + ppNp \rightarrow GpppNp \xrightarrow{+m} m^7GpppN_{mp}$

### 1.1　类型

| 类型 | 甲基化位置 |
| :--- | :--- |
| **Cap 0** | 仅 m⁷G |
| **Cap 1** | + 第一位核糖 2′-O 甲基 |
| **Cap 2** | + 第二位核糖 2′-O 甲基；第一位核苷酸为嘌呤时其碱基也甲基化 |

### 1.2　作用

1. 防止核酸外切酶降解 mRNA。
2. 被核帽子结合蛋白识别，**运出细胞核**。
3. **启动翻译**（招募起始因子）
4. 启动靠近 5′ 端的内含子剪接。

---

## 2　3′ poly(A) 尾

- **PAP**（多核苷酸腺苷酰转移酶）添加多聚腺苷酸尾。
- **多聚腺苷酸信号**：5′-**AAUAAA**-3′。
- **poly(A) tail**：约 **250 个 A**（部分教材记 ~200）。

### 2.1　作用

1. 防止 mRNA 被降解。
2. 参与**转录终止**。
3. 促进 mRNA **运出细胞核**。
4. 增加**翻译起始效率**。

### 2.2　选择性多聚腺苷酸化（APA）

- 若序列中有多个 poly-A 信号，选择其中一个进行切割加尾 → **一个基因编码多个 mRNA**。

### 2.3　机制组件

| 组分 | 全称 / 功能 |
| :--- | :--- |
| **CTD** | RNA Pol II C 末端结构域，搭载加工因子 |
| **CPSF** | 剪切和多聚腺苷酸化特异性因子 |
| **CstF** | 剪切刺激因子 |
| **PAP** | poly(A) 聚合酶 |

- CPSF、CstF 搭载在 CTD 上被带到转录位点。

## 3　剪接的基本概念

| 概念 | 定义 |
| :--- | :--- |
| **外显子** | 编码序列 |
| **内含子** | 间插的非编码序列，在 RNA 阶段被移除 |
| **间隔基因** | 编码区被非编码区分隔成片段的基因 |
| **剪接信号** | **5′ 剪接位点、3′ 剪接位点、分支位点** |
| **剪接** | 切除内含子、连接外显子的过程 |

> [!important] 能量
> **剪接反应本身不消耗 ATP**，但**剪接体的组装和构象变化需要能量**。

### 3.1　内含子类型

| 类型 | 分支位点 | 说明 |
| :--- | :--- | :--- |
| **自剪接 Group Ⅰ** | **G** | 自我催化 |
| **自剪接 Group Ⅱ** | **A** | 自我催化 |
| 自剪接 Group Ⅲ | — | — |
| **依赖剪接体** | A | 由 snRNP 组成的剪接体催化 |
| **反式剪接** | — | 两条不同 mRNA 的外显子拼接成基因 |

---

## 4　剪接的化学过程：两次转酯反应

1. **第一次转酯**：分支点 **A 的 2′-OH** 作为亲核试剂，攻击 **5′ 剪接位点 G 上的磷酸**，内含子 5′ 端与分支点 A 形成新的 **2′-5′ 磷酸二酯键**，产生带尾巴的环状结构——**套索（Lariat）**。
2. **第二次转酯**：上游外显子的 **3′-OH** 作为亲核试剂，攻击 **3′ 剪接位点**，外显子连接，套索内含子释放。

---

## 5　剪接体

- **组成**：snRNA + protein → **snRNP**；snRNA 富含 U，又称 U-RNA。

### 5.1　主要剪接体（U2 型）

- 组成：**U1、U2、U4、U5、U6**。
- 序列特征：5′-**GU** … **AG**-3′。
- 分支位点：**A**；**嘧啶富含区（PPT）**位于分支位点与 3′ 端之间。
- **组装步骤**
  1. **U1** 识别 5′ 剪接位点（GU）；**U2** 定位到分支位点。
  2. **U4-U6 复合体 + U5** 替代 U1（U4、U6 可配对形成双链）。
  3. **U4 退出**，激活 U6。
  4. 分支位点 OH 进攻磷酸（第一次转酯）。
  5. 断裂处释放的 OH 进攻 3′ 端分界（第二次转酯）。

### 5.2　小剪接体（U12 型）

- 组成：**U11、U12、U4atac、U5、U6atac**。
- 边界：**AU-AC**；分支位点：**A**；有嘧啶富含区。

---

## 6　可变剪接（Alternative Splicing）

> **定义**：一个 pre-mRNA 的内含子有的被剪掉、有的被保留，从而产生不同成熟 mRNA。

### 6.1　类型

| 类型 | 说明 |
| :--- | :--- |
| **外显子跳读** | 某个外显子被跳过 |
| **外显子互斥** | 一对可变外显子中**一个且只有一个**被包含 |
| **5′ 选择性剪接** | 选用不同的 5′ 剪接位点 |
| **3′ 选择性剪接** | 选用不同的 3′ 剪接位点 |
| **内含子滞留** | 内含子保留在成熟 mRNA 中 |

- **SR 蛋白的浓度**可决定使用哪个 5′ 位点。

### 6.2　剪接定位机制

1. **共转录剪接**：剪接因子不等 RNA 转录完，而是被 RNA Pol II 的 **CTD 尾巴直接递送**到新生 RNA 上，从而有效**防止外显子跳读**。
2. **剪接调控蛋白**：**SR 蛋白**结合外显子内部的**剪接增强子**序列，招募剪接机器组件。

---

## 7　RNA 编辑

> **定义**：转录后通过改变 RNA 序列中的个别碱基（插入、删除或修改）来改变编码信息。

### 7.1　脱氨编辑

| 类型 | 酶 | 结果 |
| :--- | :--- | :--- |
| **C → U** | 胞嘧啶脱氨酶 | C 变 U |
| **A → I** | **ADAR** | A 变肌苷（I），翻译时被识别为 **G** |

### 7.2　gRNA 指导的 U 插入/删除

1. **gRNA 与 mRNA 配对**，mRNA 上未配对区域形成单链环。
2. **内切酶**在环处切断 mRNA。
3. **TUTase** 以 gRNA 为模板在断口处插入 U。
4. **RNA 连接酶**重新封接断端，完成修复。

---

## 8　mRNA 运输

1. **选择性运输的关键**：RNA 所结合的蛋白质组合（如 **SR 蛋白**和**外显子连接复合体 EJC**）。
2. **通道**：核孔复合体。
3. **能量**：**GTP**。
4. 负责运输的蛋白护送 mRNA 进入细胞质后**重新运回细胞核**，结合新的 mRNA。

<details>
<summary><b>自测 1：两次转酯反应的亲核试剂分别是什么？</b></summary>

第一次是**分支点 A 的 2′-OH** 攻击 5′ 剪接位点的磷酸，形成 2′-5′ 磷酸二酯键并生成套索；第二次是**上游外显子 3′-OH** 攻击 3′ 剪接位点，连接两个外显子、释放套索内含子。
</details>

<details>
<summary><b>自测 2：主要剪接体与小剪接体有何区别？</b></summary>

主要剪接体（U2 型）由 U1/U2/U4/U5/U6 组成，识别 **GU-AG** 边界；小剪接体（U12 型）由 U11/U12/U4atac/U5/U6atac 组成，识别 **AU-AC** 边界。两者分支位点都是 A，都有嘧啶富含区。
</details>

<details>
<summary><b>自测 3：A→I 编辑为什么相当于 A→G？</b></summary>

ADAR 把腺苷脱氨生成**肌苷（I）**；核糖体/翻译系统把 I 识别为鸟苷（G），因此密码子信息实际由 A 变为 G。
</details>

<details>
<summary><b>自测 4：剪接本身不消耗 ATP，为何还说剪接需要能量？</b></summary>

两次转酯反应是能量中性的；但剪接体的组装、snRNP 的招募与构象重排需要 ATP 水解提供能量。
</details>
