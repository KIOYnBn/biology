# 02 · 基因突变与修复

> [!abstract] 一句话定位
> 突变是**核苷酸替换、插入或缺失**引起的变异；内源（自发、复制差错、修复错误）和外源（化学、物理）因素都能诱发。细胞则靠**直接修复、切除修复、错配修复、重组修复与 SOS 修复**把损伤控制在可接受范围内。

## 1　突变概览

**定义**：由核苷酸**替换、插入、删除**引起的变异。

| 划分依据 | 类型 |
| :--- | :--- |
| 来源 | **自发突变**（碱基构象变化）、**差错复制**（绕过 DNA 损伤）、**修复时引入的错误**、**诱发突变** |
| 诱因 | 自发突变（复制过程中的变化）、诱发突变（化学试剂、物理因素） |
| 发生细胞 | **生殖细胞突变**（发生在形成配子的组织或配子中）、**体细胞突变** |

**自发突变的类型**：碱基互变异构、DNA 脱嘌呤、DNA 碱基脱氨基、滑序复性。

**自发突变率**

| 生物 | 突变率 |
| :--- | :--- |
| 细菌 | $10^{-8}$ |
| 动物 | $10^{-6} \sim 10^{-5}$ |
| 真菌 | $10^{-5} \sim 10^{-4}$ |

## 2　突变的分子机制

### 2.1　碱基替换（点突变）

| 类型 | 定义 |
| :--- | :--- |
| **转换** | 嘌呤 → 嘌呤，或嘧啶 → 嘧啶 |
| **颠换** | 嘌呤与嘧啶互换 |

**(1) 互变异构变换**——导致碱基对转换

- **酮式–烯醇式互变**：如胸腺嘧啶 T 异构，使 $\mathrm{AT} \rightarrow \mathrm{TG}$。
- **氨基–亚氨基互变**：涉及腺嘌呤 A（形成 C–A 错配）与胞嘧啶 C 的异构。

**(2) 碱基类似物**——能替代嘌呤或嘧啶参与 DNA 复制的小分子

| 类似物 | 模拟对象 | 特点 |
| :--- | :--- | :--- |
| 5-BU（BrdU / BUdR，$-\mathrm{OH} \rightarrow -\mathrm{Br}$） | T | 酮式 / 烯醇式异构概率高于 T |
| 2-氨基嘌呤（2-AP） | A | 腺嘌呤类似物 |

**(3) 烷化剂**——为核苷酸的氨基或酮基提供烷基的分子

- 结果：引起**碱基转化**，例如 $\mathrm{G-C} \rightarrow \mathrm{G-T}$。
- 常见物质：**EMS（乙基磺酸甲酯）**、**EES（乙基磺酸乙酯）**、**芥子气**。

**(4) 脱氨基**

- C、A、G 脱氨基形成酮基。
- $\mathrm{C} \rightarrow \mathrm{U}$，使 $\mathrm{CG} \rightarrow \mathrm{UA}$。
- $\mathrm{A} \rightarrow$ 次黄嘌呤（与 C 配对）。
- $\mathrm{G} \rightarrow$ 黄嘌呤（与 C 配对）。

### 2.2　插入或删除碱基

- 引起**移码突变**。
- **吖啶染料**：能插入或楔入 DNA 碱基对之间的小分子，造成增添 / 缺失。
- **脱嘌呤位点**：嘌呤与戊糖的 $1'$-糖苷键断裂，引起碱基缺失。

### 2.3　物理因素

| 因素 | 损伤机制 |
| :--- | :--- |
| **紫外线** | 形成**嘧啶二聚体（T–T）**，扭曲 DNA 结构，阻碍转录和复制 |
| **电离辐射** | 打断染色体，引起缺失、易位、染色体片段化；具有**剂量效应**（直接作用于染色体） |

## 3　突变的遗传效应

| 效应类别 | 说明 |
| :--- | :--- |
| **沉默突变** | 不影响功能，但产生多态性；发生于基因间隔区、内含子、非翻译区或为同义密码子 |
| **影响表型** | 发生在调控序列、关键氨基酸编码区；包括**无义突变**（产生提前终止密码）与**移码突变** |

> [!note] 与染色体畸变的区别
> 本节讨论**基因内部**的碱基变化；染色体片段或数目的改变见 [[遗传学/02-染色体与基因组/02-染色体畸变与核型分析|染色体畸变与核型分析]]。

## 4　DNA 修复系统

**总览**

| 修复方式 | 主要对象 | 关键机制 |
| :--- | :--- | :--- |
| 直接修复 | 嘧啶二聚体 | 光复活酶直接切开 T–T 化学键 |
| 切除修复（BER / NER） | 单链损伤 | 切除损伤片段后重新合成 |
| 错配修复 | 新合成链的错配碱基 | 依据甲基化状态识别模板链 |
| 同源重组修复 | DNA 双链断裂 | $3'$ 端入侵（详见 [[遗传学/03-遗传信息的维持与变异/03-重组与转座\|重组与转座]]） |
| 非同源性末端连接 | DNA 双链断裂 | 直接连接断端，可造成基因沉默；依赖粘性末端与 DNA 连接酶 |
| SOS 修复 | 严重损伤 | **差错倾向修复**，以突变率升高换取存活 |

### 4.1　直接修复（光修复）

- 原核生物的**光修复酶（PRE）**：切开 T–T 二聚体的化学键。
- 能量来源：蓝光 / UV（能量高）。

### 4.2　切除修复（真核与原核共有，针对单链损伤）

**碱基切除修复（BER）**

1. **糖苷酶**：切除受损碱基，形成 AP 位点。
2. **AP 内切酶**：切开单链。
3. **DNA POL**：填补缺口。
4. **DNA 连接酶**：封口。

**核苷酸切除修复（NER）**——修复 T–T 二聚体等体积较大的损伤

| 生物 | 关键酶 |
| :--- | :--- |
| 真核 | 多种酶参与 |
| 原核 | **UvrABC 内切酶**（UvrC 切割）、**UvrD 解旋酶**、**DNA POL Ⅰ** |

### 4.3　错配修复（MMR）

- **任务**：修复**新合成 DNA 链**上的碱基错配。
- **链识别机制**：依赖 **DNA 甲基化**——新链尚未甲基化，旧链已甲基化；由 **DNA 腺嘌呤甲基转移酶**催化。

**大肠杆菌（E. coli）实例**

| 蛋白 | 作用 |
| :--- | :--- |
| **MutS** | 识别错配部位，与 MutL 结合并弯曲 DNA |
| **MutL** | 介导 MutS 与 MutH 结合 |
| **MutH** | 与甲基化位点结合，被 MutL 激活后切割新链 |

### 4.4　双链断裂修复

- **同源重组修复**：以 $3'$ 端入侵同源模板，实现**无损**修复；机制见 [[遗传学/03-遗传信息的维持与变异/03-重组与转座|DSB 模型]]。
- **非同源性末端连接（NHEJ）**：不依赖同源模板直接连接断端，容易产生小的插入 / 缺失，甚至基因沉默。
- **SOS 修复**：损伤严重时启动的**差错倾向修复**，以引入突变为代价维持基因组完整性。

## 5　考点速记

- 突变按效应分：沉默（多态性）vs 影响表型（无义、移码、调控区、关键氨基酸）。
- 转换 = 同类碱基互换；颠换 = 嘌呤与嘧啶互换。
- 诱发因素：碱基类似物（5-BU、2-AP）、烷化剂（EMS、EES、芥子气）、吖啶染料（移码）、UV（T–T 二聚体）、电离辐射（染色体断裂）。
- BER 用糖苷酶 + AP 内切酶；NER 用 UvrABC（原核）/ 多种酶（真核）。
- 错配修复靠**甲基化区分新旧链**：MutS 识别 → MutL 介导 → MutH 切割。
- HR 精确、NHEJ 易错、SOS 是应急的差错倾向修复。

<details>
<summary><b>自测 1：错配修复如何判断哪一条链是错的？</b></summary>

DNA 甲基化提供标记：亲代模板链已甲基化，新合成链暂时未甲基化。MutS 识别错配后经 MutL 招募并激活 MutH，MutH 在未甲基化链的 GATC 位点切开，从而定向切除新链上的错误碱基。
</details>

<details>
<summary><b>自测 2：BER 与 NER 分别处理什么损伤？关键酶有何不同？</b></summary>

BER 处理小范围碱基损伤：糖苷酶切除碱基 → AP 内切酶切链 → POL 填补 → 连接酶封口。NER 处理体积较大的损伤（如 T–T 二聚体）：原核由 UvrABC 内切酶 + UvrD 解旋酶 + POL Ⅰ 完成，真核由多种酶参与。
</details>
