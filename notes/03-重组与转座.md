# 03 · 重组与转座

> [!abstract] 一句话定位
> 重组与转座都是**DNA 片段的重新组合**：同源重组依赖长同源区（Holliday / DSB / RecBCD 模型），位点特异性重组只需一小段同源区，转座则由可移动元件借助转座酶或逆转录酶完成。

## 1　同源重组

### 1.1　概念与作用

**概念**：两条相似或相同的 DNA 分子在**相同位置**发生交换。

**作用**

1. 修复 DNA 双链损伤断裂。
2. 减数分裂中交换遗传物质。
3. 促进物种间的水平基因转移。

### 1.2　Holliday 模型

- 核心中间体：**Holliday 连接体（Holliday junction）**。
- 结果取决于拆分方式：**横切**与**竖切**产生不同产物。

> [!tip] 理解要点
> 在 Holliday 模型和 DSB 模型中，**竖切的位置发生重组，横切的位置不发生重组**（个人理解笔记，供对照记忆）。

### 1.3　双链断裂修复模型（DSB）

用于同源重组修复 DNA 双链断裂。

| 步骤 | 事件 |
| :--- | :--- |
| 1 | 内切酶切断 DNA 双链 |
| 2 | 产生 $3'$ 端突出的单链 |
| 3 | 单链入侵同源 DNA |
| 4 | $3'$ 端延伸补齐 |
| 5 | 两个重组点连接，形成**双 Holliday 交叉** |
| 6 | 同向或异向切割重组叉（共**四种切法**），得到不同产物 |

### 1.4　RecBCD 模型（原核生物）

**RecBCD 复合物**：识别 DNA 双链断裂并解开双螺旋。

| 亚基 | 功能 |
| :--- | :--- |
| RecB | $3' \rightarrow 5'$ 解旋酶、核酸酶 |
| RecD | $5' \rightarrow 3'$ 解旋酶 |
| RecC | 识别 $\chi$ 位点（序列：**GCTGGTGG**） |

**过程**

1. 复合物识别断裂端口。
2. 解螺旋沿 DNA 移动至 $\chi$ 位点。
3. 切断单链，产生 $3'$ 单链并入侵同源链。
4. **RecA** 促成 Holliday 交叉形成。
5. **RuvABC** 驱动交叉端移动并切割：RuvAB 固定并旋转 Holliday 交叉，RuvC 执行切割。

### 1.5　重组的结果

| 类型 | 含义 |
| :--- | :--- |
| **相互重组** | 两条 DNA 分子对称交换片段 |
| **非相互重组** | 遗传信息单向转移（如基因转换） |

## 2　位点特异性重组

- **定义**：借助**一小段同源区**进行的 DNA 重组，由位点特异性重组酶（SSRs）催化。
- **过程（以 λ 噬菌体整合为例）**

| 组分 | 符号 |
| :--- | :--- |
| 噬菌体附着位点 | P–O–P |
| 细菌附着位点 | B–O–B |
| 核心同源区 | O |

1. 整合酶在核心同源区 O 切割，形成**粘性末端**。
2. 噬菌体 DNA 与细菌 DNA 相互连接。
3. 整合后结构：**B–O–P–P–O–B**。

> [!note] 与同源重组的区别
> 同源重组需要较长同源区和 RecA/Rad51 等蛋白；位点特异性重组只识别**特定短序列**，由专一重组酶完成。

---

## 3　随机体细胞重组

- 免疫球蛋白 DNA 在 B 细胞中发生**可变区序列的随机组合**。
- 是**抗体多样性**产生的基本原理。

## 4　转座元件

**可转座的遗传元件（Transposable Genetic Elements）**：能在基因组内改变位置的 DNA 序列。

### 4.1　细菌的转座元件

**插入序列（IS）与极性突变**

- 以**半乳糖操纵子**为例：结构为 $P\text{-}galE\text{-}galT\text{-}galK$
  - $galE$：半乳糖差向异构酶
  - $galT$：半乳糖-1-磷酸尿苷酰转移酶
  - $galK$：半乳糖激酶
  - 反应链：$\mathrm{gal} \xrightarrow{galK} \mathrm{Gal\text{-}1\text{-}P} \xrightarrow{galT} \mathrm{UDP\text{-}Gal} \xrightarrow{galE} \mathrm{UDP\text{-}Gal}$
- **极性突变**：某个基因的突变影响**下游基因**的表达。
  - 原因：基因插入引起移码突变（如 Gal-1-P 积累有毒性）。

**IS 的结构**

| 元件 | 说明 |
| :--- | :--- |
| 转座酶基因 | 编码转座酶（Transposase） |
| 末端颠倒重复 ITRs | 转座酶识别的末端序列 |
| 末端直接重复 DR | 由**交错切割**产生——IS 插入造成宿主序列重复 |

**DNA 转座机理**

| 方式 | 特点 |
| :--- | :--- |
| **非复制型转座** | 元件本身不复制，从一个位置移动到另一个位置 |
| **复制型转座** | 形成**复合转座子（Tn）**：两个 IS 元件夹带一段 DNA 一起转座 |

### 4.2　真核生物的可转座元件

**Ac/Ds 系统**

- **Ac**：完整的可转座元件。
- **Ds**：Ac 的突变体，**缺少转座酶基因**，需 Ac 提供转座酶才能移动。

**逆转座子**：借助 RNA 中间体反转录成 cDNA 后插入基因组。

| 类型 | 特征 |
| :--- | :--- |
| **LTR 逆转座子** | 与逆转录病毒相似：具有**逆转录酶**和**整合酶**；两端有 **LTR（长末端重复）**；转座过程 $\mathrm{DNA} \rightarrow \mathrm{RNA} \xrightarrow{\text{逆转录酶}} \mathrm{cDNA} \xrightarrow{\text{整合酶}} \mathrm{其他\,DNA}$ |
| **非 LTR 逆转座子** | 无 LTR；一端有 **AT 同源区**；编码逆转录酶；由 **RNA POL Ⅱ** 转录 |
| **逆转座子（不编码蛋白型）** | 与非 LTR 型相比**不编码蛋白**，借用非 LTR 逆转座子的逆转录酶；由 **RNA POL Ⅲ** 转录 |

> [!note] 基因组中的遗迹
> 非 LTR 逆转座子中的 LINE / SINE 属于分散重复序列，见 [[遗传学/02-染色体与基因组/01-染色体结构与基因组组织|染色体结构与基因组组织]]。

## 5　考点速记

- 同源重组三模型：Holliday（连接体横切 / 竖切）、DSB（$3'$ 端入侵、双 Holliday 交叉）、RecBCD（$\chi$ 位点 GCTGGTGG、RecA、RuvABC）。
- 竖切重组、横切不重组（记忆口诀）。
- 位点特异性重组只需短同源区 O；噬菌体整合产物 B–O–P–P–O–B。
- 随机体细胞重组 → 抗体多样性。
- IS 三类结构：转座酶基因 + ITR + DR；复合转座子 Tn = 两个 IS + 中间 DNA。
- LTR 型有 LTR 且编码逆转录酶 / 整合酶；非 LTR 型无 LTR、一端 AT 同源、POL Ⅱ 转录；不编码蛋白型借酶转座、POL Ⅲ 转录。

<details>
<summary><b>自测 1：RecBCD 复合物各亚基如何分工？</b></summary>

RecB 是 $3' \rightarrow 5'$ 解旋酶和核酸酶；RecD 是 $5' \rightarrow 3'$ 解旋酶；RecC 识别 $\chi$ 位点（GCTGGTGG）。复合物到达 $\chi$ 位点后切开单链，产生 $3'$ 端由 RecA 介导入侵同源链，最后 RuvABC 完成交叉迁移与切割。
</details>

<details>
<summary><b>自测 2：什么是极性突变？IS 插入为何会引起极性突变？</b></summary>

极性突变指一个基因的突变影响同一操纵子中下游基因的表达。IS 插入编码区会引入移码，使下游基因无法正常翻译（如半乳糖操纵子中 Gal-1-P 积累产生毒性），从而表现出极性效应。
</details>
