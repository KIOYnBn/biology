# 02 · 基因表达调控

> [!abstract] 一句话定位
> 原核生物用**操纵子**把功能相关基因串成多顺反子 mRNA，通过阻遏蛋白和衰减子快速响应环境；真核及更广泛的转录后层面则靠**选择性剪接、siRNA / miRNA 介导的基因沉默**精细调节表达量。

## 1　原核生物的基因调控

### 1.1　诱导现象与操纵子

**β-半乳糖苷酶的诱导现象**

- **诱导物不一定是该酶的底物**。
- **组成型突变**：
  - 体现**一因多效**。
  - 例：β-半乳糖苷酶基因同时控制**三种酶**的表达，对应**三种突变体**。

**操纵子（operon）**：被一起转录到**同一条 mRNA** 上的一簇基因，形成**多顺反子 mRNA**。

> [!note] 表型背景
> β-半乳糖苷酶同时影响多种酶的现象，也是「一因多效」的经典例证，见 [[遗传学/01-经典遗传学/01-绪论与孟德尔遗传扩展|绪论与孟德尔遗传扩展]]。

### 1.2　色氨酸操纵子（合成代谢）

**结构组成**

$$\mathrm{trpR} - \mathrm{trpP} - \mathrm{trpO} - \mathrm{leader} - \mathrm{trpE} - \mathrm{trpD} - \mathrm{trpC} - \mathrm{trpB} - \mathrm{trpA}$$

**结构基因及其产物**

| 基因 | 产物 |
| :--- | :--- |
| $trpA$ | 色氨酸合成酶 α 亚基 |
| $trpB$ | 色氨酸合成酶 β 亚基 |
| $trpC$ | 吲哚-3-甘油磷酸合成酶 |
| $trpD$ | 邻氨基苯甲酸合成酶组分 Ⅱ |
| $trpE$ | 邻氨基苯甲酸合成酶组分 Ⅰ |

**归纳**

- $trpA + trpB$ = **色氨酸合成酶**
- $trpD + trpE$ = **邻氨基苯甲酸合成酶**
- $trpC$ = **吲哚-3-甘油磷酸合成酶**

**调节元件**

| 元件 | 功能 |
| :--- | :--- |
| $trpR$ | 编码**抑制蛋白**；抑制蛋白与 $trpO$ 结合**需要色氨酸**作为辅阻遏物 |
| $trpP$ | 启动子 |
| $trpO$ | 操纵区（抑制蛋白结合位点） |
| $trpL$（前导区） | 含衰减子，通过形成不同发卡结构调控转录是否提前终止 |

**衰减机制**

- 前导区 mRNA 序列：$5'\text{-UGGUGG-1-2-3-4-UUUUU-}3'$
- 终止方式：**不依赖 ρ 因子**的终止。
- 同源区 1–2–3–4 可形成三种发卡结构：

| 配对方式 | 结果 |
| :--- | :--- |
| 1–2 和 3–4 | **终止**转录 |
| 2–3 | **衰减**（色氨酸缺乏时形成，转录继续） |

> [!important] 两个层次的实现
> $trpR$ / $trpO$ 负责**阻遏**起始；前导区负责**衰减**——即使抑制后，leader 仍可转录一小段，由色氨酸浓度决定是否提前终止。

## 2　转录后调控

### 2.1　选择性剪接

- 选择性剪接可产生多种 mRNA / 蛋白异构体。
- 笔记中提到相关**分子元件基因为 X 连锁**。
- 与 5′ 帽促进靠近 5′ 端内含子剪切的作用相呼应，见 [[遗传学/04-基因表达与调控/01-RNA加工与翻译|RNA 加工与翻译]]。

### 2.2　RNA 诱导的基因沉默

| 分子 | 定义 |
| :--- | :--- |
| **siRNA** | 小干扰 RNA，**双链** |
| **miRNA** | 短双链 RNA，由**内源基因转录**产生 |

**作用机制**

| 通路 | 过程 |
| :--- | :--- |
| siRNA | $\mathrm{dsRNA} \rightarrow \mathrm{siRNA} \xrightarrow{\mathrm{RISC}} \mathrm{单链RNA} \rightarrow \mathrm{mRNA\,配对}$ |
| miRNA（经典） | $\mathrm{miRNA\,gene} \xrightarrow{\mathrm{Dicer}} \mathrm{miRNA} \xrightarrow{\mathrm{RISC}} \mathrm{mRNA}$ |
| miRNA（转录调控） | $\mathrm{miRNA\,gene} \xrightarrow{\mathrm{Dicer}} \mathrm{miRNA} \xrightarrow{\mathrm{RITS}} \mathrm{调控DNA}$ |

### 2.3　环境调控

- 基因表达还受**环境因素**调节（如诱导物、温度、营养状态等）。

> [!note] 相关机制
> X 染色体失活也由长非编码 RNA（XIST）主导，是 RNA 介导调控的另一个典型例子，见 [[遗传学/05-专题遗传/01-性别决定与剂量补偿|性别决定与剂量补偿]]。

## 3　考点速记

- 操纵子 = 启动子 + 操纵区 + 结构基因簇 → 多顺反子 mRNA。
- 诱导物**不一定**是底物；组成型突变体现一因多效。
- 色氨酸操纵子结构基因：$trpE(D)$ 邻氨基苯甲酸合成酶 → $trpC$ 吲哚甘油磷酸合成酶 → $trpB(A)$ 色氨酸合成酶。
- $trpR$ 抑制蛋白需要**色氨酸**作为辅阻遏物才能结合 $trpO$。
- 衰减子：1–2 + 3–4 发卡 → 终止；2–3 发卡 → 衰减（色氨酸缺乏）。
- siRNA 双链、外源来源；miRNA 内源转录；Dicer 加工，RISC 靶向 mRNA，RITS 参与染色质 / DNA 层面调控。

<details>
<summary><b>自测 1：色氨酸操纵子如何通过衰减作用响应色氨酸浓度？</b></summary>

前导区 mRNA 含 1–2–3–4 四段同源区。色氨酸充足时核糖体顺利翻译前导肽，形成 3–4 终止发卡，转录提前终止；色氨酸缺乏时核糖体停滞，形成 2–3 发卡，3–4 无法配对，转录继续通过结构基因。
</details>

<details>
<summary><b>自测 2：siRNA 与 miRNA 的来源和作用方式有何不同？</b></summary>

siRNA 通常为外源或人工引入的双链 RNA，经 Dicer 加工后由 RISC 装载单链，与靶 mRNA 配对引导降解；miRNA 由内源基因转录产生，同样经 Dicer/RISC 通路抑制 mRNA，也可通过 RITS 参与 DNA / 染色质层面的调控。
</details>
