# 03 · 原肠作用与胚轴建立

> [!abstract] 本章速览
> 原肠作用是**囊胚细胞迁移形成三胚层和体轴**的过程，是胚胎发育的"关键一跃"。本章按动物类群展开：海胆（内移 / 内陷）→ 两栖类（组织者与 Nieuwkoop 中心）→ 鱼类（胚盾）→ 鸟类（原条 / 原结）→ 哺乳类（原条 / 着床）→ 果蝇（母体效应基因与体节）。
>
> 上一章 ← [[02-卵裂与囊胚形成]] ｜ 下一章 → [[04-器官发生总论与外胚层]]

---

## 3.1 原肠作用概述

- **定义**：囊胚细胞迁移的过程；形成内胚层和中胚层的细胞迁入内部，外胚层细胞位于外层。
- **原肠胚**：处于原肠作用期的胚胎。
- **结果**：形成三胚层胚胎结构 + 体轴建立。

**五种细胞运动方式（高频考点）**

| 运动方式 | 要点 |
| --- | --- |
| **内陷** | 局部区域内陷 |
| **内卷** | 外层细胞向内卷折，铺盖于外层细胞内侧 |
| **内移** | 单个细胞迁移到胚胎内部，变成间充质（独立迁移） |
| **分层** | 一层细胞分成两个细胞层 |
| **外包** | 上皮层作为整体包裹深层细胞 |

- 外包的机制：细胞分裂、细胞形状改变、细胞嵌插（减少细胞层数）。

## 3.2 海胆的原肠作用

- 发育阶段：三棱幼虫 → 长腕幼虫 → 成虫。
- 主要细胞运动方式：**内移**（后口动物）。

**过程**

1. **起始**：植物极加厚、扁平，形成植物极板。
2. **内移（中胚层）**
   - 中央小分裂球（16 细胞期位于胚胎最低端的 4 个细胞）内移进入囊胚腔，成为**初级间质细胞**——经历 EMT；
   - 小分裂球可诱导胚轴形成，使外胚层细胞分化为内胚层和中胚层；
   - 初级间质细胞伸出伪足，外胚层向内形成丝足，二者信息交流保证运动；
   - 细胞定位到腹两侧，形成索状合胞体并产生骨针，将来形成幼虫碳酸钙骨针主轴 → 称**成骨间质细胞**。
3. **内陷（内胚层）**
   - 植物极板内陷 1/2 或 1/4，陷入部分为**原肠**，其在植物极的开口为**胚孔**；
   - 植物极板细胞分泌 CSPG（硫酸软骨素蛋白聚糖）到透明层内层，使其吸水膨胀而外层不变；
   - **透明层**：皮层颗粒释放透明质素在卵周隙吸水膨胀，附着于受精膜内侧形成胶状层，有助于卵裂球互相黏着。
4. **集中延伸**：原肠细胞彼此嵌插，使原肠变细变长。
5. **口形成**：原肠顶端细胞形成次级间质细胞，伸出伪足附着囊胚腔壁内表面，牵拉原肠与之融合形成口。

## 3.3 两栖类的原肠作用

### 3.3.1 前提与起始

- **前提**：中期囊胚转换（合子基因组激活）→ 不同细胞转录不同基因组、卵裂球获得运动能力。
- **起始**：赤道附近（灰色新月区）内陷 → 形成**瓶状细胞**，排列方向即原肠形成方向；瓶状细胞挤入深层并拉动边缘区细胞迁移，将植物极细胞拉入胚胎内部；瓶状细胞最终变成方形，成为原肠腔壁细胞，最后形成前肠咽部细胞。
- **内部缘区细胞内卷**
  - 胚孔背部预定形成脊索中胚层和头部中胚层的细胞内卷；
  - 动力：深层缘区细胞的内卷；
  - 迁移机制：原肠运动前预定外胚层细胞分泌**纤连蛋白**，内卷细胞的**整合素**结合，提供粘附位点与运动方向。
- **集中延伸**：预定脊索中胚层细胞形成轴性中胚层，出现极性。
- **外包**：动物极外胚层细胞覆盖整个胚胎（细胞分裂 + 数层合并为单层）。
- **完成**：囊胚腔消失 → 三胚层形成（外包的上皮细胞 → 外胚层；内卷入囊胚腔的 → 中胚层；卵黄栓 → 内胚层）。

> [!note] 囊胚腔的作用
> 为原肠运动提供空间，并分隔植物极与动物极细胞（承接 [[02-卵裂与囊胚形成#2.5 囊胚形成与中期囊胚转换]]）。

### 3.3.2 胚孔与卵黄栓

- 瓶状细胞内卷形成的小孔为**胚孔**，内凹的唇形结构为**背唇**（胚胎背面）。
- 背唇向侧面、腹面扩散形成侧唇和腹唇；随内卷胚孔形成环状，包绕植物极细胞。
- 暴露在植物极外的内胚层细胞为**卵黄栓** → 形成内胚层。
- **胚孔定位**：精子入卵点对面的一组植物极卵裂球上，由细胞因子的不对称分布决定；精子入卵点形成腹面，胚孔定位处为背面与原肠作用起始处。

### 3.3.3 脊索的作用

- 临时性支撑结构：坚韧、半透明、有弹性、圆柱形、不分节。
- 后退化为结缔组织形成的软骨或硬骨脊柱取代。
- **核心作用：诱导神经系统分化**。

### 3.3.4 胚轴建立

| 轴 | 建立机制 |
| --- | --- |
| **背腹轴** | 灰色新月区形成背部，精子入卵点形成腹部 |
| **前后轴** | 背腹轴建立之后；先迁入通过背唇的中胚层细胞形成前端（动物极），侧唇与腹唇形成后端（植物极） |
| **左右轴** | 受精后细胞质旋转，使细胞质动植物极轴与表面动植物极轴偏移 30%，形成左右对称 |

### 3.3.5 原肠运动组织者（Spemann 组织者）

- **组织者**：背唇及其衍生组织（预定脊索和头部中胚层），具有自我分化能力并能诱导邻近细胞发生原肠作用。
- **作用**
  1. 启动原肠作用；
  2. 发育成背部中胚层；
  3. 诱导周围中胚层背部化形成侧板中胚层；
  4. 诱导外胚层背部化形成神经板，进而发育成神经管。

**Nieuwkoop 中心**

- 两栖类囊胚中，胚孔下最靠近背侧的植物极细胞，可诱导组织者形成；位于背方。
- 因此原肠作用中，**预定内胚层细胞（植物极）诱导预定外胚层细胞（动物极）形成预定中胚层细胞**。
- **β-catenin** 是形成 Nieuwkoop 中心的主要细胞因子（母体效应基因）：
  - 受精卵旋转使其在背部积累，覆盖组织者与 Nieuwkoop 中心；
  - DSH 与 GBP 也随微管向背部转运；Wnt11 mRNA 可扩增信号；
  - 背侧 DSH 抑制 GSK-3 的磷酸化，保护 β-catenin；Wnt 激活并稳定 β-catenin。
- **β-catenin 的两大功能**：① 锚定细胞膜的钙黏着蛋白；② 作为 Wnt 通路中核内转录因子的激活因子。
- **Wnt 通路**：Wnt → Frz → DSH → GSK3β 降解复合体解散 → β-catenin 入核 → TCF/LEF 转录因子 → 下游基因激活。
- **通路机理**：β-catenin 与 TCF3 转录因子结合，激活 *siamois*、*twin* 基因，并与 TGF-β 通路的 Smad2 协同参与组织者基因增强子表达。

### 3.3.6 Xnr 浓度对中胚层分化的影响

| Xnr 浓度 | 分化命运 |
| --- | --- |
| 高 | 组织者 |
| 中 | 侧板中胚层 |
| 低 | 腹部中胚层 |

- 通路：VegT（TGF-β 家族）与 Vg1（TGF-β 家族配体）结合激活 Xnr → Xnr 激活受体磷酸化 → Smad2 入核 → 调控下游基因（如 *sox17*）。

## 3.4 鱼类的原肠作用

**中期囊胚转换与胚盘层**

| 层次 | 命运 |
| --- | --- |
| 包被层 | 表皮化单层细胞，后期脱落 |
| 深层细胞 | 发育成胚胎本体 |
| 卵黄合胞体层 | 靠近植物极的胚盘细胞与卵黄融合形成，环状排列 —— 组织者产生、图式分化 |

**原肠运动**

1. 深层细胞向外移动，卵黄细胞向外推动形成内 / 外卵黄合胞体层。
2. 覆盖大半卵黄后深层细胞增厚形成**胚环**：
   - 上胚层 → 外胚层；
   - 下胚层 → 内胚层和中胚层（背部由上胚层细胞内移形成，腹部由上胚层内卷 + 下胚层细胞内卷并增殖形成中胚层）。
3. 上下胚层细胞在背侧相互嵌插，胚环某处增厚形成**胚盾**：
   - 背侧：细胞汇聚延伸，形成脊索中胚层（*notail* 基因）、轴旁中胚层（*snail* 基因）与内胚层；
   - 腹侧：胚环在植物极闭合；
   - 脊索中胚层外表面的上胚层细胞集中延伸形成神经龙骨 → 中空神经管，其余上胚层细胞发育成皮肤。
4. **胚盾与背唇同源，具组织者作用**：将预定侧板 / 腹部中胚层转化为背部中胚层（脊索 / 体节），诱导外胚层形成神经细胞。

**羊膜**：爬行类、鸟类、哺乳类具羊膜卵；胚外膜包括绒毛膜（包裹卵黄膜、尿囊、羊膜），尿囊与母体进行物质交换。

## 3.5 鸟类的原肠作用

### 3.5.1 输卵管结构与产蛋过程

| 部位 | 功能 |
| --- | --- |
| 漏斗部 | 输卵管起始部，受精场所，摄入卵子 |
| 膨大部（蛋白分泌部） | 腺体丰富，分泌蛋白、盐 |
| 峡部 | 分泌蛋白，形成内 / 外壳膜；开始第一次卵裂 |
| 子宫（壳腺部） | 分泌碳酸根，与血钙形成碳酸钙蛋壳 |
| 阴道 | 形成蛋外层胶质层 |

**产蛋时间线**：精子入卵 3–5 h 到峡部开始第一次卵裂 → 20 min 后第二次卵裂 → 进入子宫才发生纬裂形成胚盘 → 2 h 后卵裂至 32 细胞 → 到达子宫 20 h 后发育到囊胚期（盘状囊胚）→ 产蛋。

### 3.5.2 上胚层与下胚层

- 大部分细胞处于表面、一层细胞厚，为**上胚层**。
- 上下胚层围成的腔相当于囊胚腔；**鸟类胚胎完全来自上胚层**；下胚层形成部分胚外结构（主要是卵黄囊和连接卵黄与消化管的基柄）。
- 形成过程：上胚层**内移**形成初级下胚层；明区与边缘区之间的后部边界处，一层细胞在表面下向前迁移，与下胚层岛组合形成完整下胚层，又称次级下胚层 / 内胚层。

### 3.5.3 原条与原结（亨氏结）

- **原条形成**：Koller 镰形区（产蛋后明区后缘）及其上部上胚层细胞加厚，从后向前延伸；细胞分裂与集中延伸共同促进原条伸长。
- **原沟**：原条中央的凹陷；与两栖类**胚孔同源**，原条与胚孔唇同源。
- **原结（亨氏结）**：原条前端加厚区，即**组织者**；中央漏斗状凹陷为原窝。亨氏结先向前移到明区中央，随后固定与原条共同后退，内部细胞长出脊索，最后退到肛门处；前端先形成脊索。
- **亨氏结分泌分散因子**，使内移细胞变成松散间质细胞（上皮性细胞分散 → 间质细胞）；上胚层细胞产生透明质酸包裹细胞，保持迁移细胞松散。

### 3.5.4 胚层形成与原条后退

- 胚层细胞通过原沟进入囊胚：
  - 前端最先进入：咽部中胚层；随后：头部中胚层、脊索；
  - 后部进入：其他组织；两侧：内胚层器官、胚外结构；剩余形成中胚层及少量胚外结构。
- **原条后退**：亨氏结移至明区中央时与原条一起后退，过程中长出脊索；退至最后端将形成肛门区；胚胎前端比后端发育提前。
- **外胚层下包**：暗区边缘细胞是下包动因。
- **结果**：外胚层位于最外层包裹卵黄；内胚层代替下胚层；形成中胚层。

### 3.5.5 胚轴形成与后端诱导

| 轴 | 机制 |
| --- | --- |
| **背腹轴** | 标志：囊胚期上下胚层分化；机制：电位差。**正电为腹侧**（靠近卵黄侧），**负电为背侧**（上胚层外表面，蛋清一侧） |
| **前后轴** | 清蛋黄成分在输卵管中被旋转到胚盘一侧形成前端；原条在后端形成，由后部边缘区诱发 |

- **后端边缘区诱导原条发生**，类似于爪蟾的 Nieuwkoop 中心。

## 3.6 哺乳类的原肠作用

- **标志**：原条的出现；**少黄卵**；原肠作用起始于内细胞团。
- **特点**：形成胚盘、形成羊膜腔、卵黄囊退化。

### 3.6.1 着床与胚外结构

- 内细胞团分化为**上胚层（胚胎）**和**下胚层（卵黄囊）**；上胚层细胞间出现缝隙并合并形成羊膜腔（防止失水、缓冲撞击、保护胎儿）。
- **胚泡孵化**：胰蛋白酶消化透明带 + 渗透作用。
- **着床**：滋养层细胞侵入子宫内膜；进入子宫后部分细胞只进行核分裂形成合胞体滋养层并融入子宫，内侧单核细胞形成细胞滋养层；两层形成绒毛突入子宫。
  - 滋养层通过黏着分子附着子宫内膜；
  - 滋养层蛋白水解酶降解子宫细胞外基质，使胚泡埋入子宫壁。
- **绒毛膜**：合胞体滋养层 + 胚外中胚层；分泌激素、保护胎儿免受免疫排斥（抗体仍可进入）。
- **胎盘**：绒毛膜 + 子宫膜（母体部分称蜕膜），双向扩散；母体血管进入绒毛膜；滋养层出现滋养层陷窝，母体血管侵入并为胚胎提供营养。

### 3.6.2 原肠运动

1. 胚盘形成长椭圆形，头部宽、尾部小。
2. 原条形成，与鸟类类似。
3. 上胚层细胞内迁移：一部分替换下胚层形成内胚层，一部分形成中胚层。
4. 头尾两端各留双胚层区：顶部为**口咽膜**，尾部为**泄殖腔膜**（原肠与羊膜腔开口）。
5. 脊索形成：原结迁移来的中胚层细胞沿正中线形成脊索原基；脊索腹侧壁与内胚层融合形成**神经肠管**，随后分离闭合；神经-肠管顶壁演变成脊索，脊索最终退化为成人椎间盘的髓核。
6. 40 天妊娠后，胚胎被羊膜包裹，外面再被绒毛膜包被。

### 3.6.3 双胎与绒毛膜功能

| 分离时间 | 结果 |
| --- | --- |
| 滋胚层形成前分离 | 独立绒毛膜、独立羊膜 |
| 滋胚层形成后、羊膜形成前分离 | 独立羊膜（共用绒毛膜） |
| 羊膜形成后分离 | 连体婴儿 |

**绒毛膜激素**：HCG（绒毛膜促性腺激素 → 维持黄体、促使胎盘细胞产生孕酮）；孕酮（使子宫壁增厚、布满血管）；绒毛膜催乳素 PRL（乳房发育与泌乳）。同时抑制母体对胎儿的免疫排斥。

## 3.7 果蝇的原肠作用及胚轴建立

### 3.7.1 原肠作用

- **起始**：腹部中线细胞内褶形成**腹沟** → 脱离表面形成腹管 → 中胚层细胞从腹管表面脱离到达预定位置，形成肌细胞、脂肪体、生殖腺。
- **胚带伸展**：后躯干部移到背侧，胚胎弯曲形成头沟；**胚带**是构成躯干腹部的胚层。
- **内、外胚层分化**：腹沟前后两端形成凹窝，在胚胎中部融合形成中肠、前肠、后肠；腹部外胚层部分细胞内移覆盖腹神经索，形成成神经外胚层；剩余外胚层向背中线迁移、闭合形成表皮层。
- **副体节**：胚带伸展中细胞分化形成的重复节段结构；随后胚带回缩形成真正体节。

### 3.7.2 母体效应基因与形态发生素

- 卵到成体都具有前后轴和背腹轴，由**卵子与卵泡细胞相互作用**决定；卵位于卵室时胚胎极性已确立。
- **母体效应基因**：卵子发生中滋养细胞合成并转运到卵子的 mRNA，受精后立刻翻译。
- **形态发生素**：母体效应基因的蛋白产物。
- **Gurken 通路**：Gurken → TORPEDO 受体 → 蛋白激酶 A → 微管定向（生长端位于后部）；Bicoid mRNA 与动力蛋白结合运至卵前端，Oskar mRNA 与驱动蛋白结合运至卵后端。

### 3.7.3 前后轴建立

体节从前到后：原头、头节、胸节、腹节、尾节。

| 组织中心 | 关键基因 | 作用 |
| --- | --- | --- |
| **前端（头胸）** | *bicoid*（母体效应基因，前部形态发生素） | 3′ 非翻译区与 mRNA 定位有关；前端翻译、前端积累并向后端扩散降解，形成浓度梯度；作为转录调节因子激活 *hunchback* → HB 蛋白前高后低梯度；BCD 蛋白超阈值才表达，不同基因启动子阈值不同 |
| **后端（腹部）** | *nanos*（母体效应基因） | 从后向前浓度梯度，抑制 Hunchback 翻译 |
| **后端（腹部）** | *caudal* | 从前往后浓度梯度；BICOID 抑制其翻译 |
| **末端** | *torso* / *torsolike* | 跨膜酪氨酸激酶受体，自身磷酸化启动激酶活性；失活导致前端原头区和后端尾节缺失；在合胞体表面表达 |

### 3.7.4 背腹轴

- 卵母细胞体积增大，微管将细胞核推向前端背部，因此只有背部卵泡细胞的 TORPEDO 受体能接受 Gurken 信号，抑制 Pipe 蛋白合成。
- **Dorsal 通路**：受精后 90 min 翻译，Dorsal 蛋白分布全身，随后仅腹部进入核内。
  - 腹侧卵泡细胞 → Spatzle 蛋白 → 卵细胞膜 TOLL 蛋白 → CACTUS 蛋白降解 → DORSAL 入核 → 激活合子基因 *twist*、*snail*，抑制 *dpp*、*zen*；
  - 背侧表达 *dpp*、*zen*。
- **突变效应**：*Dorsal* 突变 → 背部化；*Cactus* 突变 → 腹部化。

### 3.7.5 体节分化与同源异型

**体节结构**：头节（大颚、下颚、唇部）；胸节（前胸—腿，中胸—腿和翅，后胸—腿和平衡棒）。

**分节基因调控层级**

| 基因类别 | 突变表型 | 要点 |
| --- | --- | --- |
| **缺口基因** | 连续体节缺失 | 一组合子基因，如 *hunchback*；使分节明显、体节数量正常 |
| **成对规则基因** | 每隔一个体节缺失一部分 | 缺口基因下游；形成 14 个副体节（胚胎基因表达活性区域的基本单位）；突变后仅剩奇数或偶数副体节；如 *eve*，具增强子模块化（每个增强子调节一个或一对条带） |
| **体节极性基因** | 每个体节都出现缺陷（缺失、重复、极性反转） | 在每个体节特定区域表达，形成副体节界限；*wg* 基因在体节最前端，*En*、*Hh* 在体节最后端 |
| **同源异型基因（HOM-C）** | 一个体节变成另一个体节的形态 | 转录因子，调控其他基因表达，决定体节发育命运；两组复合体：触角足复合体（头部和前胸）、双胸复合体（后胸和腹部） |

**调控通路**：母源基因 → 缺口基因 → 成对规则基因 → 体节极性基因 + 同源异型基因。

### 3.7.6 果蝇图式形成总结

1. 前后轴与背腹轴分别**独立地**由母体效应基因产物决定。
2. 这些母体效应基因主要编码转录因子，其产物形成**浓度梯度**并产生位置信息，进一步激活一系列合子基因：缺口基因、成对规则基因、体节极性基因。
3. 随着这些基因表达，胚胎被分成不同区域；每个区域表达特异性基因组合，沿前后轴形成间隔性图式，即体节前体形式。
4. 最后每一体节通过 **HOM-C 基因**的特异性表达确定其特征。
