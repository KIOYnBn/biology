# 02 · 染色体畸变与核型分析

> [!abstract] 一句话定位
> 先靠**分带技术**把染色体「看得清、认得准」，再按**数目变异**（整倍体 / 非整倍体）和**结构变异**（缺失 / 重复 / 倒位 / 易位）两条线索梳理畸变的类型、成因与表型效应。

## 1　染色体识别与核型

### 1.1　染色体分带

染色体经化学试剂处理后染色不均一，形成可识别的带纹。

| 带型 | 方法 | 观察重点 |
| :--- | :--- | :--- |
| **Q 带** | 奎吖因染色，荧光显微镜观察 | 富含 AT 的区域（异染色质）结合染料 |
| **G 带** | 胰蛋白酶消化 → Giemsa（吉姆萨）染色 | 染色可永久保存，最常用 |
| **C 带** | Giemsa 染色 | 着丝粒或组成型异染色质 |
| **R 带** | 与 G 带相反 | G-C 丰富区显现 |
| **T 带** | 专染端粒 | 端粒区域 |
| **m-FISH** | 携带不同荧光素的核酸探针与染色体杂交 | 多色区分各条染色体 |

**带纹命名需依次标注四级标记**：① 染色体序号 → ② 臂序号 → ③ 区序号 → ④ 带序号。

### 1.2　核型（karyotype）

- **定义**：体细胞中染色体的**结构和数目**特征。
- **写法**：染色体总数，性染色体组成。
- **示例**：`46,XY`（男性）、`46,XX`（女性）。

> [!note] 与性别决定的分工
> 性染色体组成如何决定性别，见 [[遗传学/05-专题遗传/01-性别决定与剂量补偿|性别决定与剂量补偿]]；本节只负责「如何识别与描述」。

## 2　染色体数目变异

### 2.1　非整倍性变异

**定义**：增加或丢失**一条或几条**染色体。

| 类型 | 核型 | 说明 |
| :--- | :--- | :--- |
| 单体性 | $2n-1$ | 某一对染色体丢失一条 |
| 双单体性 | $2n-1-1$ | 两对染色体各丢失一条 |
| 缺体性 | $2n-2$ | 某一对染色体全部丢失 |
| 三体性 | $2n+1$ | 某一对染色体多一条 |
| 四体性 | $2n+2$ | 一对染色体变成两对 |

**成因**

1. **染色体不分离**
   - 同源染色体不分开：四个配子均异常 → 2 个三体 + 2 个单体。
   - 姐妹染色单体不分开：一半配子异常 → 1 个三体 + 1 个单体。
2. **有丝分裂中 X 染色体丢失**：产生 `46,XX` 与 `45,X` 细胞系，个体仍能存活。

**表型效应**

- **单体**：除 $45,X$ 外一般致死；致死原因是**隐性致死基因假显性**。
- **三体**：多一条较大常染色体一般致死；多数源于**母亲卵子染色体不分离**。
  - 典型例：**21-三体综合征（唐氏综合征）**。

### 2.2　整倍性变异

**定义**：染色体**成套**增加或减少。

| 类型 | 定义 | 成因 | 表型效应 |
| :--- | :--- | :--- | :--- |
| **同源多倍体** | 同一基因组成倍增加 | 染色体不分离、多受精、杂交、有丝分裂异常（低温、秋水仙素诱导） | 动物一般死亡 |
| **异源多倍体** | 不同物种的完整基因组混合 | 近缘物种杂交 | 植物中较常见 |

## 3　染色体结构变异

**总成因**：染色体断裂后**错误重接**。基本类型包括缺失、重复、倒位、易位。

### 3.1　缺失（deletion）

- 染色体的一部分丢失。
- 类型：
  - **末端缺失**：断裂后不再重接。
  - **臂内缺失**：两处断裂后中间片段丢失、两端重接。
- 细胞学效应：染色体**长度改变**；减数分裂联会时出现**缺失环**。
- 典型例：**猫叫综合征**——5 号染色体短臂末端缺失。

### 3.2　重复（duplication）

> [!warning] 术语辨析
> **重复 duplication** 指染色体片段多出一份或几份；**复制 replication** 指 DNA 合成。两者不可混用（→ [[遗传学/03-遗传信息的维持与变异/01-DNA复制|DNA 复制]]）。

- 类型：**顺接重复**、**反接重复**。
- 成因：反转座、不等交换（→ [[遗传学/03-遗传信息的维持与变异/03-重组与转座|重组与转座]]）。
- 遗传效应：
  - **基因冗余**（如 rDNA，属于正常现象）。
  - 表型变异。
- 进化意义：为**新基因的产生提供原材料**。

### 3.3　倒位（inversion）

- 染色体片段颠倒 $180^\circ$ 后重接。
- 类型：
  - **臂内倒位**：倒位片段**不包含**着丝粒。
  - **臂间倒位**：倒位片段**包含**着丝粒。
- 细胞遗传学效应：
  - 联会时出现**倒位环**。
  - 倒位环内的基因**交换被抑制**：一旦发生交换，会产生重复、缺失、双着丝粒或无着丝粒染色体，导致死亡，只有未交换的染色体被保留下来。

### 3.4　易位（translocation）

- 一条染色体的片段移到另一条染色体上。

| 类型 | 定义 |
| :--- | :--- |
| 相互易位 | 非同源染色体之间**交换**片段 |
| 单向易位 | 一条染色体的片段移到另一条染色体 |
| 移位 | 片段移到**同一条**染色体的另一个位置 |
| 罗伯逊易位 | 两条近端着丝粒染色体的**长臂相接** |

- 遗传效应：**相互易位杂合体**在减数分裂联会时形成**十字形结构**，产生**半不育**（约一半配子致死）。

## 4　考点速记

- 分带：G 带最常用且可永久保存；Q 带看 AT；R 带与 G 带相反；C 带着丝粒；T 带端粒；m-FISH 多色区分。
- 核型写法：总数 + 性染色体，如 `46,XX`。
- 单体 $2n-1$、缺体 $2n-2$、三体 $2n+1$、四体 $2n+2$；双单体 $2n-1-1$。
- 单体致死原因是**假显性**；三体多因母方卵子不分离；$45,X$ 是唯一可存活的单体。
- 缺失环、倒位环、联会十字架分别是缺失、倒位、相互易位的细胞学标志。
- 倒位抑制重组；相互易位杂合体半不育。

<details>
<summary><b>自测 1：倒位为什么会导致倒位环内基因的重组被抑制？</b></summary>

倒位杂合体联会时形成倒位环；若环内发生交换，会产生带重复、缺失、双着丝粒或无着丝粒的异常染色体，配子死亡，因此能存活的子代只来自未发生交换的染色体，表现为重组被抑制。
</details>

<details>
<summary><b>自测 2：如何区分同源多倍体与异源多倍体？</b></summary>

同源多倍体的多套染色体来自**同一物种**（如染色体不分离、多受精、秋水仙素诱导）；异源多倍体来自**不同物种完整基因组的杂交组合**（近缘物种杂交）。
</details>
