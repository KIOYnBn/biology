# 08 · 胚后发育

> [!abstract] 本章速览
> 胚后发育 = 出生 / 孵化后的**生长、变态、再生、衰老与死亡**。重点掌握骨发生两种方式、生长的内分泌调控、昆虫与两栖类变态的激素机制、再生的四种类型及衰老学说。
>

---

## 8.1 概述

- **定义**：幼体从卵膜孵化或从母体生出后的发育过程，包括生长、衰老死亡。
- **直接发育动物** vs **间接发育动物**（变态：昆虫、两栖类）。

---

## 8.2 生长

- **个体水平**：重量、体积增加。
- **细胞水平**：数目、体积增加，细胞间质积累。

**成体干细胞维持的组织更新**

| 组织 | 更新路径 |
| --- | --- |
| 肌肉 | 卫星干细胞 → 肌细胞 → 修复肌纤维 |
| 表皮 | 表皮基底层干细胞 → 角质形成细胞 → 角质层细胞 |
| 肠 | 小肠隐窝干细胞 → 肠上皮细胞 |

### 8.2.1 骨发生

| 方式 | 过程 |
| --- | --- |
| **膜内成骨** | 间充质细胞部分直接发育成骨细胞 |
| **软骨内成骨** | 间充质细胞先形成软骨，随后被骨细胞替代 |

**软骨内成骨五步**

1. **定型**：间充质细胞定型为软骨细胞；
2. **致密**：细胞密集成结节；
3. **增殖**：细胞增殖并分泌软骨膜；
4. **生长**：肥大软骨细胞；
5. **软骨细胞凋亡 + 新骨形成**：血管入侵带来成骨细胞与破骨细胞——成骨细胞分泌类骨质，破骨细胞形成中空骨髓腔以容纳造血骨髓。

- **骨的延长**：骨两端骨化点形成**次级骨化中心**，逐渐骨化，仅外侧保留软骨（**骨骺生长板 / 软骨板**），其细胞增殖使骨延伸。

### 8.2.2 动物生长的调控

- **幼体生长**：无新器官形成。
  - 分阶段持续生长：主要在出生后一年或半年、青春期两个快速发育期；
  - 器官**异律生长**（不同器官生长速度不同）；
  - **大脑保护效应**：子宫内营养不良时优先维持大脑发育。
- **激素调控**（腺垂体来源：外胚层）
  - 下丘脑：生长激素释放激素、生长激素抑制素 → 垂体：生长激素 → **IGF-1（胰岛素样生长因子）** → 促进生长（受 IGFBP 调节）。
- **生殖生长**：性成熟（生殖腺系统功能成熟）后的一段生长期，出现第二性征 / 变态。

四肢软骨模型经软骨内成骨形成骨，见 [[07-四肢发生#7.5 人四肢发生时间线]]。

## 8.3 变态

**定义**：幼体到成体的结构变化过程；成体一般用于繁殖，幼体一般用于生长或扩散。
**共同机制**：幼体结构大部分程序性死亡，成体器官来自**成虫细胞**（成虫盘、成虫细胞簇、成虫组织细胞）；幼体细胞执行幼体功能。

### 8.3.1 昆虫变态

- **蜕皮**：节肢动物成年前的角质退化脱落。
- **类型**：非变态发育（预若虫期，类似成体，经历蜕皮）、半变态发育、完全变态发育（幼体期 + 蛹）。
- **龄**：换羽之间的时期；最后一龄为变态换羽。

**激素调控**

| 激素 | 作用 |
| --- | --- |
| **20-羟基蜕皮激素** | 启动、协调蜕皮 |
| **保幼激素** | 与蜕皮激素拮抗，保证幼体蜕皮的结果仍是幼体 |

### 8.3.2 两栖类变态（蛙）

- 尾退化、四肢形成、颅骨骨质化、牙齿退化与舌肌发育、肠变短、鳃衰退与肺变大。
- **激素调控**：甲状腺激素 **T4、T3（三碘甲状腺激素）**。

## 8.4 再生

| 类型 | 机制 |
| --- | --- |
| **变形再生** | 直接转分化 |
| **新建再生** | 去分化 → 再分化 |
| **干细胞介导的再生** | 成体干细胞参与 |
| **补偿性再生** | 已分化细胞分裂产生具类似功能的细胞 |

**哺乳动物再生**

- **鹿角**：哺乳动物自然情况下唯一能周期性完全再生的器官。
- **肝补偿性再生**：成体干细胞进行补偿性再生；肝组细胞进行新建再生。

---

## 8.5 衰老

- **定义**：生物体形态、结构、生理功能衰退，是**损伤积累**的过程。
- **自由基学说**：化学键均裂形成带孤电子的基团，诱导氧化反应 → DNA 损伤、基因突变、诱导肿瘤；当活性氧 ROS 超过抗氧化剂消除能力时发生**氧化应激**。
- **寿命基因相关通路**

| 类别 | 要点 |
| --- | --- |
| DNA 修复酶 | 修复损伤 |
| 胰岛素信号途径 | mTORC1 促进 mRNA 翻译；降低含量促进衰老细胞自噬 |
| 染色质修饰 | 组蛋白去乙酰化酶 |
| 端粒酶 | 维持端粒长度 |
