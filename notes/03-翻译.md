# 03 · 翻译

> [!abstract] 一句话定位
> 翻译是**以 mRNA 为模板、按遗传密码聚合氨基酸**的过程。核心是三件事：起始时把核糖体精准放到 AUG 上，延长时靠小沟识别 + 动力学校对保真，终止时由释放因子而非 tRNA 识别终止密码子。

## 1　总论

- **翻译定义**：以 mRNA 为模板，按照遗传密码规则，聚合氨基酸产生蛋白质的过程。
- **四大核心组分**
  1. **mRNA**：5′ cap — 5′ UTR — 编码区 — 3′ UTR — 3′ poly(A) tail。
  2. **tRNA**：核酸密码 ↔ 氨基酸的物理桥梁。
  3. **氨酰-tRNA 合成酶（aaRS）**。
  4. **核糖体**。
- **ORF**：mRNA 上从起始密码子到终止密码子的连续三联体序列，是实际编码蛋白质的区域。
  - 三联体密码：3 个相邻碱基决定 1 个氨基酸。
  - **起始密码子：AUG**（编码第一个氨基酸）。
  - **终止密码子**：UAG、UGA、UAA。
- **多聚核糖体**：多条核糖体同时翻译一条 mRNA。

### 1.1　能量消耗

| 阶段 | 消耗 | 目的 |
| :--- | :--- | :--- |
| 活化 | **1 ATP** | 把氨基酸连接到 tRNA，为肽键形成储备能量 |
| 延伸 | **1 GTP** | EF-Tu 护送 tRNA 并校对 |
| 延伸 | **1 GTP** | EF-G 驱动核糖体在 mRNA 上移动 |
| 起始 | GTP | IF2 等驱动大小亚基组装 |
| 终止 | GTP | RF3 等驱动核糖体解体 |

## 2　mRNA

| 特征 | 原核生物 | 真核生物 |
| :--- | :--- | :--- |
| ORF 数量 | 常为**多顺反子** | 常为**单顺反子** |
| 核糖体招募 | 5′ UTR 的**核糖体结合位点 RBS** 与 16S rRNA 互补配对，直接定位到起始密码子附近 | 依赖 **5′ 帽**招募核糖体 |
| 起始上下文 | RBS 匹配度及与 AUG 的距离决定效率 | **Kozak 序列**（G/ANNAUGG）增强效率，与起始 tRNA 相互作用 |
| 3′ 端辅助 | 无特殊 | **poly-A 尾**招募起始因子，增强翻译效率 |

## 3　tRNA

- 沉降系数 **4S**，长度 **75–90 nt**。

### 3.1　一级结构

- 3′ 末端序列高度保守，均为 **CCA**；最末端腺苷的 **3′-OH** 正是连接氨基酸的位置。
- 含**稀有碱基**：假尿嘧啶核苷（Ψ）、次黄嘌呤（I）等。

### 3.2　二级结构：三叶草型

1. **氨基酸接受臂**：5′ 与 3′ 端碱基配对形成，末端单链 CCA 是氨基酸装载点。
2. **三大功能环**
   - **Ψ 环**（含假尿嘧啶）
   - **D 环**（含二氢尿嘧啶）
   - **反密码子环**（含反密码子三联体，直接与 mRNA 密码子配对）
3. **可变环**：位于反密码子环与 Ψ 环之间，长度可变。

### 3.3　三级结构：倒 L 型

- 3′ 端是 **CCA**，A 的羟基结合氨基酸。
- 5′ 端是环，携带**反密码子**。
- 靠三方面相互作用稳定：延伸螺旋内的**碱基堆积力**、**氢键**、**碱基与糖-磷酸骨架的相互作用**。

## 4　氨基酸与 tRNA 的连接

- 连有氨基酸的 tRNA 称**已负载（氨酰-tRNA）**，否则为**未负载**。
- **高能酰基键**：氨基酸羧基与 tRNA 3′ 末端腺苷的 2′ 或 3′ 羟基形成**高能酯键**；水解释放的能量直接驱动后续肽键形成。

### 4.1　氨酰-tRNA 合成酶（aaRS）

| 类别 | 连接位置 |
| :--- | :--- |
| **Ⅰ 类 aaRS** | 连接到 CCA 的 **2′-OH** |
| **Ⅱ 类 aaRS** | 连接到 CCA 的 **3′-OH** |

- 一种氨基酸通常只有一类 tRNA，赖氨酸例外。
- aaRS 识别**氨基酸接受臂**。
- **两级校对机制**
  1. **催化口袋（活性位点）**：初步筛选，但结构极相似的分子仍可能混入。
  2. **编辑口袋（校对中心）**：对活化的氨酰-AMP 产物二次校对；错误产物被水解清除，正确产物因空间位阻无法进入而保留。

## 5　核糖体

- **小亚基先结合 mRNA 和起始 tRNA**，再招募大亚基形成完整核糖体。
- **肽键合成**
  - 方向：**氨基端 → 羧基端**。
  - 机制：**转肽反应**——把生长中的肽链从 P 位 tRNA 转移到 A 位氨酰-tRNA 上；亲核攻击由 A 位氨基酸的氨基发起，攻击 P 位肽链与 tRNA 连接处的羰基。
  - 能量来源：氨酰-tRNA 上的**高能酯键**。
- **肽基转移酶中心（PTC）**与三个位点

| 位点 | 功能 |
| :--- | :--- |
| **A site** | 氨酰-tRNA 结合位点 |
| **P site** | 肽酰-tRNA 结合位点 |
| **E site** | 空 tRNA 出口 |

- **mRNA 通道**位于小亚基，入口狭窄，确保 mRNA 解开二级结构以单链形式进入。
- **肽链出口通道**位于大亚基，狭窄通道限制新生肽链折叠。
- **核糖体蛋白功能**：协助 rRNA 正确折叠并稳定其结构，中和 RNA 骨架负电荷。

### 5.1　原核 / 真核核糖体对照

| | 原核（70S） | 真核（80S） |
| :--- | :--- | :--- |
| 大亚基 | **50S**：23S rRNA + 31 protein + 5S rRNA | **60S**：28S rRNA + 49 protein + 5S rRNA + 5.8S RNA |
| 小亚基 | **30S**：16S rRNA + 21 protein | **40S**：18S rRNA + 33 protein |
| 功能分工 | 肽键形成的肽基转移酶中心 | 密码子-反密码子识别 |

> 表中"功能"一行按原笔记保留：原核 rRNA（23S）承担肽基转移酶中心，小亚基 16S rRNA 负责解码。

## 6　翻译起始

> **三个必需事件**：① 小亚基被招募到 mRNA；② 特化起始 tRNA 放入 **P 位**；③ 核糖体精确定位在起始密码子上，确保正确阅读框。

### 6.1　原核

1. **mRNA 识别**：RBS 序列与小亚基 **16S rRNA** 互补配对，把小亚基锚定在起始密码子附近。
2. **SD 序列**：起始密码子上游约 8 nt 的保守序列，与 30S 小亚基 16S rRNA 的 3′ 端碱基配对。
3. **起始 tRNA**：携带 **N-甲酰甲硫氨酸（fMet）** 的特化 tRNA，直接进入 **P 位**。
4. **起始因子 IFs**

| 因子 | 功能 |
| :--- | :--- |
| **IF1** | 阻断 A 位 |
| **IF2** | 帮助 fMet-tRNA 与 30S 结合，结合 GTP |
| **IF3** | 帮助 30S 与 mRNA 结合，防止大小亚基提前结合 |

5. **组装**：小亚基在 IFs 帮助下先结合 mRNA 与起始 tRNA → 定位准确后招募大亚基 → 水解 GTP 释放 IFs → 形成 **70S 起始复合物**。

![[attachments/原核翻译起始.jpg|400]]

### 6.2　真核

1. **mRNA 识别**：小亚基先结合 **5′ 帽**，沿 mRNA 向 3′ 方向**扫描**，直到找到第一个 AUG（通常位于 Kozak 序列中）。
2. **起始 tRNA**：携带普通甲硫氨酸（Met-tRNAᵢ^Met），**无甲酰化**。
3. **起始因子 eIFs**
   - **eIF2**：GTP 酶，护送起始 tRNA。
   - **eIF4F 复合物**（eIF4E、eIF4G、eIF4A）：识别帽结构、解开二级结构。
   - **eIF3**：连接 mRNA 帽复合物与小亚基。
4. **组装过程**
   1. 小亚基 + 起始 tRNA → **43S 预起始复合物**。
   2. eIF3-eIF4G 相互作用被招募到 mRNA → **48S 复合物**。
   3. 扫描识别起始密码子后，**eIF1、eIF5** 构象改变并释放，解除对后续步骤的抑制。
   4. eIF2 水解 GTP 并释放，小亚基锁定在起始密码子上。
   5. 第二个 GTP 酶 **eIF5B** 水解 GTP → 60S 大亚基加入，释放剩余起始因子 → **80S 起始复合物**。
5. **mRNA 环化**
   - 结合 5′ 帽的 **eIF4G** 同时与结合 3′ poly(A) 尾的 **PABP** 相互作用，把 mRNA 两端拉近成环。
   - 意义：保护 mRNA 免于降解；物理上拉近终止与起始位点，使刚结束翻译的核糖体快速重新启动，**大幅提高翻译效率**。

### 6.3　起始因子对照

| 原核 | 真核 | 对应关系 |
| :--- | :--- | :--- |
| IF1 | eIF1A | 都守护 A 位，防止 tRNA 提前进入 |
| IF2 | eIF2 + eIF5B | IF2 功能在真核中分裂：eIF2 招募起始 tRNA 并感应 AUG 配对；eIF5B 负责大亚基加入 |
| IF3 | eIF1 | 都守护 P 位，并在起始 tRNA 配对成功后触发释放 |

## 7　翻译延长

### 7.1　三步循环

1. **进位**：EF-Tu 护送 aa-tRNA 进入 A 位。
2. **转肽**：P 位肽链羧基端与 A 位新氨基酸氨基之间形成肽键，肽链整体转移到 A 位 tRNA 上。
3. **移位**：核糖体沿 mRNA 移动一个密码子，A 位肽基-tRNA 移至 P 位，空出 A 位。
   - EF-G·GTP 结合并稳定**杂合状态**的核糖体。
   - EF-G·GDP 构象变化使其占据 A 位解码中心。

### 7.2　延伸因子

| 因子 | 功能 |
| :--- | :--- |
| **EF-Tu** | 与 GTP 结合，把 aa-tRNA 带入 A 位 |
| **EF-Ts** | 鸟苷酸交换因子：把 EF-Tu 上的 GDP 置换出来，帮助结合新的 GTP |
| **EF-G** | 激活核糖体滑动，需 GTP |

### 7.3　校对机制（三道）

1. **解码中心的小沟识别**：**16S rRNA 的两个腺嘌呤**识别正确配对碱基对的小沟，验证配对是否标准。
2. **GTP 水解门控**：只有正确的密码子-反密码子配对才足以激活 EF-Tu 的 GTP 水解。
3. **结构张力校对**：tRNA 从与 EF-Tu 结合状态旋转进入大亚基 PTC，结构张力物理性筛选配对，不稳定的错配 tRNA 在此阶段脱落。

## 8　翻译终止与回收

### 8.1　终止密码子识别

- 终止密码子（UAG、UGA、UAA）进入 A 位时**没有 tRNA 能识别**，由**Ⅰ 类释放因子**识别。
- 释放因子一个结构域像**反密码子**一样读取密码子；另一个保守 **GGQ 基序**伸入肽基转移酶中心，催化肽链从 tRNA 上水解下来。

| 因子 | 识别 |
| :--- | :--- |
| **RF1** | UAA、UAG |
| **RF2** | UGA、UAA |
| **RF3** | 激活 RF1、RF2 |

### 8.2　步骤

1. Ⅰ 类因子（RF1/RF2）识别终止密码子并水解肽链。
2. **Ⅱ 类因子 RF3 循环**：RF3·GDP 被招募 → 受Ⅰ类因子刺激将 GDP 换为 GTP → 构象变化排出Ⅰ类因子 → RF3 水解 GTP 变为 RF3·GDP 解离。
3. **核糖体回收**
   - **原核**：**RRF**（模拟 tRNA 结合 A 位）+ **EF-G** 驱动空载 tRNA 与 mRNA 释放；随后 **IF3** 结合小亚基阻止重新聚合。
   - **真核**：**eRF1 + ATP 酶 Rli1** 共同介导核糖体解体，无专门 RRF。

### 8.3　原核 / 真核终止对照

| 步骤 | 原核生物 | 真核生物 |
| :--- | :--- | :--- |
| 识别终止密码子 | RF1 / RF2 分工识别 UAG/UAA 与 UGA/UAA | **eRF1 单独识别全部三个** |
| Ⅰ 类因子功能 | 识别并水解 | 识别并水解 |
| Ⅱ 类因子功能 | RF3 促使 RF1/RF2 释放 | eRF3·GTP 护送 eRF1（类似 EF-Tu） |
| 核糖体回收 | RRF + EF-G + IF3 | eRF1 + Rli1（ATP 酶） |

## 9　翻译调控

> **主要方式**：干扰核糖体小亚基识别 mRNA。

**原核起始抑制两种方式**
1. **空间位阻阻断**：阻遏蛋白结合在 RBS 附近，物理阻挡 30S 小亚基结合。
2. **RNA 结构掩蔽**：mRNA 分子内碱基配对把 RBS 掩蔽起来；可被上游翻译事件或温度等环境信号（**核糖开关**）打开。

## 10　遗传密码

### 10.1　定义与特点

- **遗传密码**：mRNA 核苷酸排列顺序与蛋白质氨基酸排列顺序之间的对应关系。
- **特点**
  1. **简并性**：大多数氨基酸由多个密码子编码；原理是反密码子 5′ 端碱基的**摆动（wobble）**。
  2. **通用性**：几乎所有生物共用一套遗传密码。

### 10.2　规则

1. **方向性**：密码子从 mRNA 5′ → 3′ 读取。
2. **非重叠且无间隔**：密码子连续且不重叠。
3. **固定阅读框**：mRNA 有 3 种理论阅读方式，翻译机器只选一种，由起始密码子 AUG 的位置唯一确定。

### 10.3　突变类型（蛋白质效应）

沉默突变（不影响功能，产生多态性；位于基因间隔区、内含子、UTR 或同义密码子）· 移码突变 · 无义突变（产生终止密码）· 错义突变 · 逆转突变。

> 突变的分子来源、互变异构与修复机制见 [[分子生物学/02-基因组维持/03-DNA损伤突变与修复|DNA 损伤突变与修复]]；此处只保留翻译视角的效应分类。

<details>
<summary><b>自测 1：为什么起始 tRNA 直接进入 P 位而不是 A 位？</b></summary>

因为肽键合成时肽链从 P 位 tRNA 转移到 A 位氨酰-tRNA；起始 tRNA 携带第一个氨基酸，必须占据 P 位才能让第一个肽键在 A 位新进氨基酸的氨基攻击下形成。原核靠 IF2 直接把 fMet-tRNA 放入 P 位，真核靠扫描锁定 AUG 后由 eIF5B 协助定位。
</details>

<details>
<summary><b>自测 2：原核和真核翻译起始最大的区别是什么？</b></summary>

核糖体招募方式：原核靠 RBS/SD 序列与 16S rRNA 配对**直接定位**到起始密码子附近；真核靠 5′ 帽招募小亚基后沿 mRNA **扫描**到 Kozak 中的 AUG。此外起始氨基酸分别为 fMet 与 Met，核糖体为 70S 与 80S。
</details>

<details>
<summary><b>自测 3：翻译如何保证准确性？</b></summary>

三道校对：① 16S rRNA 两个腺嘌呤读取正确配对碱基对的**小沟**；② 只有正确配对才激活 EF-Tu 的 GTP 水解；③ tRNA 旋转进入 PTC 过程中由结构张力筛掉不稳定的错配 tRNA。此外 aaRS 有催化口袋与编辑口袋两级校对。
</details>

<details>
<summary><b>自测 4：终止密码子由谁识别？为什么不是 tRNA？</b></summary>

由**Ⅰ 类释放因子**识别（原核 RF1/RF2 分工，真核 eRF1 通读三个）。终止密码子没有对应的氨酰-tRNA；释放因子用类似反密码子的结构域读码，并用 GGQ 基序伸入 PTC 催化肽链水解。
</details>
