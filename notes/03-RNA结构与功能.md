# 03 · RNA 结构与功能

> [!abstract] 一句话定位
> RNA 是**单链**，因此能形成丰富的局部双链与高级结构——结构多样性正是功能多样性的基础。

## 1　RNA 与 DNA 对比

| | RNA | DNA |
| :--- | :--- | :--- |
| 糖成分 | 核糖 | 2′-脱氧核糖 |
| 碱基 | A-U、G-C | A-T、G-C |
| 结构 | 通常单链 | 通常双链 |

- RNA 除经典 A-U、G-C 配对外，还可形成特殊配对如 **G-U**。
- **RNA 结构多样性的根本原因：单链**。RNA 也能形成与 A-DNA 类似的局部双链。

### 1.1　类型与功能

```
RNA
├─ 编码 RNA：mRNA
└─ 非编码 RNA
   ├─ 调控型
   │  ├─ 短链：miRNA、siRNA
   │  └─ 长链：lncRNA
   └─ 管家型：tRNA、rRNA
```

| 功能 | 说明 |
| :--- | :--- |
| 遗传信息载体 | 某些病毒以 RNA 为基因组 |
| 结构组成 | 核糖体的结构与催化骨架（rRNA） |
| 酶 | 核酶（ribozyme） |
| 调控 | miRNA、siRNA、lncRNA |
| 表达媒介 | mRNA 传递遗传信息 |
| 接头分子 | tRNA 将密码子翻译成氨基酸 |

### 1.2　非编码 RNA 的类型

> 整合自「生物学知识引用块」：`RNA/非编码RNA的类型.md`。

**看家型非编码 RNA**

它们持续表达，参与细胞基本功能。

- **小核 RNA（snRNA）**：参与前体 mRNA 剪接。与蛋白质组成**剪接体**，其中 U1、U2、U4、U5、U6 等 snRNA 通过碱基配对识别剪接位点并催化反应。
- **小核仁 RNA（snoRNA）**：主要指导 rRNA 和 tRNA 的化学修饰，如确定假尿嘧啶化和 2′-O-甲基化的具体位置。
- **端粒酶 RNA（TERC）**：作为模板，指导端粒 DNA 重复序列的合成，维持染色体末端长度。
- **信号识别颗粒 RNA（SRP RNA）**：与蛋白质组成信号识别颗粒，识别新生肽链的信号序列，引导蛋白质进入内质网。

**调控型非编码 RNA**

它们主要在特定阶段或应激时表达，参与基因表达调控。

- **微 RNA（miRNA）**：内源编码，约 22 个核苷酸。通过与靶 mRNA 不完全互补配对，主要抑制其翻译或诱导降解，调控个体发育、细胞分化等过程。
- **小干扰 RNA（siRNA）**：通常外源或内源双链 RNA 来源，与靶 mRNA 完全互补配对，直接切割降解目标，是基因沉默的强大工具。
- **Piwi 蛋白互作 RNA（piRNA）**：较长（24–31 个核苷酸），主要在生殖细胞中与 Piwi 蛋白结合，沉默转座子，保护基因组的稳定性。
- **长链非编码 RNA（lncRNA）**：长度大于 200 个核苷酸，作用方式多样，包括作为蛋白复合物支架、诱饵分子、引导分子等，在 X 染色体失活、基因组印记等表观遗传调控中起关键作用。

## 2　RNA 二级结构

> [!note] 四种基本元件
> **茎 · 发卡（茎环）· 凸起 · 内环**，再加上特殊的**假结**。

1. **茎（Stem）**：连续互补碱基配对形成的双螺旋区域。
2. **茎环 / 发卡（Hairpin）**：单链上两段相邻（或接近）的反向互补序列配对形成局部双螺旋"茎"，夹在中间不能配对的序列被顶出形成单链"环"。
3. **凸起（Bulge）**：茎区中**只有一条链**出现一个或多个未配对核苷酸，双链不对称向外膨出。
4. **内环（Internal loop）**：茎区中**两条链对应位置**都出现未配对核苷酸，配对在环区两侧都被打断。
   - 关键区别：**凸起**只有一条链有未配对核苷酸，另一链连续配对；**内环**两条链都有未配对核苷酸。
5. **假结（Pseudoknot）**：发卡环区内的未配对核苷酸，与该发卡茎区外侧（上游或下游）另一处互补序列配对，形成**交叉重叠**的配对关系。

### 2.1　假结的生物学功能

- mRNA 中的假结常位于基因末端，**阻止核糖体前进**。
- 构成**催化活性区域**，具有催化功能。
- 维持**端粒酶 RNA** 等的结构与功能稳定。

## 3　RNA 三级结构

形成因素
1. **碱基三联体**（如 U:A:U）等非经典相互作用。
2. RNA 骨架与蛋白质**正电氨基酸**的相互作用。

常见类型
- **倒 L 型（tRNA）**：三叶草二级结构通过碱基三联体和碱基-骨架氢键等非常规相互作用，进一步折叠成倒 L 形三维分子。

> tRNA 完整结构（一级 CCA、二级三叶草、三级倒 L）详见 [[分子生物学/03-基因组表达/03-翻译|翻译]]。

<details>
<summary><b>自测 1：凸起与内环的关键区别是什么？</b></summary>

凸起只有一条链出现未配对核苷酸，另一条链保持连续配对；内环则两条链对应位置都有未配对核苷酸，配对在环区两侧都被打断。
</details>

<details>
<summary><b>自测 2：假结如何形成？有什么功能？</b></summary>

发卡环区未配对核苷酸与茎区外侧另一段互补序列配对，形成交叉重叠的配对关系。功能：位于 mRNA 末端阻碍核糖体前进、构成催化活性中心、维持端粒酶 RNA 结构稳定。
</details>

<details>
<summary><b>自测 3：为什么 RNA 比 DNA 结构更多样？</b></summary>

RNA 通常为单链，可自由回折形成茎、环、凸起、内环、假结等局部双链与高级结构；DNA 为规则双螺旋，结构变化空间小。
</details>
