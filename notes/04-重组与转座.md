# 04 · 重组与转座

> [!abstract] 一句话定位
> 三类"主动重排 DNA"的机制按**位点特异性**排列：**同源重组**（长同源区，任意位置）→ **位点特异性重组**（两个精确识别的短位点）→ **转座**（特定元件 → 非特异靶位点）。

**导航**：[[分子生物学/02-基因组维持/03-DNA损伤突变与修复|← DNA 损伤突变与修复]] · [[分子生物学/00-复习总览|复习总览]] · [[分子生物学/03-基因组表达/01-转录|转录 →]]

## 0　三类重组总览

| | 同源重组 | 位点特异性重组 | 转座 |
| :--- | :--- | :--- | :--- |
| 发生位置 | 任意两个**足够相似**的 DNA 区域（相同位置交换） | 两个**特定、被精确识别**的 DNA 序列之间 | 特定元件（转座子）→ **非特异** DNA 位点 |
| 依赖 | 长同源区 + 链侵入 | 重组酶识别特异位点 | 转座酶/逆转录酶 + 末端序列 |
| 能量 | — | **不消耗能量** | 复制型需能量 |
| 主要结果 | 交换、基因转换、DSB 修复 | 插入、缺失、倒位 | 插入、缺失、倒位、基因组扩张 |

- **共同方式**：插入、倒位、移位。
- **共同催化者**：特化的**重组酶**识别特定 DNA 序列。
- 转座**不依赖插入位点的序列特异性**。

---

## 1　同源重组

### 1.1　生物学功能

1. **产生遗传多样性**。
2. **DNA 损伤修复**。
3. **调控基因表达**（如通过切换染色体内的特定片段，把休眠基因置于可表达位置）。
4. **复制叉重启**：修复崩塌的复制叉，保证复制完成。

### 1.2　核心机制（三步）

1. **末端加工** → 2. **链侵入** → 3. **连接体拆分**

### 1.3　DSB 是启动同源重组的关键信号

**DSB 来源**
- **直接产生**：电离辐射直接打断 DNA 骨架。
- **间接产生**：单链损伤（切口或模板链损伤）干扰复制叉 → 复制叉崩塌/停滞 → 核酸酶加工形成 DSB。
- **程序性产生**：减数分裂中细胞主动制造 DSB 启动重组。

**DSB 的两条修复路线**：同源重组（主要途径，准确）vs 非同源末端连接（NHEJ，易出错；NHEJ 组分见 [[分子生物学/02-基因组维持/03-DNA损伤突变与修复|DNA 损伤突变与修复]]）。

### 1.4　重组频率

1. 基因间重组概率通常与**物理距离成正比**——距离越远越易发生交叉，遗传距离越大。
2. **热点**（如 Chi 位点、Spo11 切割位点附近）重组频率高于平均，遗传距离被放大；**冷点**相反。

## 2　同源重组模型

### 2.1　Holliday 模型

> **Holliday junction**：同源重组过程中由两条同源 dsDNA 经单链入侵与链交换形成的**交叉状 DNA 结构**。

1. 两条同源 DNA 分子**对齐**。
2. 引入断裂及**末端加工**。
3. **链侵入**：形成起始的短碱基配对区域。
4. **Holliday 连接体形成**：经加工的 ssDNA 侵入同源双链模板，与互补链配对形成异源双链区。
   - **分支迁移**：连接体交叉点通过碱基对不断解离与重组而滑动。
5. **连接体拆分**
   - 方式
     - **切割**：内切酶切割，不同切割方向决定产物是局部基因转换还是大范围染色体交叉互换。
     - **瓦解**（真核特有）：通过拓扑异构酶之类机制使双链体解开纠缠。
   - 结果
     - 切割发生在**纯合链** → 重组。
     - 切割发生在**杂合链** → 不重组。

![[attachments/Holiday模型.jpg|500]]

### 2.2　双链断裂修复模型（DSBR）

1. **双链断裂**。
2. **末端加工**：核酸酶降解断裂末端，产生 **3′ 单链 DNA 尾巴**。
3. **链侵入**：单链尾巴侵入同源双链 DNA 配对。
   - **基因转换**：一个等位基因丢失，被对方的等位基因取代。
4. 形成**双 Holliday 连接体**。
5. **分支迁移**。
6. **连接体拆分**：产生**交叉产物**或**非交叉产物**。

**作用**：修复 DSB · 减数分裂交换遗传物质 · 种间水平转移。

![[attachments/双链断裂-修复模型.jpg|500]]

> [!note] 两个模型的区别
> Holliday 模型从**单链缺口**起始，形成**单个** Holliday 连接体；DSB 修复模型从**双链断裂**起始，形成**双** Holliday 连接体。

## 3　同源重组的蛋白机器

### 3.1　大肠杆菌：RecBCD 途径

| 蛋白 | 功能 |
| :--- | :--- |
| **RecBCD** | 加工断裂末端，产生单链尾巴 |
| └ RecB | 3′→5′ 解旋酶 + 核酸酶；与 RecA 相互作用，将 RecA 装载到 3′ 单链末端，避免 SSB 占据 |
| └ RecD | 5′→3′ 解旋酶 |
| └ RecC | 识别 **χ 位点（GCTGGTGG）**；外源序列没有 χ 位点 |
| **RecA** | 链交换蛋白，寻找同源序列并介导链侵入 |
| **RuvA / RuvB** | 驱动 Holliday 连接体分支迁移：RuvA 识别四臂结构并招募 RuvB；RuvB 为 ATP 酶提供能量 |
| **RuvC** | 内切酶，拆分 Holliday 连接体，切口末端可直接供连接酶连接 |

**χ 位点效应**
- 遇到 χ 位点**之前**：RecD 主导，降解 **3′ 链**。
- 遇到 χ **之后**：降解 **5′ 链**，产物是一段带 χ 序列的 **3′ 单链悬尾**。

**RecA 工作条件与特点**
- 前提：有 ssDNA、有同源序列（互补性）、有游离末端。
- 机制：两个 DNA 结合位点——一个结合 ssDNA，一个结合 dsDNA；靠碱基配对。
- 特点：**协同组装**，倾向与 **3′ 端**结合。
- 同源物：RadA（古菌）、**Rad51**、Dmc1（真核）。

**过程**：复合物识别 DSB 末端 → 解螺旋并移动到 χ 位点 → 切断单链、入侵同源链 → RecA 形成 Holliday 交叉 → RuvABC 驱动交叉端移动并切割。

### 3.2　真核生物

| 蛋白 | 功能 |
| :--- | :--- |
| **Spo11** 内切酶 | 制造断裂：利用酪氨酸侧链攻击 DNA 骨架，与切割末端形成**共价连接**，产生**交错末端**；5′ 端因共价连接 Spo11 而被保护 |
| **MRX 复合物** | 末端加工并移除 Spo11；仅在与其共价相连的 5′ 端链上按 **5′→3′** 方向切除 |
| **Rad51 / Dmc1** | 链交换蛋白：Rad51 用于有丝分裂与减数分裂；Dmc1 仅减数分裂 |
| 连接体拆分 | **切割途径**：Rad51C-XRCC3 复合物（内切酶，类似 RuvC）；**瓦解途径**：RecQ 家族解旋酶 |

## 4　保守的位点特异性重组

1. **定义**：由重组酶识别特定 DNA 序列（重组位点），在其上进行**精确的 DNA 切割与重连**。
2. **类型**：插入、缺失、倒位。
3. **不消耗能量**。

---

## 5　转座

> **定义**：将转座子从基因组一个位置移动到另一个位置的特殊重组过程。

### 5.1　转座子类型

| 类别 | DNA 转座子 | 病毒样反转录转座子（LTR） | 聚腺苷酸反转录转座子（非 LTR） |
| :--- | :--- | :--- | :--- |
| 核心移动机制 | **"剪切-粘贴"**：直接 DNA 切割与重连 | **"复制-粘贴"**：转录成 RNA 中间体，逆转录酶合成 DNA 后整合 | **"复制-粘贴"**：同样经 RNA 中间体，整合机制不同 |
| 关键酶 | **转座酶** | **整合酶 + 逆转录酶** | **ORF2 蛋白**（兼具逆转录酶与内切核酸酶） |
| 末端序列 | 较短的**反向重复序列** | 两端较长的**长末端重复** | 两端不同，一端带 **poly-A 尾**，结构更像典型基因 |

- **自主元件**：自带全套移动所需基因（转座酶或逆转录酶），能自主移动。
- **非自主元件**：仅保留被转座酶识别的末端序列。

### 5.2　剪切-粘贴转座（多数 DNA 转座子）

**关键执行者：转座体** = 转座酶多聚体 + 转座子 DNA 两端形成的稳定复合物；确保反应精确、同步，并保护 DNA 末端。

1. **切除**：转座体催化两端 DNA 断裂，将转座子完整切离，产生游离 **3′-OH** 末端。
2. **链转移**：3′-OH 直接攻击新靶 DNA，通过一次性**转酯反应**完成连接；靶 DNA 两条链上攻击位点**错开几个核苷酸**，错开距离决定靶位点重复的长度。
3. **修复**
   - 新插入位点：错开造成的单链缺口由宿主 DNA 聚合酶填补、连接酶封口，生成**靶位点重复**。
   - 原切除位点：留下 DSB，需由宿主 **HR 或末端连接**修复。

### 5.3　复制转座

- **核心区别**：初始切割阶段转座酶只在转座子两端各切**一条链**，产生 3′-OH，**转座子未被切离**——这是与剪切-粘贴路径的根本分叉点。
- 后续步骤
  1. 被切开的 3′-OH 攻击靶 DNA 完成链转移，形成连接新旧位点的**双分支 DNA 结构**。
  2. 宿主复制蛋白将分支结构识别为复制叉，启动 DNA 合成并穿过整个转座子，最终产生**两个转座子拷贝**。

### 5.4　生物学意义

1. **基因组组成**
   - 病毒基因组整合：某些病毒借此将自身 DNA 插入宿主染色体。
   - 基因结构改变：DNA 片段倒位可调控基因开关。
   - **基因组扩张**：转座元件构成人类基因组近**一半**序列。
2. **免疫系统发育**：脊椎动物免疫系统多样性依赖程序性 DNA 重排。
3. **自发突变**：转座是许多生物中突变的主要来源之一。

> 转座元件与基因密度、重复序列的关系见 [[分子生物学/02-基因组维持/01-基因组与染色体包装|基因组与染色体包装]]。

<details>
<summary><b>自测 1：同源重组、位点特异性重组、转座如何区分？</b></summary>

同源重组发生在任意两个足够相似的 DNA 区域之间，依赖长同源区与链侵入；位点特异性重组发生在两个被精确识别的特定序列之间，由重组酶催化且不耗能；转座是特定转座元件插入**非特异**位点，不依赖靶位点的序列特异性。
</details>

<details>
<summary><b>自测 2：χ 位点如何改变 RecBCD 的降解方向？</b></summary>

遇到 χ 位点前 RecD 主导、降解 3′ 链；遇到 χ 后转为降解 5′ 链，最终产生一段带 χ 序列的 3′ 单链悬尾，供 RecA 装载并介导链侵入。
</details>

<details>
<summary><b>自测 3：剪切-粘贴与复制转座的根本分叉点是什么？</b></summary>

初始切割是否把转座子完整切离。剪切-粘贴在两端各切**两条链**，转座子被完整切离；复制转座只在两端各切**一条链**，转座子仍留在原位，随后通过宿主复制产生两个拷贝。
</details>
