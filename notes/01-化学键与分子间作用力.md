# 01 · 化学键与分子间作用力

> [!abstract] 一句话定位
> **强键搭骨架，弱键塑形态**。共价键决定"是什么"，非共价键决定"长什么样、怎么互动"。

## 1　两类化学键总览

> [!note] 本质
> 所有化学键的本质都是**静电力**。区别在于键能高低、是否可逆。

| 特征 | 强化学键（共价键） | 弱化学键（非共价键） |
| :--- | :--- | :--- |
| 本质 | 原子间**电子共享**，高强度共价相互作用 | 静电效应、瞬时偶极等形成的低强度相互作用 |
| 键能 | 高，生理温度下几乎不会自发断裂 | 低，生理条件下可动态形成与断裂 |
| 键长 | 短 | 长 |
| 最大成键数量 | 由**价**决定 | 由**位阻**决定（氢键还有额外限制） |
| 键角 | 固定 | 多变 |
| 旋转自由度 | 单键可自由旋转；双键、三键及具部分双键性质的键（如肽键）刚性强 | 自由度高 |
| 可逆性 | 不可逆（生理条件下） | **可逆、瞬时、动态** |
| 生物学角色 | 维持一级序列、储能、维持分子骨架 | 决定三维折叠、特异性识别、动态调控 |

### 1.1　强键：骨架与储能

- **主要类型**：共价单键、双键、三键，以及具部分双键性质的键（如肽键）。
- **生物学意义**
  1. 维持生物大分子内部组成单元的连接（**一级序列**）。
  2. 储存能量（如 ATP 的磷酸酐键）。
  3. 维持分子骨架。
- **典型实例**

| 键 | 所在结构 |
| :--- | :--- |
| 肽键 | 蛋白质一级结构 |
| 磷酸二酯键 | 核酸骨架（3′,5′-磷酸二酯键） |
| 二硫键 | 蛋白质三级结构 |
| 糖苷键 | 单糖连接、核苷中糖与碱基的连接 |

### 1.2　弱键：形态与识别

> [!tip] 核心规律
> **单个键弱，多个弱键集合很稳定**。正是"可逆 + 协同"让生命活动既能稳定维持，又能灵活调控。

- **四个基本特点**：单个键弱但集合稳定 · 可逆 · 瞬时 · 动态。
- **生物学意义**
  1. 决定生物大分子的三维空间折叠结构，进而决定功能。
  2. 介导分子间**特异性识别与结合**（酶-底物、转录因子-DNA 位点）。
  3. 动态可逆支撑酶的高效催化、基因表达调控、信号传导等核心过程。
- **典型实例**：DNA 双螺旋（氢键 + 碱基堆积力）、酶结合底物、转录调控因子结合 DNA。

## 2　能量概念

- 化学键的形成涉及能量形式的改变。
- 单位：**kcal（千卡路里）**、**kJ（千焦每摩尔）**。
- 卡路里定义：将 1 g 水从 14.5 ℃ 升高到 15.5 ℃ 所需的能量。

## 3　生物系统中的四类弱键

### 3.1　范德华力

1. **定义**：原子相互靠近时，由诱导产生的瞬时波动电荷引发的**非特异性静电吸引力**。所有分子都能形成。
2. **最弱的化学键**；形状互补的分子相互作用时范德华力最强。
3. **范德华半径**：范德华吸引力与斥力平衡时的原子间距离。
4. **三种成分**：取向力、诱导力、色散力。
   - **电偶极矩**：正电荷中心与负电荷中心互不重合的组合。
   - 电负性原子倾向得到电子；电正性原子倾向失去电子。
   - 具有偶极矩的分子为**极性分子**，否则为**非极性分子**。
   - **诱导效应**：邻近分子的电场改变其他分子的电荷分布，使非极性分子产生瞬时微弱极性。
5. 对极性分子而言，范德华力一般**不是**主导的结合模式。

### 3.2　氢键

1. **定义**：正电供体氢与负电受体原子间形成的弱静电相互作用。
2. 供体与受体电荷差异越大，氢键越强；**O、N** 是氢键中最重要的原子。
3. 每个水分子可形成 **4 个**氢键——极性分子的水溶性源于此。
4. 两大特点
   - **高度方向性**：供体直接指向受体时能量最大。
   - **特异性**：必须同时存在互补的供体基团与受体基团。

### 3.3　离子键

- **定义**：相反带电基团之间的静电作用力。
- **无机离子的中和效应**：水溶液中无机离子被水合层包裹，与有机带电基团无固定结合，因此几乎不影响有机分子的空间构象。

### 3.4　疏水相互作用

- **定义**：水分子排斥非极性分子的趋势。
- **生物学功能**
  1. 蛋白质三维折叠的核心驱动力之一。
  2. 维持蛋白质复合物稳定性。
  3. 介导蛋白质嵌入生物膜。

### 3.5　碱基堆积力（核酸中的典型弱键合力）

- 相邻碱基平面垂直堆叠产生的吸引力，由**共轭 π 电子云**（π-π 堆积 / 范德华色散力）+ **疏水相互作用**共同提供。
- 电子云之间通过瞬时诱导偶极吸引。
- 与氢键共同维持 DNA 双螺旋稳定性；其中**氢键提供特异性，堆积力提供主要稳定性**。

<details>
<summary><b>自测 1：为什么弱键"单个弱"却能形成稳定的生物大分子结构？</b></summary>

单个弱键键能低、易断裂，但多个弱键协同叠加后总结合能很高；同时动态可逆的特性允许结构在需要时解开与重组，兼顾稳定性与灵活性。
</details>

<details>
<summary><b>自测 2：DNA 双螺旋靠什么维持？特异性又由谁决定？</b></summary>

稳定性主要来自**碱基堆积力**（疏水作用 + π-π 堆积 / 范德华力），氢键也参与；**特异性由氢键提供**——A-T、G-C 的供体/受体排布互补。
</details>

<details>
<summary><b>自测 3：极性分子易溶于水的原因是什么？</b></summary>

水分子可提供氢键供体和受体，极性分子能与水形成氢键，因而易溶；范德华力对极性分子通常不是主导结合模式。
</details>
