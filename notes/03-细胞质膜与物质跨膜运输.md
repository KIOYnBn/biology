# 03 细胞质膜与物质跨膜运输

> 返回 [[00-总览]] ｜ 配套总结：[章节总结-物质跨膜运输](attachments/章节总结-物质跨膜运输.pdf)

## 1. 生物膜概述

- 生物膜包括**细胞质膜（质膜）**和**细胞内膜**。
- 冰冻断裂电镜中的膜面命名：
  - **ES**：细胞外表面；**PS**：原生质表面。
  - **EF**：细胞外小叶断裂面；**PF**：原生质小叶断裂面。

## 2. 膜的化学组成

### 2.1 脂类

| 类别 | 要点 |
|---|---|
| 鞘脂、甘油脂、糖脂、磷脂 | 构成膜脂的主体 |
| 胆固醇 | 动物细胞膜；真菌为麦角固醇；植物为谷固醇、豆固醇 |
| 甘油磷脂 | 主要为 PC、PE、PS、PI |
| 脂质体 | 两亲性脂分子在水中自发形成的聚合体，可作为膜模型与药物载体 |

### 2.2 膜蛋白

- 类型：**膜周边蛋白**、**脂锚定蛋白**、**膜整合蛋白**。
- 分离方法：
  - 去垢剂（两性分子，形成可溶颗粒）用于分离膜整合蛋白。
  - 离子型去垢剂：**SDS**，会使蛋白变性。
  - 非离子型去垢剂：**Triton X-100**，较温和。

## 3. 膜的基本特性

### 3.1 流动性

- 影响因素：脂肪酸链**短**、**不饱和**程度高 → 流动性更强；温度升高流动性增强；胆固醇起调节作用。
- 运动方式：自旋、侧向扩散、尾部摆动、翻转（flip-flop，罕见且需酶协助）。
- 检测方法：**FRAP（荧光漂白恢复）**——激光淬灭荧光后测量恢复速率，可定量膜流动性。

### 3.2 不对称性

- 检测方法：**电镜冷冻蚀刻技术**、胰酶消化法。
- 表现：膜脂与膜蛋白在内外小叶分布不同；糖链多位于细胞外侧。

## 4. 膜的功能

1. 提供稳定的细胞内环境。
2. 物质运输。
3. 信号转导（见 [[08-细胞信号转导]]）。
4. 介导细胞—细胞或细胞—细胞外基质的连接。
5. 提供酶的结合位点，提高反应效率。
6. 区块化：生物膜将细胞分隔为功能不同的区室（见 [[04-细胞质基质与内膜系统]]）。

## 5. 物质跨膜运输

### 5.1 转运蛋白

| 类型 | 机制 | 特点 |
|---|---|---|
| 通道蛋白 | 形成亲水性通道，介导离子/水顺电化学梯度通过 | 高速、门控、不饱和 |
| 载体蛋白 | 与底物特异性结合后改变构象 | 特异性、饱和性 |

### 5.2 被动运输（顺浓度或电化学梯度，不耗能）

- **简单扩散**：不依赖转运蛋白；取决于分子大小、极性和脂溶性。
  - 可通过：气体、小的极性分子、脂溶性分子、氨基酸、甘油、脂肪酸、葡萄糖（部分）。
- **协助扩散**：需转运蛋白协助。
  - 离子通道：
    - 孔蛋白（细菌质膜、线粒体与叶绿体外膜）。
    - 水通道蛋白 AQP：与水分子形成氢键，特异性介导水分子跨膜（2003 年诺贝尔化学奖）。
    - 门控类型：**电压门控**（膜电位变化）、**配体门控**（配体结合）、**应力门控**（机械应力）。
    - 影响因素：通道直径、形状、带电氨基酸分布。
  - 载体蛋白：**GLUT（葡萄糖转运蛋白）**。
- 生物学意义：维持膜电位、营养吸收、渗透平衡。

### 5.3 主动运输（逆梯度，需能量）

**初级主动运输：直接利用 ATP 水解能量**

| 泵 | 分布与功能 | 要点 |
|---|---|---|
| **Na⁺/K⁺ 泵（P 型）** | 动物细胞质膜，排 3 Na⁺、吸 2 K⁺ | 去磷酸化构象亲和 Na⁺，磷酸化构象亲和 K⁺；抑制剂：乌本苷（ouabain） |
| **Ca²⁺ 泵（P 型）** | 质膜与内质网膜，维持胞质低 Ca²⁺ | 质膜钙泵可被 CaM 激活；内质网钙泵无 CaM 结合位点 |
| **V 型质子泵** | 溶酶体、胞内体、植物/真菌液泡膜 | 将 H⁺ 泵入膜泡，维持胞质中性、膜泡酸性；不形成磷酸化中间体 |
| **F 型质子泵** | 线粒体内膜、叶绿体类囊体膜、细菌质膜 | 双向：水解 ATP 泵 H⁺，或利用 H⁺ 梯度合成 ATP；不产生磷酸化中间体 |
| **ABC 超家族** | 细菌（吸收单糖、氨基酸等）、动物质膜（排出磷脂、脂质、脂溶性药物） | ATP 结合引起二聚化与构象改变；真核中参与排毒 |

**次级主动运输：利用偶联物质的浓度梯度**

- 由偶联转运蛋白将一种物质的逆梯度运输与另一种物质的顺梯度运输相偶联。
- **同向转运**：两种底物运输方向相同。
- **反向转运**：两种底物运输方向相反。

**光驱动主动运输**：利用光能实现逆浓度或电化学梯度运输。

### 5.4 膜泡运输（大分子与颗粒）

- **胞吞作用**：质膜内陷形成囊泡，将胞外物质运入细胞。
  - 按物质大小：吞噬作用（颗粒大、需受体介导、非普遍）、胞饮作用（颗粒小、无需受体、普遍）。
  - 受体介导的胞吞：配体与受体结合 → 召集网格蛋白形成有被小窝 → 颈部发动蛋白（GTP 依赖）水解缢缩 → 网格蛋白脱离形成无被小泡 → 与胞内体融合。
  - 受体去向：返回质膜、进入溶酶体降解、激活信号通路。
- **胞吐作用**：分泌泡与质膜融合，将物质运出细胞。
  - 组成型胞吐：持续进行，参与质膜更新。
  - 调节型胞吐：分泌物储存在分泌小泡中，受刺激后释放。
- **跨细胞转运**：物质从细胞一侧摄入、另一侧排出。

> 膜泡运输在细胞内的分选机制和信号假说详见 [[05-蛋白分选与膜泡运输]]。
