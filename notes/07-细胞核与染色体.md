# 07 细胞核与染色体

> 返回 [[00-总览]] ｜ 配套总结：[章节总结-细胞核与染色体](attachments/章节总结-细胞核与染色体.pdf)

## 1. 细胞核总论

- **定义**：真核细胞储存遗传物质的场所，细胞内最大的细胞器。
- **功能**：遗传与代谢的调控中心。
- **组成**：核被膜、核孔、核基质、染色质/染色体、核仁与核体。

## 2. 核被膜与核孔复合体

### 2.1 核被膜

- 结构：外膜、核周腔（perinuclear space）、内膜、**核纤层（nuclear lamina）**。
- 核纤层由核纤层蛋白（lamins，中间纤维蛋白）组成，功能：
  - 机械支撑；连接核骨架与细胞质骨架。
  - 为染色质提供锚定位点；介导核被膜解体和重建（见 [[10-细胞分裂]]）。

### 2.2 核孔复合体（NPC）

- 由内外核膜融合形成，核孔蛋白（nucleoporin, NUP）连接 NPC 与核被膜。
- 结构：
  - **胞质环**：靠近细胞质，8 条纤维对称伸向胞质。
  - **核质环**：靠近核基质，8 条纤维伸向核内并在末端形成环（**核篮**）。
  - **中央栓**：位于核孔中心。
  - **辐（spoke）**：从核孔边缘伸向中心，包括柱状、腔内、环带亚单位。
- 功能：分隔核质；介导核—质物质运输与信息交流，兼具被动扩散与主动运输。

**亲核蛋白入核过程**

1. NLS 被输入蛋白 α 识别，与 importin α/β 二聚体结合。
2. β 蛋白介导复合物与胞质环结合并运入细胞核。
3. Ran-GTP 结合复合物使亲核蛋白释放。
4. 复合物返回细胞质，Ran-GTP 水解后与复合物脱离并回到核内。
- 特点：**NLS 不被切除，蛋白质无需解折叠**。

**出核与 RNA 运输**

- 核输出信号 NES 介导蛋白质出核。
- RNA 聚合酶 Ⅰ 转录 rRNA，在核内加工成核糖核蛋白亚单位（RNP）后经核孔进入细胞质。
- RNA 聚合酶 Ⅱ 转录 hnRNA，经 5′ 加帽、3′ 加尾加工。
- RNA 聚合酶 Ⅲ 转录 tRNA、小 RNA（sRNA）。

## 3. 染色质与染色体

### 3.1 基本概念

- **染色质**：DNA 与蛋白质的复合物；**染色体**：染色质的高度凝缩状态。
- DNA 与蛋白质结合的意义：压缩 DNA 体积；保护 DNA 免受核酸酶降解；保证遗传物质平均分配；利于基因重组。
- 染色质可被碱性染料染色；组成包括 DNA、RNA、组蛋白和非组蛋白。

### 3.2 基因组与序列类型

- 两类遗传信息：**编码序列**与**调控序列**。
- 序列类型：蛋白编码序列；编码 RNA 和组蛋白的序列；含重复序列的 DNA；未分类的间隔 DNA。
- 真核基因组与原核基因组相比：基因组大、含内含子、基因表达具有时空特异性，转录与翻译在空间上分离，并伴有组蛋白包装。

### 3.3 DNA 的二级结构

| 构型 | 特点 |
|---|---|
| **B-DNA** | 右手双螺旋；生理条件下主要形式 |
| **A-DNA** | 右手螺旋，较 B 型短粗 |
| **Z-DNA** | 左手螺旋；通常与无活性染色质相关 |

- 转录活性大致为 **B > A > Z**。

### 3.4 染色质类型

- **常染色质（euchromatin）**：压缩程度低，具转录活性。
- **异染色质（heterochromatin）**：
  - 结构异染色质：永久凝缩。
  - 兼性异染色质：可转变状态，如失活 X 染色体形成的**巴氏小体（Barr body）**。
- 巨大染色体：多线染色体、灯刷染色体。

### 3.5 组蛋白与非组蛋白

- **组蛋白**：染色体主要成分，呈碱性，无序列特异性。
  - C 端折叠域：参与组蛋白结合与核小体组装。
  - N 端尾巴：修饰位点，参与 DNA 缠绕与调控。
- **非组蛋白**：与 DNA 序列特异性结合的酸性蛋白质。
  - 特性：多样性、特异性识别 DNA、功能多样。
  - 功能：帮助 DNA 折叠、复制、调控基因表达。
  - 常见 DNA 结合结构模式：
    - **螺旋-转角-螺旋**：C 端识别螺旋结合 DNA 大沟，N 端辅助螺旋结合磷酸戊糖骨架。
    - **锌指模式**：每个锌指由两个半胱氨酸和两个组氨酸配位 Zn²⁺。
    - **亮氨酸拉链**：C 端重复亮氨酸形成疏水螺旋，介导二聚化。
    - **螺旋-环-螺旋（HLH）**。
    - **HMG 盒**：三个螺旋形成回旋镖形。

### 3.6 染色体高级结构与形态

- 组装层次：DNA → 核小体 → 螺线管（每圈约 6 个核小体）→ 超螺线管 → 平面放射环 → 中期染色体。
- 按着丝粒位置分为：中着丝粒（metacentric）、亚中着丝粒（submetacentric）、近端着丝粒（acrocentric）、端着丝粒（telocentric）。
- **着丝粒（centromere）**：中期姐妹染色单体相互连接的特殊部位。
  - 动粒结构域（kinetochore domain）：内板、外板、中间间隙、纤维冠。
  - 着丝粒 DNA 主要由 α 卫星 DNA 组成。
- **着丝点/动粒（kinetochore）**：主缢痕处染色单体外侧的特殊结构，与纺锤体微管连接。
- **核仁组织区（NOR）**：位于染色体次缢痕区；rRNA 基因多拷贝、无组蛋白核心、裸露，基因间为间隔 DNA。
- **端粒（telomere）**：由端粒 DNA 与端粒结构蛋白（非组蛋白）组成。
  - 作用：解决末端复制问题；防止黏性末端融合；维持染色体独立性与稳定性；充当细胞分裂计时器。
  - **端粒酶**：体细胞中一般无活性。
- **重要功能元件**：ARS（自主复制序列）、CEN（着丝粒序列）、TEL（端粒序列）。
- **核型（karyotype）**：有丝分裂中期染色体组的表型，包括数目、大小与形态特征总和。

### 3.7 染色质复制、活性调控与表观遗传

**染色质复制与修复**

- 父代核小体核心颗粒与 DNA 分离，复制完成后转移到其中一条子链。
- 新合成组蛋白直接组装到新复制的 DNA 上。

**活性染色质与非活性染色质**

| | 活性染色质 | 非活性染色质 |
|---|---|---|
| 转录 | 有转录活性 | 无转录活性 |
| 特征 | DNase Ⅰ 超敏感位点；HMG14/17 存在；很少结合 H1 | 组蛋白修饰状态不同 |
| 标志 | H3 N 端第 4、9 位赖氨酸乙酰化 | H3 N 端第 9 位赖氨酸甲基化 |

**染色质激活与失活**

- 核心问题：如何形成活性染色质启动转录；如何隔离活性与非活性区域；RNA 聚合酶如何起始转录。
- 激活方式：
  - 组蛋白修饰：核心组蛋白赖氨酸乙酰化；H1 磷酸化（发生于有丝分裂期）。
  - HMG 蛋白：HMG1/HMG2 含 A、B、C 三个结构域，结合 DNA 双螺旋小沟。
- 失活方式：
  - X 染色体失活：雌性失活 X 的 H4 组蛋白不发生乙酰化。
  - 位置花斑效应：活性基因转位到异染色质附近后失活。

**染色质与基因表达调控**

- RNA 聚合酶解除组蛋白与 DNA 的相互作用：转录时撤掉两个 H2A-H2B 形成四聚体，四聚体移至聚合酶后方自由 DNA 上，两个 H2A-H2B 重新结合恢复八聚体。
- 转录因子：
  - 通用转录因子：结合 RNA 聚合酶相关的启动子位点。
  - 特异转录因子：结合特异基因调控位点；含 DNA 结合域与激活结构域。
  - 转录抑制因子：抑制结合区附近基因的转录。
- DNA 甲基化：干扰转录因子识别结合位点；或将激活序列转换为抑制因子结合位点。
- 组蛋白修饰：乙酰化/去乙酰化改变核小体与染色质紧密程度。
- **表观遗传**：通过组蛋白与 DNA 的不同修饰改变染色体结构，从而改变基因组信息表达。
  - 途径：组蛋白密码、染色体重塑、组蛋白异型体、DNA 甲基化与非编码 DNA 的作用。

## 4. 核仁

- **功能**：核糖体生物发生（rRNA 合成与核糖体亚基组装）。
- 结构分区：

| 分区 | 染色 | 作用 |
|---|---|---|
| 纤维中心 FC | 浅 | 含编码 rRNA 的基因 |
| 致密纤维组分 DFC | 深 | 前体 rRNA 所在位置 |
| 颗粒组分 GC | 居中 | 正在加工的成熟核糖体亚单位前体颗粒（RNP） |

- **核仁染色体**：间期时变为核仁相随染色质；伸入核仁内部的称核仁内染色质，形成袢环与**核仁组织区（NOR）**；核仁周围的称核仁周边染色质。
  - NOR 位于次缢痕区；核仁消失时 NOR 折叠压缩定位在此。
  - 意义：提高启动子局部浓度；使 RNA 聚合酶在同一转录单位上连续运作。
- 真核生物核糖体组成：5.8S、18S、28S、5S rRNA。

## 5. 核体、核基质与核骨架

- **核体（nuclear body）**：无膜包被，与生物大分子的合成、组装和储存有关。
  - 组成：Cajal 体、GEMS（gemini of coiled body）、染色质间颗粒。
- **核基质（nuclear matrix）**：蛋白网架结构；作为染色体骨架、核纤层蛋白骨架，提供染色质附着位点。
- **核骨架（nuclear skeleton）**：
  - 狭义：等同于核基质。
  - 广义：包括核基质、核纤层（及核孔复合体）、染色体骨架。
  - 认识：与核纤层、中间丝相互连接，贯穿核质与细胞质；由非组蛋白纤维蛋白组成；与 DNA 复制、基因表达、染色体组装有关。
