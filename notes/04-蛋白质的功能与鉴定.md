# 04 蛋白质的功能与鉴定

蛋白质是生命活动的主要执行者。本篇先梳理蛋白质的功能类型与典型代表（肌红蛋白、血红蛋白、抗体、分子马达），再集中介绍一级结构测定、分离纯化与鉴定方法。

## 一、蛋白质的功能概览

| 功能 | 代表 |
| --- | --- |
| 催化 | 酶；酶与底物通过结构互补实现识别 |
| 信号分子与信号转导 | 激素、生长因子、细胞因子（胰岛素、干扰素）；G 蛋白偶联受体 |
| 转运 | 转运蛋白、核定位信号 |
| 结构 | α-角蛋白、胶原蛋白、弹性蛋白 |
| 运动 | 马达蛋白、肌动蛋白、微管蛋白 |
| 保护 | 抗体、凝血因子、毒素 |
| 养分 | 卵清蛋白 |

> [!note] 诱导契合
> 蛋白质与配体结合常伴随构象变化，使结合部位与配体结合更紧密。被酶作用的分子称为**底物**而不是配体。

## 二、蛋白质–配体相互作用的定量分析

$$
\begin{align*}
& P + L \rightleftharpoons PL \tag{1} \\
& K_a = \frac{[PL]}{[P][L]} = \frac{k_a}{k_d} \tag{2} \\
& K_d = \frac{1}{K_a} = \frac{k_d}{k_a} \tag{3} \\
& \theta = \frac{\text{占据的结合部位}}{\text{总结合部位}} = \frac{[PL]}{[PL]+[P]} = \frac{[L]}{[L]+K_d} \tag{4}
\end{align*}
$$

其中 $K_a$ 为结合常数，$K_d$ 为解离常数，$k_a$、$k_d$ 为速率常数。

## 三、氧结合蛋白

### 1. 血红素

- **血红素**：原卟啉 Ⅸ 与 Fe 的络合物。
  - 卟吩：四吡咯环 + 甲叉桥；卟吩中特定 H 被取代后称卟啉。
  - 中心 Fe 为八面体配位、6 个配位键：4 个由吡咯环 N 占据，留下垂直方向 2 个空位；作为辅基与蛋白结合时，一个被蛋白的 His 侧链 N 占据，另一个用于结合氧。

![[attachments/血红素结构.png|500]]

- 亚铁血红素中心为 $Fe^{2+}$，高铁血红素中心为 $Fe^{3+}$；只有 $Fe^{2+}$ 是氧结合部位。
- 要点：
  1. 氨基酸侧链中没有能与氧结合的基团。
  2. 高铁肌红蛋白的 $Fe^{3+}$ 可直接与 $H_2O$ 的 O 配位。
  3. 游离 $Fe^{2+}$ 与氧反应易形成氧自由基，需通过螯合固定 Fe。
  4. CO、NO 与肌红蛋白的结合能力更强。
  5. 一个氧可以同时与两个血红素反应。

### 2. 肌红蛋白（Mb）

- 作用：**贮存氧**；组成：珠蛋白（单多肽链）+ 血红素。
- **近组氨酸**占据 Fe 的第 5 个配位；**远组氨酸**位于第 6 个配位方向但离 Fe 较远，不形成配位键，而与 O 形成氢键。
- 结合氧时为氧合肌红蛋白，失去氧时为去氧肌红蛋白；氧结合曲线为**双曲线**。

### 3. 血红蛋白（Hb）

- 作用：**运输氧**；来源：未成熟红细胞；英文 Hemoglobin，缩写 Hb。
- 编码基因共 7 种：$\alpha$、$\beta$、$^{A}\gamma$、$^{G}\gamma$、$\delta$、$\varepsilon$、$\zeta$。
- 结构：四聚体，4 个亚基各缔合 1 个血红素，由两个二聚体结合形成；尿素可使其解聚为二聚体。四级结构具 $C_2$ 点群对称。

![[attachments/血红蛋白结构.png|500]]

| 类型 | 组成 |
| --- | --- |
| 幼年 Hb F | $\alpha_2\gamma_2$ |
| 成年 Hb A | $\alpha_2\beta_2$ |

- Hb F 结合氧的能力强于 Hb A，因此胎儿可从母体血液中获取氧。
- Hb A 可与其他物质反应形成变异形式，如 $HbA_{1c}$ 是 Hb A 的葡糖基化形式。

> [!warning] 氧结合曲线的表述
> 肌红蛋白为双曲线；血红蛋白因正协同效应呈 **S 形（sigmoidal）曲线**。原笔记中「血红蛋白双曲线型氧结合曲线」为笔误，此处按协同结合机理修正。

### 4. 结合氧时血红蛋白的结构变化

血红蛋白从去氧态（T 态）到氧合态（R 态）的转变，根源在于血红素铁原子的微小移动，包括空间效应和电子效应。

**T 态（去氧态）**

1. **电子效应**：$Fe^{2+}$ 未结合 $O_2$，6 个 d 电子为「4 个不成对 + 1 对成对」，处于**高自旋态（顺磁性）**。
2. **空间效应**：高自旋态下铁原子体积较大，且只与卟啉环 4 个 N 及 F 螺旋上的 His F8 配位（共 5 个配体）；因体积和空间排斥，向 His F8 方向突出卟啉平面约 0.06 nm，血红素被顶成圆顶状；Fe—N 键也偏离垂直方向约 8°。

**R 态（氧合态）**

1. **电子效应**：$O_2$ 成为第 6 个配体，$Fe^{2+}$ 的 6 个 d 电子重排为 3 对成对电子，进入**低自旋态（反磁性）**，原子体积缩小。
2. **空间效应**：铁原子向卟啉平面中心靠拢约 0.039 nm，最终离平面仅约 0.021 nm，血红素变为平面形；Fe 与 His F8 的键缩短并重新垂直于卟啉平面。

**结果**：铁原子移动拉动 His F8 → F 螺旋位移 → 亚基界面变化 → 四级结构改变，使其他亚基更容易结合 $O_2$。这就是别构协同效应的「开关」。

### 5. 协同效应及其量化

血红蛋白与氧的结合具有**同促别构效应**：氧与一个亚基结合促进其他亚基与氧结合。

$$
\begin{align*}
& P + nL \leftrightarrow PL_n \tag{1} \\
& K_a = \frac{[PL_n]}{[P][L]^n},\quad K_d = \frac{[P][L]^n}{[PL_n]} \tag{2} \\
& \theta = \frac{[L]^n}{[L]^n + K_d} \tag{3} \\
& \lg\frac{\theta}{1-\theta} = n\lg[L] - \lg K_d \tag{4}
\end{align*}
$$

$n$ 为结合部位相互作用的程度：$n>1$ 正协同，$n<1$ 负协同，$n=1$ 无协同。

### 6. Bohr 效应、$CO_2$ 与 BPG

- **Bohr 效应**：pH 和 $CO_2$ 浓度影响血红蛋白与氧的结合。
  - H⁺ 的影响：$\beta$ 亚基 His 146 质子化后与 $\alpha$ 亚基 Asp 94 形成盐桥，稳固 T 态。
  - $H^+$ 的来源：
    1. $CO_2 + H_2O \xleftrightarrow{\text{碳酸酐酶}} H^+ + HCO_3^-$（红细胞中碳酸酐酶含量丰富）。
    2. 血红蛋白与 $CO_2$ 结合：珠蛋白链游离氨基端与 $CO_2$ 形成氨甲酰血红蛋白，氨甲酰基也可形成盐桥。

    ![[attachments/氨甲酰血红蛋白.png|500]]

- **BPG（2,3-二磷酸甘油酸）**：
  - 作用：**降低**血红蛋白对氧的亲和力；缺氧时提高 BPG 浓度使氧曲线右移，释放更多氧给组织。
  - 原理：每个血红蛋白仅有 1 个 BPG 结合部位，位于 $\beta$ 亚基之间的带正电洞穴，与带负电的 BPG 形成盐桥、稳固 T 态。
  - 胎儿血红蛋白以 $\gamma$ 亚基替代 $\beta$ 亚基，对氧亲和力更强。

### 7. 血红蛋白分子病

- **镰状细胞贫血症**：隐性基因，异常血红蛋白为 Hb S。
  1. $\beta$ 链 N 端第 6 位谷氨酸（Glu，带负电）被缬氨酸（Val，中性疏水）替代，且该位点位于分子表面，出现疏水侧链、溶解度降低。
  2. Hb S 通过疏水侧链相互作用形成聚集体并沉降。
  3. 沉降使红细胞变成镰刀状。
  - 治疗：氰酸钾（KCNO）。
- **地中海贫血**：$\beta$ 或 $\alpha$ 链缺失，分为 $\alpha$ 地中海贫血与 $\beta$ 地中海贫血。

## 四、免疫球蛋白与分子马达

- 免疫系统相关内容参见《生物学知识引用块》中的免疫笔记；免疫球蛋白本质是抗体，也是酶抗体的基础。
- **马达蛋白**：
  1. 肌球蛋白。
  2. 动力蛋白：与微管相互作用，驱动鞭毛、纤毛运动。
  3. 驱动蛋白：胞内「货物」运输。
- 马达蛋白的相互作用力：离子键、氢键、疏水相互作用、范德华力。

### 1. 肌肉与肌节

- 肌肉收缩力量来源于**肌球蛋白与肌动蛋白的相互作用**。
- 相关蛋白：
  - **原肌球蛋白**：纤维状，两条 α-螺旋相互缠绕。
  - **肌钙蛋白**：3 个亚基——I 亚基阻止肌球蛋白与肌动蛋白结合；C 亚基结合 $Ca^{2+}$；T 亚基连接肌钙蛋白与原肌球蛋白。
  - **肌联蛋白**：N 端连接 Z 盘和细肌丝，C 端连接粗肌丝和 M 线；是一种弹性蛋白，参与肌节稳定、被动张力维持、弹性势能储存和收缩时力的增加。

  ![[attachments/肌联蛋白.png|400]]

```mermaid

	A[骨骼肌] --> B[肌束] --> C[肌纤维] --> D[肌原纤维] --> E[肌节]
```

- 多个成肌细胞前体细胞融合形成肌细胞（肌纤维），肌细胞的肌质（内质网）为钙库；肌原纤维由粗肌丝、细肌丝和其他蛋白组成。

| 结构 | 定义 |
| --- | --- |
| 明带（I 带） | 各向同性，仅含细肌丝的部分 |
| Z 盘 | I 带中央，由 α-辅肌动蛋白、结蛋白、波形蛋白等锚定细肌丝 |
| 暗带（A 带） | 各向异性，整个粗肌丝所在部分 |
| H 区 | 粗肌丝重链部分 |
| M 线 | H 区中央，由副原肌球蛋白、C 蛋白、M 蛋白等锚定粗肌丝 |

### 2. 肌球蛋白与肌动蛋白

- **肌球蛋白**：棒状分子，6 亚基（2 条重链 + 4 条轻链）。重链为 α-螺旋，以左手卷曲螺旋缠绕，N 端为球状结构域；轻链与重链球状结构域结合，能与细肌丝结合，具 ATP 酶活性（肌动蛋白可提高其 ATP 酶活性）。肌球蛋白通过离子相互作用聚集形成粗肌丝，C 端在中间、N 端在两侧。

  ![[attachments/肌球蛋白.png|500]]

- **肌动蛋白**：G-肌动蛋白（Globular actin）为单体；F-肌动蛋白（Filamentous actin）为纤维状多聚体。

### 3. 肌肉运动机制

- **纤丝滑动模型**：Z 盘向 M 线滑动，H 区、I 区缩短；粗、细肌丝本身长度不变。
- **ATP 水解模型**：
  1. ATP 与粗肌丝头基结合，使其与肌动蛋白分离。
  2. ATP 水解引起头基构象变化。
  3. Pi 释放，头基与肌动蛋白丝结合。
  4. Pi 释放引发肌动蛋白与肌球蛋白相对移动，同时 ADP 释放。
- **静息状态**：原肌球蛋白结合肌动蛋白；肌钙蛋白结合肌动蛋白–原肌球蛋白复合体。
- **兴奋收缩偶联**：神经冲动引起 $Ca^{2+}$ 从肌质网释放，与 TnC 结合，移开 TnI 和原肌球蛋白，使肌球蛋白与肌动蛋白结合。

## 五、蛋白质一级结构测定

### 1. 总体流程

末端残基鉴定 → 二硫键断裂 → 氨基酸组成分析 → 多肽链部分裂解 → 肽段测序 → 全序列重建 → 二硫键位置确定。

### 2. 具体方法

| 步骤 | 方法 |
| --- | --- |
| N 端鉴定 | FDNB（二硝基氟苯）法；也可结合Edman降解 |

![[attachments/蛋白质N端残基鉴定.png|500]]

| 步骤 | 方法 |
| --- | --- |
| C 端鉴定 | 羧肽酶，从 C 端逐个释放氨基酸 |
| 二硫键断裂 | 过甲酸氧化；二硫苏糖醇（DTT）还原 |
| 氨基酸组成分析 | 氨基酸自动分析仪，一般酸水解，辅以碱水解测定色氨酸 |
| 多肽链部分裂解 | 胰蛋白酶（Trypsin）：切割赖氨酸羧基侧与精氨酸羧基侧肽键 |
| 全序列重建 | 重叠肽法 |
| 二硫键位置确定 | 对角线电泳 |

### 3. Edman 测序法

- 降解试剂：**PITC（苯异硫氰酸酯）**。
- 通常将肽链的羧基端与不溶性树脂偶联后逐步降解测序。

![[attachments/Edman测序法.png|800]]

### 4. 质谱法（MS）

通常使用串联质谱 MS/MS。

- **ESI-MS/MS（电喷雾离子化）**：
  1. 酸性溶剂加蛋白作为样品（液相）。
  2. 高压电场使液体分散为小液滴（静电斥力大于表面张力）。
  3. 小液滴飞行中逐渐蒸发，到达 MS 时几乎只剩带电蛋白质（肽段）。
  4. 按质荷比分离。
  5. 进入碰撞池，惰性气体撞击使肽键随机断裂（通常只断一个）。
  6. 根据质谱图峰的质荷比差值推断序列（亮氨酸与异亮氨酸质量相同，无法区分）。
- **用途**：
  - 样品为酶解后的多肽链：测序后与数据库比对，适合大规模分析。
  - 样品为完整蛋白质：MS-1 测分子量，MS-2 测序。
- **MALDI-TOF MS**：飞行时间质谱，是蛋白质气化与质谱分析的另一常用方式。

![[attachments/MALDI-TOF MS.png|800]]

- 也可根据核苷酸序列推断蛋白质序列。

### 5. 对角线电泳确定二硫键位置

1. 用酶解含二硫键的蛋白质获得肽段。
2. 一维电泳分离。
3. 在过甲酸蒸汽中断裂二硫键，滤纸旋转 90°。
4. 进行第二维电泳。
5. 偏离对角线的肽段即含二硫键。
6. 取该肽段进行序列分析。

## 六、氨基酸序列与生物进化

| 概念 | 定义 |
| --- | --- |
| 序列同源性 | 两个基因具有明显的序列相似性 |
| 同源蛋白质 | 具有序列相似性的基因编码的蛋白质 |
| 直向同源蛋白质 | 来自不同物种，通常结构和功能相似 |
| 共生同源蛋白质 | 来自同一物种（由基因重复产生），通常结构相似 |
| 蛋白质家族 | 具有特定结构和功能特点的一组蛋白质 |
| 结构域 | 蛋白质家族中较长的相似序列 |
| 序列模体（motif） | 具有家族标志性的不太长的肽段 |
| 不变残基 | 功能必需、进化过程中保守的氨基酸 |
| 可变残基 | 进化过程中不保守的氨基酸 |

- 进化上相距越远，氨基酸序列的残基差异数通常越多。
- **细胞色素 c** 的氨基酸序列常用于分析物种分类关系和绘制系统进化树。

## 七、肽和蛋白质的合成

- 肽的获得途径：从动植物组织中分离、基因工程、化学合成。
- **保护基要求**：接肽时起保护作用；接肽后容易去除；不会断裂肽键。
  - 氨基保护基：BOC（叔丁氧羰基）、Fmoc（芴甲氧羰基），二者用 $CF_3COOH$ 去除。
  - 羧基保护基：盐或酯（钠盐、钾盐、甲酯、乙酯、叔丁酯）；甲酯、乙酯用皂化去除但容易消旋，叔丁酯用酸去除。
- **缩合剂**：DCC（$N,N'$-二环己基碳二亚胺），直接与被保护的氨基、羧基反应成肽；反应后成固体，过滤去除。
- **固相肽合成（SPPS）**：C 末端氨基酸与氯甲基聚苯乙烯–二乙烯苯树脂反应，DCC 为缩合剂；最后用 $CF_3COOH + HF$ 使肽与树脂脱离并切除保护基。仪器为固相肽合成仪。

## 八、蛋白质的性质

### 1. 溶解性与胶体

- **中性盐**可改变蛋白质等电点和滴定曲线：通过与蛋白质结合改变其电荷。
- **等离子点**：蛋白质质子供体解离出的质子数与质子受体基团结合的质子数相等时的 pH。
- 蛋白质溶液属于**胶体**：大多数蛋白质大小在 1–10 nm，分散相质点即蛋白质本身，因此也是均相系统（一般只有真溶液才是均相系统）。
- 胶体稳定的条件：
  1. 质点大小 1–100 nm，介质对质点碰撞合力不为零，产生布朗运动。
  2. 质点带同种电荷。
  3. 质点与水形成水化层。

### 2. 蛋白质沉淀（结晶）

- 原理：破坏水化层，或使静电荷为零。
- 方法：

| 方法 | 要点 |
| --- | --- |
| 盐析法 | 中性盐破坏水化层 |
| 有机溶剂沉淀法 | 破坏水化层、降低介电常数，会引起变性 |
| 重金属盐沉淀法 | pH > 等电点时不溶性盐沉淀，会引起变性 |
| 生物碱/某些酸沉淀 | 形成不溶性盐 |
| 加热变性 | 构象变化、疏水基外露、破坏水化层 |

## 九、蛋白质的分离纯化与鉴定

### 1. 分离纯化流程

1. **前处理**：将蛋白质从组织/细胞中释放。
   - 动物：剔除结缔组织、脂肪 → 捣碎机/匀浆器/超声破碎。
   - 植物：种子去皮 → 研磨/纤维素酶处理。
   - 细菌：超声震荡/溶菌酶。
   - 差速离心分离。
2. **粗分离**：选择性沉淀（盐析、等电点沉淀、有机溶剂分离）；不能沉淀的用层析法；缓冲液重溶换液；透析/超滤脱盐。
3. **细分离**：柱层析。
4. **结晶**：控制温度、盐析、有机溶剂、pH 使溶液过饱和。变性的蛋白不能结晶。

### 2. 分离依据

| 依据 | 方法 |
| --- | --- |
| 溶解度 | 受 pH、离子强度、介电常数、温度影响；盐析、等电点沉淀、有机溶剂分级 |
| 分子大小 | 凝胶过滤 |
| 电荷 | 电泳、离子交换层析 |
| 结合性质 | 疏水相互作用层析、SDS-PAGE、亲和层析 |

### 3. 选择性沉淀与脱盐

- **等电点沉淀**：等电点时蛋白质分子间无静电排斥，溶解度最低，可聚集沉淀。
- **盐溶与盐析**：
  - 盐溶：低浓度中性盐增加蛋白质溶解度（蛋白吸附盐离子后静电排斥增强，与水相互作用增强）。
  - 盐析：大量中性盐降低水的活度，自由水变为盐离子的水化水，蛋白质疏水基团暴露并通过疏水相互作用沉淀。
  - 离子强度 $I = \dfrac{1}{2}\sum C_i Z_i^2$；例如 2 mol/L 硫酸铵：$I=\dfrac{(4\times1)+(2\times4)}{2}=6$。
- **有机溶剂分级分离**：改变介电常数（介电常数降低使电荷吸引力增加）；聚乙二醇等水溶性非离子聚合物可脱去蛋白质水化层。
- **脱盐**：
  - 透析：蛋白质不能通过半透膜，从而与小分子分离。
  - 超滤：压力或离心力强制水和小分子通过半透膜，兼具浓缩和脱盐作用。
- **密度梯度超速离心**：蛋白质颗粒沉降到与自身密度相同的梯度位置；常用蔗糖梯度、聚蔗糖梯度。
- 其他方法：电泳、层析（见相关专题笔记）。

### 4. 相对分子质量测定

| 方法 | 原理与特点 |
| --- | --- |
| 凝胶过滤 | $\lg_{10}M_r = a - bV_e$；用标准蛋白绘制标准曲线。优点：样品可不纯；缺点：仅限于球蛋白 |
| SDS-PAGE | SDS 为变性试剂，破坏氢键和疏水作用使肽链展开，其负电荷掩盖蛋白本身电荷；考马斯亮蓝染色；$\lg M_r = a - b\mu_R$。缺点：迁移率受亲疏水基团比例影响，误差较大 |
| 沉降速度法 | $M_r = \dfrac{RTs}{D(1-\bar{v}\rho)}$，$\dfrac{d\lg x}{dt}=\dfrac{s\omega^2}{2.303}$；工具为超速离心机，通过界面折射率变化观察移动（$\bar{v}\approx0.74$） |
| 质谱法 | $\dfrac{m}{z}=\dfrac{M+nH}{n}$，由相邻两峰确定 $M$；常用电喷雾离子化质谱 |

### 5. 含量测定与纯度鉴定

- **总蛋白绝对含量测定方法**：凯氏定氮法、双缩脲法、Lowry 法、BCA 法、紫外吸收法、Bradford 法、胶体金测定法。
- **纯度鉴定**：电泳、等点聚焦电泳（IEF）。
