# 02 · 卵裂与囊胚形成

> [!abstract] 本章速览
> 受精卵在透明带内连续有丝分裂 → 卵裂球 → 囊胚。核心线索：**卵黄的多少与分布决定卵裂方式**；**核质比决定合子基因组激活时机**；哺乳动物在此基础上出现致密化与内细胞团 / 滋养层分化。
>

## 2.1 卵裂概述

- **定义**：单细胞受精卵在**透明带内**连续不断有丝分裂，形成多细胞胚体的过程。
- **卵裂球**：卵裂过程中快速形成的子细胞。
- **调控**：母本 mRNA 和蛋白质决定卵裂速度与卵裂球位置。

**卵裂的意义**

1. 建立细胞间联系；
2. 早期定向分化：胞质不均等分配 → 形态发生决定物不对称分布；
3. 母源性调控转变为合子型调控。

> [!note] 与绪论呼应
> "胞质定域 → 命运早定"对应[[01-绪论与发育基本过程#1.3.4 镶嵌型发育 vs 调整型发育|镶嵌型发育]]；"早期卵裂球全能"对应**调整型发育**。

---

## 2.2 卵裂方向与早期卵裂周期

### 2.2.1 卵裂方向

- **动物极（A）**：卵黄少的一端；**植物极（V）**：卵黄多的一端；A–V 轴即卵轴。
- 卵裂面与 A–V 轴**平行** → 纵裂（经裂）。
- 纺锤体与 A–V 轴**平行** → 纵裂；**垂直** → 横裂（纬裂）。

### 2.2.2 早期卵裂周期特点

| 特点 | 说明 |
| --- | --- |
| 周期短、速度快 | 受母源 mRNA 和蛋白调控 |
| 无需合成新 mRNA | 利用母本储备 |
| G1、G2 期不生长 | 细胞体积逐渐变小 |
| 仍受细胞周期调控 | 并非"失控"分裂 |

### 2.2.3 影响因素

1. **卵黄含量及分布**：卵黄多会妨碍卵裂。
   - 多卵黄：昆虫、鱼类、爬行类、鸟类 → 不完全卵裂；
   - 少卵黄：海胆 → 通常迅速发育成幼虫；
   - 哺乳动物：无卵黄 → 依赖胎盘。
2. **纺锤体方位角度与形成时间**：纺锤体位置通常与卵裂面垂直；**卵裂沟形成取决于星体而非纺锤**。

## 2.3 卵黄分布与卵裂类型

### 2.3.1 卵黄分布类型

| 卵类型 | 卵黄分布 | 卵裂方式 |
| --- | --- | --- |
| 均黄卵 | 卵黄均匀分布 | 完全卵裂（两栖类为偏移辐射型） |
| 中黄卵 | 中等程度植物极卵黄 | 偏移辐射卵裂 |
| 端黄卵 | 细胞大部分为密集卵黄 | 盘状卵裂 |
| 中央卵黄卵 | 卵黄位于卵中央 | 表面卵裂 |

### 2.3.2 完全卵裂

| 类型 | 代表动物 | 关键特征 |
| --- | --- | --- |
| **辐射型** | 棘皮动物、半索动物、毛颚动物 | 第 1、2 次经裂，第 3 次纬裂，卵裂球呈辐射状；有丝分裂器与卵轴垂直或平行，卵裂沟对称 |
| **偏移辐射型** | 两栖类（蛙） | 植物极卵黄多，卵裂落后于动物极；第 1 次卵裂沟较大，后续形成囊胚腔 |
| **螺旋型** | 环节、软体、扁形、纽形动物 | 纺锤体与赤道面呈 45°；右旋 / 左旋，多为左右旋交替；前两次经裂，第三次旋转不均等分裂；**实囊胚**，原肠运动早 |
| **两侧对称型** | 刺胞动物、尾索动物（水螅、海鞘） | 第 1 次经裂确定胚胎对称面，后续卵裂围绕该面进行 |
| **旋转型** | 线虫、哺乳动物 | 第 1 次经裂，第 2 次一个经裂一个纬裂 |

> [!important] 囊胚腔的作用（两栖类）
> ① 为原肠运动提供空间，利于细胞迁移；② 防止上下层细胞过早接触，影响分化。原肠作用详见 [[03-原肠作用与胚轴建立]]。

**哺乳动物卵裂特征**：速度慢；交替旋转对称均裂；早期卵裂不同步；合子基因组在早期即开始活动；出现[[#2.6 胚胎紧锁现象（致密化）|致密化]]。

### 2.3.3 不完全卵裂

大量卵黄使卵裂沟仅局限于无卵黄或动物极，卵黄部分不分开。

**① 盘状卵裂（盘状囊胚）**

- 细胞质集中在动物极顶端形成胚盘，细胞核位于其中，卵裂只在胚盘进行；代表：鱼类、鸟类、爬行类。
- **鸟类**：前三次均为经裂；细胞间及与卵黄均连通；在输卵管中胚盘为单细胞层，进入子宫后行纬裂；胚盘与卵黄分开形成**胚下腔** → 中央透明为**明区**，边缘细胞与卵黄接触不透明为**暗区**。
- **斑马鱼**：钙波刺激机动蛋白挤压细胞质形成梨形；顶部为胚盘；前五次为经裂；囊胚期在 128 细胞期。

**② 表面卵裂**

- 卵黄集中于卵中央；最初几次在原生质岛卵裂，核数增多后卵黄进入卵质，在表面继续分裂。
- 特征：**核分裂而细胞质不分裂** → 合胞体胚盘。
- **活质体**：合胞体中每个细胞核所在的、由微管微丝细胞骨架围成的区域。
- 第 13 次分裂周期后活质体被分割成单个细胞，形成细胞胚盘（单细胞层）。代表：大部分节肢动物。
- **果蝇补充**：早期核分裂位于合胞体中央，随后迁移到细胞边缘；体内受精；不需要受精刺激，在输卵管受刺激启动减数分裂；受精时无卵融合、精子直接进入卵子；通过精孔阻止多精入卵。

### 2.3.4 按卵裂球大小

- **均等卵裂** vs **不均等卵裂**（胞质不对称分配 → 命运差异）。

## 2.4 不同物种卵裂实例

| 物种 | 时间 / 节点 | 特征 |
| --- | --- | --- |
| **小鼠** | 1→2 细胞约 24 h；囊胚约 5 天（人约 7 天） | 8 细胞具全能性；16 细胞致密化（细胞黏着分子）；致密化后细胞出现极性；桑葚胚约 32 细胞 |
| **人** | 30 h 第一次卵裂；第 4 天桑葚胚 | 8 细胞期致密化，依赖 E-钙黏素 |

## 2.5 囊胚形成与中期囊胚转换

### 2.5.1 囊胚与囊胚腔

- **囊胚**：卵裂后的细胞球；**囊胚腔**：囊胚的空腔（无脊椎动物无）。
- **囊胚脱离透明带**
  - 透明带作用：阻止胚泡与输卵管壁黏连。
  - Na⁺-K⁺ 泵吸入 Na⁺ 使囊胚腔增大。
  - 胚泡到达子宫后分泌胰蛋白酶（trypsin），使透明带穿孔，胚泡挤出并与子宫壁接触。

### 2.5.2 中期囊胚转换（MBT）：合子基因转录激活

| 概念 | 含义 |
| --- | --- |
| 母体效应基因 | 在母体中发挥活性的基因 |
| 母体信使 | 卵母细胞中的 mRNA |
| 转换过程 | 伴随母体 mRNA 清除 |

**非哺乳类**

- 早期受精卵转录受抑制 → 合子基因组转录启动；
- 伴随细胞分裂减缓（受**核质比**影响）、失去同步化、细胞表型变化 → 合子型调控；
- 非洲爪蟾、海胆、果蝇等：**核质比回归平衡决定合子基因转录**（即中期囊胚转换）。

**哺乳类**

- 卵裂早期胚胎基因组即开始表达，否则发育阻滞（体外培养停滞于不同阶段）；
- 分为辅助时相与主要时相：
  - 小鼠：1 细胞晚期辅助期开始 → 2 细胞早期合成少量蛋白 → 2 细胞晚期为主要激活期；
  - 其他哺乳动物：2–3 卵裂期。

## 2.6 胚胎紧锁现象（致密化）

- 第三次卵裂后，卵裂球挤在一起形成紧密细胞球——**致密化**。
- 连接类型：外部细胞为**紧密连接**，内部细胞为**间隙连接**。
- 16 细胞桑葚胚分化为：

| 细胞群 | 位置 | 命运 |
| --- | --- | --- |
| **内细胞团 ICM** | 内部少数细胞 | 胚胎本体及卵黄囊、尿囊、羊膜；为胚胎干细胞，可分化成身体任何细胞类型 |
| **滋养层 TE（滋胚层）** | 外部细胞（绒毛层） | 摄取营养与氧气；产生免疫调控因子避免排斥；产生激素维持妊娠 |

> [!tip] 复习提示
> 小鼠 **8 细胞全能 → 16 细胞致密化并出现极性** 是常考时间点。致密化后外部细胞走滋养层命运、内部细胞走 ICM 命运，衔接 [[03-原肠作用与胚轴建立]] 中哺乳类的上 / 下胚层形成。
