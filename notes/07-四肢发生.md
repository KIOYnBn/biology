# 07 · 四肢（附肢）发生

> [!abstract] 本章速览
> 四肢是**三个轴（前后、背腹、近远）协同图式形成**的经典模型。核心信号对：**AER–FGF**（近远轴）、**ZPA–SHH**（前后轴）、**Wnt7a–Lmx1 / BMP–En1**（背腹轴），三者相互依赖。
>
> 上一章 ← [[06-内胚层及其衍生器官]] ｜ 下一章 → [[08-胚后发育]]

---

## 7.1 形态发生原则

- **四足动物**：具有四肢的脊椎动物。

**三个轴**

| 轴 | 含义 |
| --- | --- |
| **背腹轴** | 手掌（腹面）与指关节（背面） |
| **前后轴** | 拇指（前端）到小指（后端） |
| **近远轴** | 肩 → 手指，臀 → 足趾 |

**近—中—远三段**

- 近端肢柱：肱骨、股骨；
- 中端肢杆：桡骨、尺骨、腓骨；
- 远端肢梢：腕骨、踝骨。

**发育要点**：图式形成 → 细胞区域化 → 细胞迁移与凋亡 → 神经轴突导入。

---

## 7.2 肢芽形成

- **肢芽**：体轴两侧的突起，来自**侧板中胚层**。
- **肢场**：其内细胞能够自身形成一个肢的所有细胞。
- **腹肢**：胚胎体壁向外生长形成；来自中胚层的疏松间质形成中央核（骨骼和肌肉），外胚层形成表皮。
- **Hox 基因**：同源异形基因；**HOX13 突变**导致多指并指综合征。

---

## 7.3 肢体发育的细胞来源与启动

| 细胞来源 | 迁移去向 | 形成 |
| --- | --- | --- |
| 侧板中胚层间充质细胞 | 迁入肢场 | 骨骼前体细胞（与生骨节发育不同） |
| 体节中胚层间充质细胞 | 迁入肢场 | 肌肉前体细胞 |

- 侧板中胚层间质细胞分泌 **FGF10** → 启动肢场表皮外胚层与中胚层的相互作用，可诱导生成**额外肢芽**。
- **TBX5 / TBX4** 分别激活不同 HOX 基因，指定前肢 / 后肢芽发育。

### 7.3.1 顶端外胚层嵴（AER）

- 位于远端背腹交界处，是肢体生长的主要信号中心，对附肢继续向外生长至关重要。
- 由中胚层间质细胞诱导外侧胚层细胞形成。
- **作用**：维持间充质增殖与近远轴；维持前后轴因子表达；促进前后、背腹轴因子互作。
- **AER 与中胚层的相互作用**：中胚层启动腹肢芽向外生长并形成 AER → AER 诱导间质细胞增殖 → 中胚层提供维持 AER 所必需的刺激。
- **FGF 是主要活性因子**（近远端的分子基础）；**间质细胞决定肢体类型**。

### 7.3.2 渐进区与极性活化区（ZPA）

| 区域 | 位置 | 功能 |
| --- | --- | --- |
| **渐进区** | AER 下方间质细胞，具分裂能力 | 发育程度决定近远轴信息：先被推离的细胞形成最近端成分，停留久的形成较远端成分；受 HOX 基因调控 |
| **极性活化区 ZPA** | 渐进区最后区域、背腹交界下的间充质细胞 | 影响前后轴形成；分泌 **SHH 蛋白** |

### 7.3.3 背腹轴与三轴互作

| 轴 | 分子机制 |
| --- | --- |
| **背侧** | 背部外胚层表达 **Wnt-7a** → 诱导背部间质细胞转录 **Lmx1** → 形成背部 |
| **腹侧** | 间质细胞 **BMP** 信号 → 外胚层表达 **En1** → 形成腹部 |

- **三轴相互影响**：维持 ZPA 既需要 AER 分泌的 FGFs，也需要肢芽背部外胚层分泌的 Wnt7a；AER 的 FGFs 与 ZPA 的 SHH 相互依赖，而 SHH 的作用需要 Wnt 信号维持。

> [!important] 速记三角
> **AER–FGF ↔ 近远轴**；**ZPA–SHH ↔ 前后轴**；**Wnt7a/BMP ↔ 背腹轴**。三者构成互相维持的网络。

---

## 7.4 肢芽发育中的形态发生

- **坏死区**：发生程序性死亡的区域，共三个——内部、前后、指趾坏死区。
- 早期肢芽：趾间组织表达 BMP → DKK1 促进凋亡；趾区头蛋白拮抗 BMP。
- 后期肢体：BMP → Wnt/β-联蛋白，促进间质细胞形成软骨。
- 关节处：BMP2 + GDF5 促进关节形成，在骨间表达。
- 上肢芽 → 臂、前臂、手；下肢芽 → 大腿、小腿、足。

## 7.5 人四肢发生时间线

| 时间 | 事件 |
| --- | --- |
| **第 26 天** | 腹侧出现上肢芽；2 天后出现下肢芽 |
| — | 肢芽增长变粗，中轴间充质先形成软骨，再以**软骨内成骨**形成骨；周围间充质分化成肌群，脊神经长入 |
| **第 6 周** | 肢芽终末段变扁形成手板 / 足板，由收缩环与近段分开；再出现一个收缩环分成三段：上肢为臂、前臂、手；下肢为大腿、小腿、足 |
| — | 部分细胞凋亡，指趾分化，末端出现四条纵行凹沟——**指（趾）放线**，手板足板呈蹼状 |
| **第 7–8 周** | 放线间组织因细胞凋亡逐渐退化消失 |
| **第 8 周末** | 形成相互分离的指（趾） |
| — | 肢体最初向前外侧伸直伸长，随伸长和关节形成转向体壁弯屈 |
