# 02 · 连锁遗传与染色体作图

> [!abstract] 一句话定位
> 自由组合适用于**非同源染色体**上的基因；同一染色体上的基因表现为**连锁**，重组率反映基因间距离，据此可把基因排成线性图谱。

## 1　连锁与交换

### 1.1　两种遗传方式

| 类型 | 条件 | 配子 / 子代特征 |
| :--- | :--- | :--- |
| **自由组合** | 基因位于**非同源染色体** | 等位基因独立分配，出现 9∶3∶3∶1 等经典比例 |
| **完全连锁** | 基因位于**同一染色体**且其间不发生交换 | 只能产生亲本型配子（果蝇杂交实验） |
| **不完全连锁** | 同一染色体上的基因间发生交换 | 子代出现少量**重组型**个体 |

### 1.2　摩尔根的交换理论与 Sturtevant 原理

**摩尔根（Morgan）的交换**

1. 连锁的基因在染色体上**线性排列**。
2. 任何两个基因之间都可能发生交叉。
3. 基因距离越远，发生交叉的次数越多。

**Sturtevant 原理**

- 交换率具有**加和性**。
- 交换率可代表基因间的图距，但二者**非线性**关系（多次交换会被低估）。
- 图距单位：$1\ \mathrm{mu} = 1\ \mathrm{cM} = 1\%$ 重组率。

> [!warning] 为什么图距非线性
> 两点之间可能发生双交换甚至三交换，使重组型被「换回去」而检测不到，因此距离越远，表观重组率越低于真实交换次数（→ 干涉，见 2.4）。

## 2　真核生物染色体作图

### 2.1　交换类型与可检测性

| 类型 | 发生范围 | 能否检测 |
| :--- | :--- | :--- |
| 单交换 | 两个基因之间 | 能检测到 |
| 双交换 | 两基因之间（涉及三个基因） | 两点测交检测不到；**三点测交可检测到** |
| 三交换 | 三个及以上区段 | 三点测交可分析 |

### 2.2　三点测交的前提

1. 亲本为**杂合体**。
2. 表现型与基因型一一对应。
3. 子代数量足够多，保证稀有重组型能被观察到。

### 2.3　作图步骤

1. **确定基因排序**
   - 亲本型：F2 中数量**最多**的两类。
   - 双交换型：F2 中数量**最少**的两类。
   - 单交换型：其余四类。
   - 比较双交换型与亲本型，只有中间基因发生互换 → 中间基因确定。
2. **确定基因间图距**：分别计算相邻两区段的重组率（含双交换个体）。
3. **计算干涉与并发系数**。

### 2.4　干涉与并发系数

- **并发系数（重合系数）**：$C = \dfrac{\text{观察到的双交换数}}{\text{预期的双交换数}}$
- **干涉**：$I = 1 - C$

| 情况 | 判据 | 含义 |
| :--- | :--- | :--- |
| 完全干涉 | $C = 0$，$I = 1$ | 观察不到双交换 |
| 正干涉 | $0 < C < 1$，$I > 0$ | 观察到的双交换**少于**预期 |
| 负干涉 | $C > 1$，$I < 0$ | 观察到的双交换**多于**预期 |

> [!important] 干涉的本质
> 一次交换会**抑制相邻部位发生第二次交换**；两个位点越近，干涉越强。这也可从染色体交叉重组的角度理解。

> [!note] 染色体分带与图谱定位
> 染色体分带（Q/G/C/R/T 带、m-FISH）是**细胞学层面**的定位标记，命名需依次注明染色体序号、臂序号、区序号、带序号；详见 [[遗传学/02-染色体与基因组/02-染色体畸变与核型分析|染色体畸变与核型分析]]。

## 3　原核生物染色体作图

### 3.1　细菌接合

| 要点 | 内容 |
| :--- | :--- |
| 方向 | **单向**传递：供体菌 → 受体菌 |
| F 因子 | 一种接合质粒，控制 F 纤毛形成，使供体菌提供遗传信息 |
| $F^+$ 菌 | 含游离 F 因子；与受体菌交换基因概率约 $10^{-7}$，接合后受体菌转变为 $F^+$ |
| Hfr 菌 | F 因子**整合进染色体**；整合概率约 $10^{-3}$，与受体菌交换基因概率约 $10^{-4}$；转移后受体菌仍为 $F^-$ |

**转移顺序**：整合位点处的染色体基因**先转移**，F 因子**最后转移**。

**中断杂交作图**：在不同时间点中断接合，按基因进入受体菌的先后顺序推断基因在染色体上的排列与相对距离。

### 3.2　性导与转化

| 方式 | 机制 |
| :--- | :--- |
| **性导** | 由 $F'$ 因子介导；$F'$ 因子携带了部分主染色体基因，转入 $F^-$ 细胞 |
| **转化** | 受体菌通过纤毛抓取外源 DNA 并整合到自身基因组 |
| **共转化** | 位于同一段 DNA 上的邻近基因一起被转化，据此判断基因相邻关系 |

## 4　考点速记

- 三点测交：**数量最多 = 亲本型；数量最少 = 双交换型**；中间基因由双交换型确定。
- 计算图距时，双交换个体要在两个区段**各计一次**。
- $C=1$ 无干涉；$C<1$ 正干涉；$C>1$ 负干涉；$I=1-C$。
- Hfr 作图依靠**进入顺序**，而不是重组率；$F^+$ 转移后受体变 $F^+$，Hfr 转移后受体仍为 $F^-$。
- 共转化说明两基因在 DNA 上相邻。

<details>
<summary><b>自测 1：为什么两点测交会低估较远基因间的图距？</b></summary>

因为两点之间可能发生双交换，使两端基因恢复到亲本组合，重组型不被计入；交换率与图距呈非线性关系，需用三点测交或作图函数校正。
</details>

<details>
<summary><b>自测 2：如何用中断杂交确定 Hfr 菌株的基因顺序？</b></summary>

让 Hfr 与 $F^-$ 接合，在不同时间中断并检测受体获得的基因。越早进入的基因离 F 因子整合位点（转移起点）越近，依进入时间先后即可排出基因顺序。
</details>
