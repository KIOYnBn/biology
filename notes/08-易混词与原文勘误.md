## 8.2 译名与拼写订正

| 原写法 | 订正后 | 理由 |
| --- | --- | --- |
| nuclear membrane：细胞膜 | **核膜** | nuclear = 核的；与 cell membrane（细胞膜）不同 |
| coccus (spherical)：双球菌 | **球菌（球形）** | 单个为球菌；pair of cocci 才是双球菌 |
| spirillum：螺旋杆菌 | **螺菌** | 与 spirochaete（螺旋体）区分 |
| spirochaete：螺旋菌 | **螺旋体** | 螺旋体的标准译名 |
| Creutzfeldt-Jacob disease | **Creutzfeldt-Jakob disease** | 标准拼写为 Jakob |
| shelf life：货期 | **货架期 / 保质期** | shelf life 指产品贮存期限 |
| siblings：同科 | **同胞，同窝个体** | sibling 指同胞兄弟姐妹 |
| alternative splicing：选择性剪切 | **选择性剪接** | 分子生物学标准译法 |
| pollen-tube-pathway：花粉孔途径 | **花粉管通道（原译花粉孔途径）** | 正文两说并存，便于对照原文 |

> [!note] 未改动的存疑条目
> `a vector in vitro` 原译「体外质粒」，但 vector 更常译作「载体」，故正文写作「体外质粒（载体）」并保留原译；`taking the advantage of` 按原文照录。

## 8.4 常见易混词辨析

| 易混组 | 区分要点 |
| --- | --- |
| heredity / inheritance / genetic trait | 遗传现象 / 遗传或继承物 / 可观察的遗传性状 |
| allele / variant / variation | 同一基因座的不同形式 / 变体 / 变异现象 |
| pathogen / causative agent / germ | 病原体（泛称）/ 引发疾病的因子 / 病原微生物 |
| coccus / pair of cocci / chain of cocci / cluster of cocci | 单个球菌 / 双球菌 / 链球菌 / 葡萄状球菌簇 |
| bacillus / spirillum / spirochaete / vibrio | 杆菌 / 螺菌 / 螺旋体 / 弧菌 |
| LM / OM / TEM / SEM / AFM | 光学显微镜（两种缩写）/ 透射电镜 / 扫描电镜 / 原子力显微镜 |
| monomer / dimer / polymer | 单体 / 二聚体 / 多聚体，规律见 [[06-词根词缀与构词法]] 6.1 |
