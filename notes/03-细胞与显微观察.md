# 03 细胞与显微观察

> [!abstract] 本篇涵盖
> 「细胞」「细胞核」「显微镜」三篇词卡，以及原第五章的 `mitochondria`。词根 **-cyto- / -cyte / karyo-** 的构词规律统一放在 [[06-词根词缀与构词法]]，本篇保留具体例词。

## 3.1 细胞的基本结构

| 英文（音标） | 中文 | 备注 |
| --- | --- | --- |
| cell | 细胞 | |
| cell membrane | 细胞膜 | |
| cell wall | 细胞壁 | 植物、细菌等具有 |
| nucleus | 细胞核 | |
| nuclear | 核的，细胞核的 | 形容词 |
| nuclear membrane | 核膜 | **原词卡误译为「细胞膜」，已订正** |
| nuclear pore | 核孔 | |
| cytoplasm | 细胞质 | -cyto- 例词 |
| cytoskeleton | 细胞骨架 | -cyto- 例词 |
| lymphocyte | 淋巴细胞 | -cyte 例词 |
| mitochondria | 线粒体 | mitochondrium 的复数；原第五章 |

> [!warning] 易错点
> `cell membrane` = 细胞膜；`nuclear membrane` = **核膜**。原词卡把后者写成「细胞膜」，属于误译，详见 [[08-易混词与原文勘误]]。
> 与细胞核相关的 `prokaryote / eukaryote / karyotype` 等词见 [[06-词根词缀与构词法]]。
