# 02 · DNA 复制

> [!abstract] 一句话定位
> 复制的核心矛盾是**又快又准**：靠几何匹配 + 动力学校对 + 外切校对 + 错配修复层层把关；靠滑动夹与长号模型实现高速协同。

## 1　DNA 合成的化学基础

### 1.1　底物与反应

1. **底物**：四种脱氧核苷三磷酸 dGTP、dCTP、dATP、dTTP。
2. **引物-模板接头**：单链 DNA 与双链 DNA 共同构成的特殊结构。
3. **磷酸二酯键通过 $S_N2$ 反应形成**（双分子亲核取代）：
   - 引物 3′ 端羟基攻击核苷三磷酸的 **α-磷酸**；β、γ 基团形成焦磷酸，随后水解。
4. **能量供给**：焦磷酸水解释放的能量。
5. 反应式：$XTP + (XMP)_n \rightarrow (XMP)_{n+1} + 2P_i$

### 1.2　重要蛋白

DNA 解旋酶 · 单链结合蛋白（SSB）· 拓扑异构酶 · 引物酶 · DNA 聚合酶

### 1.3　复制出错的后果与纠正

| 错误类型 | 后果 |
| :--- | :--- |
| 不完全复制 | 染色体分离时断裂或缺失 |
| 不复制 | 子代细胞基因组缺失 |
| 多复制 | 诱发癌变 |

**限制聚合酶精度的因素**：自发突变（碱基构象变化）· 差错复制（绕过损伤）· 修复时引入的错误 · 诱发突变。

**四级矫正**：聚合酶外切酶活性 → 合成过程检验 → 复制后错配修复（→ [[分子生物学/02-基因组维持/03-DNA损伤突变与修复|错配修复]]）。

## 2　DNA 聚合酶的机理

> [!important] 一个活性位点，四种底物
> 聚合酶**不识别碱基种类**，而靠**几何匹配**——A-T 与 G-C 配对后几何形状一致。

### 2.1　保真性的三层实现

| 层次 | 机制 |
| :--- | :--- |
| **几何匹配** | 单个活性位点催化 4 种底物，正确配对形状一致 |
| **动力学校对** | 正确配对 3′-OH 对准 α-磷酸，SN2 极易发生；错误配对速率慢约 **10 000 倍**，错误核苷酸在反应前即离开活性位点 |
| **rNTP 排斥** | 核苷酸结合口袋没有容纳 2′-OH 的空间（被两个氨基酸残基占据），靠**空间位阻**区分 dNTP 与 rNTP |

### 2.2　四个结构域

#### 手掌结构域（催化核心）

- 由 **β 折叠片**构成，含两个催化活性位点（聚合酶活性、核酸外切酶活性）。
- **催化功能**：结合两个二价金属离子（通常 Mg²⁺ 或 Zn²⁺）。
  1. 第一个离子降低 3′-羟基对氢原子的亲和力，形成 3′-O⁻，进攻 dNTP 的 α-磷酸。
  2. 第二个离子配位 dNTP 的 β、γ 磷酸负电荷，稳定焦磷酸。
- **校验功能**：与新合成 DNA 的**小沟**形成大量氢键，只有正确配对才能形成。
  - 错配破坏小沟相互作用 → 催化速率大幅下降 → 引物链脱离活性位点。
  - 3′ 端转而与外切酶位点亲和力增强 → 错配碱基被切除。

#### 拇指结构域

- 与新合成 DNA 区域相互作用：
  1. 维持引物与活性位点的正确相对位置。
  2. 增强聚合酶与底物结合强度——一次结合即可连续添加多个 dNTP 的结构基础。

#### 手指结构域

1. 多个氨基酸残基与进入的 dNTP 结合。
2. 正确配对后发生**构象合拢**，包裹 dNTP，将其推近催化金属离子。
3. 与模板链结合，使模板磷酸二酯骨架在第 1、2 个模板碱基间发生接近 **90° 弯折**，使催化位点仅暴露引物后第一个模板碱基。

#### 核酸外切酶结构域（3′→5′ 校对）

- **限制 DNA 合成精度的主要因素：碱基互变异构**。
- 原理
  1. **动力学**：错配既减慢新核苷酸添加，又提升校对外切酶活性。
  2. 引物-模板接头稳定性下降 → 解链形成 ssDNA。
     - 聚合活性位点对 ssDNA 结合能力差，外切酶位点对单链 3′ 端亲和力高。
     - 3′ 端转移到外切酶位点切除错误核苷酸 → 接头重新形成 → 回到聚合位点。

### 2.3　核苷酸添加循环（5 步）

1. 进入的核苷酸与下一个模板碱基配对。
2. 配对触发**手指结构域闭合**，包裹 dNTP。
3. 构象将催化金属离子置于合适位置，催化磷酸二酯键形成。
4. 新核苷酸连接到引物后，手指结构域**重新张开**，引物-模板接头前移 1 bp。
5. 聚合酶就绪，进入下一轮。

### 2.4　持续合成能力与限速步骤

- **持续合成的结构基础**：聚合酶沿模板滑动。
  - 作用力：DNA 磷酸骨架 ↔ 拇指结构域的**静电相互作用**；DNA 小沟 ↔ 手掌结构域的**氢键**。
  - 每添加 1 个核苷酸，小沟氢键断开但拇指静电作用始终保持；随后重新结合，位置前移 1 bp。
- **限速步骤**：聚合酶最初**定位并结合引物-模板接头**。

## 3　复制叉

### 3.1　基本概念

- **复制叉**：解螺旋分离的模板链与未复制双链形成的 **Y 形结构**。
- **前导链**：连续合成，方向与复制叉移动方向相同。
- **后随链**：不连续合成，方向与复制叉移动方向相反。
- **冈崎片段**：后随链上的不连续 DNA 片段。
- 两条链在复制叉处**同步合成**。

### 3.2　引物的合成与切除

DNA 聚合酶需要 3′-OH，无法从头合成 → 需要**引物酶**（一种 RNA 聚合酶，与解旋酶结合后活性提高）。

| 步骤 | 原核 | 真核 |
| :--- | :--- | :--- |
| 合成 | Primase | DNA Pol α（引物酶活性） |
| 切除 | DNA Pol I（5′→3′ 外切） | RNase H（切除 RNA-DNA 杂交链中的 RNA）+ FEN1 |
| 填补 | DNA Pol I + 连接酶（ATP 连接 3′-OH 与 5′-磷酸） | 修复型聚合酶 + 连接酶 |

#### Pol I 与 RNase H 的分工

| 对比维度 | DNA Pol I | RNase H |
| :--- | :--- | :--- |
| 酶切类型 | 5′→3′ 核酸外切酶 | 核酸内切酶 |
| 底物特异性 | 可切 RNA、DNA、DNA-RNA 杂合链，无专一性 | 专一识别 DNA-RNA 杂合双链，仅切其中 RNA 链 |
| 核心功能 | 切除 RNA 引物短片段、填补缺口、损伤修复 | 把长 RNA 引物切成短片段、清除 R-loop、切除错配掺入的核糖核苷酸 |
| 协同分工 | **后期**：清扫 RNA 残段 + 缺口平移填补 DNA | **前期**：打碎长 RNA 引物，启动清除流程 |
| 聚合活性 | 有 5′→3′ DNA 聚合活性 | 无 |

### 3.3　解旋酶

- 六聚体、环状，套在单链上，具**连续性**；ATP 提供能量；复制起始时开环。
- 每个亚基带一个"发夹状"蛋白环，结合 DNA 骨架上的一个磷酸及两侧相邻核糖；这些环呈**右手螺旋**排列，依次结合 ssDNA 上前后相邻的磷酸基团。
- **移动循环**
  1. 结合 ATP：亚基位于通道顶端，牢牢抓住 DNA 磷酸骨架。
  2. ATP → ADP：亚基构象改变，向通道底端移动，带动 DNA 下移一个磷酸位点。
  3. 释放 ADP 与 Pi：亚基松开 DNA，复位回顶端。
- 到达 DNA 末端后释放。

### 3.4　单链结合蛋白（SSB）

1. **重要性**：解开的 ssDNA 有自发复性或形成发卡的倾向，会阻碍聚合酶与引物酶工作。
2. **协同效应**：一个 SSB 结合会促进下一个 SSB 结合到紧邻区域（相邻 SSB 之间发生相互结合），确保 ssDNA 暴露后迅速被完全包裹。
3. **作用方式（序列非特异性）**：磷酸骨架的静电相互作用 + 与碱基的堆积相互作用。

### 3.5　拓扑异构酶

复制叉前方双链 DNA 积累越来越多的**正超螺旋**，由拓扑异构酶消除（Ⅰ 型切单链不需 ATP，Ⅱ 型切双链需 ATP；详见 [[分子生物学/01-结构基础/02-DNA结构与拓扑|DNA 结构与拓扑]]）。

### 3.6　复制叉处蛋白与 DNA 的三种作用方式

1. 磷酸骨架负电荷与骨架结构（如聚合酶**拇指**结构域）——静电作用。
2. DNA 小沟中通用的氢键位点（如聚合酶**手掌**结构域）。
3. 碱基间的疏水堆积作用（如 **SSB**）。

### 3.7　滑动 DNA 夹（PCNA / β-clamp）

- 环状复合物、六聚体；功能：
  1. **限制聚合酶扩散，提升持续合成能力**
     - 无滑动夹：聚合酶平均每合成 **20–100 bp** 即解离扩散。
     - 有滑动夹：聚合酶被限制在 DNA 近旁，可快速重新结合同一引物-模板接头，进行性极大提升。
  2. **招募其他蛋白**：冈崎片段修复相关核酸酶、连接酶、染色质组装蛋白等被 PCNA 招募到复制叉。

| 关键信息 | PCNA（真核/古菌） | β-clamp（原核） |
| :--- | :--- | :--- |
| 本质定位 | 滑动夹 | 滑动夹 |
| 蛋白结构 | **同源三聚体** | **同源二聚体** |
| 装载蛋白 | RFC（消耗 ATP） | γ 复合物 |
| 核心功能 | 沿 DNA 滑动、锚定聚合酶、提升持续性；参与修复与细胞周期调控 | 沿 DNA 滑动、固定聚合酶、维持高持续性 |
| 分布类群 | 真核生物、古菌 | 细菌 |

#### 滑动夹装载器

- 改变滑动夹构象使其装载或移除：**装载需要 ATP，移除不需要**。
- 存在引物-模板接头时诱导装载。
- 只有未结合其他蛋白时才能被移除：DNA 聚合酶、核小体组装因子、冈崎片段修复蛋白等都结合在 sliding clamp 同一区域，与加载器位点重合 → 所有结合酶完成功能脱离后，夹才能被移除。
- 过程：loader + ATP → clamp 打开 → loader-clamp + DNA → ATP→ADP → loader 释放，clamp-DNA 形成。
- DNA Pol 完成一个冈崎片段后，从滑动夹和后随链脱落，但**保持与 loader 的结合**。

## 4　DNA 聚合酶的特化

### 4.1　原核生物

- **Pol III**：多亚基、高持续合成能力、**成对活性部位的不对称二聚体**；合成速率与复制叉移动速率一致。

| 特征 | Pol I | Pol II | Pol III |
| :--- | :--- | :--- | :--- |
| 主要功能 | 修复酶（5′→3′ pol, 3′→5′ exo），移除 RNA 引物 | 修复酶（5′→3′ pol, 3′→5′ exo） | **复制酶**，校对（3′→5′ exo） |
| 持续合成能力 | 中等 | 低 | **极高** |
| 5′→3′ 外切酶 | 有 | 无 | 有（仅单链） |
| 3′→5′ 外切酶 | 有 | 有 | 有 |
| 细胞中数量 | 较多 | 较少 | 极少 |

### 4.2　真核生物

| 聚合酶 | 定位 | 核心功能 | 3′→5′ 校对 | 5′→3′ 外切 |
| :--- | :--- | :--- | :--- | :--- |
| Pol α | 细胞核 | **引物酶活性**，合成 RNA-DNA 复合引物 | 无 | 无 |
| Pol δ | 细胞核 | **后随链**聚合酶；填补缺口、完成冈崎片段延伸；参与修复 | 有 | 无 |
| Pol ε | 细胞核 | **前导链**聚合酶；复制校对、损伤修复 | 有 | 无 |
| Pol β | 细胞核 | BER，修复小型损伤 | 无 | 无 |
| Pol γ | 线粒体 | mtDNA 复制与修复 | 有 | 无 |
| Pol ζ、Pol η 等 | 细胞核 | 跨损伤修复（TLS） | 无 | 无 |

### 4.3　聚合酶转换

> **定义**：在 DNA 复制或修复过程中，不同类型 DNA 聚合酶在复制机器上"交接班"的过程。

- **复制中的切换**：Pol α 合成 RNA-DNA 引物 → **RFC** 识别引物末端挤走 Pol α → RFC 装载 **PCNA** → PCNA 招募 Pol δ / Pol ε。
- **损伤修复中的切换**：复制叉停滞 → **PCNA 泛素化**，被卡住的聚合酶被换下，换上 **TLS 聚合酶** → 跨越损伤 → 去泛素化换回复制聚合酶。

> [!tip] 去重说明
> TLS 的 SOS 应答、PCNA 泛素化信号与两种工作模型在 [[分子生物学/02-基因组维持/03-DNA损伤突变与修复|DNA 损伤突变与修复]] 中详讲，本篇只交代"聚合酶交接"这一视角。

## 5　复制叉处的协同合成

1. **DNA Pol III 全酶**：由核心酶活性组分 + 增强功能的附属组分组成的多蛋白复合物 = 五亚基 clamp loader + 2/3 个 Pol III core。
   - 夹加载器含 3 个 **τ 蛋白**亚基，每个 τ 可结合 1 个 Pol III 核心酶。
2. **长号模型**
   1. 解旋酶解开的后随链 ssDNA 先回折形成 DNA 环。
   2. 后随链聚合酶在环底部，朝与复制叉前进"看似相同"的方向合成冈崎片段。
   3. 合成进行中环逐渐缩小。
   4. 冈崎片段完成后聚合酶脱落。
   5. 解旋酶解开新 ssDNA 形成新环，聚合酶结合下一个引物开始下一轮。
3. **复制叉处蛋白互作**
   - **解旋酶-全酶**：通过滑动夹连接，提高解旋酶速率。
   - **解旋酶-引物酶**：二者结合更强 → 后随链引物合成更频繁 → 冈崎片段更短；结合更弱则冈崎片段更长。
4. **复制体**：所有在复制叉上发挥功能的蛋白共同组成的复合物。

## 6　复制起始

### 6.1　基本概念

| 概念 | 定义 |
| :--- | :--- |
| **复制起点（origin）** | DNA 解旋与复制启动发生的**物理位点**，是复制起始序列的一部分 |
| **复制子** | 单个复制起点起始复制的全部 DNA；一个细胞周期中并非所有复制子都被激活，已激活的不可再次激活 |
| **复制器 / 复制起始序列（replicator）** | 指导复制起始的全部**顺式作用 DNA 序列**；关键组件：起始蛋白结合位点 + 易解旋 DNA 区域 |

- 示例 **oriC（E. coli）** 含两个 motif：
  - **9 核苷酸基序**：起始蛋白结合位点。
  - **13 核苷酸基序**：ssDNA 形成位点。
- **起始蛋白（initiator）**：识别复制器并启动复制，是起始过程中**唯一的序列特异性 DNA 结合蛋白**。
  1. 结合复制器　2. 招募下游蛋白　3. 介导初始 DNA 解旋。
  - DnaA：结合 ATP 与 9 基序，解旋 13 基序，招募 DnaB（解旋酶）、DnaC（加载蛋白）。
  - ORC：起始识别复合物，**不能**介导解旋，招募 MCM 等解旋酶。

### 6.2　原核生物（E. coli）复制步骤

1. **起点识别**：DnaA 结合 oriC 的 9 bp 重复序列，多个 DnaA 聚集。
2. **初始解旋**：DnaA 作用于 13 bp 富 AT 区，解开约 20 bp，形成 ssDNA 泡。
3. **解旋酶加载**：DnaA 招募 DnaB-DnaC 复合物；DnaC 撬开 DnaB 六聚环套在 ssDNA 上。
4. **解旋酶激活**：引物酶被招募合成 RNA 引物；引物合成触发 DnaC 释放，DnaB 激活，双向解旋推进复制叉。
5. **复制体组装**：Pol III 全酶、滑动夹、SSB 等被招募到两个复制叉，前导链开始连续合成。
6. **后随链启动**：随解旋推进，后随链引物、滑动夹依次组装，形成两个完整双向复制体。

### 6.3　真核生物：解旋酶加载与激活

> **真核复制起始的第一步是解旋酶加载**。G1 期所有复制子完成加载；只有进入 S 期后复制起点才被激活（解旋酶活化 + 复制体组装）。

1. **ORC**（六亚基、ATP 依赖）识别复制器（类似 DnaA）。
2. 招募 loader **Cdc6、Cdt1**，共同将两个 **Mcm2-7** 六聚体以"头对头"方式套在双链起点 DNA 上。
3. 加载完成后 Cdc6、Cdt1 释放，Mcm2-7 保持**无活性**（不解旋、不移动）。
4. 进入 S 期，**CDK、DDK** 活性升高：
   - DDK 直接磷酸化 Mcm2-7 解除自抑制。
   - CDK 磷酸化 Sld2、Sld3 并结合 Dpb11，招募 Cdc45 与 GINS。
5. **CMG 复合物**形成：Cdc45 + Mcm2-7 + GINS，激活 Mcm2-7 的 ATP 酶与解旋酶活性。
6. Sld2、Sld3、Dpb11 释放。
7. **构象转换**：头对头、套双链的二聚体解开，每个解旋酶挤出一条 DNA 链，变为套单链的活性形式，向相反方向移动形成两个双向复制叉。
8. **复制体组装**：Pol ε 先结合，解旋后 Pol δ 与 Pol α/引物酶加入，形成两个完整复制体。

### 6.4　"一个周期只复制一次"的调控

- 每个细胞周期里，解旋酶**只有一次加载机会（G1 期）**，已加载的解旋酶**只有一次激活机会**。
  1. G1 期 CDK 水平低：允许加载，但无法激活。
  2. 进入 S 期 CDK 活性迅速升高：驱动已加载解旋酶激活，同时**彻底阻止新的加载**。
  3. S、G2、M 期 CDK 始终维持高位。

### 6.5　原核 / 真核起始的异同

- **共同流程**：起始蛋白识别复制器 → 招募解旋酶 loader → 解旋酶 → 解旋产生 ssDNA → 引物酶加引物。
- **差异**

| 维度 | 原核 | 真核 |
| :--- | :--- | :--- |
| 调控方式 | DnaA 的活性 | 解旋酶的**加载与激活**分离 |
| 复制次数 | 一个周期可**多次** | 一个周期**仅一次** |

## 7　复制的收尾

### 7.1　环状染色体

复制完成后两个子代 DNA 以**连环体**形式套锁在一起。连环体 = 两个相互嵌套的环状分子。
**分离方式**：Ⅱ 型拓扑异构酶。

### 7.2　线型染色体与末端复制问题

**解决方案一：蛋白替代 RNA 提供羟基**——见于部分具线型染色体的细菌与病毒。

**解决方案二：端粒酶**

| 组分 | 说明 |
| :--- | :--- |
| **TER** | 端粒酶 RNA 组分，本身充当**模板**；含一段编码端粒序列互补链的区域，可与端粒 3′ 单链 DNA 互补配对，配对后部分 RNA 仍单链，形成可被识别的引物-模板接头 |
| **TERT** | 蛋白亚基，**逆转录酶** |

- **功能**：延伸 DNA 底物的 **3′ 端**。
- **端粒**：真核染色体末端，通常由串联重复的**富 TG 序列**组成。
- **步骤**
  1. **配对**：TER 模板序列与端粒 3′ 单链互补结合，形成引物-模板接头。
  2. **延伸**：TERT 以 RNA 为模板向 DNA 3′ 端添加核苷酸，直到 RNA 模板末端。
  3. **移位**：RNA 模板解离，向前滑动一个重复单位，重新与末端碱基配对。
  4. **循环**：再次延伸，不断添加端粒重复序列。

#### 端粒长度的调控

- **端粒结合蛋白**对端粒酶活性有**弱抑制**作用；有**蛋白计数模型**：端粒越长 → 结合蛋白越多 → 累积抑制越强 → 达到平衡长度。
- 端粒结合蛋白功能：调节端粒酶活性；**保护染色体末端**（将端粒与细胞中其他 DNA 末端区分开）。
- 单链结合蛋白的双向调控
  - **正调控**：酵母 **Cdc13** 结合单链悬出，招募端粒酶到端粒。
  - **负调控**：人 **POT1** 结合单链悬出，直接抑制端粒酶；长端粒通过双链结合蛋白间接招募更多 POT1。

#### t 环（T-loop）

- 由端粒 **3′ 单链末端侵入端粒双链 DNA 区域**形成。
- 功能
  1. 掩蔽端粒末端，使其**不被识别为正常 DNA 末端**。
  2. 与端粒长度控制有关：端粒越短越难形成 t 环，3′ 端越易接近，延伸越易发生。

#### 端粒酶 vs DNA 聚合酶

| | 区别 | 共性 |
| :--- | :--- | :--- |
| 端粒酶 | 自带 RNA 组分、无需外源模板；具 RNA:DNA 解旋酶活性 | 都需要模板指导；都只能延伸 3′-OH 末端；使用相同核苷酸底物；都有进行性 |

<details>
<summary><b>自测 1：DNA 聚合酶如何在只有一个活性位点的情况下保证四种底物的特异性？</b></summary>

靠**几何匹配**而非碱基识别：A-T 与 G-C 配对后几何形状一致；正确配对使 3′-OH 精确对准 α-磷酸，SN2 反应极快，错误配对速率慢约 10⁴ 倍而先在活性位点解离。另有 dNTP/rNTP 的空间位阻排斥和小沟氢键校验。
</details>

<details>
<summary><b>自测 2：复制子、复制器、复制起点三者关系？</b></summary>

复制子是单个复制起点起始复制的全部 DNA；复制器是指导起始的全部顺式作用序列（含起始蛋白结合位点与易解旋区）；复制起点是实际发生解旋与启动合成的物理位点，是复制器的一部分。
</details>

<details>
<summary><b>自测 3：为什么真核细胞一个周期只能复制一次？</b></summary>

加载与激活分离：G1 期 CDK 低，允许 MCM 解旋酶加载但不能激活；S 期 CDK 升高，激活已加载解旋酶并同时阻止新加载；S/G2/M 期 CDK 持续高位，不能再加载。
</details>

<details>
<summary><b>自测 4：滑动夹如何提高聚合酶进行性？为何移除需要等所有蛋白脱离？</b></summary>

滑动夹把聚合酶限制在 DNA 近旁，脱离后可快速重新结合同一引物-模板接头（否则平均每 20–100 bp 就扩散离开）。聚合酶、核小体组装因子、修复蛋白等与夹结合的区域和加载器结合位点重合，因此只有它们都完成功能脱离，夹才能被移除。
</details>
