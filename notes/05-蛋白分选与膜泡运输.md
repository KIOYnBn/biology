# 05 蛋白分选与膜泡运输

> 返回 [[00-总览]] ｜ 配套总结（扫描版）：[章节总结-蛋白分选与膜泡运输](attachments/章节总结-蛋白分选与膜泡运输.pdf)

## 1. 信号假说

- 蛋白质自身携带**信号序列**，决定其在细胞内的定位与转运方向。
- 分泌蛋白在粗面内质网合成时，信号肽引导核糖体—多肽复合物到内质网膜，经易位子进入内质网腔；信号肽通常被切除。
- 示意：[信号假说](attachments/信号假说.png)

## 2. 蛋白质分选的主要途径

| 途径 | 目的地 | 关键信号/机制 |
|---|---|---|
| 翻译后转运 | 细胞核、线粒体、叶绿体、过氧化物酶体 | 蛋白质在胞质中合成后再导入；信号序列不被切除（如 NLS） |
| 共翻译转运 | 内质网 → 高尔基体 → 溶酶体/质膜/分泌 | 信号肽引导边翻译边转运（信号假说） |
| 膜泡运输 | 内膜系统各区室之间 | 被膜小泡出芽、定向、锚定与融合 |

**核定位信号（Nuclear Localization Signal, NLS）**

- 真核蛋白上的一段短氨基酸序列，引导在胞质中合成的蛋白质经核孔复合体主动转运进入细胞核。
- NLS 在入核后**不被切除**，可重复利用（详见 [[07-细胞核与染色体]]）。

## 3. 膜泡运输

- 基本过程：供体膜**出芽**形成被膜小泡 → 沿细胞骨架**定向运输** → 与靶膜**锚定** → **融合**释放内容物。
- 主要被膜类型：

| 被膜 | 运输方向 | 作用 |
|---|---|---|
| COPII | 内质网 → 高尔基体 | 顺向运输 |
| COPI | 高尔基体 → 内质网、高尔基体膜囊间 | 逆向回收 |
| 网格蛋白（clathrin） | TGN/质膜 → 胞内体/溶酶体 | 分选受体货物（如 M6P 受体、LDL 受体） |

- 关键辅助因子：小 GTP 蛋白（如 Sar1、ARF、Rab）决定出芽与靶向特异性；SNARE 蛋白介导膜融合。
- 受体介导的胞吞与胞吐过程详见 [[03-细胞质膜与物质跨膜运输]]；溶酶体酶的 M6P 分选详见 [[04-细胞质基质与内膜系统]]。

## 4. 小 GTP 蛋白与 SEC 蛋白

> 整合自「生物学知识引用块」：`蛋白家族/GTP结合蛋白.md`、`蛋白家族/SEC.md`。

**SEC 蛋白**

- sec61
- sec23
- sec24
- sec13
- sec31
- sec16
- sec12：一种 GEF

**GTP 结合蛋白**

- Sar GTP-BINDING PROTEIN：GAP，GTP 酶活化蛋白——SEC23

- GEF —— SEC12

> [!tip] 笔记归位
> Sar1、ARF、Rab 参与被膜小泡出芽与靶向；SEC23/24/13/31 为 COPII 被膜组分，SEC12 为 GEF，SEC61 为内质网易位子。Ras、Ran 分别偏向信号转导与核质运输，见 [[08-细胞信号转导]]、[[07-细胞核与染色体]]。
