# 01 · 转录

> [!abstract] 一句话定位
> 转录是把 DNA 信息"抄"成 RNA：**起始是调控关键**（闭合→开放→逃逸），原核靠一个 σ 因子，真核靠 Pol II + 一套通用转录因子 + 染色质重塑。

**导航**：[[分子生物学/02-基因组维持/04-重组与转座|← 重组与转座]] · [[分子生物学/00-复习总览|复习总览]] · [[分子生物学/03-基因组表达/02-RNA加工与剪接|RNA 加工与剪接 →]]

---

## 1　总论

- **转录**：以 DNA 为模板合成 RNA 的过程。
- **模板链**：基因部位**不含基因**的那条链（即编码链的互补链）。
- **多顺反子**：一条 mRNA 含多个 ORF（开放阅读框）——原核转录产物常见。
- **单顺反子**：真核转录产物几乎都是单顺反子。

| 概念 | 定义 |
| :--- | :--- |
| 编码基因 | 产物为蛋白质 |
| 非编码基因 | 无产物或产物为 RNA |
| **顺式元件** | 特定核苷酸序列，与蛋白结合调控**自身**基因表达 |
| └ 沉默子 | 抑制基因转录 |
| └ 绝缘子 | 阻止某一调控元件对另一侧基因产生影响 |
| **反应元件** | 基因调控区（启动子、增强子）内被转录因子识别结合的特定 DNA 序列 |

### 1.1　转录 vs 复制

| | 转录 | 复制 |
| :--- | :--- | :--- |
| 原料 | **NTP** | **dNTP** |
| 产物 | RNA | DNA |
| 引物 | **无** | **有** |
| 产物与模板关系 | 短暂结合 | 紧密结合 |
| 准确性 | 低 | 高 |
| 模板范围 | 单个基因 | 全基因组 |

### 1.2　转录周期三阶段

1. **起始（调控关键）**
   - **闭合复合物形成**：RNA 聚合酶识别并结合启动子。
   - **闭合→开放**：DNA 在启动子处局部解旋，形成**转录泡**。
   - **初始转录**：合成约 10 个核苷酸的短 RNA；效率低，常产生**流产性短转录本**。
   - **启动子逃逸**：合成超过约 10 nt 后，酶挣脱启动子束缚进入延伸。
2. **延伸**：转变为高度持续性的延伸复合物，同时
   - 前方解开 DNA 双链；
   - 后方使 DNA 重新退火，并持续将新合成 RNA 从模板上剥离；
   - 校对。
3. **终止**：在特定终止信号处停止，释放 RNA 产物与酶。

## 2　RNA 聚合酶

### 2.1　共性

1. 都催化同一反应：以 DNA 为模板合成 RNA。
2. 都是**多亚基复合物**。
3. 结构像一只**蟹爪**：两个大亚基构成钳子主体，活性位点位于钳子基部的"活性中心裂隙"，采用**双金属离子催化**。酶内部有通道引导 DNA 模板、RNA 产物与核苷酸进出。
   - 活性位点仅含一个**紧密结合的 Mg²⁺**；第二个 Mg²⁺ 随每个新核苷酸进入，并随焦磷酸一起释放。

### 2.2　原核 vs 真核

| | 原核 | 真核 |
| :--- | :--- | :--- |
| RNA 聚合酶 | **一种**核心酶 + σ 因子 | 至少三种 |
| 分工 | — | **Pol I**：rRNA；**Pol II**：mRNA、snRNA；**Pol III**：5S rRNA、tRNA |

- 聚合酶功能：① RNA 合成　② DNA 解链　③ RNA 脱离。

## 3　细菌的转录

### 3.1　反应特点

| 项目 | 内容 |
| :--- | :--- |
| 模板 | DNA 链 |
| 引物 | 无 |
| 起始核苷酸 | NTP |
| 底物 | NTP |
| 离子 | Mg²⁺ |
| 校对 | 无（但有编辑机制，见 3.4） |
| 方向 | RNA 5′→3′ |

- 转录起始碱基一般为**嘌呤**。

### 3.2　RNA 聚合酶与启动子

- **核心酶**：α₂ββ′ 四聚体。
  - **α**：组装亚基；**β**：结合底物；**β′**：结合 DNA 模板。
- **启动子**：启动基因转录的一段 DNA，位于编码区 5′ 上游。

| 元件 | 位置与功能 |
| :--- | :--- |
| **-10 区 / -35 区** | σ 因子识别和结合的关键位点 |
| **间隔区** | 位于 -35 与 -10 之间，确保两元件处于双螺旋**同一侧**，可被 σ 同时识别 |
| **UP 元件** | -35 上游，被 RNA 聚合酶 **α 亚基 CTD** 识别，增强聚合酶结合力 |
| **扩展 -10 元件** | 部分启动子以此替代 -35 功能，在标准 -10 上游多一小段序列提供额外接触面 |
| **鉴别子** | -10 下游，被 σ 区域 **1.2** 识别，其序列影响开放复合物稳定性 |

### 3.3　σ 因子

- **σ⁷⁰（管家 σ）**有 4 个结构域：
  - **domain 2**：识别 -10 区。
  - **domain 4**：识别 -35 区。
- 其他 σ 因子不一定有全部结构域。
- **解旋机理：碱基翻转**。

### 3.4　转录过程

#### ① 闭合复合物形成
σ 与 DNA 结合使其弯曲 → β 结合 σ → α 结合 β。

#### ② 闭合→开放复合物
- 启动子 DNA 在 **-11 到 +2** 区域局部解链，形成转录泡。
- **不依赖 ATP**，自发且不可逆。
- 酶前方钳子夹紧下游 DNA；σ domain 2 通过**碱基翻转**解旋。

#### ③ 启动子逃逸——"蜷缩模型"
- 逃离前经历**流产性起始**：反复合成并释放 <10 nt 的短 RNA。
- 为把模板链送入固定的活性中心，聚合酶不断将前方下游 DNA"蜷缩/拉入"酶内，以**单链凸起**形式暂时储存，实现活性中心与模板的相对运动。
- 流产时凸起释放、短 RNA 脱落；当 RNA 达约 **10 nt 以上**，聚合酶挣脱启动子、清除凸起，转变为延伸复合物。
- 逃逸成功后 **σ 因子脱离**。

#### ④ 延伸与校对
- **焦磷酸解编辑**：聚合反应的逆反应，直接移除错配核苷酸。
- **水解编辑**：聚合酶**回溯**，Gre 因子等激活其内在 RNase 活性，切除含错误的末端片段。
- **停滞处理**：**TRCF** 利用 ATP 水解沿 DNA 移动，从后方"撞开"停滞的 RNA 聚合酶使其解离，同时招募 **UvrABC** 进行**转录偶联修复**（见 [[分子生物学/02-基因组维持/03-DNA损伤突变与修复|DNA 损伤突变与修复]]）。

#### ⑤ 终止

| 类型 | 机制 |
| :--- | :--- |
| **不依赖 Rho（内在终止）** | 回文序列转录形成**颈环结构** + 连续 **U**：茎环使聚合酶停滞/构象改变；A-U 弱配对的 RNA-DNA 杂交链极易断裂 → RNA 释放 |
| **依赖 Rho** | 新生 RNA 上的 **rut 位点**（富 C、不形成结构、不被核糖体结合）；**Rho**（六聚体、ATP 酶、解旋酶）结合 rut 并沿 RNA 运动，水解 ATP 使聚合酶构象变化，RNA 脱离 |

#### ⑥ 为何不需要引物
靠 **σ 区域 3/4 接头**与模板链的特异性相互作用：接头将模板链组织在正确构象和位置，稳定仅靠两个氢键配对的起始核苷酸 A。

## 4　真核生物的转录

### 4.1　复杂性来源

| 维度 | 原核 | 真核 |
| :--- | :--- | :--- |
| 酶与因子 | 一种 RNA Pol + 一个 σ | ≥3 种 RNA Pol；Pol II 需一套通用转录因子 |
| 模板状态 | 裸露 DNA | DNA 组装成核小体，需额外调控蛋白 |
| 能量来源 | 开放复合物形成**无需 ATP** | **TFIIH 水解 ATP** 驱动解链；逃逸也需 ATP 水解与 CTD 磷酸化 |

### 4.2　Pol II 启动子元件

**核心启动子元件**

| 元件 | 位置与功能 |
| :--- | :--- |
| **TATA box** | -30 区，被 **TBP** 亚基识别 |
| **下游启动子元件（DPE）** | 转录起始点下游，为转录因子提供结合位点；常见于无 TATA 的启动子 |
| **BRE** | TATA 盒旁，被 **TFIIB** 识别，帮助精确起始 |
| **起始子 Inr** | 包含转录起始位点 |

**近端调控元件**

| 元件 | 位置与功能 |
| :--- | :--- |
| **CAAT box** | -50 ~ -100 bp；决定启动子效率，结合转录激活因子 |
| **GC box** | 约 -100 bp；**Sp1** 结合位点，帮助缺少 TATA 的启动子启动转录 |

**远端调控元件：增强子**
- 位置不固定、方向不限。
- 与激活蛋白结合 → 结合 **Mediator** → 招募转录因子 → 增强转录效率。
- 稳定转录起始前复合物，使 Pol II 可多次快速转录。

### 4.3　通用转录因子（GTF）

> 类似原核 σ 因子，具有 DNA 结合结构域；与启动子特殊序列结合激活转录。

| 因子 | 功能 |
| :--- | :--- |
| **TFIID** | = **TBP**（TATA binding protein）+ **TAFs**；首先结合核心启动子 |
| **TFIIA** | 与 TBP 结合，帮助结合 TATA 盒 |
| **TFIIB** | 与 TBP 及 RNA Pol II 结合 |
| **（DAB 复合物）** | TFIID + TFIIA + TFIIB |
| **TFIIF** | 异二聚体，与 Pol II 结合使其进入转录位置 |
| **TFIIE** | 结合 ssDNA，可能参与解旋 |
| **TFIIH** | 解旋酶 + ATP 酶 + 激酶 |

- **FACT**：在聚合酶前方结合核小体，特异性移除一个 **H2A·H2B 二聚体**，留下更易通过的六聚体；聚合酶通过后发挥组蛋白伴侣活性把二聚体放回，恢复核小体。

### 4.4　转录过程

1. **闭合复合物 / PIC 组装**
   - **TFIID** 首先结合核心启动子；TBP 结合 TATA 盒并剧烈扭曲 DNA。
   - 依次招募 TFIIA、TFIIB、TFIIF/Pol II、TFIIE、TFIIH，组装成**转录起始复合物 PIC**。
   - 组成：**启动子 + RNA Pol II + TFs（D/A/B/F/E/H）**；可寄存在增强子部位以加快转录。
2. **开放复合物**：**TFIIH 水解 ATP** 解开 DNA 双链。
3. **启动子逃逸**：TFIIH 磷酸化 **CTD 丝氨酸**，使聚合酶逃离启动子，同时招募延伸与 RNA 加工因子。
4. **延伸与加工的偶联**（CTD 作为"平台"）
   - **加帽**：延伸因子 **SPT5** 协助下，加帽酶被招募到 **Ser5 磷酸化**的 CTD 上，为新 RNA 5′ 端加甲基化鸟嘌呤帽子。
   - **剪接准备**：Ser5 去磷酸化 → **Ser2 磷酸化** → 加帽机器解离、剪接机器被招募。
   - **加尾与终止**：CPSF、CSTF 搭载在 CTD 上识别 poly-A 信号，切割 RNA 并由 PAP 加尾。
5. **终止**：加尾后聚合酶继续转录一段下游 RNA，多余 RNA 被降解，最终聚合酶脱离。
   - **鱼雷模型**：新转录的**未加帽 RNA 5′ 端**被 RNase（酵母 Rat1 / 人 Xrn2）识别，高速追赶聚合酶，追上时使其终止。
   - **变构模型**：加尾或相关因子从 CTD 解离等事件诱导聚合酶构象改变、稳定性下降，自发从 DNA 脱离。

<details>
<summary><b>自测 1：转录与复制有哪些关键差异？</b></summary>

原料 NTP vs dNTP；产物 RNA vs DNA；转录**无需引物**；转录产物与模板短暂结合而复制产物紧密结合；转录准确性较低；转录只针对单个基因而复制覆盖全基因组。
</details>

<details>
<summary><b>自测 2：原核开放复合物形成为何不需 ATP，真核却需要？</b></summary>

原核靠 σ domain 2 的**碱基翻转**使启动子局部解链，是自发且不可逆的构象变化；真核 DNA 被组装成核小体且需更大范围解链，由 **TFIIH 的 ATP 酶/解旋酶活性**驱动。
</details>

<details>
<summary><b>自测 3：不依赖 Rho 与依赖 Rho 的终止有何区别？</b></summary>

前者靠回文序列形成的颈环 + 连续 U 造成 A-U 弱配对，杂交链易断裂，RNA 自发释放；后者靠 RNA 上的 rut 位点被六聚体 Rho 结合，Rho 水解 ATP 沿 RNA 移动并改变聚合酶构象，促使 RNA 脱离。
</details>

<details>
<summary><b>自测 4：CTD 如何把转录与 RNA 加工串起来？</b></summary>

起始后 CTD 的 **Ser5 磷酸化**招募加帽酶；随后 Ser5 去磷酸化、**Ser2 磷酸化**招募剪接机器；基因末端携带 CPSF/CSTF 识别 poly-A 信号，完成切割加尾并触发终止。
</details>
