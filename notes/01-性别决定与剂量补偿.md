# 01 · 性别决定与剂量补偿

> [!abstract] 一句话定位
> 性别可由**性染色体组成**（XO / XY / ZW）、**X 与常染色体组数之比**（果蝇）或**环境温度**（爬行动物）决定；当两性 X 染色体数目不同时，靠 **X 染色体失活**实现剂量补偿。

## 1　性别决定系统

| 系统 | 雌性 | 雄性 | 说明 |
| :--- | :--- | :--- | :--- |
| **XO 型** | XX | XO | 只有 X 染色体数目差异 |
| **XY 型** | XX | XY | 雄性异型；人类属于此型 |
| **ZW 型** | ZW | ZZ | 雌性异型（鸟类等） |

> [!note] 核型写法
> 核型（染色体总数 + 性染色体）的定义与 `46,XY` / `46,XX` 写法见 [[遗传学/02-染色体与基因组/02-染色体畸变与核型分析|染色体畸变与核型分析]]。

## 2　人类的性别决定

### 2.1　关键基因

| 染色体 | 基因 | 作用 |
| :--- | :--- | :--- |
| **Y** | **SRY** | 产物为转录因子 **TDF**，与 DNA 结合并扭曲其形状 → 激活 **Sox9** → 生殖脊发育成**睾丸** |
| **X** | **AR**（X11–12） | 编码**睾酮受体** |
| | SKT | 与卵巢发育相关 |
| **常染色体** | **Sox9** | SRY 的靶基因，启动睾丸发育通路 |
| | **CYP11A** | 产生限速酶，作用于睾丸产生睾酮 |

### 2.2　性别比例

| 类型 | 定义 |
| :--- | :--- |
| **初级性比** | 受精卵形成时的性别比 |
| **次级性比** | 出生时的性别比 |

### 2.3　剂量补偿：X 染色体失活

**剂量补偿**：确保 X 连锁基因的表达量在 XX 与 XY 个体中大致相等的遗传机制。

**巴氏小体（Barr body）**

- 哺乳动物体细胞核中，除一条 X 染色体外，其余 X 染色体浓缩成染色较深的染色质体。
- **巴氏小体数目 = X 染色体总数 − 1**。

**莱昂定律（Lyonization）**

1. 胚胎发育**早期**，X 染色体**随机**失活。
2. 失活状态在**子代细胞中稳定保持**（克隆性传递）。

**分子原理**

| 元件 | 作用 |
| :--- | :--- |
| **XIST** | 长非编码 RNA，以 RNA 形式发挥作用，**包被染色体**使其失活 |
| **TSIX** | XIST 的**反义 RNA**，与 XIST 结合，阻止失活 |
| **PAR（假常染色体区）** | 部分基因可**逃避失活**，仍保持转录 |

**相关病例（均为伴 X 隐性）**

- **缺汗表皮发育异常**：汗腺缺乏呈皮肤**随机斑块状分布**，正是 X 染色体随机失活的直观证据。
- **红绿色盲**。

> [!note] 与 RNA 调控的联系
> XIST 属于长非编码 RNA，与 siRNA / miRNA 介导的基因沉默同属 RNA 层面的调控，见 [[遗传学/04-基因表达与调控/02-基因表达调控|基因表达调控]]。

## 3　果蝇的性别决定

- **性比决定性别**：$\displaystyle \text{ratio} = \frac{X\text{ 染色体个数}}{\text{染色体组数}}$
- **Y 染色体决定可育性**，不决定性别。

| 核型 | 表型 |
| :--- | :--- |
| XXY | 正常女性（X:A = 1） |
| X（XO） | 不育男性（X:A = 0.5，缺 Y） |

---

## 4　爬行动物的性别决定

- 既可由**性染色体**决定，也可由**温度**决定。

| 类型 | 温度与性别关系 |
| :--- | :--- |
| Case 1 | 高温 → 雌性；低温 → 雄性 |
| Case 2 | 高温 → 雄性；低温 → 雌性 |
| Case 3 | 高温 / 低温 → 雌性；中温 → 雄性 |

**特点**：存在某个温度区间，**同一温度既能产生雄性也能产生雌性**。

---

## 5　考点速记

- XO：XO 雄、XX 雌；ZW：ZZ 雄、ZW 雌（与 XY 型相反）。
- SRY → TDF → Sox9 → 睾丸；AR（X11–12）为睾酮受体；CYP11A 参与睾酮合成。
- 初级性比看受精卵，次级性比看出生。
- 巴氏小体数 = X 数 − 1；莱昂定律：早期随机失活、子代细胞保持。
- XIST 包被失活，TSIX 拮抗 XIST；PAR 区基因逃避失活。
- 果蝇：X:A 比值定性别，Y 定可育；爬行动物温度决定存在三种模式。

<details>
<summary><b>自测 1：为什么缺汗表皮发育异常患者的汗腺缺失呈斑块状分布？</b></summary>

因为胚胎早期 X 染色体随机失活，不同细胞克隆失活了带正常等位基因或突变等位基因的 X 染色体，导致汗腺有无在皮肤上呈随机镶嵌的斑块分布。
</details>

<details>
<summary><b>自测 2：人类与果蝇的 Y 染色体在性别决定中有何不同？</b></summary>

人类 Y 染色体上的 SRY 基因是决定雄性发育的关键（有 Y 通常为男性）；果蝇的 Y 染色体不决定性别，性别由 X:A 比值决定，Y 只影响雄性可育性。
</details>
