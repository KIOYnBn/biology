# 生态学

## 一、绪论：生态学是什么

### 1.1 定义与研究层次

**生态学**：研究生物体与其环境相互作用的学科。

| 层次 | 研究内容 |
| --- | --- |
| 生态系统生态学 | 通过生物和非生物环境的能量与物质流动 |
| 群落生态学 | 多物种间的相互作用 |
| 种群生态学 | 特定物种的种群增长、分布和调控 |
| 生理生态学 | 适应资源获取和处理环境压力 |

**生态的结构层次**：生物圈 biosphere（大气、岩石、水、生物）→ 生态群系 biome → 生态系统 → 群落（不同物种）→ 种群 → 物种（对环境的适应）。

**群落层面的多样性假说**

- Red Queen hypothesis（红皇后假说，原笔记记作 Riot hypothesis）
- Portfolio hypothesis（组合假说）
- Redundancy hypothesis（冗余假说）

### 1.2 研究过程与统计方法

**生态研究过程**：最初观察 → 提出假说 → 实验 → 观察/数据分析 → 解释 → 最终假设支持 → 理论；或回到新观察 → 新实验 → 新假说。

**统计：数据分析的工具**

- 描述性统计：提供数据集属性概述，包括集中趋势（频率直方图、平均值、中位数、众数）与分散程度（范围、方差、标准差）。
- 推论统计：提供数据支持假设的程度，以及数据是否超出检验范围的衡量标准（显著性检验）。

### 1.3 核心名词

| 名词 | 定义 |
| --- | --- |
| 环境 | 影响特定有机体的生物和非生物因素的总和 |
| 大环境 | 生物所处的大范围地理区域，如海拔、纬度、离海距离 |
| 微环境 microenvironment | 直接影响生物的邻近环境，如巢的环境 |
| 有机体 | 个体生物 |
| 物种 | 可以交配繁殖出可育后代的一群相似生物 |
| 种群 population | 特定时间生活在特定地理区域、具有交配繁殖能力的同种个体群 |
| 群落 community | 特定栖息地中所有相互作用的物种，物种数通常多于两个 |
| 栖息地 | 生物生活的地方 |
| 生态系统 | 群落 + 非生物因素（营养、水、土壤等），如池塘、森林生态系统 |
| 生物圈 biosphere | 地球 |
| 个体生态学 autecology | 个体生物（或单个物种）与环境之间的关系 |
| 群落生态学 | 对群落的生态学研究，包括群落结构、发展和分布 |
| 生态群系 biome | 一群具有相似气候和优势群落的生态系统：热带雨林、温带森林、沙漠、苔原、针叶林、草原、稀树草原 |

## 二、生物与环境

### 2.1 环境、栖息地与微环境

- **栖息地**：生物的生存之地。
- **微环境 microenvironment**：直接影响生物的邻近环境。

### 2.2 生物与环境的相互作用

| 类型 | 含义 |
| --- | --- |
| 作用 | 非生物因素对生物的影响 |
| 适应 adaptation | 生物调节自身属性以减少或消除环境限制作用的演化过程 |
| 反作用 reaction | 生物对环境的影响 |
| 相互作用 | 生物之间的作用 |

### 2.3 生态因子及其作用特征

**分类**

| 依据 | 类型 |
| --- | --- |
| 属性 | 气候因子、土壤因素、地形因素、生物因素、人为因素 |
| 密度 | 密度依赖因素（食物、捕食者）、密度非依赖因素（气候因素） |
| 性质 | 生物因素（植物、动物）、非生物因素（温度、降水、湿度、风、阳光） |

- 生物和非生物因素决定个体生存、生长及所处生态系统的生产力。

**生态因子作用的一般特征**

1. **综合作用** synthetic：因子相互联系、共同起作用。
2. **主导因子作用** dominant：某一因子起决定性作用。
3. **阶段作用** phased：如蜂王浆对蜂王不同发育阶段的作用不同；新鲜蜂王浆、对香豆酸为典型例子。
4. **不可替代性** irreplaceable 与**补偿性** compensatory。
5. **直接或间接作用**。

### 2.4 三条基本定律

| 定律 | 内容 |
| --- | --- |
| 最小因子定律（利比希） | 生物的生长、繁殖或分布受制于环境中供应量最接近需求下限的必需因子 |
| 限制因子定律 | 生物过程依赖多个因子时，其速率由最接近耐受极限的因子（不足或过量）决定 |
| 耐受性定律（谢尔福德） | 每种生态因子均有耐受上限与下限，形成生态幅；超出则生长受阻甚至死亡 |

**耐受性定律要点**

- 耐受下限：因子不足导致生理功能停滞（植物冻僵、动物休眠）。
- 最适区：生理状态最佳、繁殖率最高（如鲑鱼最适水温 10～15 ℃）。
- 耐受上限：因子过量引发代谢崩溃（高温致蛋白质变性）。
- 耐受范围**不是固定的**：随物种、季节、环境条件、生命阶段变化。
- 生物通常不处于某因子的最适状态；当某因子非最适时，对其他因子的耐受极限也会降低。

### 2.5 适应与渐变群

**适应渐变群 cline in adaptation**：物种的形态、遗传或生理特征随环境梯度（海拔、温度、纬度）发生连续性渐变，是长期适应环境异质性的结果。

| 规律 | 内容 |
| --- | --- |
| 贝格曼法则 Bergmann's Rule | 同种内温动物在寒冷地区（高纬/高海拔）体型更大，以减少单位体积散热面积 |
| 阿伦法则 Allen's Rule | 恒温动物在寒冷地区肢体与附肢（耳、尾）缩短以减少散热，热带则延长 |
| 格洛格法则 Gloger's Rule | 恒温动物在温暖湿润环境中着色更深，寒冷干燥地区颜色较浅 |
| 乔丹规律 Jordan's Rule | 水温越低，鱼类的鳍、椎骨或鳞片数量越多 |
| 环状物种形成 Ring speciation | 地理隔离使相邻种群基因流渐次分化，末端种群相遇时已产生生殖隔离 |

**机制补充**

- 贝格曼法则：自然选择驱动（环境梯度选择特定表型）+ 基因流限制（大范围分布阻碍种群间基因交流，导致局部适应性分化）。
- 阿伦法则调节因子：体型大小（大型物种符合度 > 小型）、气候带（温带 > 热带）、行为策略（迁徙或冬眠物种符合度降低）。
- 格洛格法则解释：深色羽毛可防止羽毛降解细菌；温暖环境中深色具有光保护作用。

**驯化 acclimation**：生物体适应环境变化、使自身在变化的条件范围内保持健康；改变耐受性但**不改变遗传**。通常需要一定时间逐渐发生。

**内稳态**：提高耐受性。
**适应组合**：生物表现出一系列对环境的适应性特征。

### 2.6 生物对环境的反应

| 类型 | 说明 |
| --- | --- |
| 休眠 dormancy | 生长、发育和身体活动暂时停止的时期，减少代谢、保存能量；与环境条件密切相关 |
| 预见性休眠 | 如冬眠、滞育；许多植物通过光周期和温度降低预测冬季到来 |
| 结果性休眠 | 环境已变得不利才发生，常见于气候不可预测地区，可能导致高死亡率 |
| 滞育 diapause | 发育进程停滞 |
| 夏蛰 aestivation | 炎热干燥条件下的休眠 |

## 三、光因子

**到达地球的光谱**：可见光、红外线、紫外线。

![光因子与植物](attachments/光因子与植物.png)

**对植物的作用**

- 直接作用：光合作用（影响叶绿体数量和位置、叶片结构变化）、繁殖和生长、光周期。
- 间接作用：加热（产热）、蒸腾作用、吸收、呼吸作用。

**植物对光强的适应**

- 阳地植物（日照植物）：充足光照下生长最好。
- 阴地植物（阴性植物）：弱光下生长最好。
- 光饱和点、光补偿点。
- 光强影响生物量、行为（落叶）、光合能力、植物类型。
- 光谱影响形态：紫外光抑制茎生长使其短粗；短波长光促进花青素合成与向光性。

**光周期现象**：植物对昼夜光照时长变化的生理响应，尤其是通过感知日照长度调控开花时间。

| 植物类型 | 开花条件 |
| --- | --- |
| 长日植物 | 日照长度 > 临界日长（通常 12～14 h），黑暗短于阈值 |
| 短日植物 | 日照长度 < 临界日长（通常 < 12 h），黑暗超过阈值 |
| 日中性植物 | 开花不受日长影响，由年龄、温度或营养状态驱动 |
| 中日照植物 | 需日长在特定范围，过长或过短均抑制开花 |

- 光周期是影响植物物种分布的主要原因，也影响生物节律。

**水中光**：受水体与浮游植物等影响。

**对动物的作用**

- 光谱 light quality：
  - 紫外光：性选择、个体识别、性别二态性、杀菌、皮肤癌、促进维生素 D 吸收。
  - 红外光：热源，参与变温动物体温调节与代谢。
- 光强：影响发育、形态、行为（昼行性 / 夜行性）。
- 光周期：长日照动物春天繁殖（鸟类）、短日照动物秋季繁殖（鹿）；也影响迁徙、换毛 molt、滞育 diapause、冬眠 hibernation。

## 四、温度因子

**温度 Tm**：表征冷热程度的强度，可用华氏度、摄氏度、开尔文标度测量；既有时间变化又有空间变化，随海拔和纬度变化。温度耐受区间（最大与最小温度）影响地球上所有生物。

**按温度适应分类动物**

- 冷血 / 温血（Cold-blooded / Warm-blooded）；恒温 / 变温（Homeotherm / Poikilotherm）。
- **外温性 Ectotherm**：依赖外部环境获取热能，代谢产热极少。
- **内温性 Endotherm**：通过代谢高效产热，仅鸟类和哺乳类属于此类。
- **温中心区**：内温动物无需额外代谢产热或散热即可维持基础体温的环境温度范围。

**极端温度影响与适应**

- 耐受冻结：少数动物能耐受一定程度的身体冻结。
- 超冷现象：昆虫体液降到冰点以下而不结冰。
- 热损伤：蛋白质变性、酶失活、发烧。
- 适应：蜡质层、蒸发、出汗。

**常见的温度作用**：酶活性、代谢、生长发育、繁殖、繁殖力、性别比、自然色彩、形态。

- **温周期**：昼夜温度波动周期；植物在波动温度中比恒定温度生长更好，热带植物例外（恒温有利）。
- **温周期现象**：植物对温度昼夜波动的响应。
- 温度通过温周期影响开花植物。

**总积温 sum of heat**

$$K = N(T - C)$$

- K：发育所需总热量；N：发育时间；T：发育期间平均温度；C：生物零度（发育起点温度）。

![有效积温曲线](attachments/有效积温曲线.png)

**春化作用**：通过低温诱导植物开花；春化后植物获得开花能力，但可能还需额外季节诱因或几周生长。温带植物多需经历冬季低温来启动或加速开花。

**气候驯化**：有机体的生理反应适应环境条件，通常需一定时间逐渐发生。

## 五、种群

### 5.1 定义与特征

**种群 population**：一定时间占据一定生态位的一群相同物种；即特定时间生活在特定地理区域并具有交配繁殖能力的同物种个体群。

- 种群是物种、物种进化和生物群落的基本单位。
- **种群动态学**：将种群作为动态系统，利用数学模型研究种群大小和组成。

**三大特征**

| 特征 | 说明 |
| --- | --- |
| 空间 | 种群有一定的分布区域 |
| 数量 | 数量/密度随时间变化 |
| 基因 | 具有一定的基因组成以区别于其他物种，但基因组成也是动态的 |

### 5.2 单体生物与构件生物

- **单体生物**：有特定生活史、个体特异性；从受精卵到成体有确定生命阶段，个体与群体在视觉上不同。
- **构件生物（模块化生物）**：受精卵发育成单元/模块，模块再无性繁殖出更多模块；没有特定生命阶段，发育不可预测且受环境影响大，难以区分整体与模块；模块在群体中可具特定功能。

### 5.3 种群动态与属性

**初级属性**：出生、死亡、迁入、迁出、存活率。

- 出生：生殖力（单位时间产生的后代数）；实际生殖力（实际存活数量）。
- 迁入：进入种群的个体；迁出：离开种群。
- 存活率 survivorship：单位时间内没有死亡的比例。

**年龄结构（种群金字塔）**：影响实际增长率（从正到负的变化）。

**性别比例**

- **费雪原理 Fisher's principle**：解释为什么多数有性繁殖物种的性别比约为 1:1。
  1. 亲代投资均衡：雌雄后代对亲代繁殖成功的贡献价值相等；雄性比例过高→竞争加剧→雄性繁殖成功率下降→投资回报下降；反之亦然。自然选择使两性投资总量相等，即性比 1:1。
  2. 数学表达：设雄性占比 *m*、雌性占比 *f*（*m*+*f*=1），雄性平均繁殖成功率为 1/*m*，雌性为 1/*f*；当 *m*>*f* 时选择偏好生产雌性，推动 *m* 降至 0.5。

- 性别偏差原因：局部资源竞争、局域配偶竞争、**Trivers-Willard 假说**（食物在雌雄需求上的差异、母系质量、雄性质量）。
- 四级性比：初级（繁育）、次级（出生）、三级（性成熟）、四级（生殖后期）。

### 5.4 密度

| 类型 | 说明 | 测量方法 |
| --- | --- | --- |
| 绝对密度 | 单位面积/体积内的生物数量，是实际个体数的估计 | 普查、样方法（固着生物）、标记重捕法 |
| 相对密度 | 种群大小的相对指标，提供丰度指数而非实际密度 | 陷阱、粪便颗粒、鸣叫计数、啃食痕迹、雷达、路边观察、披毛/路杀记录、单位努力捕获量 |

**密度的限制因素**：自然灾难、竞争、偶然天气、寄生和疾病、捕食。

| 限制因素类型 | 特点 |
| --- | --- |
| 密度非依赖 | 通常为非生物因素（飓风、干旱、洪水、野火、火山），以相似方式影响所有种群 |
| 密度依赖 | 通常为生物因素（竞争、捕食、寄生），只有密度达到一定水平才起作用，对小而分散的种群影响不大 |

**自疏 self-thinning / Yoda -3/2 法则**

- 高密度种群中出现死亡、存活个体生长。
- 个体植物株重随密度降低而增加，这一过程称为自疏。

![密度制约效应](attachments/密度制约效应.png)

### 5.5 分布与集合种群

**分布类型**

- 随机分布
- 均匀分布
- 集群分布（成群）：最常见，由环境条件、行为适应、繁殖策略造成。

**集合种群 metapopulation**

- 一系列小的、独立的种群通过偶尔的扩散联合在一起；局部种群（亚种群）占据斑块。
- 斑块条件：足够大、与原来区块质量相同、波动不一致、与其他区块隔离。

**Levins 模型**

$$\frac{dp}{dt} = cp(1-p) - mp$$

- *p*：被占据斑块比例；*c*：定植率；*m*：灭绝率。

![集合种群Levins模型](attachments/集合种群Levins模型.jpg)

### 5.6 增长率与寿命

**内禀增长率**

$$r = \frac{\ln R_0}{T}$$

- *T*：世代时间（出生到繁殖的时间）；*R₀*：净增值率。
- 实际增长率受年龄分布、社会结构、基因组成、环境因子波动影响，可从正变负。

![内禀增长率公式](attachments/内禀增长率公式.png)

**最大（内在）增长率 Rm**：最适条件下的最大增长率，取决于繁殖力、寿命、个体发育速度。

**寿命**

- 生理寿命：最佳条件下种群个体的平均寿命，个体死于衰老。
- 生态寿命：自然条件下种群个体的平均寿命，个体死于捕食、疾病、寄生虫等。

### 5.7 种群增长模型

**无限制增长**

- 离散型：$N_t = N_0 \lambda^t$
- 连续型：$N_t = N_0 e^{rt}$，$\dfrac{dN}{dt} = rN$（指数增长 / J 型）

**有限制增长（逻辑斯蒂 / S 型）**

$$\frac{dN}{dt} = rN\left(1 - \frac{N}{K}\right)$$

- *K*：环境容纳量（环境能支持的特定物种最大个体数，由资源可用性、疾病和捕食者决定）；*N*：种群密度；*r*：内在增长率。

![两种增长模型对比](attachments/两种增长模型对比.png)

![种群增长手写笔记](attachments/种群增长手写笔记.jpeg)

**逻辑斯蒂模型假设**

1. 种群在恒定但有限的环境中，起初增长迅速，接近容纳量时增长率下降。
2. 密度与增长率呈线性关系，每增加 1 个个体使增长率降低 1/*K*；剩余增长空间为 1−*N*/*K*。
3. 种群最初有稳定的年龄分布（SAD 假设）。
4. 密度已用适当单位测量。
5. 密度对增长率的抑制瞬间发生，无时间滞后。

**自然条件不符合逻辑斯蒂模型的原因**

- 每增加个体并不会导致 *r* 等量下降。
- 生长过程常有时间滞后（如哺乳动物怀孕数月）。
- *K* 值可能随季节或气候变化。
- 通常少数个体完成多数交配。
- 阻止扩散的障碍很少。

**最大持续产量 MSY**：在 *K*/2 附近收获可获得最大持续产量（复习提纲要点）。

## 七、生活史策略

**生活史 life history**：生物体一生中发育模式和繁殖方式的任何方面；个体在一生中将时间和精力分配给生长、损伤修复、繁殖等基本活动的模式。

**适应度 fitness**：有机体繁殖成功的尺度；留下最多成熟后代的个体最适合环境。

**属性**：个体大小、生长率、寿命（变态、滞育、衰老）、繁殖。

**权衡 trade-off 与分配原则**：若能量用于一种功能（如生长），可用于其他功能（如繁殖）的能量就减少。生长与繁殖的权衡体现在：

- 卵、幼体或种子的数量与大小（繁殖力）
- 繁殖方式（奇偶）
- 初产年龄（成熟期）
- 生育分配
- 亲代抚育
- 何时停止繁殖（衰老）

**R/K 选择理论**

| 类型 | r-对策者 | K-对策者 |
| --- | --- | --- |
| 选择压力 | 高死亡率、不可预测环境（荒漠、灾变区） | 资源稳定、高竞争环境（热带雨林、珊瑚礁） |
| 特征 | 早熟、高繁殖力（如蝗虫单次产卵 1000 粒）、短寿命、低亲代投入 | 晚熟（如大象 15 岁繁殖）、低繁殖力（每胎 1 崽）、高亲代抚育、长寿 |
| 模型 | dN/dt = rN（指数增长主导） | dN/dt = rN(1−N/K)（密度制约主导） |

**CSR 策略**（Grime）

![植物CSR生活史策略](attachments/植物CSR生活史策略.png)

- C 竞争型：高资源、低干扰；强竞争能力。
- S 胁迫耐受型：低资源、低干扰；耐受恶劣条件。
- R 杂草型：高资源、高干扰；快速生长繁殖。

**两面下注理论 bet-hedging**

- **终生一胎 semelparity**：用尽资源繁殖一次后死亡（多数昆虫、鲑鱼、竹子、豚草）；规模小、短命，环境灾难性影响大。
- **多次繁殖 iteroparity**：一次生育较少后代，一生中重复繁殖；需平衡生长、维持、避敌、保卫领域与繁殖；多数脊椎动物、多年生草本、灌木和乔木。

**亲代投资取决于后代数量与大小**

- 大量后代、很少或没有亲代照顾（鱼卵、植物种子）。
- 无助的后代：孵化投入少但需大量亲代照顾。
- 更成熟的后代：妊娠期长，在有利发育阶段出生。
- 合作育种者、寄生幼虫（杜鹃）。

**交配制度 mating system**

| 类型 | 要点 |
| --- | --- |
| 一夫一妻 | 雌性同步易接受；双亲照顾；季节性或永久性；可分担成本、提高后代存活；"出轨"可带来额外父系关系 |
| 一夫多妻 | 个体争夺资源与领地；雌性照顾幼崽 |
| 一妻多夫 | 性二态反转 |
| 滥交 | 最大子代数、竞争激烈；雌性仅负责后代资源；后代存活机会较少 |

## 八、竞争与生态位

**竞争 competition**：由对有限资源的共同需求引起的个体间相互作用，导致竞争个体的生存、生长和/或繁殖减少。关键点：资源必须有限；相互作用是负面的。

**类型**

- 种内竞争：同种成员间，资源需求相同因而特别强烈；调节种群规模、影响自然选择。
- 种间竞争：不同物种间；也可调节种群大小、构建群落、影响自然选择。

**两种模式**

| 模式 | 特点 |
| --- | --- |
| 利用竞争 | 通过消耗共享资源（食物、水、光照）间接产生负面影响；无需接触 |
| 干扰竞争 | 通过直接物理或化学对抗排除竞争者（攻击、领域标记、毒素释放） |

**竞争的一般特征**：竞争不对称（部分个体受负面影响更大）；可直接或间接竞争。

**竞争排斥原则 competitive exclusion principle**：两个竞争物种若需要相同的有限资源，不能在稳定环境中共存；若能共存，是因为生态位存在差异（实现的生态位略有不同），竞争减少。

**共存的机制**

- 逃避竞争。
- 捕食和疾病使各种群保持在足够低的水平。
- 资源在空间和时间上可变，物种不会同时找到资源。

**哈钦森的生态位定义**

- **基础生态位 fundamental niche**：允许生物体生存和繁殖的资源与条件集合。
- **已实现生态位 realized niche**：受竞争、捕食、寄生、疾病限制时，物种实际占据的基础生态位的一部分。

![生态位符号含义表](attachments/生态位符号含义表.png)

**资源利用曲线**

![资源利用曲线](attachments/资源利用曲线.png)

- *d*：峰间距；*w*：标准差；限制相似性 *d/w* = 1。
- 窄生态位重叠少、竞争弱；宽生态位重叠多、竞争强。

**竞争释放 competitive release**：没有竞争时，物种会扩大其生态位。

**性状替换 character displacement**：共存物种因竞争压力在形态、行为或生理上分化，减少生态位重叠。

**Lotka-Volterra 竞争模型**

![种间竞争模型](attachments/种间竞争模型.png)

![种间竞争四种结局](attachments/种间竞争四种结局.png)

- *α*、*β*：竞争系数；*K*：环境容纳量。
- 物种 1 胜：*K*₁ > *K*₂/*β*；物种 2 胜：*K*₂ > *K*₁/*α*。
- 稳定共存：*K*₁ < *K*₂/*β* 且 *K*₂ < *K*₁/*α*。
- 不稳定共存：*K*₁ > *K*₂/*β* 且 *K*₂ > *K*₁/*α*。
- **零增长等斜线**：判定共存条件的图解工具。

**最终产量恒定定律 constant final yield**

- 种内竞争的一种形式；存活率不降低，但植物大小和繁殖产量受影响。
- 低密度时产量随密度增加而增加；最终产量与密度无关。

**物种丰富度模型**

![物种丰富度模型](attachments/物种丰富度模型.png)

- 物种因资源范围更大、更特化、重叠更多、资源轴充分利用而增多。

## 九、群落

### 9.1 概念与划分

**生物群落**：同一地点、同一时间共同出现的相互作用物种群体。

- 群落的存在取决于存在的物种、它们之间的相互作用及物理环境。
- 按自然环境特征划分（物理定义）：沙丘、山涧、沙漠。
- 按生物特征划分（生物定义）：海带森林、淡水沼泽、珊瑚礁。
- 用物种子集定义群落：分类亲和性、作用群、食物网、相互作用网。

**群落的基本特征**：一定的外貌、种类组成、物种相互联系、内部环境、结构、动态特征、分布范围、边界特征、各物种群落学重要性不等。

![群落基本特征](attachments/群落基本特征.png)

### 9.2 群落结构与物种多样性

- **物种多样性**与**物种组成**是群落结构的重要描述因子。
- **物种丰富度**：一个地区的物种数量，最简单的多样性衡量标准；是迁移与灭绝之间的平衡。
- **物种均匀度**：每个物种个体数的相对比例；衡量方法包括数量/密度、生物量、覆盖面积。
- 丰富度与均匀度结合成**物种多样性指数**。

![群落结构与多样性对比](attachments/群落结构与多样性对比.png)

**香农多样性指数 Shannon index**

$$H = -\sum_{i=1}^{S} p_i \ln p_i$$

- *pᵢ*：第 i 物种个体比例；*S*：总物种数；−ln(*pᵢ*) 使稀有种权重更高。

![香农多样性指数公式](attachments/香农多样性指数公式.png)

**等级丰度曲线 rank abundance curve**

![秩多度曲线](attachments/秩多度曲线.png)

**物种积累曲线**：多样性估计值因采样力度和规模而异。

![物种累积曲线](attachments/物种累积曲线.png)

### 9.3 物种相互作用与物种分类

**直接相互作用**：发生在两个物种之间，包括竞争、捕食、促进。
**间接相互作用**：由第三个（或更多）物种介导，如营养级联（食肉动物捕食食草动物）、营养促进。

- 第三个物种的加入可能极大改变原始相互作用结果："朋友的朋友就是敌人，敌人的敌人就是朋友"。
- 相互作用在强度和方向上变化很大。

**人均相互作用强度**

$$S = \frac{\ln(C/E)}{I}$$

- *C*：有相互作用时目标种个体数；*E*：无相互作用时个体数；*I*：相互作用者个体数。

![相互作用强度公式](attachments/相互作用强度公式.png)

**物种分类**

| 类型 | 说明 |
| --- | --- |
| 优势种 | 大而丰富的物种（如树木），通过提供栖息地或食物影响群落，也是空间、光线、营养的强竞争者 |
| 生态系统工程师 | 通过"生物工程"改变环境（如树木提供栖息地、改变温湿度；海狸） |
| 关键物种 keystone species | 因生态角色产生强烈影响而非数量多（如海獭） |
| 亚优势种、伴生种、稀有种 | — |

**群落稳定性假说**：红皇后（Red Queen）、组合（Portfolio）、冗余（Redundancy）假说，见 [1.1 节](#11-定义与研究层次)。

### 9.4 多样性的空间尺度与生物地理学

| 尺度 | 说明 |
| --- | --- |
| α 多样性 | 局部尺度（相当于一个群落），物种生理与种间相互作用占重要地位 |
| β 多样性 | 局域与区域尺度间的联系；反映群落间物种更替，共享物种少则 β 大 |
| γ 多样性 | 一个区域内的全部物种，即区域物种库 |

**区域生物地理学**

- 物种多样性的区域差异受**面积**和**距离**控制，源于迁移率与灭绝率的平衡。
- 物种丰富度随面积增加而增加，随距离增加而减少。

**种—面积关系**

$$S = cA^z$$

- *S*：物种数；*A*：岛屿面积；*c*：栖息地类型常数（热带雨林≈0.5、沙漠≈0.1）；*z*：曲线斜率，理论值 0.263（实测 0.15～0.35）。

![种-面积关系](attachments/种-面积关系.png)

**岛屿生物地理学平衡理论（MacArthur-Wilson）**

- 迁入率随物种增多而下降，受距离影响（近岸岛高而陡、远洋岛低而缓）。
- 灭绝率随物种增多而上升，受面积影响（大岛低而缓、小岛高而陡）。
- 两线交点给出平衡物种数 *S*\*：近岸大岛高，远洋小岛低。

![岛屿生物地理学模型](attachments/岛屿生物地理学模型.png)

### 9.5 干扰、间隙与演替

**干扰 disturbance**：任何导致群落完全或部分破坏、造成裸露空间的因素。

- 物理因素：火灾、冰暴、洪水、干旱、大风、山体滑坡、大浪。
- 生物因素：严重放牧、捕食、疾病、挖掘与挖洞。
- 属性：**强度**（受损生物量或种群比例）、**频率**（特定时间间隔内的平均次数）。

**间隙与竞争性彩票**

- 干扰在连续群落中造成间隙（森林缝隙由强风、闪电、伐木、火灾形成；草地由放牧、挖掘、践踏形成）。
- 竞争性彩票：许多物种有类似的占据空隙能力；先占据者抑制后来者；"第一个到达者赢，但谁赢是随机的"。

**中间干扰假说**：干扰使群落处于非平衡状态，通过更新可殖民空间，使本会因竞争排斥而灭绝的物种得以延续。

**演替 succession**：物种种群在一个地点的非季节性、定向、连续的定植与灭绝模式。

| 类型 | 说明 |
| --- | --- |
| 原生演替 | 在从未有过生命的地方（熔岩流、火山爆发、冰川退缩、裸岩风化） |
| 次生演替 | 原有生命残余尚存（火灾、洪水、风暴、严重放牧、收割） |
| 降解性演替 | 基质腐烂被分解者利用（尸体、腐烂原木） |

**演替机制**

- **促进演替**：最早物种积极改变环境使后来物种受益，但最终阻碍自身持续优势；早期物种抗逆、善改造栖息地；最终形成顶极群落。
- **耐受演替**：最早物种以中性方式改变环境，既不受益也不抑制后来物种；早期物种快速生长繁殖。
- **抑制演替**：先到物种占据空间阻止后来者定居，只有死亡后才被替换。

**演替方向**

- 渐进式演替：群落结构与物种组成由简单到复杂；资源利用由不足到充分；生产力由低到高；对外部环境的转化日益强烈。
- 退行演替：相反，通常由污染物等环境因素引起。

**顶极学说**

- 顶极群落：植物、动物和真菌群落通过生态演替达到稳定状态。
- 单元顶极学说：同一气候区只能有一个顶极群落，特征完全由当地气候决定。
- 多元顶极学说：一个区域的顶极群落可由几种不同类型镶嵌而成，受土壤湿度、营养、地形、动物活动等环境条件控制。
