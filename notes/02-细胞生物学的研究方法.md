# 02 细胞生物学的研究方法

> 返回 [[00-总览]]

## 1. 显微镜技术

### 1.1 光学显微镜

**基本构成**

- 核心：光学放大系统——物镜、目镜。
- 其他：光源、机械支撑系统、（数码图像采集系统）。
- 重要参数：放大倍数、**分辨率**（最重要）。

**分辨率**

- 定义：能区分开两个小点间的最小距离，受干涉与衍射现象制约。
- 公式：$D = 0.61\lambda / (N \sin\alpha)$，最大值约 0.2 μm。
  - 光源波长 λ：最大约 400 nm。
  - 物镜镜口角 α：最大约 140°。
  - 介质折射率 N：空气 = 1，油镜 ≈ 1.5。

**超分辨率显微镜**

- 关键点：荧光分子（2014 年诺贝尔物理学奖）。
- 成像方法：先获得单分子荧光图像，再将成千上万的单分子图像叠加，获得高分辨率图像。

**相差显微镜**

- 作用：观察**活细胞**。
- 部件：环状光阑、相差板。
- 原理：光线通过不同密度物体产生相位差，再将相位差转化为振幅差（明暗差）。
- 拓展阅读：[相差显微镜与微分干涉差显微镜（飞书文档）](https://qqeggtfhkm7.feishu.cn/docx/IpUZd1prEoOwUgx7fAvc7nk6nZg#share-QbChd7e05oNCFjxWK9VcywZBn9e)

**荧光显微镜**

- 结构：[荧光显微镜结构图](attachments/荧光显微镜结构图.png)
- 部件：
  - 超高压汞灯：提供更多短波长光。
  - 转盘（双色镜与激发滤片）：产生不同激发光。
    - 激发滤片：只允许特定波长光通过。
    - 双色镜：反射短波长光、透过长波长光。
  - 物镜：光学质量优于普通光学显微镜。
- 原理：分子吸收入射光能量后电子跃迁，返回基态时发出荧光。
- 光路：激发光 → 激发滤片 → 双色镜 → 样品（产生荧光）→ 物镜 → 双色镜 → 阻断滤光片 → 目镜。
- 荧光标记：
  - 常用荧光分子：罗丹明（标记蛋白质）、DAPI（标记 DNA）、FURA-2（标记 Ca²⁺）、GFP / RFP（荧光蛋白）。
  - 激发/发射波长：[荧光标记波长图](attachments/荧光标记波长图.png)
  - **免疫荧光术**：需固定死细胞并孵育；基于抗原—抗体特异性结合。
    - 直接荧光标记：适合蛋白质含量高的样品；DAPI 直接标记 DNA。
    - 二抗放大信号：间接标记，提高灵敏度。
  - **荧光蛋白标记技术**：基因工程将荧光蛋白基因与目标蛋白基因融合表达。
    - 应用：蛋白质动态追踪、FISH（核酸定位与定性）、荧光共振能量转移（FRET，检测蛋白质相互作用）。

**激光共焦扫描显微镜**

- 光源：激光。
- 特点：聚光镜与物镜聚焦到同一点（共焦），提高分辨率。
- 通过不同焦平面逐层扫描、计算机三维重建，又称**光学切片**。

### 1.2 电子显微镜

**透射电子显微镜（TEM）**

- 设备：电子枪（电子束作光源）、电磁透镜（聚焦）、荧光屏（成像）。
- 原理：样品不同部位密度不同，穿透电子数不同形成反差。
- 分辨率：约 0.2 nm。
- 特异蛋白定位：免疫胶体金技术——胶体金颗粒偶联抗体，形成电子致密物。
- 放射自显影技术：
  - 作用：对生物大分子定性、定位、半定量。
  - 原理：放射性同位素使乳胶感光。
  - 过程：同位素标记前体（脉冲标记）→ 电镜曝光成像。
  - 常用标记：DNA—³H-TdR；RNA—³H-尿嘧啶；蛋白质—³⁵S。
- 制样关键：
  - CHON 对电子散射能力差 → **重金属盐染色**：柠檬酸铅（蛋白质）、醋酸双氧铀（核酸）、锇酸（脂类）。
  - 电子穿透能力低 → **超薄切片**：取材 → 固定 → 包埋（环氧树脂）→ 切片 → 染色。
  - 其他技术：负染（细胞器等）、冷冻蚀刻（蛋白质：冰冻断裂 → 蚀刻 → 倾斜喷重金属 → 垂直喷碳 → 保存断裂面）。

**扫描电子显微镜（SEM）**

- 原理：电子轰击细胞产生二次电子，收集二次电子成像。
- 制样：二氧化碳临界点干燥保存形态；表面镀金提高二次电子发射能力。

## 2. 制片技术

| 样品 | 方法 | 要点 |
|---|---|---|
| 死细胞 | 石蜡包埋 | 甲醛固定 → 石蜡包埋 → 切片 → 苏木精（核）/ 伊红（质）染色；缺点是温度高、破坏酶活性 |
| 死细胞 | 冰冻切片 | 低温使组织变硬并保持酶活性，适合观察酶活性 |
| 活细胞 | 相差显微镜 / 微分干涉差显微镜 | 无需固定，可观察活细胞动态 |

## 3. 流式细胞术

- 定义：以流式细胞仪为手段，定量分析并分选单个细胞的理化特性。
- 原理：使细胞带上荧光分子——直接标记或抗体偶联。
- 仪器：激光、分析仪、细胞悬液、细胞收集器。
- 应用：测定 DNA（碘化丙啶染色）、RNA、蛋白质含量、细胞数量及细胞分选。

## 4. 细胞培养

### 4.1 意义与流程

- 意义：持续获取实验材料；便于在体外控制实验条件。
- 原代培养流程：取出组织/肿瘤块 → 剪碎 → 胰酶或胶原酶 + EDTA 处理 → 破坏细胞连接、分散细胞 → 加入含小牛/胚牛血清（含生长因子）的培养基培养。

### 4.2 原代细胞与细胞系

- 原代细胞：直接从组织培养获得的细胞。
- 生长规律：约 10 代后大部分衰老死亡；少数可继续繁殖 40–50 代，之后衰老或突变成癌细胞（形成细胞系）。
- 常用细胞系：

| 细胞系 | 来源/特征 |
|---|---|
| 3T3 | 小鼠成纤维细胞 |
| HeLa | 人上皮细胞 |
| 293 | 腺病毒转化的人肾细胞 |
| CHO | 中国仓鼠卵巢细胞 |
| H1、H9 | 人胚胎干细胞系 |

### 4.3 单克隆抗体技术（B 淋巴细胞杂交瘤）

- 目的：获取大量均一抗体。
- 流程：
  1. 用蛋白免疫小鼠，分离能分泌抗体的 B 淋巴细胞。
  2. 提取缺陷型小鼠骨髓瘤细胞（胸苷激酶缺陷、次黄嘌呤鸟嘌呤磷酸核糖转移酶缺陷）。
  3. 用聚乙二醇或灭活仙台病毒介导融合，形成异核体，进而融合为杂交瘤细胞。
  4. 在 HAT 培养基中筛选。
- 原理：
  - DNA 合成有正常（C、N）通路与补救通路（胸苷、次黄嘌呤）。
  - 氨基嘌呤阻断正常通路；B 淋巴细胞会衰老，骨髓瘤细胞不能经补救通路合成 DNA。
  - 只有杂交瘤细胞兼具无限增殖能力与补救通路，得以存活。
