# 12 专业名词速查

> 返回 [[00-总览]] ｜ 按英文/缩写字母序排列，详细机制见链接章节

## 1. 核心名词

| 名词 | 释义 | 详见 |
|---|---|---|
| **信号转导（signal transduction）** | 胞外信号转化为胞内信号的过程 | [[08-细胞信号转导]] |
| **核定位信号（NLS, Nuclear Localization Signal）** | 真核蛋白上的一段短氨基酸序列，引导在胞质中合成的蛋白质通过核孔复合体主动转运进入细胞核；入核后不被切除 | [[05-蛋白分选与膜泡运输]] · [[07-细胞核与染色体]] |
| **APC（后期促进复合体）** | 泛素连接酶，降解 securin 与 cyclin B，启动姐妹染色单体分离 | [[09-细胞周期及其调控]] |
| **Caspase** | 天冬氨酸特异性半胱氨酸蛋白水解酶，凋亡执行的核心酶类 | [[11-细胞衰老与死亡]] |
| **CDK / Cyclin** | 周期蛋白依赖性激酶 / 周期蛋白，组成 MPF 等复合物驱动周期 | [[09-细胞周期及其调控]] |
| **Cohesin / Condensin** | 黏连蛋白（黏着姐妹染色单体）/ 凝缩蛋白（介导 DNA 凝缩） | [[10-细胞分裂]] |
| **FRAP（荧光漂白恢复）** | 激光淬灭荧光后检测恢复速率，定量膜流动性 | [[03-细胞质膜与物质跨膜运输]] |
| **M6P（6-磷酸甘露糖）** | 溶酶体酶的分选标记，被 TGN 的 M6P 受体识别 | [[04-细胞质基质与内膜系统]] |
| **MPF（成熟/有丝分裂促进因子）** | Cyclin B-CDK1 复合物，推动 G2/M 转换 | [[09-细胞周期及其调控]] |
| **MTOC（微管组织中心）** | 介导微管成核与延伸的结构，如中心体、基体 | [[06-细胞骨架]] |
| **NOR（核仁组织区）** | 染色体次缢痕区的 rRNA 基因区域，与核仁形成有关 | [[07-细胞核与染色体]] |
| **PCC（早熟凝集染色体）** | 细胞提前进入 M 期导致的染色体异常凝缩，形态随原时相而异 | [[09-细胞周期及其调控]] |
| **Rb / E2F** | 视网膜母细胞瘤蛋白 / 转录因子，控制 G1/S 转换；Rb 突变致检查点失控 | [[09-细胞周期及其调控]] |
| **SAC（纺锤体组装检查点）** | Mad/Bub 监控动粒与微管连接，未正确连接时抑制 APC | [[09-细胞周期及其调控]] |
| **第二信使** | 胞外信号作用于表面受体后产生的非蛋白小分子，如 cAMP、IP₃、DAG、Ca²⁺ | [[08-细胞信号转导]] |
| **细胞全能性** | 单个细胞含全套遗传信息，具有发育成完整个体的潜能 | [[01-绪论]] |
| **端粒 / 端粒酶** | 染色体末端结构，解决末端复制问题并作为分裂计时器；端粒酶在体细胞中一般无活性 | [[07-细胞核与染色体]] · [[11-细胞衰老与死亡]] |
| **凋亡小体** | 凋亡细胞质膜反折包裹细胞碎片形成的芽状结构，被吞噬细胞清除 | [[11-细胞衰老与死亡]] |
