# 01 · RNA 加工与翻译

> [!abstract] 一句话定位
> 真核 mRNA 经历 **5′ 加帽 + 3′ 加 poly(A)** 才成熟；随后核糖体按 mRNA 密码子、借 tRNA 和翻译因子合成多肽，原核与真核在起始识别（SD vs Kozak）和因子命名上不同；新生肽还需翻译后修饰才具备功能。

## 1　真核 mRNA 的加工

成熟 mRNA 的结构：$\mathrm{Cap} — 5'\mathrm{OTR} — \mathrm{CDS} — 3'\mathrm{OTR} — \mathrm{poly(A)}$

### 1.1　5′ 帽（cap）

- **添加 7-甲基鸟嘌呤（$m^7\mathrm{G}$）**：鸟嘌呤的三磷酸取代 mRNA 5′ 端的三磷酸，随后甲基化。
- **反应过程**：
  - $\mathrm{Gppp} \rightarrow \mathrm{Gp} + \mathrm{pp}$
  - $\mathrm{pppNp} \rightarrow \mathrm{p} + \mathrm{ppNp}$
  - $\mathrm{Gp} + \mathrm{ppNp} \rightarrow \mathrm{GpppNp} \xrightarrow{+\,m} m^7\mathrm{GpppN}_{mp}$

| 类型 | 修饰位置 |
| :--- | :--- |
| Cap 0 | 末端 G 的 $m^7$ |
| Cap 1 | 第一个核苷酸的 $2'\mathrm{OH}$ 甲基化 |
| Cap 2 | 第二个核苷酸的 $2'\mathrm{OH}$ 甲基化 + 第一个核苷酸的嘌呤甲基化 |

**作用**：① 防止核酸外切酶降解；② 被核帽子结合蛋白识别、运出细胞核；③ 启动翻译；④ 启动靠近 5′ 端的内含子剪切。

### 1.2　3′ poly(A) 尾

- **多核苷酸腺苷酰转移酶（PAP）** 添加多聚腺苷酸。
- **多聚腺苷酸信号**：$5'\text{-AAUAAA-}3'$。
- **poly(A) 尾长度**：约 250 个 A。

**作用**：① 防止 mRNA 降解；② 参与转录终止；③ 帮助 mRNA 运出细胞核；④ 提高翻译起始效率。

**选择性多聚腺苷酸化（APA）**：当 RNA 上存在多个加尾信号时，选择其中一个进行剪切加尾，使**一个基因编码多个 mRNA**。

> 可变剪接、RNA 干扰（siRNA / miRNA）等转录后调控见 [[遗传学/04-基因表达与调控/02-基因表达调控|基因表达调控]]。

## 2　核糖体与 tRNA

### 2.1　核糖体结构

| 项目 | 原核生物 | 真核生物 |
| :--- | :--- | :--- |
| 整体 | **70S** | **80S** |
| 大亚基 | 50S：23S rRNA、31 种蛋白、5S rRNA | 60S：28S rRNA、49 种蛋白、5S rRNA、5.8S RNA |
| 小亚基 | 30S：16S rRNA、21 种蛋白 | 40S：18S rRNA、33 种蛋白 |

**核糖体结合位点（原核）**

| 位点 | 功能 |
| :--- | :--- |
| A site | 氨酰-tRNA 结合位点 |
| P site | 肽酰-tRNA 结合位点 |
| E site | 空 tRNA 出口 |

**组分功能**

- 蛋白质：促进不同分子相互结合。
- rRNA：参与起始时与 mRNA 结合；**催化转肽反应**。

**SD 序列（Shine–Dalgarno）**

- 原核 mRNA 起始密码上游约 **8 nt** 的一段保守序列。
- 一致序列：$5'\text{-AGGAGGU(SD)-AUG-}$
- 与核糖体 **30S 小亚基 16S rRNA 的 $3'$ 端**碱基配对。

### 2.2　tRNA 结构与装载

**结构（原核）**

- 沉降系数 4S，长度 75～90 nt，含**稀有碱基**。
- $3'$ 端为 **CCA**，其中 A 的羟基与氨基酸结合。
- 中部有**反密码子**。

**装载（形成氨酰-tRNA）**

| 氨酰-tRNA 合成酶（aaRS） | 连接位置 |
| :--- | :--- |
| 一类 aaRS | CCA 末端 $2'\mathrm{OH}$ |
| 二类 aaRS | CCA 末端 $3'\mathrm{OH}$ |

- 一种氨基酸通常只对应一类 tRNA，**赖氨酸例外**。
- 装载步骤：① 氨基酸与 ATP 结合，ATP 脱去两个磷酸形成复合物；② 结合相应 aaRS；③ tRNA 通过反密码子被 aaRS 识别，氨基酸连接到 tRNA 上。

## 3　原核生物的翻译

### 3.1　起始

**30S 起始复合物**组分：

| 组分 | 作用 |
| :--- | :--- |
| IF1 | 稳定 30S 小亚基 |
| IF2 | 帮助 fMet-tRNA 与 30S 结合，与 GTP 结合 |
| IF3 | 帮助 30S 与 mRNA 结合 |
| 小亚基 + mRNA（SD 序列） | 模板识别 |
| GTP、$\mathrm{Mg}^{2+}$ | 能量与离子环境 |
| $\mathrm{fMet-tRNA}^{f\mathrm{Met}}$ | 起始氨酰-tRNA |

**70S 起始复合物**：在 30S 起始复合物基础上加入大亚基。

### 3.2　延伸

1. aa-tRNA 进入 **A 位**。
2. P 位氨基酸转移到 A 位，形成**肽键**。
3. 延伸因子参与：

| 因子 | 作用 |
| :--- | :--- |
| EF-Tu | 与 GTP 结合，把 aa-tRNA 带入 A 位 |
| EF-Ts | 激活 EF-Tu（促进 GDP/GTP 交换） |
| EF-G | 驱动核糖体沿 mRNA 滑动，需 GTP |

4. mRNA–tRNA–肽链整体后退，A 位肽链进入 P 位，P 位空 tRNA 进入 E 位并释放。

### 3.3　终止

- **终止密码子**：UAG、UAA、UGA。
- **释放因子（RF）**

| 因子 | 识别与功能 |
| :--- | :--- |
| RF1 | 识别 UAA、UAG，释放多肽 |
| RF2 | 识别 UGA、UAA |
| RF3 | 激活 RF1、RF2 |

- 整个过程需 GTP 供能。

**多聚核糖体**：多条核糖体同时翻译同一条 mRNA，提高翻译效率。

## 4　真核生物的翻译

| 特点 | 说明 |
| :--- | :--- |
| 核糖体位点 | **无 E site** |
| SD 序列类似物 | **Kozak 序列**：$5'\text{-ACCAUGG-}3'$，参与核糖体结合 |
| 起始 tRNA 与氨基酸 | $\mathrm{Met-tRNA}_i^{\mathrm{Met}}$（甲硫氨酸，非甲酰化） |
| 因子 | 起始 eIF、延伸 eEF、终止 eRF（eRF 与终止密码结合释放肽链） |

**过程**：eIF 帮助核糖体与 mRNA 的 **cap** 结合（因为没有 SD 序列）→ 扫描至起始 AUG，tRNA 与之配对 → 开始翻译。

## 5　翻译后修饰与功能结构域

| 修饰类型 | 具体方式 |
| :--- | :--- |
| 去除起始氨基酸 | 原核：肽链脱甲酰酶、甲硫氨酰氨肽酶 |
| 去除信号肽 | 信号肽酶 |
| 去除内含肽 | 内含肽是自私 / 寄生的遗传元件，可**自我剪切** |
| 其他修饰 | 磷酸化、糖基化、乙酰化、烷基化、修剪、折叠 |

**蛋白质的功能结构域**：与蛋白质其他部分**相对独立**的保守三级结构。

> [!note] 病例索引
> 苯丙氨酸代谢途径与相关先天代谢病（PKU、尿黑酸尿症、白化病）已移入 [[遗传学/01-经典遗传学/01-绪论与孟德尔遗传扩展|绪论与孟德尔遗传扩展]]，作为「一因多效」的实例。

## 6　考点速记

- 5′ 帽：m⁷G，Cap 0/1/2；四大作用（保护、出核、起始翻译、首端剪接）。
- 3′ poly(A)：AAUAAA 信号、PAP、~250A；APA 使一基因产生多个 mRNA。
- 核糖体：原核 70S（50S + 30S），真核 80S（60S + 40S）；A/P/E 三位点。
- SD 序列 AGGAGGU 与 16S rRNA $3'$ 配对；真核对应 Kozak ACCAUGG，靠 cap 招募。
- aaRS 一类接 $2'\mathrm{OH}$、二类接 $3'\mathrm{OH}$；赖氨酸例外。
- 原核起始 fMet + IF1/2/3；终止 RF1（UAA/UAG）、RF2（UGA/UAA）、RF3。
- 延伸：EF-Tu 送 tRNA、EF-Ts 激活、EF-G 滑动；真核对应 eEF。

<details>
<summary><b>自测 1：5′ 帽和 poly(A) 尾各有哪些功能？</b></summary>

5′ 帽：防外切酶降解、经帽子结合蛋白介导出核、启动翻译、促进靠近 5′ 端的内含子剪切。poly(A) 尾：防降解、参与转录终止、帮助出核、提高翻译起始效率。
</details>

<details>
<summary><b>自测 2：原核与真核翻译起始有何关键差别？</b></summary>

原核靠 SD 序列与 16S rRNA 配对定位起始密码，起始氨基酸为甲酰甲硫氨酸（fMet），由 IF1/2/3 辅助；真核无 SD 序列，由 eIF 识别 5′ cap 后扫描至 Kozak 序列中的 AUG，起始氨基酸为 Met。
</details>
