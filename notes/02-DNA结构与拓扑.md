# 02 · DNA 结构与拓扑

> [!abstract] 一句话定位
> DNA 用**反向平行双螺旋**存信息，靠**碱基互补**实现自编码，靠**大小沟**被蛋白质读取，靠**超螺旋**压缩与调控。

## 1　DNA 结构的基本特征

1. 最显著的结构特征是**反向平行**与**双螺旋**。
2. 两条相互缠绕链的碱基序列形成**互补关系**。
3. 每条链的骨架由交替的**糖和磷酸**组成。
4. 稳定性由**碱基堆积力**（疏水作用 + π-π 堆积）和**氢键**共同提供。
   - 氢键的形成伴随熵增效应。
   - π-π 堆积的本质是电子云之间通过瞬时诱导偶极吸引（范德华力）。
5. **DNA 特异性由氢键提供**。
6. 组成层次
   - 基本单元：**核苷酸** = 2′-脱氧核苷 + 磷酸。
     - 3′、5′ 羟基形成**磷酸二酯键**。
     - 2′-脱氧核苷 = 2′-脱氧核糖 + 碱基（1′ 羟基形成**糖苷键**）。
   - 核糖碳编号加 `′`，与碱基碳编号区分。
7. **链具有极性**：一端为游离 5′ 磷酸，另一端为游离 3′ 羟基。

### 1.1　染色体层面的原核 / 真核差异

| 特征 | 原核 | 真核 |
| :--- | :--- | :--- |
| 染色体大小 | 小 | 大 |
| 形状 | 环状 | 线型 |
| 染色体拷贝数 | 多数为单拷贝 | 多数为多拷贝（常为二拷贝） |
| 基因密度 | 高 | 低 |
| 位置 | 拟核、质粒 | 染色体（细胞核） |

> 序列层面的差异见 [[分子生物学/02-基因组维持/01-基因组与染色体包装|基因组与染色体包装]]；全模块对照见 [[分子生物学/00-复习总览|复习总览]]。

## 2　碱基

1. 碱基是**扁平的杂环**。
2. **沃森–克里克配对**：A-T、G-C。
   - 原理：碱基的**形状**与**氢键**匹配。
   - 生物学意义：产生 DNA 的**反向平行**与**序列互补（自编码）**特性。
3. **碱基翻转**：单个碱基可以从双螺旋中突出，以便进行修饰或突变。
4. 碱基朝内，但可通过大沟、小沟被接触。

| | 嘌呤 | 嘧啶 |
| :--- | :--- | :--- |
| 类型 | 腺嘌呤 A、鸟嘌呤 G | 胞嘧啶 C、胸腺嘧啶 T、尿嘧啶 U |
| 结构 | 双环（嘧啶环 + 咪唑环） | 单环 |
| 糖苷键连接位 | **N9** | **N1** |
| 互变异构 | A：氨基式 ↔ 亚氨式；G：酮式 ↔ 烯醇式 | C：氨基式 ↔ 亚氨式；T/U：酮式 ↔ 烯醇式 |

## 3　大沟与小沟

> [!important] 形成原因
> 两个糖苷键之间形成**窄角 120°** 与**宽角 240°**：窄角处形成**小沟**，宽角处形成**大沟**。

- 大小沟暴露碱基的特定基团，构成可读的"密码"：
  - **A** = 氢键受体，**D** = 氢键供体，**M** = 疏水甲基，**H** = 非极性氢。
- **大沟**（读取序列与方向 → 调控）

| 碱基对 | 大沟基团模式 |
| :--- | :--- |
| A-T | ADAM |
| G-C | AADH |
| T-A | MADA |
| C-G | HDAA |

- **小沟**（识别整体构象与配对 → 修复、复制）

| 碱基对 | 小沟基团模式 |
| :--- | :--- |
| AT / TA | AHA |
| GC / CG | ADA |

> [!tip] 功能分工
> **蛋白质通过大沟读取序列和方向（调控）；通过小沟识别整体构象和配对（修复与复制）。**

## 4　DNA 结构的多样性

- 碱基对中两个碱基不在同一平面，而是呈**螺旋桨式**。
- Z-DNA 中嘌呤糖苷键为**顺式**、嘧啶糖苷键为**反式**，产生 Z 字形。
- 多样性来源：核苷酸顺序与数量、链数（单/双）、螺旋手性（左/右）、局部碱基对朝向、分子形态（线性/环状）、高级结构（超螺旋）。

| | B-DNA | A-DNA | Z-DNA |
| :--- | :--- | :--- | :--- |
| 特征 | 长、细 | 短、宽 | 细长 |
| 螺旋方向 | 右手 | 右手 | **左手** |
| 每圈碱基对 | 10.5 | 11 | 12（二核苷酸重复） |
| 每碱基对轴向升距 (Å) | 3.4 | 2.6 | 3.7 |
| 螺距 (nm) | 3.57 | 2.86 | 4.4 |
| 直径 (nm) | 2.0 | 2.3 | 1.8 |
| 糖环构象 | C2′-endo | C3′-endo | C：C2′-endo；G：C3′-endo |
| 糖苷键构象 | 反式 | 反式 | C：反式；G：**顺式** |
| 大沟 | 宽深 | 窄深 | 平坦 |
| 小沟 | 窄深 | 宽浅 | 窄深 |
| 典型存在 | 生理条件下的主流构象 | RNA-DNA 杂合；脱水时；蛋白质部分区域 | 交替嘌呤-嘧啶序列 |
| 生物学功能 | 基因信息稳定读取 | 复制/转录中的瞬时构象 | 基因调控、重组 |

## 5　DNA 变性与复性

- **变性方法**：温度、pH。
- **影响稳定性的因素**：GC 含量、溶液离子强度（阳离子中和骨架负电荷）。
- **退火 / 复性**：分开的 DNA 重新形成双螺旋。
- **分子杂交**：复性过程中 DNA 可与不同来源的 DNA、RNA 结合形成杂交双链——用于 **Southern 印迹**和 **DNA 微阵列**。
- **增色效应**：单链对紫外光吸收强于双链；通过 **260 nm** 吸收值判断 DNA 状态。

## 6　DNA 拓扑结构

### 6.1　怀特公式

$$Lk = Tw + Wr$$

| 量 | 含义 |
| :--- | :--- |
| **Lk**（连接数/连环数） | 闭环双链 DNA 中，一条链绕另一条链的总缠绕次数。**完全松弛态记为 $Lk_0$ = 碱基数 / 10.4** |
| **Tw**（扭转数） | 双螺旋本身的局部缠绕圈数，即两链绕中心轴旋转的总周数；天然 B-DNA 每 10.5 bp 一圈 |
| **Wr**（缠绕数/超螺旋数） | 双螺旋中心轴在三维空间盘绕、折叠的次数，即超螺旋的量化值；包括相缠式与螺旋式 |

- **cccDNA**：covalently closed circular DNA（共价闭合环状 DNA）。
- 细胞中 DNA 一般为**负超螺旋**：$\Delta Lk = Lk - Lk_0 < 0$。
  - 意义：储存能量，供拓扑异构酶等过程利用。
  - 引入方式：DNA 以**左手螺旋**缠绕组蛋白引入负超螺旋（螺旋式）。

### 6.2　拓扑异构酶

| 类型 | 切割链数 | ATP |
| :--- | :--- | :--- |
| Ⅰ 型 | 单链 | **不需要** |
| Ⅱ 型 | 双链 | **需要** |

- Ⅱ 型用途：原核环状 DNA 复制（滚轮复制）后分离连环体。

### 6.3　拓扑异构体与迁移率

- 三种形态：**线型、松弛环状、超螺旋**。
- 凝胶电泳迁移速度：**超螺旋 > 线型 > 环状**（松弛环状最慢）。

### 6.4　拓扑结构的作用

1. 基因组压缩　2. 表达调控　3. 协调 DNA 复制　4. DNA 重组与修复　5. 维持染色体结构域组织状态

<details>
<summary><b>自测 1：为什么说 DNA 具有"自编码"特性？</b></summary>

沃森–克里克配对（A-T、G-C）由碱基形状与氢键决定，一条链的序列唯一确定互补链序列，因此信息可自我复制与恢复。
</details>

<details>
<summary><b>自测 2：蛋白质为什么能通过大沟"读序列"，却通过小沟"查配对"？</b></summary>

大沟宽深，暴露 A/D/M/H 基团的组合，不同碱基对模式不同（ADAM/AADH/MADA/HDAA），可区分序列；小沟较窄，暴露模式在 AT/TA 与 GC/CG 间差异有限，主要反映整体构象与是否配对，因此用于修复和复制中的检查。
</details>

<details>
<summary><b>自测 3：细胞中为何维持负超螺旋？如何引入？</b></summary>

负超螺旋储存能量，有利于解旋、复制起始和转录起始。真核通过 DNA 左手螺旋缠绕组蛋白引入；原核通过拓扑异构酶（旋转酶，耗能）引入。
</details>

<details>
<summary><b>自测 4：拓扑异构酶 Ⅰ 型与 Ⅱ 型的区别？</b></summary>

Ⅰ 型切单链、不需 ATP；Ⅱ 型切双链、需 ATP，可解决复制后环状染色体的连环体问题。
</details>
