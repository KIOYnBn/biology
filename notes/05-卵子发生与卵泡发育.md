# 05 卵子发生与卵泡发育

> [!abstract] 本章要点
> 卵子发生过程与减数分裂阻滞；卵泡从原始到成熟各阶段；卵泡募集与选择；排卵与黄体；月经周期；卵子胞质物质与基因印迹。

## 雌性生殖系统

- 原始生殖细胞 → 卵黄囊（生殖嵴）→ 在性腺的性索繁殖 → 发育成输卵管 → 输卵管伞。
- **卵巢**：产生卵细胞、分泌雌性激素；由表面上皮、白膜、实质（皮质、髓质、门细胞）组成。
- **输卵管**：受精部位，输送生殖细胞；壶腹为卵子停留等待受精处，未受精则凋亡、不进入峡部；伞部防止卵子进入腹腔。
- **子宫**：月经与胎儿孕育；**阴道**与**外生殖器**。

## 卵子发生

**概念**：雌性生殖细胞的形成、发育和成熟过程，即原始生殖细胞 → 卵原细胞 → 排出成熟卵子。

### 过程

1. **卵原细胞增殖**：边增殖边向皮质迁移；原始生殖细胞在胎儿出生前完成有丝分裂；增殖后大量生殖细胞凋亡。
2. **卵母细胞生长**：初级卵母细胞体积增大，卵黄颗粒多，出现透明带。
3. **卵母细胞成熟**：完成减数分裂。

### 特点与减数分裂阻滞

- 形成丰富的**细胞质库**（蛋白质、mRNA、细胞器、酶、代谢底物），故减数分裂前期长。
- 两次阻滞：第一次停滞于双线期，第二次停滞于 MⅡ 期。
- **生发泡（GV）**：初级卵母细胞停滞在双线期的核，染色体疏松、核膜界限明显、呈圆形，又称核网期。
- **生发泡破裂（GVBD）**：标志卵母细胞进一步成熟；性成熟后在促性腺激素作用下恢复减数分裂，排出第一极体，进入 MⅡ 期并排卵。
- **成熟标准**：
  - 核成熟：GVBD、排出第一极体、停滞于第二次减数分裂中期。
  - 质成熟：达到一定体积，细胞质含充足蛋白质、细胞器、RNA、DNA 和能量。
- **关键点**：第一次减数分裂的阻滞、第一次减数分裂恢复、第二次减数分裂的阻滞。

### 不同动物的卵子发生

| 受精时卵子所处阶段 | 代表动物 |
| --- | --- |
| 初级卵母细胞 | 狗、狐狸 |
| 第一次减数分裂 | 昆虫 |
| 第二次减数分裂 | 多数哺乳动物、鱼类、两栖类、鸟类 |
| 减数分裂完成 | 海胆 |

- **昆虫（滋养型）**：卵巢 → 卵巢管 → 卵子；一个生殖干细胞 + 一个成胞囊细胞 → 有丝分裂形成 16 细胞胞囊 → 后端一个细胞成为卵母细胞，其余为滋养细胞 → 胞囊被卵泡细胞包围形成卵室，卵室相连。
- **鱼类、两栖类**：灯刷染色体；多黄卵，双线期卵黄发生；卵黄蛋白原由肝脏合成 → 血液循环 → 转运 → 胞饮；成熟周期长。
- **哺乳动物**：卵子发生与卵泡发育同步进行（见下）。

## 卵泡发育

**定义**：雌性生殖细胞与卵巢体细胞构成的功能复合体，以卵泡形式进行后期发育至排卵的过程。

- 无腔卵泡：原始卵泡、次级卵泡。
- 有腔卵泡：三级卵泡、成熟卵泡。

### 各阶段

| 阶段 | 结构 | 关键事件 |
| --- | --- | --- |
| 原始卵泡 | 初级卵母细胞 + 前颗粒细胞；位于皮质，数目固定 | PGC 来自中胚层尿囊，向卵巢迁移增殖分化；月经初潮前生长受抑制；卵母细胞不完全分裂形成合胞体，仅一个成为功能性卵母细胞，其余为滋养细胞；合胞体间可经胞间连桥交融；前颗粒细胞来自卵巢上皮、中肾、间充质细胞；细胞凋亡是卵母细胞死亡主要方式 |
| 初级卵泡 | 单层立方状颗粒细胞 + 初级卵母细胞 | 卵母细胞明显增长，分泌透明带蛋白形成 ZP（位于卵母细胞与放射冠之间，由颗粒细胞与卵母细胞共同分泌）；颗粒细胞表达 FSH 受体；颗粒细胞与卵母细胞经连接蛋白（Cx）形成间隙连接交换营养 |
| 次级卵泡 | 初级卵母细胞 + 多层立方颗粒细胞 | GDF9、BMP15、Cx43 参与多层化；出现膜层（内膜 + 外膜）：外膜为纤维结缔组织、合成雄激素（经基膜在颗粒细胞转化为雌激素），内膜具内分泌功能；膜层表达 LH 受体、颗粒细胞表达 FSH 受体 |
| 三级卵泡 | 卵泡腔形成 | 卵泡液成分复杂；kit 配基（颗粒细胞产生）与 Cx37（卵母细胞）为卵泡腔形成必需；卵丘形成（卵母细胞外与之进行代谢联系的颗粒细胞群）；COC（卵丘卵母细胞复合体）调控卵母细胞成熟；壁层颗粒细胞负责类固醇合成 |
| 格拉夫卵泡 | 属三级卵泡 | 卵泡拓展至卵巢皮质厚度 |
| 成熟卵泡 | 卵泡液体积最大 | 促性腺激素作用下排卵；卵母细胞与卵丘细胞排入输卵管；壁层颗粒细胞与膜细胞发育成黄体 |

原始卵泡的三种命运：保持休眠、死亡、始动募集（从休眠进入活跃，颗粒细胞由扁平变立方）。

**分群现象**：中肾来源的前颗粒细胞位于髓质，参与第一波原始卵泡形成，与早期子代繁育有关；卵巢上皮细胞位于皮质，产生终生卵子。

### 卵泡发生与募集

- 卵泡发生：原始卵泡募集 → 腔前卵泡发育 → 有腔卵泡选择与生长 → 卵泡闭锁。
- **募集**：卵泡从受抑制的原始卵泡进入生长卵泡（原始卵泡 → 初级卵泡）。
  - 启动募集：卵泡形成后持续生长，未募集卵泡休眠。
  - 周期募集：能对激素变化应答的有腔卵泡加快生长、生发泡破裂；作用激素为 FSH；依赖 HPG 轴，每个发情周期有序排出；未募集卵泡凋亡。
- **卵泡选择**：从三级卵泡中选择一个优势卵泡；发育周期包括募集期、选择器、优势期；其余卵泡闭锁。
- **闭锁**：激活卵母细胞与颗粒细胞凋亡；原因可为原始卵泡中两种细胞发育不同步；GnRH 促进闭锁，促性腺激素抑制闭锁。
- 优势卵泡抑制其他卵泡发育。

## 排卵

**排卵**：成熟卵泡破裂，卵母细胞及周围卵丘细胞排出的过程。

- **类型**：自发排卵（形成功能性黄体，黄体功能维持时间决定发情周期；部分动物需交配刺激黄体才有内分泌功能，未受孕可出现假妊娠）与诱导排卵（需交配或精液刺激）。
- **过程**：卵母细胞核与细胞质成熟 → 卵丘细胞聚合力松散 → 卵泡外壁变薄破裂。
- **特点**：卵泡增大、核成熟、卵丘松散、排卵柱头形成（卵泡内膜和基底膜从破口处形成的无血管水泡）；机理为 LH → 孕酮 → COX2 + 前列腺素 → 蛋白溶解酶 → 卵巢上皮细胞从基膜分离。
- **调控**：FSH（与 LH 协同，非必需）、LH（单独作用可使所有卵泡破裂；FSH+LH 使成熟卵泡破裂）、前列腺素、孕酮、雌激素、GnRH（促 LH 分泌）、组织型纤溶酶原激活因子 tPA；卵巢血流量增加、卵泡外膜水肿、卵丘细胞扩散等结构代谢变化。

> [!note] 激素来源与功能
> FSH、LH、前列腺素、孕酮的来源与作用见 [[02-生殖激素与内分泌调控]]。

## 黄体的形成与退化

- **形成**：排卵后颗粒细胞继续增大，表面有空泡、积累叶黄素；卵泡壁坍塌，LH 作用下卵泡壁细胞增大分化为内分泌细胞团（黄体）。
- **结构**：间质为支持细胞；实质为黄体细胞——粒黄体细胞（颗粒细胞来源，分泌孕激素、雌激素、松弛素）与膜黄体细胞（膜细胞来源，分泌雌激素）；LH 是重要的促黄体激素。
- **发育**：
  - 未受精（无着床）：月经黄体退化；功能性退化为孕酮下降，结构性退化为黄体组织破坏清除；黄体细胞退化形成白色，被成纤维细胞替代形成白体；意义是促进进入下一个生殖周期。未受精时黄体持续约 10 天。
  - 受精：妊娠黄体分泌孕酮维持妊娠，约 6 个月后退化为白体。
- **调控**：PGF2α（前列腺素）；颗粒细胞、膜层细胞（中肾迁入的间充质细胞来源，分泌类固醇）与髓质基质细胞等具有内分泌功能；次级卵泡时与基膜相连的基质细胞形成卵泡内膜层，其外的非类固醇合成型细胞带形成外膜。

## 月经周期

月经期 → 卵泡期（卵泡募集）→ 排卵期 → 黄体期。

## 卵子胞质物质与基因印迹

- **卵子胞质物质**：蛋白质；核糖体和 tRNA（早期胚胎利用卵子中预留的核糖体与 tRNA 合成蛋白质）；母源 mRNA（中期囊胚前受精卵使用母源性 mRNA，之后才合成自身 mRNA）；形态形成因子（指导细胞分化，卵裂中分配到不同细胞）；保护性化学物质（紫外线滤波酶、DNA 修复酶）。
- **基因印迹**：印记基因用于判断父源/母源，雌雄原核表达模式不同，某些组织中等位基因只有一个表达；涉及组蛋白修饰；机制为双启动子甲基化和绝缘子甲基化；性别分化后印迹在生殖系删除，子代印迹来自父代而非祖代。

> [!note] 分工说明
> PGC 中的印记去除与重新甲基化见 [[03-原始生殖细胞与性别决定]]；胚胎中的基因印记与剂量补偿见 [[07-早期胚胎发育与干细胞]]。

## 不孕类型

卵巢性不孕、输卵管性不孕、子宫性不孕。

> [!abstract] 考点速记
> 1. 卵子发生三阶段：增殖 → 生长 → 成熟；细胞质库丰富导致减数分裂前期长。
> 2. 两次阻滞（双线期 GV、MⅡ 期）与 GVBD；核成熟 vs 质成熟标准。
> 3. 卵泡阶段顺序与关键事件：原始（固定数目、合胞体）→ 初级（透明带、FSH 受体）→ 次级（膜层、LH 受体）→ 三级（卵泡腔、COC）→ 成熟卵泡。
> 4. 募集、选择、优势卵泡与闭锁的激素调控。
> 5. 排卵柱头机制、LH 峰；黄体类型与白体形成；月经周期四期。

2. 比较原始卵泡、初级卵泡、次级卵泡和三级卵泡的关键事件。

4. 未受精与受精后黄体的命运有何不同？

<details>
<summary>参考答案</summary>

1. 核成熟：GVBD、排出第一极体、停滞于 MⅡ 期；质成熟：体积达标，胞质含充足蛋白质、细胞器、RNA、DNA 与能量。
2. 原始卵泡：数目固定、合胞体、三种命运；初级：透明带出现、颗粒细胞 FSH 受体、间隙连接；次级：多层颗粒、膜层形成、LH 受体；三级：卵泡腔、卵丘与 COC、kit 配基/Cx37。
3. 启动募集是原始卵泡形成后持续进入生长轨道；周期募集依赖 FSH 与 HPG 轴，使有腔卵泡在周期内加速生长并排卵，未募集者凋亡。
4. 未受精形成月经黄体，孕酮下降、组织破坏形成白体，约 10 天；受精后形成妊娠黄体，分泌孕酮维持妊娠约 6 个月后退化。
