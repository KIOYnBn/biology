# 08 细胞信号转导

> 返回 [[00-总览]] ｜ 配套总结：[章节总结-细胞信号转导](attachments/章节总结-细胞信号转导.pdf)

## 1. 细胞通讯与信号转导

- **细胞通讯**：细胞产生的胞外信号与靶细胞受体结合，引起受体构象改变，建立胞内信号转导通路，调节靶细胞代谢、结构功能或基因表达。
- **信号转导**：胞外信号转化为胞内信号的过程。^518c30
- 细胞通讯过程：
  1. 信号细胞合成、释放信号分子。
  2. 信号分子运输。
  3. 信号分子与靶细胞受体结合。
  4. 受体激活下游信号转导。
  5. 细胞代谢、功能与基因表达改变。
  6. 信号解除。
- 细胞信号转导过程（质膜受体介导）：受体识别胞外信号 → 产生第二信使/活化信号蛋白 → 级联放大 → 细胞应答 → 脱敏反应。
- 信号传递形式：自分泌（作用于分泌细胞自身）、内分泌（经血液循环）、旁分泌（作用于邻近细胞）、化学突触（神经递质）、接触依赖信号转导。
- 细胞应答的意义：激活细胞内酶、改变细胞代谢；改变细胞骨架与形态运动；改变质膜离子通道通透性；引发 DNA 合成；影响基因表达。

## 2. 信号分子、第二信使与受体

### 2.1 信号分子（配体）

- 定义：细胞通讯的信息载体，与受体特异性结合引发生物学效应；具有亲和性、特异性与饱和性。
- 类型：
  - 脂溶性激素：甾类、甲状腺激素。
  - 水溶性激素：神经递质等。
  - 气体信号分子：NO 等。
  - 膜结合信号分子：细胞表面抗原。
- 识别规律：脂溶性信号结合**细胞内受体**；水溶性信号结合**细胞表面受体**。

### 2.2 第二信使

- **第二信使学说**：胞外化学信号不能进入细胞，作用于表面受体后产生胞内信号，引发生化反应，并随第二信使降解而终止。
- 实质：非蛋白小分子。
- 常见第二信使：

| 第二信使 | 主要靶点 |
|---|---|
| cAMP | 激活 PKA |
| cGMP | 激活 PKG |
| Ca²⁺ | 激活钙调蛋白（CaM） |
| DAG | 激活 PKC |
| IP₃ | 打开内质网 Ca²⁺ 通道 |

### 2.3 受体

- 大多为糖蛋白；定义为能与配体相互识别并引发生物学效应的分子。
- 分类：
  - 按位置：**细胞表面受体**、**细胞内受体**（位于细胞质基质或核基质）。
  - 按机制：离子通道偶联受体、G 蛋白偶联受体、酶联受体。

## 3. 细胞表面受体介导的信号通路

### 3.1 G 蛋白偶联受体（GPCR）

- 结构特征：7 次跨膜 α 螺旋；N 端识别信号分子；C 端（胞内侧）富含丝氨酸/苏氨酸，连接 G 蛋白。
- G 蛋白循环：
  1. 配体结合引发受体构象改变。
  2. 受体与 G 蛋白 α 亚基结合。
  3. α 亚基释放 GDP。
  4. α 亚基结合 GTP 并与 βγ 脱离。
  5. α 亚基与效应蛋白结合并激活之。
  6. GTP 水解，α 亚基脱离效应蛋白，回归三聚体。
- α 亚基具有 GTP 结合位点、GTP 酶活性和 ADP-核糖化位点。
- 主要效应器与通路：

| 效应器 | 第二信使/下游 | 要点 |
|---|---|---|
| 腺苷酸环化酶 AC | cAMP → PKA | Gs（刺激型）升高 cAMP；Gi（抑制型）降低 cAMP；PDE 降解 cAMP；PKA 抑制糖原合酶、激活磷酸化酶激酶 |
| 磷脂酶 C（PLC） | 水解 PIP₂ → IP₃ + DAG | IP₃ 打开内质网 Ca²⁺ 通道；DAG 激活 PKC；Ca²⁺ 与钙调蛋白结合激活 CaM 激酶 |
| 离子通道蛋白 | 电信号 | 化学信号转为电信号 |

- Ca²⁺ 的作用：与 PKC 结合介导其结合质膜；与钙调蛋白等结合；促进受精卵发育、激活肌肉细胞、促进分泌细胞与神经细胞分泌、参与渗透压调节。
- 毒素示例：霍乱毒素使 Gs 保持激活、cAMP 升高；百日咳毒素使 Gi 永久失活、cAMP 升高。

### 3.2 酶联受体

**受体酪氨酸激酶（RTK）**

- 通过二聚化与交叉（自）磷酸化激活。
- SH 结构域（Src homology region）：
  - SH1：激酶活性区；Src 位于胞质，属非受体型酪氨酸激酶。
  - SH2：选择性结合磷酸化酪氨酸残基。
  - SH3：选择性结合富含脯氨酸的序列。
- 下游通路：
  - 磷酸化 RTK 与含 SH2 的 GRB2 结合 → GRB2 调控 SOS（Ras 激活蛋白）→ Ras 发生 GDP/GTP 交换而激活 → **MAPK 通路**。
  - PI3K → PIP₃ → PKB（Akt）→ 抑制 BAD，影响细胞凋亡。
  - PLCγ → Ca²⁺ 升高。

**细胞因子受体（JAK-STAT 通路）**

- 细胞因子：调控细胞增殖、分化与成熟的分泌性活性因子；受体为与酪氨酸蛋白激酶偶联的表面受体。
- JAK：N 端结合受体，C 端为酪氨酸激酶结构域，属胞质酪氨酸激酶。
- STAT：信号转导子和转录激活子，含 SH2 结构域，被 JAK 激活后二聚化、暴露 NLS 并入核调控基因。

**其他通路**

- **Notch**：信号分子与受体均为膜整合蛋白；受体经两次切割后释放胞内段入核。
- **NF-κB**：核转录因子；通过泛素化降解抑制蛋白而激活。

### 3.3 离子通道偶联受体

- 配体结合后通道开放，化学信号直接转化为电信号。

### 3.4 细胞内受体

- 配体为脂溶性信号（甾类激素、甲状腺激素、NO 等），穿过质膜后与胞质或核内受体结合，直接调控基因转录。

## 4. 分子开关与信号复合物

### 4.1 分子开关

- **定义**：胞内蛋白通过激活与失活机制控制信号传递级联反应。
- 类型：
  1. **GTP 酶分子开关调控蛋白**（GTP 酶超家族）：三聚体 G 蛋白（大 G 蛋白）、单体 G 蛋白（小 G 蛋白，如 Ras）。
  2. **蛋白激酶 / 蛋白磷酸酶**：通过磷酸化与去磷酸化切换状态。
  3. **钙调蛋白**：与 Ca²⁺ 结合后改变构象并激活下游酶。

### 4.2 细胞内信号蛋白复合物的装配方式

1. 表面受体、胞内信号蛋白与支架蛋白预先结合成复合物。
2. 自磷酸化为信号蛋白提供锚点（SH2 识别），形成短暂信号转导复合物。
3. 肌醇磷脂分子募集含 PH 结构域的蛋白，形成信号复合物。

### 4.3 小 G 蛋白与蛋白激酶家族（引用块整合）

> 整合自「生物学知识引用块」：`蛋白家族/小g蛋白家族.md`、`蛋白家族/蛋白激酶家族.md`。

- **小 G 蛋白家族**：Ras 蛋白。
- **蛋白激酶家族**：PKA、PKC、PKG、JAK、CAMK、MAPKKK。

## 5. 信号系统的特性与终止

### 5.1 特性

- **特异性**、**放大效应**、**模块化**、**网络化与反馈调节**。
- **整合作用**：
  - 收敛：不同信号汇入同一通路。
  - 发散：同一信号激活多条通路。
  - 不同受体激活不同通路，或一条通路影响其他通路；通路间交互实现网络信息整合。

### 5.2 受体脱敏与信号终止

- 脱敏蛋白：参与反馈调节和受体脱敏、介导信号终止的蛋白质。
- 三条脱敏途径：
  1. **构象改变**（receptor inactivation by alteration）。
  2. **内在化**（receptor sequestration by internalization）——受体内吞进入细胞。
  3. **溶酶体降解**（receptor down-regulation by destroying in lysosomes）——受体下调。
- 第二信使的降解（如 PDE 降解 cAMP）同样使信号终止。

> 信号通路与细胞周期的交叉示例：促分裂原 → SOS → Ras → MAPK → G1/S 转换，见 [[09-细胞周期及其调控]]。
