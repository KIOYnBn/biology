# 02 生殖激素与内分泌调控

> [!abstract] 本章要点
> 激素的概念与分类；生殖激素的作用特点；下丘脑-垂体-性腺轴；GnRH、催产素、FSH、LH、促乳素、性腺激素、胎盘激素、前列腺素与性外激素的来源、作用、调控和应用。

## 激素总论

**激素**：动物机体产生，经体液循环或空气传播作用于靶器官或靶细胞，具有调节机体生理功能的微量信息传递物质（微量生物活性物质）。

### 作用途径

远距分泌、旁分泌、自分泌、神经分泌、外激素。

### 类型

| 划分依据 | 类型 |
| --- | --- |
| 产生部位 | 下丘脑激素释放激素（GnRH、催乳素释放激素）；垂体激素（促性腺激素、催乳素）；性腺激素（雌激素、孕激素、松弛素、睾酮）；胎盘激素（hCG、PMSG）；松果腺（褪黑素）；其他（前列腺素等） |
| 来源 | 天然激素、人工合成激素、内分泌激素（无管腺体产生）、外激素（管腺体产生） |
| 化学特性 | 含氮类（下丘脑、垂体、胎盘：FSH、LH）；类固醇类（性腺、肾上腺：雌激素、雄激素、孕激素）；脂肪酸类（子宫、前列腺、外分泌腺：前列腺素） |
| 生理作用 | 神经激素（神经多肽/氨基酸衍生物：催产素、乙酰胆碱、肾上腺素）；生殖激素（调节生殖机能，分主要与次要）；代谢激素（生长素、胰岛素、甲状腺素） |

### 含量单位与运输

- ng（纳克）= 10⁻⁹ g；pg（皮克）= 10⁻¹² g。
- **多肽类**：产生后储存，需要时释放入血。
- **类固醇类**：边合成边分泌入血，与载体蛋白结合，需要时释放。
- **脂肪酸类**：需要时合成，经局部血管作用于附近组织，也称局部激素。

### 生殖激素作用特点

生理活性强；消失快（**半衰期**：激素浓度或生物学活性在体内消失一半所需时间）；无种间特异性；可协同或拮抗；具有专一性；生物学效应与生理期、剂量有关；结构决定功能。

## 下丘脑-垂体-性腺轴（HPG 轴）

### 下丘脑

- 位置：间脑基底部、丘脑下部；前为视交叉及终板，后为乳头体及脑脚间窝，上为丘脑部，腹侧为蝶骨并与垂体柄相连。
- 合成部位：下丘脑促垂体区。

![[attachments/下丘脑激素.png|500]]

### 垂体

- 位置：下丘脑腹侧蝶骨凹部，分前叶、中叶、后叶。
- 前叶（腺垂体）：促甲状腺素、生长激素、促乳素、促肾上腺皮质激素、促黑色细胞素。
- 后叶（神经垂体）：催产素。
- 作用方式：下丘脑神经分泌细胞分泌释放激素 → 神经末梢释放 → 垂体上、下动脉 → 到达垂体 → 分泌垂体激素。

### GnRH 的调节

- 神经调节；激素调节：LH-RH → FSH/LH → GnRH（反馈）。

![[attachments/下丘脑-垂体-性腺轴.png|550]]

## 下丘脑激素

### 促性腺激素释放激素（GnRH / LH-RH）

- **来源**：下丘脑弓状核，贮存于正中隆起。
- **化学结构**：十肽；前 3 个氨基酸为功能部位，后 7 位为结合部位。
- **作用**：促进腺垂体合成与释放 LH、FSH；诱导发情、排卵；增强公畜性欲。
- **分泌调节**：
  - 神经调节。
  - 激素调节：紧张中枢控制 LH-RH 持续释放（负反馈）；周期中枢控制 LH-RH 周期性大量释放，雌激素正反馈、孕酮负反馈；雄激素抑制周期中枢，故雄性不表现周期性发情。
- **应用**：诱发排卵、超数排卵；治疗卵巢囊肿引起的排卵障碍；人工授精提高受胎率。

![[attachments/LH-RH分泌调节.png|500]]

### 催产素

- **来源**：下丘脑室旁核（贮存于垂体后叶）、卵巢、胎盘；化学本质为多肽。
- **作用**：促进分娩、泌乳；促进前列腺素分泌、溶解黄体、促进发情（小剂量促进黄体形成）；升高血压；促进精卵运输；促进雌性性行为。
- **分泌调节**：乳头刺激 → 下丘脑视上核与室旁核 → 垂体后叶 → 催产素 → 子宫平滑肌收缩。

## 垂体促性腺激素

垂体前叶有嫌色性细胞（无染色颗粒）与嗜色性细胞（有染色颗粒，包括嗜酸性、嗜碱性）；二者可相互转变：嗜色性细胞分泌激素 → 嫌色细胞 → 产生颗粒 → 嗜色性细胞。中间部分分泌 MSH（促黑素细胞激素）。

![[attachments/垂体激素.png|500]]

### FSH（促卵泡素）

- 来源：嗜碱性细胞；性质：糖蛋白。
- 功能：促进卵泡发育（卵泡内膜细胞分化、颗粒细胞增生、卵泡液分泌）；促进卵巢生长；与 LH 协同促进雌激素分泌；促进睾酮分泌；促进精子生成与精细管形成。
- 分泌调控：GnRH 促进；卵泡抑制素抑制；雌激素低剂量促进、高剂量抑制。
- 应用：提早性成熟；超数排卵、诱导发情；治疗卵巢囊肿、精液品质不良；诱导泌乳期动物发情。

### LH（促黄体生成素）

- 来源：嗜碱性细胞；性质：糖蛋白。
- 作用：
  - 雌性：控制发情与排卵；促进卵泡发育、排卵；促进黄体形成、维持妊娠；刺激雄激素产生。
  - 雄性：刺激睾酮分泌；促进副性腺发育与精子成熟。
- 分泌调节：与 FSH 相同。
- 应用：雌性诱导排卵、治疗卵泡囊肿、预防流产；雄性治疗不育。

### 促乳素

- 来源：嗜酸性细胞；性质：蛋白。
- 作用：促进乳腺发育与乳汁生成；促进黄体分泌孕酮维持妊娠；与雌激素协同促进生殖道黏液分泌；调节雌性性行为；促进雄性性器官发育与精子生成；抑制性腺发育。

> [!note] 在配子发生中的具体作用
> FSH/LH/睾酮对精子发生的调控见 [[04-精子发生与睾丸结构]]；FSH/LH 对卵泡发育、排卵与黄体的调控见 [[05-卵子发生与卵泡发育]]。

## 性腺激素

概念：睾丸和卵巢分泌的激素，主要指睾酮（T）、雌激素（E）、孕酮（P4），均为类固醇激素，有时包括松弛素（蛋白）。

### 雄激素（主要为睾酮 T）

- 来源：睾丸间质细胞，肾上腺皮质也可分泌。
- 作用：维持雄性性行为；刺激并维持雄性第二性征；参与精子发生；促进性器官发育；受 LH、FSH 调节；促进骨骼与肌肉发育。
- 应用：治疗雄性机能衰退、家畜役力衰退。

### 雌激素

- 来源：卵巢颗粒细胞，睾丸、胎盘产生少量；主要为雌二醇。
- 作用：微量促进性行为；刺激并维持雌性生殖道发育；维持第二性征；促进乳腺发育；调节 LH、FSH；小剂量促进雄性性行为。
- 应用：人工流产、泌乳、诱导发情排卵；人工产品如苯甲酸雌二醇。

### 孕激素（孕酮 P4）

- 来源：卵巢黄体细胞；主要为 P4。
- 作用：胚胎着床；维持妊娠；促进生殖道发育；小剂量促进发情；促进乳腺发育。
- 应用：诱导发情、预防流产；根据 P4 含量判断是否妊娠。

### 松弛素

- 来源：妊娠黄体。
- 作用：防止流产；促进分娩；促进乳腺发育。
- 应用：子宫镇痛、预防流产和早产、诱导分娩。

## 胎盘激素

### 人绒毛膜促性腺激素（hCG）

- 来源：绒毛膜合胞体滋养层细胞；糖蛋白激素。
- 功能：具有 LH、FSH 双重活性；维持妊娠黄体；免疫抑制；促进睾酮分泌；治疗卵巢囊肿。
- 应用：诱发排卵、定时配种、治疗卵泡囊肿、促进雄性生精。

### 孕马血清促性腺激素（PMSG）

- 来源：孕马子宫内膜的蜕膜细胞；糖蛋白。
- 功能：兼具 FSH、LH 活性；促进排卵与卵泡发育；治疗卵泡发育迟缓；维持黄体；提高雄性性机能。

## 前列腺素

脂肪酸类、不饱和脂肪酸。

- 雌性：促进排卵；溶解黄体（子宫分泌 → 子宫静脉 → 卵巢动脉 → 作用于黄体）；促进分娩；促进输卵管平滑肌收缩（配子运输）。
- 雄性：促进 FSH、LH 释放；促进性成熟与性欲；提高精子质量。

## 性外激素

动物释放到体外，刺激异性交配、调节同种动物周期性活动的激素，多为类固醇或脂肪酸类。雄性由皮脂腺、副性腺、唾液腺分泌外激素引诱异性；雌性外激素来自阴道分泌物；共同作用是刺激求偶与交配。

## 生殖激素测定

生物学测定（定量）、放射免疫测定（放射性元素标记，定量）、受体测定法。

## 生殖激素与生殖机能的关系

1. 雄性激素分泌不足 → 男性生殖器官女性化。
2. 妊娠期服用雄性激素或孕激素 → 女性婴儿生殖器官男性化；服用雌激素 → 男性婴儿生殖器官女性化。
3. 妊娠期孕激素分泌不足或雌激素过多 → 流产。
4. 服用孕激素可抑制排卵。

> [!abstract] 考点速记
> - 生殖激素的概念、类型、作用、调控通路是本章第一考点。
> - 下丘脑（GnRH）→ 垂体（FSH/LH）→ 性腺（T/E/P4）三级调控与正、负反馈。
> - 含氮类（FSH、LH）与类固醇类（T、E、P4）的产生部位与运输方式不同。
> - hCG 与 PMSG 均兼具 FSH/LH 活性，但来源不同。
> - 前列腺素由子宫分泌，经子宫静脉 → 卵巢动脉逆向转运溶解黄体。

<summary>参考答案</summary>

1. 下丘脑 GnRH → 腺垂体 FSH/LH → 性腺 T/E/P4；性激素与抑制素负反馈下丘脑与垂体；雌激素在排卵前对下丘脑/垂体正反馈形成 LH 峰。
2. 二者均由嗜碱性细胞分泌、均为糖蛋白；FSH 偏重卵泡发育与精子生成，LH 偏重排卵、黄体形成与睾酮分泌；FSH 用于超数排卵等，LH 用于诱导排卵、治疗雄性不育等。
3. 雄激素抑制周期中枢，因此雄性不表现周期性发情。
4. hCG 来自绒毛膜合胞体滋养层，PMSG 来自孕马子宫内膜蜕膜细胞；两者均为糖蛋白且兼具 FSH/LH 活性，都能促卵泡发育、排卵与维持黄体。
