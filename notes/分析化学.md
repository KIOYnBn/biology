# 分析化学
## 一、分析化学概论

### 1.1 定义与分析方法分类

**分析化学**：研究物质的组成、结构和含量的学科。

| 分类依据 | 类型 |
| --- | --- |
| 要求不同 | 常规分析、裁判分析 |
| 分析对象 | 无机分析、有机分析 |
| 分析目的 | 定性分析、定量分析、结构分析 |
| 分析方法 | **化学分析**：根据化学反应及其化学计量关系测定物质组成及含量，包括重量分析、滴定分析（酸碱、氧化还原、络合、沉淀滴定）；**仪器分析**：根据物质的物理性质和物理化学性质，包括光学、电化学、色谱法等 |

按试剂用量分类：常量、半微量、微量、超微量。
按组分含量分类：常量、微量、痕量。

| 划分 | 含量范围 | 试样用量（固体 / 液体） |
| --- | --- | --- |
| 常量 | > 1% | > 100 g / > 10 mL |
| 微量 | 0.01%～1% | 10～100 g / 1～10 mL |
| 痕量 | < 0.01% | < 10 g / < 1 mL |

![分析化学概论](attachments/分析化学概论.png)

### 1.2 定量分析过程

**步骤**：取样 → 处理 → 消除干扰 → 测定 → 计算 → 误差评价。

| 步骤 | 要点 |
| --- | --- |
| 取样 | 均匀、有代表性、符合实际、妥善保存 |
| 处理 | 溶解、熔融、消化、灰化 |
| 消除干扰 | 掩蔽、分离 |
| 测定 | 常量组分用化学法；微量组分用仪器分析法 |
| 计算 | 有效数字与计算规则 |
| 误差评价 | 准确度与精密度检验 |

![定量分析过程](attachments/定量分析过程.jpg)

### 1.3 含量与浓度表示

**固体试剂**：质量分数（ppm / ppb / ppt）。
**液体试剂**：物质的量浓度、质量摩尔浓度、质量分数、体积分数、摩尔分数、质量浓度。
**气体试剂**：体积分数。

- **质量摩尔浓度**：溶质物质的量除以溶剂质量，单位 mol/kg。
- **摩尔分数**：混合物中某一组分的摩尔数与所有组分总摩尔数之比。

**常用单位简写**

![单位简写](attachments/单位简写.jpg)

### 1.4 试剂与标准溶液

- **基准物质**：纯度高、组成与化学式相符、可定量反应、稳定、无副反应。
- **试剂规格**：生化试剂、优级纯 GR（绿色）、分析纯 AR（红色）、化学纯 CP（蓝色）。
- 浓盐酸浓度：**12 mol/L**。
- 半微量、微量组分测定的误差要求见 [2.1 节](#21-准确度与精密度)。

## 二、误差与数据处理

### 2.1 准确度与精密度

| 概念 | 说明 |
| --- | --- |
| 准确度 | 测量值与真实值的接近程度，用绝对误差 / 相对误差表示 |
| 精密度 | 多次平行测定结果相互接近的程度，用偏差表示 |
| 绝对误差 | 测定值 − 真实值 |
| 相对误差 | 绝对误差 / 真实值 |
| 千分率 | ‰ |
| 偏差 | 绝对偏差、相对平均偏差、平均偏差、标准偏差 |
| 自由度 | f = n − 1 |
| 平均值的标准偏差 | s / √n |

- 原笔记要点：常量组分的分析误差要小于 5%，微量组分的分析误差小于 0.2%。
  - 【待核对】常规教材通常要求常量组分相对误差 < 0.2%、微量组分 < 5%，此处数值疑为记反，建议复核。

![总体标准差和样本标准差](attachments/总体标准差和样本标准差.png)

### 2.2 误差类型与检验

- **系统误差**：可测、可校正，来源包括方法、仪器、试剂、操作。
- **偶然误差**：符合正态分布规律，不可校正但可统计评估。
- **总误差 TE（Total Error）**：测量结果与真实值之间的差异，包括系统误差与随机误差，是评估测量精度的重要指标之一。
- **误差检验**
  - 显著性检验：t 检验法，基于平均值的置信区间。
  - 异常值检验：4d 法（原笔记写作 1.4d 法）、Q 检验法。
  - 相关概念：置信度、显著性水准、极差、总体平均值。

### 2.3 有效数字

- 加减法规则：以小数点后位数最少的数为准。
- 乘除法规则：以有效数字位数最少的数为准。
- **对数的有效数字位数要与其真数的有效位数一致**（pH 的计算同样遵循）。

## 三、滴定分析法

### 3.1 总论

- **SP**（stoichiometric point）：化学计量点。
- **EP**（end point）：滴定终点。
- 终点与计量点之间的差异构成滴定误差。

![滴定分析法](attachments/滴定分析法.png)

### 3.2 酸碱滴定法

**酸碱指示剂**：以酸碱反应为基础，又称中和法。

| 指示剂 | 变色范围与颜色 |
| --- | --- |
| 甲基橙 MO | pH 3.4 红 → 4.4 黄 |
| 甲基红 MR | pH 4.4 红 → 6.2 黄 |
| 溴甲酚绿 + 甲基红 | 混合指示剂 |
| 酚酞 PP | pH 8.0 无色 → 9.6 粉红 |
| 百里酚酞 | 碱性范围变色 |

- 指示剂选择标准；影响指示剂变色范围的因素。
- **pH 计算**：强酸强碱；一元弱酸弱碱。
- **一元弱酸碱滴定至最后一滴时**，用缓冲溶液的近似式计算 pH。
- **标准溶液配制**：标准酸、标准碱、浓溶液稀释。
- **混合碱分析**；应用：氨的测定（甲醛法）。

### 3.3 络合滴定法

- **络合剂**：有机络合剂（乙二胺 / EDTA）、无机络合剂。
- **金属指示剂**

| 指示剂 | 适用范围 | 颜色变化 |
| --- | --- | --- |
| 铬黑 T（EBT） | pH 7～10 | 结合态红 → 游离态蓝 |
| 二甲酚橙（XO） | pH < 6 | 结合态红 → 游离态黄 |

- 变色错误原因：指示剂封闭、僵化、氧化变质。
- **滴定计算**：化学计量点公式、滴定范围公式、变色点公式。
- **酸度控制**：缓冲剂选择、最低 pH、最高 pH。
- **分步络合**：lgΔlK ≥ 6 可直接滴定；< 6 时用掩蔽剂滴定（沉淀掩蔽、氧化还原掩蔽、配位掩蔽）。

### 3.4 氧化还原滴定法

**指示剂**

- 氧化还原指示剂：邻二氮菲、邻苯氨基苯甲酸、二苯胺磺酸钠。
- 自身指示剂：高锰酸钾。
- 特殊指示剂：淀粉。

**基本公式**：能斯特公式；滴定终点电极电位计算。

**可逆电对**：在氧化还原反应中，任一瞬间能够迅速建立平衡的电对。其实际电势与 Nernst 公式计算值基本相符，表现出电对称性；半反应中氧化态与还原态物质系数相同。可逆电对常用于描述金属间的氧化还原反应。

| 方法 | 要点 |
| --- | --- |
| 高锰酸钾法 | 配制与保存（煮沸、粗 KMnO₄ 溶于水、微沸充分氧化还原杂质）；基准物草酸钠标定；自身指示剂 |
| 重铬酸钾法 | 优点：稳定；缺点：有毒，需做空白实验；指示剂二苯胺磺酸钠；用于测铁 |
| 碘量法 | 直接碘量法（碘溶液配制、基准物三氧化二砷标定）；间接碘量法；淀粉指示剂；测葡萄糖；卡尔·费歇尔法测水（费歇尔试剂：吡啶、碘、二氧化硫、甲醇） |

- 碘量法测铜。
- 重铬酸钾与碘离子反应（过量重铬酸钾，避光放置）：

$$\mathrm{Cr_2O_7^{2-} + 14H^+ \xrightarrow[\text{放置}]{\text{避光}} 2Cr^{3+} + 3I_2 + 7H_2O}$$

- 【待核对】原笔记式中未标出 Cr₂O₇ 的 2− 电荷，此处补全以配平。

### 3.5 沉淀滴定法

| 方法 | 指示剂 | 要点 |
| --- | --- | --- |
| 莫尔法 Mohr | 铬酸钾 | 测 Cl⁻、Br⁻；pH 6.5～10.5；优点简单准确，缺点干扰大 |
| 佛尔哈德法 Volhard | 铁铵矾 FeNH₄(SO₄)₂ | 滴定剂硫氰酸铵；提高准确度：加入硝基苯包裹 AgCl、增大 Fe³⁺ 浓度 |
| 法扬司法 Fajans | 吸附指示剂（荧光黄、曙红） | 吸附指示剂法 |

## 四、重量分析法

**特点**：准确但繁琐耗时。
**分类**：电解质法、沉淀法、挥发法。

**流程**：待测物质 → 沉淀获取 → 称量形式 → 结果计算。

**沉淀的形成**

- 异相成核 → 晶核 → 沉淀颗粒 → 晶形沉淀 / 无定形沉淀。
- 相对过饱和度、过饱和度、计算公式、冯·韦曼经验公式。

**沉淀形**

| 类型 | 粒径 |
| --- | --- |
| 晶形沉淀 | > 1 μm |
| 凝乳状沉淀 | 0.02～1 μm |
| 胶体 | < 0.02 μm |

**影响沉淀溶解度的因素**

- 增大溶解度：酸效应、盐效应、络合效应、升高温度。
- 减小溶解度：同离子效应、利用相似相溶原理选择溶剂、加入电解质使胶体沉淀。

**后处理**

- 陈化 → 过滤（玻璃砂漏斗；定性滤纸：红色慢速—细晶形、蓝色中速—粗晶形、白色快速—无定形）→ 洗涤（溶解度大的用稀沉淀剂再水洗；易形成胶体的用稀易挥发电解质洗）→ 烘干（低温或微波快速干燥；瓷坩埚高温时少量多次）→ 结果计算（重量因数 F，四位有效数字）。

**提高沉淀纯度的方法**：再沉淀、改变杂质存在形式、选择合适的沉淀剂、改善沉淀条件、选择适当的分析步骤。

**共沉淀规则**：构晶离子优先；溶解度小的优先；价态高、浓度高的优先；表面积大则吸附杂质多；升高温度可去除杂质。

## 五、分光光度分析法

**光的二象性**：波动性、微粒性；各有代表性质及计算公式，注意单位。
**单色光与混合光**；互补光与最大吸收波长；互补光表。

**光吸收基本定律**

- 朗伯-比尔定律 A = εbc。
- 适用条件：吸光质点稳定不变、入射光为单色光、低浓度溶液。
- 相关量：透射比、摩尔吸光系数、吸光系数、桑德尔灵敏度。
- **光度值即吸光度**。
- 偏差来源：非单色光、介质不均匀；解决方法：控制酸度、掩蔽、分离、对照实验。

**显色反应**

- 显色剂：无机（过氧化氢、硫氰酸根）；有机（助色团、生色团、磺基水杨酸、邻二氮菲）。
- 选择原则：灵敏度高、吸收最大且干扰最小、测定波长选择。
- 影响因素：溶液酸度、显色剂用量、反应时间及温度；显色反应的干扰。

**仪器与类型**

| 部件 | 要点 |
| --- | --- |
| 光源 | 钨灯 / 碘钨灯（可见光区）；氢灯 / 氘灯（紫外区） |
| 单色器 | 棱镜（不同波长折射率不同）；光栅（衍射与干涉，平面透射光栅、透镜、光屏） |
| 吸收池 | 玻璃池（可见光区）；石英池（紫外区） |
| 检测器与数据分析装置 | — |

- 类型：单光束、双光束、双波长。
- 特点：灵敏度高、精确度高、操作方便、应用广泛。
- 其他方法：目视比色法（方便灵敏、准确度差）、光电比色法。
- 紫外区与可见光区的波长区间数值；仪器分析法与化学分析法的区别（精密度、灵敏度）。
