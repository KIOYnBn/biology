# 09 核酸的结构与功能

核酸是贮存和传递遗传信息的大分子。本篇先介绍核酸的种类、化学组成，再分别梳理 DNA 与 RNA 的各级结构及功能。

## 一、核酸的种类及分布

### 1. 脱氧核糖核酸（DNA）

- 原核生物：DNA 分布在核区。
- 真核生物：DNA 分布在核内，组成染色体。
- 细胞器：线粒体、叶绿体中也有 DNA。

### 2. 核糖核酸（RNA）

| 类别 | 类型 | 说明 |
| --- | --- | --- |
| 参与蛋白质合成 | tRNA | 转移 RNA |
| 参与蛋白质合成 | rRNA | 核糖体 RNA：原核小亚基 16S，大亚基 5S、23S；真核小亚基 18S，大亚基 5S、5.8S、26S |
| 参与蛋白质合成 | mRNA | 信使 RNA |
| 调节 RNA | snRNA | 核内小 RNA |
| 调节 RNA | snoRNA | 核仁小 RNA |
| 调节 RNA | scRNA | 胞质小 RNA |

## 二、核酸的化学组成

- 核酸（多聚核苷酸）的基本单位是**核苷酸**，分为核糖核苷酸与脱氧核糖核苷酸，二者所含戊糖分别为 D-核糖和 D-2-脱氧核糖。
- **核苷酸 = 核苷 + 磷酸**；**核苷 = 戊糖 + 碱基**。

### 1. 碱基

- **嘧啶碱**：胞嘧啶（C）、尿嘧啶（U）、胸腺嘧啶（T）。

![[attachments/嘧啶.jpg|500]]

- **嘌呤碱**：腺嘌呤（A）、鸟嘌呤（G）。

![[attachments/嘌呤.jpg|500]]

### 2. 核苷

- 戊糖与碱基通过 **N-糖苷键（均为 β-糖苷键）**连接：糖的 C1 与嘧啶碱 N1 或嘌呤碱 N9 相连。
- 戊糖为**呋喃型**；碱基与戊糖平面相互**垂直**。
- 命名时戊糖碳原子加撇号（′）；主要修饰方式为甲基化。

### 3. 核苷酸

- 核苷的戊糖羟基被磷酸酯化形成核苷酸；生物中游离的通常是 **5′-核苷酸**。
- **核苷酸衍生物**：
  1. 能量载体：多磷酸核苷酸（NTP），酸酐键用「~」表示。
  2. 辅酶的组成部分。
  3. 化学信号：cAMP（腺苷 3′,5′-环磷酸）、cGMP（鸟苷 3′,5′-环磷酸）。
- **核苷酸聚合物**：
  - 寡核苷酸：几个或几十个核苷酸连接而成。
  - 多聚核苷酸：上百个核苷酸连接而成。
  - 核酸：更大的聚合物；可形成 3′,5′-磷酸二酯键，可被酸、碱、酶水解（酯键）。
  - 核酸酶：牛脾磷酸二酯酶（产生 5′-羟基）、蛇毒磷酸二酯酶（产生 3′-羟基）。

## 三、DNA 的结构与功能

### 1. 一级结构

核苷酸序列。

### 2. 二级结构：双螺旋

- 测定方法：X 射线晶体衍射；晶体获取方式是用针从浓 DNA 溶液中抽出纤维。
- 稳定作用力：**氢键** + **碱基堆积力**（一种范德华力，源于 π 电子相互作用）。
- 碱基对呈**螺旋桨状结构**。

![[attachments/DNA碱基对螺旋桨结构.jpg|350]]

- **内式/外式构象**：糖环为呋喃构象，突出的原子折向 $C_5$ 为内式，反之为外式。
- **顺式/反式构象**：嘌呤/嘧啶的酮基指向远离糖的方向为反式，反之为顺式；天然 DNA 中主要是反式。

| 结构特征 | B-DNA | A-DNA | Z-DNA |
| --- | --- | --- | --- |
| 螺旋旋向 | 右手螺旋 | 右手螺旋 | 左手螺旋 |
| 外形 | 粗细均匀、表面平滑 | 短粗，大沟深窄、小沟宽浅 | 细长，骨架呈之字形 |
| 每圈碱基数（bp） | 10.5 | 11 | 12（6 个二聚体） |
| 螺距 | 约 3.4 nm | 约 2.8 nm | 约 4.5 nm |
| 螺旋直径 | 约 2.0 nm | 约 2.3 nm | 约 1.8 nm |
| 碱基对倾角 | 基本垂直轴（约 −1.2°） | 偏离垂直轴约 19° | 约 −9° |
| 碱基对位置 | 螺旋中心轴 | 偏离中心轴，移向大沟侧 | 偏离中心 |
| 大沟 | 宽而深，利于蛋白质识别 | 窄而深 | 平坦、几乎不明显 |
| 小沟 | 窄而浅 | 宽而浅 | 窄而深 |
| 主要存在环境 | 生理条件（高湿度、低盐） | 低湿度、DNA-RNA 杂交链、RNA 双链 | 高盐、嘌呤–嘧啶交替序列（如 CGCGCG） |
| 生物学意义 | 最常见形式，转录与复制模板 | RNA 双链与杂交链形式；部分耐旱生物中保护 DNA | 参与基因转录调控（可能与负超螺旋有关）；与某些遗传病相关 |

### 4. 三级结构：超螺旋

$L_k = T_w + W_r$

- $L_k$：连环数；$T_w$：扭转数；$W_r$：缠绕数。

### 5. 功能

1. 染色体的主要成分，贮存遗传信息。
2. **C 值悖论**：生物的进化复杂度与其 DNA 总量并不成正比；原因是重复序列和染色体多倍性。

## 四、RNA 的结构与功能

### 1. 一级结构

- 原核生物 mRNA 没有修饰碱基；真核生物 mRNA 有少量甲基化碱基。
- 5′ 帽可抗 5′ 外切核酸酶降解。

### 2. 高级结构

- RNA 在溶液中通过**碱基堆积**形成单链右手螺旋，主要是嘌呤–嘌呤的 π 电子堆积力，因此嘌呤间的嘧啶可被排除在螺旋外。
- **假结**：RNA 不连续序列之间的碱基配对。

### 3. tRNA 的高级结构

- 二级结构：**三叶草型**，包括氨基酸臂、二氢尿嘧啶环、反密码子环、可变环、胸苷–假尿苷–胞苷环；氨基酸臂的 3′-CCA-OH 可共价连接氨基酸。
- 三级结构：**倒 L 型**。
- 功能：
  1. 参与蛋白质合成。
  2. 谷氨酰-tRNA 参与叶绿素生物合成。
  3. 某些氨酰-tRNA 参与氨酰磷脂酰甘油和细菌细胞壁糖肽的合成。

### 4. rRNA 的高级结构

- 功能：参与核糖体组成。
  - 小亚基 16S rRNA：负责识别 mRNA 和 tRNA 的解码中心。
  - 大亚基 23S rRNA：催化肽键合成（肽基转移酶中心）。

### 5. RNA 的功能

1. **遗传信息表达**：
   - 一般性加工：不改变编码序列，包括切割、修剪、添加、修饰、异构化。
   - 选择性加工：剪接、编辑、再编码；剪接有四种方式——Ⅰ型自我剪接、Ⅱ型自我剪接、剪接体剪接、核 tRNA 的酶促剪接。
2. 参与蛋白质合成。
3. 催化功能：小型核酶家族可在特定位点催化核酸降解。
4. 基因表达调控：
   - 顺式作用：mRNA 具有调控自身翻译活性的结构。
   - 反式作用：调节 RNA 与被调节 RNA 不是同一分子。
5. 染色体结构组装：染色体含少量 RNA，RNA 与组蛋白协同组装 DNA。
