# 01 · 绪论：发育生物学的基本问题

> [!abstract] 本章速览

## 1.2 发育的六个基本过程

### 1.2.1 细胞分裂

- **定义**：一个细胞分成两个子细胞（1 → 2）。
- **类型**：核分裂、质分裂。
- **分裂方式**

| 方式 | 要点 |
| --- | --- |
| 无丝分裂 | 无纺锤丝与染色体变化 |
| 有丝分裂 | 染色体均等分配，卵裂的主要方式 |
| 减数分裂 | 配子发生；前期Ⅰ分五个时期（见下） |

**减数分裂前期Ⅰ（高频考点）**

| 时期 | 事件 |
| --- | --- |
| 细线期 | 染色质凝集 |
| 偶线期 | 同源染色体配对 → 联会 → 联会复合体 |
| 粗线期 | 染色体浓缩变短，基因重组 |
| 双线期 | 同源染色体分离、去凝集，灯刷染色体活跃转录 |
| 终变期 | 染色质凝集，转录停滞，核仁消失 |

### 1.2.2 细胞分化

- **定义**：同一来源的细胞，在形态结构与功能特征上产生差异。
- **本质**：**基因组选择性表达**（遗传物质不变，表达谱改变）。
- **细胞谱系**：细胞从最初的卵裂球开始，经过分裂和分化，最终形成特定组织和器官细胞的发育历程。
- **过程**：特化（定型不稳定） → 命运决定（稳定）。

### 1.2.3 图式形成（pattern formation）

- **定义**：细胞活动的空间和时间样式建立，形成结构有序的发育。
- **内容**：主轴与方向（前后、背腹、远近端）、胚层分化（外 / 中 / 内）。

### 1.2.4 形态发生（morphogenesis）

- **定义**：细胞或细胞群在形态、空间排列上变化，组织形成特定功能的结构。
- **信号传递**
  - 基本元件：受体、配体。
  - 方式：近分泌、旁分泌等。
  - 实例（钙黏着蛋白）：钙黏着蛋白 — 联蛋白 — 肌动蛋白相连。
  - 快反应：通常为酶促反应；慢反应：通常是调控基因的反应。
- **EMT（上皮—间充质转换）**

| 比较 | 上皮细胞 | 间充质细胞 |
| --- | --- | --- |
| 排列 | 紧密，片状 / 管状 | 分散，可独立迁移 |
| 机制 | 钙黏着蛋白表达改变 | 同上 |

  典型例子：**中胚层形成**、**神经嵴细胞迁移**。

### 1.2.5 生长

- **定义**：细胞数量增加、细胞体积增大、细胞外物质积累（如骨）。

> [!note] 概念辨析
> **分化**改变"是什么"，**图式形成**决定"在哪里"，**形态发生**决定"长成什么样"，**生长**决定"有多大"。

## 1.3 发育理论的演变

### 1.3.1 先成论 vs 后成论

| 学说 | 代表人物 | 核心观点 |
| --- | --- | --- |
| **先成论** Preformation | 精源学说 / 卵源学说 | 胎儿形状无太大变化，成体的一切已预先存在 |
| **后成论** Epigenesis | William Harvey | 发育是简单到复杂的过程，组织和器官逐渐形成 |

### 1.3.2 关键人物与发现

| 人物 | 贡献 |
| --- | --- |
| Volcher Coiter | 卵子从卵巢形成 |
| William Harvey | 变态在昆虫中普遍存在 |
| 冯贝尔（von Baer） | 冯贝尔法则（见下） |
| 列文虎克 | 显微镜 |
| 施莱登、施旺 | 细胞学说 |
| 魏斯曼 | 生殖细胞论：遗传信息**仅通过生殖细胞**传递 |
| 赫特威格 | 细胞核含有遗传的物质基础 |

### 1.3.3 冯贝尔法则（von Baer's laws）

> 不同纲脊椎动物的早期胚胎极其相似；发育中**门的性状最先出现**，随后依次出现目、科、属、种的性状。

1. 每一较大动物类群的共同性状比专门性状形成得早；
2. 先出现最共同的性状，再出现较专门的性状，最后才出现最专门的性状；
3. 不同纲动物的胚胎最初相似，在以后发育中才逐步分歧。

*（在器官发生部分会再次用到此规律，见 [[04-器官发生总论与外胚层]]）*

### 1.3.4 镶嵌型发育 vs 调整型发育

| 类型 | 提出者 / 证据 | 核心观点 |
| --- | --- | --- |
| **镶嵌型发育** | 魏斯曼；"定子"（特殊因子）；蛙胚针刺实验 | 卵裂时细胞质定域明显，细胞命运决定早，每个卵裂球命运固定 |
| **调整型发育** | — | 早期卵裂球相同、均具全能性，命运决定晚；附近组织对细胞分化起作用 |

> [!important] 实例对照
> 线虫、海鞘偏镶嵌型；海胆四细胞前为调整型、后期具镶嵌型特点；哺乳动物 16 细胞前具全能性。详见 [[02-卵裂与囊胚形成]]。

### 1.3.5 胚胎诱导（embryonic induction）

- **定义**：来自一群细胞的信号，能影响相接触的另一部分细胞的发育命运。
- **组成**

| 要素 | 说明 |
| --- | --- |
| 诱导物 | 通常为一个组织，产生改变另一组织细胞行为的信号（多为旁分泌因子 / 分泌性蛋白） |
| 应答物 | 受诱导的细胞或组织 |
| 感受态（反应力） | 应答能力，具有**时效性**和**遗传性** |
| 形态发生素 | 旁分泌因子形成浓度梯度，通过**阈值**控制细胞命运特化 |

> [!tip] 联系后文
> 两栖类的"组织者"、果蝇的 Bicoid 梯度都是胚胎诱导的具体案例，见 [[03-原肠作用与胚轴建立]]。

## 1.4 模式生物

- **定义**：选定用于研究、以揭示普遍规律的生物。
- **特点**：① 代表性；② 易于实验。

| 模式生物 | 优势 |
| --- | --- |
| **线虫** | 易养殖、易冷冻保存；繁殖快；细胞透明且数量少；基因组测序完成 |
| **果蝇** | 易繁殖；产卵多、性成熟短；易遗传操作；染色体组简单；卵大易观察；有变态；基因组测序完成 |

- 脊椎动物具有**相似的发育阶段**：脊索 → 体节 → 躯干各部分。

## 1.5 胚胎观察与细胞标记技术

| 方法 | 原理 / 操作 | 特点 |
| --- | --- | --- |
| 直接观察 | 胚胎细胞本身具有颜色 | 最简单 |
| 活体染料标记 | Vogt 发明；活体染料与琼脂混合，用染色琼脂使细胞染色 | 经典细胞谱系追踪 |
| 荧光染料标记 | 荧光标记细胞 | 能观察后代细胞；**缺点**：不能长时间激发 |
| 遗传标记 | 不同遗传背景的细胞组成胚胎（如嵌合体胚胎） | **永久性**标记 |
| 转基因嵌合体 | 移植遗传修饰的细胞追踪细胞谱系；修饰细胞使其表达荧光蛋白 | 可长期追踪 + 活体观察 |
