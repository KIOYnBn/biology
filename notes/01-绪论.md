# 01 绪论

> 返回 [[00-总览]]

## 1. 细胞学说

- 有机体由细胞组成。
- 细胞是生物体结构与功能的基本单位。
- 所有细胞都来自先前存在的细胞（细胞通过分裂增殖）。

### 论述：为什么说细胞是生命体的基本单位？

1. **结构基本单位**：一切生物体（除病毒外）由细胞构成。
2. **功能基本单位**：各项生命活动在细胞内或在细胞参与下完成。
3. **繁殖的基本单位**：细胞通过分裂产生新细胞，是生殖的基础。
4. **生长发育的基础**：个体生长依赖细胞数量增加与体积增大。
5. **细胞全能性**：单个细胞含有全套遗传信息，具备发育成完整个体的潜能。

## 2. 细胞的基本性质

| 层面 | 要点 |
|---|---|
| 结构 | 具有质膜，界定细胞边界 |
| 组成 | 含 DNA 与 RNA，携带并表达遗传信息 |
| 代谢 | 含核糖体，能合成蛋白质 |
| 能量 | 能获取和利用能量（如 ATP） |

## 3. 细胞大小

- 一般为**微米级**，且大小有限。
- 限制因素：
  - **核质比**：细胞核控制细胞质范围有限。
  - **表面积/体积比**：体积增大时相对表面积下降，物质交换效率降低。
  - **细胞内大分子与细胞器的运输需求**是重要影响因素。
- 解决方式：细胞骨架支撑、改变细胞形状（如扁平化、形成突起）以增大有效表面积。

## 4. 细胞的分类与比较

### 三类细胞

- **原核细胞**、**真核细胞**、**古核细胞（古菌）**。

### 原核与真核的主要区别

| 比较维度 | 原核细胞 | 真核细胞 |
|---|---|---|
| 核 | 无真正细胞核（拟核） | 有核膜包被的细胞核 |
| 遗传信息 | 遗传与表达相对简单 | 遗传信息储存与表达高度区室化 |
| 细胞质 | 无发达细胞骨架 | 有细胞骨架系统 |
| 膜系统 | 无复杂内膜系统 | 有发达的生物膜系统（内质网、高尔基体等） |

### 植物细胞与动物细胞的区别

- **中心体**：动物细胞有，高等植物细胞一般无。
- **液泡**：植物细胞有中央大液泡；动物细胞液泡小而不明显。
  - 中性液泡：主要用于储存。
  - 酸性液泡：主要参与消化。
- **细胞壁**：植物细胞有（纤维素等），动物细胞无。
- **叶绿体**：植物细胞有，动物细胞无。

### 病毒

- 非细胞形态，必须寄生于活细胞；**对干扰素敏感**。
