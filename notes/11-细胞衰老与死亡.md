# 11 细胞衰老与死亡

> 返回 [[00-总览]] ｜ 配套总结：[章节总结-细胞衰老与死亡](attachments/章节总结-细胞衰老与死亡.pdf)

## 1. 细胞衰老

- **定义**：细胞经过有限次数分裂后，在形态、结构和功能水平上明显退化的现象。
- **特征**：
  1. 细胞核增大、核膜内折、染色体固缩。
  2. 水分减少，细胞萎缩、体积减小，代谢速度减慢。
  3. 色素积累、颜色加深，阻碍信息、物质和能量交流。
  4. 细胞膜通透性与流动性下降。
  5. 细胞间通讯减少。
- **Hayflick 界限**：体外培养的正常细胞只能进行有限次数分裂。
- **分子机制**：
  - **自由基学说**：活性氧自由基造成损伤积累。
  - **端粒学说**：端粒随分裂逐渐缩短，短端粒使 DNA 稳定性下降并阻断细胞周期（见 [[07-细胞核与染色体]]）。

## 2. 细胞死亡的类型

- 随机被动死亡（坏死）。
- 程序性细胞死亡（PCD）：
  - **细胞凋亡（apoptosis）**。
  - **自噬（autophagy）**：溶酶体降解自身物质。
  - **程序性坏死（necroptosis）**。
- 植物细胞的程序性死亡：液泡破裂、水解酶消化细胞内含物；或液泡膜与细胞膜融合释放水解酶，触发细胞死亡；参与超敏反应（HR）和环境胁迫响应。

## 3. 细胞凋亡

### 3.1 意义与形态学过程

- 意义：参与组织形态发生；清除病变或衰老细胞；维持免疫耐受与**稳态（homeostasis）**。
- 形态学过程：
  1. **凋亡起始**：染色质凝缩并沿核膜分布，细胞质收缩。
  2. **凋亡小体形成**：细胞质膜反折，包裹染色体片段和细胞器等碎片，形成芽状突起并脱离。
  3. **吞噬清除**：凋亡小体被吞噬细胞吞噬。
- 分子阶段：信号 → 活化 → 执行 → 清除。

### 3.2 凋亡途径

**① 死亡受体途径（外源性）**

- 死亡配体 FASL 与受体 FAS 结合 → 形成 DISC（死亡诱导信号复合体）→ 接头蛋白 FADD → 激活起始 caspase（caspase-8）→ 激活效应 caspase。
- 活化 T 细胞和 NK 细胞可通过此途径杀伤靶细胞。

**② 线粒体途径（内源性）**

- 胞内损伤信号 → Bax/Bak 复合体促使线粒体释放 **Cyt c** → Cyt c 与 Apaf-1 形成**凋亡复合体** → 激活起始 caspase（caspase-9）。
- 其他因子：AIF（引起染色质收缩）、EndoG（降解 DNA）、HtrA/Omi、Smac（抑制 IAP）。

**③ Caspase 依赖性途径的核心机制**

- **Caspase**：天冬氨酸特异性半胱氨酸蛋白水解酶，通常以无活性前体存在；活性位点含半胱氨酸残基，切割靶蛋白天冬氨酸残基后的肽键。
- 分类：
  - 炎症 caspase：1、4、5、11、12，负责产生活性白介素。
  - 凋亡 caspase：2、3、6、7、8、9、10。
    - 起始 caspase：2、8、9、10——切割效应酶前体使其活化。
    - 效应 caspase：3、6、7——切割细胞内结构蛋白和调节蛋白。
- 活化：起始 caspase 通过同源聚集形成二聚体而活化；活化的起始 caspase 切割并激活效应 caspase。
- 底物：活化 **CAD**（caspase 激活的 DNase，导致 DNA 片段化）；失活 **PARP**（聚腺苷酸二磷酸核糖转移酶）。
- Bcl-2 家族调控线粒体途径：[BCL2家族](attachments/BCL2家族.png)

**④ Caspase 非依赖性途径**

- 由 AIF、EndoG 等线粒体因子介导，不依赖 caspase 级联。
- 图示：[caspase非依赖性凋亡](attachments/caspase非依赖性凋亡.png)

### 3.3 标志与检测方法

- **DNA 梯状条带**：凋亡时在核小体间切割 DNA，片段约为 180–200 bp 的整数倍。
- 检测方法：

| 方法 | 原理/要点 |
|---|---|
| 形态学观察 | 染色法、透射/扫描电镜 |
| DNA 电泳 | 出现梯状条带 |
| TUNEL 测定 | DNA 断裂形成 3′-OH 末端，标记脱氧核苷酸掺入 |
| 彗星电泳 | 降解 DNA 片段泳动较快，细胞呈彗星状；无降解则呈圆形 |
| 流式细胞分析 | 凋亡细胞 DNA 含量呈连续分布（亚 G1 峰） |
| 其他 | 检测磷脂酰丝氨酸外翻、caspase 激活、Cyt c 释放、线粒体膜电位变化 |

- 图示：[彗星电泳法](attachments/彗星电泳法.png)

### 3.4 存活信号

- 存活因子与受体结合 → 活化蛋白激酶 → 促进 Bcl-2 活性、抑制凋亡；或激活 **NF-κB** 转录因子，启动 Bcl-2 基因转录。
