# 有机化学

## 一、共振论

### 1.1 共振杂化体的判断

- 凡按价键规则可写出**两个及以上**路易斯结构式的分子，其真实结构是这些结构式的**共振杂化体**。

### 1.2 共振式的书写原则

1. **原子核位置不变**——只移动电子，不移动原子。
2. 各极限式须符合**路易斯结构式**。
3. **未成对电子数**不变。
4. **键和电子**可以移动。

### 1.3 共振稳定性判断

**① 杂化体与极限式的关系**

- 共振杂化体比任何一个极限式都更稳定（即能量更低）。
  - 【待核对】原笔记写作「稳定性都低」，若指「能量更低」则与「更稳定」同义，建议复核表述。

**② 极限式的贡献大小**

- 极限式自身越稳定，在共振杂化体中的参与度（贡献）越高。
- 极限式越多，共振杂化体越稳定；其中**结构相同的等价极限式**越多，稳定化作用越明显。

**③ 等价性与共价键数目**

- **等价共振**（共价键数目相等的共振）比不等价共振更重要。
- 共价键数目多的极限式更稳定。

**④ 降低稳定性的因素**

- 电荷分离的极限式稳定性低。
- 违背电负性规律的极限式稳定性低——电子倾向于位于电负性大的原子上。
  - 【订正】原笔记「不遵守颠覆性电负性」疑为笔误，按语义整理。
- 不符合八隅体的极限式稳定性低（符合八隅体者更稳定）。

## 二、基础概念速查

### 2.1 质子酸与路易斯酸

- **路易斯酸**：亲电子试剂，能接受电子对的物质，通过接受电子对发生酸碱反应。
  - 常见的路易斯酸：[三氯化铝](https://baike.baidu.com/item/%E4%B8%89%E6%B0%AF%E5%8C%96%E9%93%9D/8244345?fromModule=lemma_inlink)、[三氟化硼](https://baike.baidu.com/item/%E4%B8%89%E6%B0%9F%E5%8C%96%E7%A1%BC/2515326?fromModule=lemma_inlink)、[三氧化硫](https://baike.baidu.com/item/%E4%B8%89%E6%B0%A7%E5%8C%96%E7%A1%AB/7613592?fromModule=lemma_inlink)、[溴化铁](https://baike.baidu.com/item/%E6%BA%B4%E5%8C%96%E9%93%81/10178442?fromModule=lemma_inlink)。
- **质子酸**：能够失去一个或多个质子的物质，通过失去质子发生酸碱反应。

| 对比维度 | 质子酸 | 路易斯酸 |
| --- | --- | --- |
| 定义 | 能失去质子的物质 | 能接受电子对的物质 |
| 反应方式 | 失去质子发生酸碱反应 | 接受电子对发生酸碱反应 |
| 代表物质 | HCl、H₂SO₄ | AlCl₃、FeCl₃ 等 |
| 化学性质 | 表现为酸性 | 表现为亲电子试剂 / 电子对受体 |

### 2.2 化合物命名原则

按以下优先次序判断：

1. **官能团**（先确定主官能团）
2. **碳链长**
3. **支链多**

### 2.3 自由基与碳正离子稳定性

- **共轭效应越强，越稳定。**
- 取代基越多，碳正离子越稳定。
  - 【原笔记备注】此条原列于「自由基稳定性」标题下，按原文保留，复习时留意归属。
- 稳定性顺序：**烯丙基自由基 > 2° 碳自由基**。
- 烯丙基自由基结构：·CH₂—CH=CH₂（原笔记写作 `*CH₂CH=CH₂`）。

## 五、官能团反应速查

> 本章整合自《化学.md》原笔记，按官能团重新归类；原笔记中重复出现的烯烃、炔烃、环烃、卤代烃、醇、酚各节已合并。存疑处标注【待核对】，笔画/排版笔误直接订正。

### 5.1 烯烃

| 反应类型 | 条件与产物 |
| --- | --- |
| 与水加成 | 加热、酸性条件，产物为醇 |
| 与硫酸加成 | 最终产物为醇（水解后） |
| 冷高锰酸钾氧化 | 生成邻二醇 |
| 酸性 / 热高锰酸钾氧化 | 发生正常氧化断键 |
| 臭氧化 + 金属还原 | 生成酮或醛 |
| Ag 催化 + 高温 | 生成环氧乙烷 |

### 5.2 炔烃

| 反应类型 | 条件与产物 |
| --- | --- |
| 与水加成 | 烯醇互变异构为羰基化合物 |
| 与 HCN 加成 | 条件：氯化亚铜 + 氯化铵 |
| 与卤化氢加成 | — |
| 酸性（末端炔氢） | 生成金属炔化物 |

### 5.3 脂环烃与芳烃

**取代反应**

- 与卤素取代：条件为铁或铁盐（Fe / FeX₃）。
- 傅-克反应：傅-克烷基化、傅-克酰基化。

**氧化反应**

- 萘的氧化：V₂O₅ 催化。
- 蒽、菲的氧化。

### 5.4 卤代烃

| 反应类型 | 条件与产物 |
| --- | --- |
| 被羟基取代 | 加热，生成醇 |
| 被氰基取代 | 乙醇中加热，生成腈 |
| 被氨基取代 | 生成胺 |
| 被烷氧基取代 | Williamson 合成，生成醚 |
| 消去反应 | 醇溶液 + 碱，加热，生成烯烃 |
| 与金属镁反应 | 生成格氏试剂 |
| 格氏试剂 + CO₂ | 酸化后生成羧酸 |

**立体化学要点**

- SN2：构型反转。
- SN1：生成外消旋体。

### 5.5 醇

- **脱水**：醇分子内脱水生成烯烃。
- **取代**：与卤代烃反应生成醚（加热）。
- **氧化**：邻二醇与高碘酸反应，断键生成醛；α-羟基醛酮也可被高碘酸氧化。
- **与碱金属反应**：生成醇化物，见 [4.6 节](#46-醇)。

### 5.6 酚

| 反应类型 | 要点 |
| --- | --- |
| 制醚 | 酚钠与三卤甲烷（原笔记「三卤甲基」）反应 |
| 氧化 | 生成醌；苯酚与对羟基苯酚均生成对苯醌 |
| 取代 | 卤化：水溶液与有机溶剂中的产物不同 |

### 5.7 醚

- **醚键断裂**：醚与氢卤酸反应生成醇（和卤代烃）。
- **氧化**：生成过氧化物。

### 5.8 醛酮

**亲核加成与缩合**

- 与含 N 亲核试剂（N 反应物）发生加成-缩合。
- α,β-不饱和羰基化合物的亲核加成：反马氏规则。

**还原**

| 还原方式 | 要点 |
| --- | --- |
| H₂ 催化氢化 | — |
| 金属氢化物 | 不影响碳碳双键 |
| 金属 + 酸 | — |
| 黄鸣龙还原 | Wolff-Kishner 改良法，碱性条件将羰基还原为亚甲基 |

**氧化**

- 土伦试剂（Tollens）：用于鉴别醛、酮及双键。
  - 【待核对】土伦试剂通常只氧化醛基，不氧化普通碳碳双键。
- α-羟基酮可被土伦试剂氧化。
- 强氧化剂氧化：酮与醛的产物不同，氧化酮需要断键。

**α-氢的反应**

- 卤仿反应：碱性条件下反应进行到底，发生三取代并断键。
  - 碱性条件下 I₂ 生成 NaOI，具氧化性可氧化醇；具 α-氢则可发生卤仿反应。
- 羟醛缩合：β-羟基醛酮在加热条件下失水生成双键。

**其他反应**

- 歧化反应（Cannizzaro）：浓碱条件下，无 α-氢的醛发生歧化。
- 缩醛形成：无水 HCl 催化下与醇反应。
- 羰基与胺缩合生成亚胺类产物。

### 5.9 羧酸

- **α-氢取代**：光照条件下卤代。
- **多元羧酸受热反应**：
  - 2～3 个碳，或 β-羰基酸：失去 CO₂。
  - 4～5 个碳：失去水；若在氢氧化钡催化下，同时失水与脱羧。
  - 大于 5 个碳：形成酸酐。
- **还原**：原笔记仅列标题，待补充具体试剂与产物。

### 5.10 羧酸衍生物

- **水解**：原笔记仅列标题，待补充。
- **缩合反应**：类似醛酮的缩合行为。
- **与格氏试剂反应**：原笔记仅列标题，待补充。
- **其他反应**：类似醛酮。

### 5.11 取代酸

**羟基酸**

- α-羟基酸：氧化（土伦试剂、浓硫酸加热）；失水。
- β-羟基酸：失水。

**羰基酸**

- α-羰基酸：卡尼查罗反应（歧化，NaOH）；氧化（硫酸、浓硫酸、土伦试剂）。
- β-羰基酸：脱羧；克莱门森缩合（原笔记如此，待核对是否指克莱森缩合）；分解（碱/酸/加热条件不同）；烷基化。

### 5.12 含氮化合物

| 反应 | 要点 |
| --- | --- |
| 酸性影响因素 | 给电子基团越多酸性越强；另受位阻影响。【待核对】胺类通常讨论碱性，此句需结合具体体系复核 |
| 缩合反应 | 生成含双键产物 |
| 还原 | 金属 + 酸 |
| 胺的氧化 | 可生成双键、单键产物或负离子 |
| 烷基化 | — |
| 磺酰化（Hinsberg 试验） | 用于鉴定多级胺：一级胺产物溶于碱，二级胺产物不溶于碱，三级胺不反应 |
| 酰基化 | 乙酸酐；用于保护氨基 |

- 【订正】原笔记「一级荣誉碱，二级不容碱」按 Hinsberg 试验语义整理为上述表述。
