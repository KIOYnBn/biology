# 01 · 染色体结构与基因组组织

> [!abstract] 一句话定位
> 染色体是遗传信息的**包装形式**：从病毒、细菌、细胞器到真核生物，包装方式越来越复杂；真核染色质以**核小体**为基本单位，通过逐级压缩和化学修饰在「紧密储存」与「按需读取」之间切换。

## 1　不同生物的染色体

### 1.1　总览对照

| 类型 | 核酸与结构 | 结合蛋白 | 包装特点与功能状态 |
| :--- | :--- | :--- | :--- |
| **病毒** | dsDNA / ssDNA / dsRNA / ssRNA；遗传信息少、组织形式简单 | 缺少结合蛋白 | 致密包装，遗传物质**不发挥功能** |
| **细菌** | 环状 DNA | DNA 结合蛋白（H 蛋白 / HU 蛋白） | 形成**伪核（nucleoid）**；紧密包装但遗传物质**有功能** |
| **线粒体** | mtDNA：dsDNA，多为环形（少数线性），多拷贝 | 无结合蛋白 | 见 1.2 |
| **叶绿体** | cpDNA：dsDNA，环形，多拷贝 | 无结合蛋白 | 见 1.2 |

### 1.2　细胞器染色体

**线粒体 DNA（mtDNA）**

- 序列组成：**无内含子、无基因重复**。
- 编码产物：rRNA、tRNA、部分呼吸链相关酶。
- **半自主性**：DNA 复制等重要蛋白由细胞核提供，而非线粒体自主生产。
- 双链 DNA 上的基因分布**不均匀**：一条链某位点为基因时，互补链对应位置通常不是基因。

**叶绿体 DNA（cpDNA）**

- 序列组成：长非编码序列、重复序列。
- 编码产物：5S rRNA、16S rRNA、tRNA 及部分光合酶。
- 重要酶由**核基因编码**，同样具有半自主性。

> [!note] 与核外遗传的联系
> 细胞器 DNA 的遗传不遵循孟德尔分离规律，见 [[遗传学/01-经典遗传学/01-绪论与孟德尔遗传扩展|核外遗传]]。

## 2　特殊染色体

### 2.1　多线染色体（polytene chromosome）

- **来源**：部分昆虫幼虫、原生动物、植物。
- **形成**：同源染色体复制**但不分离**，形成 1000～5000 条 DNA 并排的结构。
- **特点**：
  1. 染色体巨大，光学显微镜下可见。
  2. 具有**带（Band）/ 间带（Interband）/ 胀泡（Puff）**结构：
     - **Puff**：胀泡处的基因正在活跃转录。
     - **Band**：压缩程度深，通常是基因序列。
     - **Interband**：压缩程度浅，通常是调控元件。

### 2.2　灯刷染色体（lampbrush chromosome）

- 卵细胞减数分裂**双线期**的特殊染色体。
- 常见于动物（哺乳动物除外）。
- **侧环**是转录活跃区域。

## 3　真核染色质与染色体包装

### 3.1　染色质的基本单位：核小体

- 化学组成：**DNA + 蛋白质**
  - 组蛋白：H1、H2A、H2B、H3、H4
  - 非组蛋白
- 结构模型：**组蛋白八聚体** $= 2 \times (\mathrm{H2A,\ H2B,\ H3,\ H4})$，**147 bp DNA** 缠绕其上，H1 负责固定。

### 3.2　四级包装

![[attachments/染色体包装.png|600]]

| 层级 | 结构 | 直径变化 |
| :--- | :--- | :--- |
| 串珠模型 | 核小体，53 bp spacer DNA 与 H1 连接相邻核小体 | 2 nm → 11 nm |
| 螺线管 | 每圈 6 个核小体 | 11 nm → 30 nm |
| 染色体纤维 | 形成**环状结构域** | 30 nm → 300 nm |
| 染色体 | 环状结构域进一步压缩，形成染色体臂 | 300 nm → 700 nm |

### 3.3　染色体重建（chromatin remodeling）

> [!important] 目的
> 为 DNA 转录活动创造可及性：改变染色体结构，便于**非组蛋白**作用于 DNA。

**组蛋白共价修饰**（发生在未被 DNA 缠绕、伸出的**组蛋白尾巴**上）：

| 修饰 | 修饰酶 | 主要对象 | 表达效应 |
| :--- | :--- | :--- | :--- |
| 甲基化 | 组蛋白甲基转移酶 | 精氨酸、赖氨酸 | **抑制**基因表达 |
| 乙酰化 | 组蛋白乙酰化酶 | 赖氨酸 | **激活**基因表达 |
| 磷酸化 | — | 丝氨酸、苏氨酸、组氨酸 | **激活**基因表达 |

- **组蛋白密码**：组蛋白尾巴上共价修饰形成的复杂组合方式。
- 其他重建方式：**移动、移除或替换组蛋白**（由其他组蛋白取代）。

### 3.4　常染色质与异染色质

| 类型 | 间期状态 | 位置 | 基因与复制 | 功能 |
| :--- | :--- | :--- | :--- | :--- |
| **异染色质** | 浓缩 | 多位于核边缘 | 基因少、不表达；**晚复制** | 维持染色体结构（如着丝粒） |
| **常染色质** | 松散 | 散布于核内 | 活跃表达；**早复制** | 大部分基因组所处状态 |

## 4　真核生物 DNA 序列组织

![[attachments/人类基因组组成.jpg|500]]

![[attachments/重复DNA.jpg|500]]

### 4.1　重复序列 DNA

| 类别 | 亚型 | 特征 |
| :--- | :--- | :--- |
| 染色体末端重复 | — | 如质粒、整合进 DNA 的病毒基因 |
| **顺接重复** | 卫星 DNA | 重复单位约 200 bp；序列组成与常染色质不同 |
| | 小卫星 DNA | 重复单位约 10～100 bp |
| | 微卫星 DNA | 重复单位 < 10 bp，主要位于端粒 |

**端粒 DNA 特征**：短顺接重复、富含 TG。

**DNA 指纹**：基于 **STR（短串联重复）扩增**，利用个体间重复次数差异进行个体鉴别。

**分散重复**

- 转座元件（原核 / 真核中的可移动序列，详见 [[遗传学/03-遗传信息的维持与变异/03-重组与转座|重组与转座]]）。
- 非 LTR 逆转座子：
  - **LINE**：长分散核元件。
  - **SINE**：短分散核元件。

### 4.2　单一序列

- 基因组中只有一份或几份拷贝，约占基因组一半。
- **包含大多数功能基因**。
- 但多数序列为**非编码序列**：假基因、内含子、调控区、基因间隔区、非翻译区（UTR）。

## 5　考点速记

- 病毒、细菌、细胞器染色体都缺少典型核小体；真核染色体的基本单位是核小体（147 bp + 八聚体 + H1）。
- 包装四级：2 → 11 → 30 → 300 → 700 nm，对应串珠、螺线管、环状结构域、染色体臂。
- 组蛋白修饰口诀：**乙酰/磷酸激活，甲基抑制**（就本笔记语境而言）。
- 异染色质：晚复制、基因少、核边缘、结构支撑；常染色质：早复制、活跃表达。
- 重复序列按重复单位长度：卫星（~200 bp）> 小卫星（10～100 bp）> 微卫星（<10 bp）；STR 用于 DNA 指纹。
- 单一序列虽含大多数功能基因，但**大部分是非编码序列**。

<details>
<summary><b>自测 1：多线染色体与灯刷染色体各有什么观察价值？</b></summary>

多线染色体因同源染色体多次复制不分离而巨大，带/间带/胀泡可直接反映基因分布与转录活性；灯刷染色体见于卵母细胞减数分裂双线期，侧环是活跃转录区，便于观察转录活动。
</details>

<details>
<summary><b>自测 2：比较病毒、细菌、线粒体染色体在包装上的差异。</b></summary>

病毒：遗传信息少、无结合蛋白、致密包装且遗传物质不发挥功能；细菌：H/HU 蛋白结合形成伪核，紧密包装但有功能；线粒体：dsDNA 多拷贝、无结合蛋白、无内含子和基因重复，半自主（关键蛋白由核基因编码）。
</details>
