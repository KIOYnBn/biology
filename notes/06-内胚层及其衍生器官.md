# 06 · 内胚层及其衍生器官

> [!abstract] 本章速览

## 6.1 内胚层早期分化

### 6.1.1 功能与起源

- **主要功能**：形成消化管、呼吸管及腺体上皮。
- 内胚层细胞随胚胎向内卷折进入胚体内，形成封闭通道——**原肠**。
- 原肠分化为**前肠、中肠、后肠**。
- 头部额鼻隆起与上下颌隆起之间出现凹陷——**口凹（原口）**；原口与前肠接触形成**口板**，口板破裂形成口腔。
- 尾端肛膜凹陷形成**肛凹**，与后肠形成**泄殖腔膜**；肛凹破裂形成泄殖腔开口。

### 6.1.2 信号调控

| 信号强度 | 命运 |
| --- | --- |
| **Nodal** 信号多 | 内胚层 |
| BMP + FGF（成纤维细胞生长因子） | 中胚层 |
| 高浓度 WNT、BMP、FGF | 中肠、后肠 |
| 上述信号浓度低 | 前肠 |

> Nodal 信号激活上胚层发育成中、内胚层。

---

## 6.2 原始消化管形成

- 外胚层细胞下移形成内胚层，随羊膜腔下包。
- **上皮来源对照**

| 结构 | 来源 |
| --- | --- |
| 消化管及呼吸道**上皮、腺体** | 内胚层 |
| 结缔组织、肌肉、软骨等 | 脏壁中胚层 |

**三段划分**

| 肠段 | 范围与衍生物 |
| --- | --- |
| **前肠** | 至十二指肠前部 + 肝、胆、胰 |
| **中肠** | 至结肠（空肠、回肠、盲肠、升结肠、横结肠大部） |
| **后肠** | 横结肠后部、降结肠、乙状结肠、直肠，参与膀胱等 |

> 消化管贯穿全身，衍生肝、胆囊、胰腺（开口于十二指肠）。

---

## 6.3 消化管各段发生

### 6.3.1 咽与咽囊

- 消化管与呼吸管共同开口于咽；**原始咽**是前肠的膨大部。
- **五对咽囊的衍生物（高频考点）**

| 咽囊 | 衍生物 |
| --- | --- |
| 第一对 | 鼓室 + 咽鼓管 |
| 第二对 | 扁桃体；两对之间形成盲管 → 甲状腺 |
| 第三对 | 胸腺 + 一对甲状旁腺 |
| 第四对 | 另一对甲状旁腺 |
| 第五对 | 鳃后体 |

### 6.3.2 食管

1. 原始上皮由单层增生为复层，管腔闭锁；
2. 上皮退化，管腔重现；
3. 上皮周围间充质分化为食管壁的结缔组织和平滑肌。

### 6.3.3 胃

- 前肠尾端膨大形成**胃原基**；背侧发育迅速形成胃大弯与胃小弯。
- 背系膜突向左侧，胃大弯凸向左、小弯向右，使胃**旋转 90°**，形成左上—右下的形态。

### 6.3.4 肠与泄殖腔分隔

- 胃原基后端为肠管端部；十二指肠发育快，形成 U 形弯曲——**中肠袢**。

| 肠管区域 | 衍生物 |
| --- | --- |
| 前肠尾端 + 中肠头端 | 十二指肠 |
| 中肠头支 | 空肠、回肠大部 |
| 中肠尾端 | 回肠尾、横结肠部分 |
| 盲肠芽 | 盲肠 + 阑尾 |
| 后肠 | 横结肠、直肠等 |
| 后肠末端 | 泄殖腔 |

- 尿囊与后肠之间的间充质增生形成**尿直肠隔**，突入泄殖腔并与泄殖腔膜相连，将泄殖腔分隔为背腹两侧。

## 6.4 消化腺发生

### 6.4.1 肝和胆囊

- 十二指肠腹侧壁的上皮增生，形成向外突出的囊状突起——**肝憩室**，是肝与胆的原基。
- 肝憩室膨大分为两支

| 分支 | 命运 |
| --- | --- |
| 头支 | 上皮细胞增殖形成细胞索 → 分支形成肝索 → 肝板，围绕静脉形成**肝小叶** |
| 尾支 | 发育成**胆囊和胆囊管** |

- 根部发育成**总胆管**，开口于十二指肠背内侧。

### 6.4.2 胰腺的发生（整合版）

- 十二指肠腹侧靠近肝憩室的尾缘内胚层细胞增生，形成两个憩室：**背胰芽**与**腹胰芽**与之相对。
- 腹胰芽和背胰芽分化形成腹胰、背胰，各有一条贯穿腺体的管。
- 随十二指肠和胃的移位，**腹胰翻转到背侧与背胰融合**，形成整合的胰腺：

| 来源 | 形成部分 |
| --- | --- |
| 腹胰 | 胰头下分 |
| 背胰 | 胰头上分、胰体、胰尾 |

- 腹胰管与背胰管远端汇合形成**主胰导管**，和胆总管共同通过**大乳头**开口于十二指肠。

> [!tip] 易混对照
> 肝憩室"头支成肝、尾支成胆囊"；胰腺"腹胰成胰头下分、背胰成胰头上分+体尾"。

## 6.5 呼吸系统发生

- **来源**：除鼻腔上皮来自外胚层外，其余来自消化管内胚层。
- **结构基础**：支气管树；**肺叶** = 二级支气管及其管辖范围；**肺泡** = 细支气管末端膨大成囊，囊周围的小囊泡。

**发育过程**

1. 原始咽尾段正中出现浅沟，愈合形成**喉气管憩室**；
2. 憩室末端膨大成两支**肺芽**，分支形成支气管树；
3. 左肺芽分两支、右肺芽分三支，形成肺叶支气管；
4. 肺泡为半球形囊泡，开口于肺泡囊、肺泡管或呼吸性细支气管。

**肺泡上皮与气体交换**

| 细胞类型 | 特点 |
| --- | --- |
| 一型肺泡细胞 | 无增殖能力 |
| 二型肺泡细胞 | 有增殖能力，一型受损时替换一型；分泌液体 |

- 氧气依次通过**肺泡内表面液膜 → 上皮细胞膜 → 肺泡上皮与肺毛细血管内皮间的间质 → 毛细血管内皮细胞膜**，共四层膜。
