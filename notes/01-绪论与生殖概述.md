# 01 绪论与生殖概述

> [!abstract] 本章要点
> 生殖的概念；有性生殖与无性生殖的区别；生殖系统与三大调节系统；四种分泌方式；生殖质、核型等基础术语。

## 生殖的概念

生殖是生物产生后代、延续种族的过程。按是否需要两性生殖细胞融合，分为有性生殖与无性生殖。

## 有性生殖

- **体细胞类型**：体细胞、生殖细胞。胚胎发育早期，体细胞可以转化为生殖细胞。
- **核心特征**：存在减数分裂，产生单倍体配子，两性配子融合形成合子。
- **过程**：性别分化 → 性发育 → 性行为 → 配子发生 → 受精 → 胚胎发育 → 妊娠 → 分娩。
- **融合生殖**：有性生殖的一种形式。
- **重要性**：种族延续、畜牧生产、科学研究、辅助生殖。

## 无性生殖

- 概念：不经过两性生殖细胞融合，由一个生物体产生后代。
- 应用：动物克隆（详见 [[09-辅助生殖与生物技术]]）。

| 比较项 | 有性生殖 | 无性生殖 |
| --- | --- | --- |
| 两性配子融合 | 需要 | 不需要 |
| 减数分裂 | 有 | 无 |
| 后代遗传组成 | 双亲重组，变异丰富 | 与亲本基本一致 |
| 典型例子 | 哺乳类、鸟类、多数动植物 | 克隆、分裂生殖 |

## 生殖系统基础

- **性腺**：人体中兼具生殖和内分泌功能的腺体；包括睾丸与卵巢。肾上腺和性腺均起源于生殖嵴。
- **第一性征**：男女在生殖器官上的差异。
- **第二性征**：两性在身体其他方面的差异，青春期出现；幼年切除性腺后第二性征消失。
- **第三性征**：两性在性格、行为方面的差异。

## 机体调节系统

| 系统 | 调节方式 | 组成/特点 |
| --- | --- | --- |
| 神经系统 | 神经细胞分泌神经介质，通过神经冲动传递信息，调节生长发育 | 常见神经递质：多巴胺、儿茶酚胺、5-羟色胺、β-内啡肽 |
| 内分泌系统 | 激素经腺泡和淋巴管运输至器官发挥调节 | 无管道腺体，经体液运输 |
| 免疫系统 | 免疫细胞和器官保护机体 | 血细胞、脾脏、淋巴结 |

## 分泌方式

| 方式 | 特点 |
| --- | --- |
| 内分泌 | 无管道，激素释放入体液，经血液运输 |
| 旁分泌 | 作用于邻近细胞，不进入血液 |
| 近分泌 | 特殊的旁分泌，作用于紧邻细胞 |
| 自分泌 | 作用于自身细胞 |
| 外分泌 | 经管道排至体表或管腔 |

> [!note] 与激素的联系
> 激素按作用途径可分为远距分泌、旁分泌、自分泌、神经分泌与外激素，详见 [[02-生殖激素与内分泌调控]]。

## 基础术语

- **前口动物**：胚孔发育成口；**后口动物**：胚孔发育成肛门。
- **生殖质**：位于卵或胚胎特定部分的特定细胞质成分，决定原始生殖细胞的分化（详见 [[03-原始生殖细胞与性别决定]]）。
- **卵裂**：无细胞生长的间期，周期短、速度快（详见 [[07-早期胚胎发育与干细胞]]）。
- **核型**：生物体细胞中所有染色体的大小、形状、数量特征的总和（与染色体病见 [[08-生殖健康：遗传营养与环境]]）。

> [!abstract] 考点速记
> 1. 有性生殖与无性生殖的核心区别：是否经过两性生殖细胞融合。
> 2. 有性生殖的完整过程链：性别分化 → 性发育 → 性行为 → 配子发生 → 受精 → 胚胎发育 → 妊娠 → 分娩。
> 3. 性腺兼具生殖与内分泌功能；第一、二、三性征的定义与区别。
> 4. 内分泌 / 旁分泌 / 近分泌 / 自分泌 / 外分泌五种方式的定义。

<details>
<summary>自测题</summary>

1. 为什么说性腺既是生殖器官又是内分泌器官？
2. 幼年切除性腺后第二性征消失，说明性腺与第二性征是什么关系？
3. 近分泌与旁分泌有何区别？
4. 生殖质在生殖细胞发生中起什么作用？

<details>
<summary>参考答案</summary>

1. 性腺既产生配子（生殖功能），又分泌性激素（内分泌功能）。
2. 第二性征的维持依赖性腺分泌的性激素。
3. 近分泌是作用于紧邻细胞的特殊旁分泌，旁分泌泛指作用于邻近细胞且不进入血液。
4. 生殖质是决定原始生殖细胞分化的特定细胞质成分，含这种细胞质的子代细胞将发育为 PGC。
</details>
</details>
