# 02 · 真核转录调控

> [!abstract] 一句话定位
> 真核调控在原核的"激活子/抑制子 + 转录起始"之上，叠加了**染色质关卡**、**远距离调控元件**与**组合控制**；稳定的位置效应进一步形成**基因沉默与表观遗传**。

**导航**：[[分子生物学/04-表达调控/01-原核转录调控|← 原核转录调控]] · [[分子生物学/00-复习总览|复习总览]]

---

## 1　真核与原核调控的异同

### 1.1　相似性

1. **转录起始依然是基因表达调控的核心**。
2. **机制相同**：都靠调控蛋白（激活子、抑制子/阻遏子）。

### 1.2　真核的复杂性

- **核小体及其修饰**（原核无）。
- **更多调控因子**。
- **更远的调控序列**。

### 1.3　特点

| 特点 | 说明 |
| :--- | :--- |
| **多层次** | 转录 → 转录后加工（加工、运输、稳定性）→ 翻译 → 翻译后修饰 |
| **异时空** | 依细胞种类、发育阶段而异 |
| **可变类型** | 逆转座子、甲基化 |

| 概念 | 定义 |
| :--- | :--- |
| **调控因子结合位点** | 单个调控蛋白结合的短 DNA 序列 |
| **调控序列** | 包含某基因全部调控因子结合位点的 DNA 区段 |

---

## 2　调控蛋白的结构域

### 2.1　DNA 结合域

- 通常蛋白质以**二聚体**形式，利用嵌入 DNA **大沟**的 **α 螺旋**读取碱基对信息。

| 类型 | 结构特点 |
| :--- | :--- |
| **同源域蛋白** | 高度保守的**螺旋-转角-螺旋**基序，广泛存在于所有真核生物，在发育调控中起关键作用 |
| **含锌结构域** | 经典"锌指蛋白"与 Gal4 的"锌簇"；锌原子起**结构稳定**作用，由 α 螺旋嵌入大沟识别；锌指可**串联排列**增强特异性与亲和力 |
| **亮氨酸拉链** | 兼具二聚化与 DNA 结合：两个 α 螺旋像钳子夹住 DNA，通过**亮氨酸残基的疏水作用**形成卷曲螺旋实现二聚化 |
| **螺旋-环-螺旋（HLH）** | 与亮氨酸拉链类似，但二聚化界面由一延伸螺旋与一较短螺旋经柔性环连接；DNA 结合区富碱性氨基酸，故称碱性拉链 / bHLH |
| **HMG 蛋白** | 通过"**AT 钩**"基序识别 DNA **小沟**，常剧烈改变 DNA 构象，促进高阶蛋白-DNA 复合物形成 |

### 2.2　激活域

- 通常**缺乏稳定的三维结构**，在与靶蛋白相互作用时才被"诱导"形成螺旋。

---

## 3　激活子与抑制子

### 3.1　激活子

> **核心作用：招募蛋白质**

1. 招募**转录机器**。
2. 招募**核小体修饰与重塑因子**。
3. 招募**起始/延伸因子**。

### 3.2　抑制子

1. 抑制激活子。
2. 招募**染色体修饰酶**。
3. 抑制转录机器。
4. 参与**基因沉默**。

---

## 4　信号集成与组合控制

### 4.1　协同作用

| 实现方式 | 说明 |
| :--- | :--- |
| 多激活子招募**同一**复合物 | — |
| 多激活子招募**不同**复合物 | — |
| 激活子间相互帮助结合 DNA | **经典协同**：激活子直接互作稳定彼此与 DNA 的结合；**间接协助**：一个激活子招募染色质修饰/重塑因子改变局部染色质结构，为另一个创造结合位点 |

### 4.2　组合调控

一个特定基因受**一组特定调控因子**（激活子/阻遏子）组合控制；同一调控因子也可与其他不同因子组合去调控不同基因。

> [!tip] 与核小体调控的衔接
> 核小体重塑、组蛋白修饰与核小体定位的具体机制见 [[分子生物学/02-基因组维持/01-基因组与染色体包装|基因组与染色体包装]]；激活子招募这些因子的过程正是"染色质关卡"的分子基础。

---

## 5　基因沉默与表观遗传

### 5.1　基因沉默

> **定义**：一种基于**位置效应**的稳定、可遗传的抑制状态。

1. 是**位置效应**：基因因在染色体上的位置（如靠近端粒、着丝粒）而被稳定抑制，不依赖特定环境信号的瞬时调控。
2. 可沿染色质**扩散**，影响大段区域内的多个基因，形成致密、转录惰性的**异染色质**。

### 5.2　表观遗传

> **定义**：基因表达模式在没有原始起始信号的情况下，通过细胞分裂稳定遗传给子代细胞的现象。

**机制**
1. **蛋白质正调控反馈**。
2. **DNA 甲基化的化学标记**。
3. **组蛋白修饰继承**。

**相关现象**

| 现象 | 说明 |
| :--- | :--- |
| **基因组印记** | 子代表型取决于基因来自父母哪一方 |
| **双启动子机制** | 上游与下游各一个启动子，产生正义与反义链 |

> 原核/真核 DNA 甲基化功能差异（错配修复标记 vs 表观调控）见 [[分子生物学/02-基因组维持/03-DNA损伤突变与修复|DNA 损伤突变与修复]] 与 [[分子生物学/00-复习总览|复习总览]]。

## 6　自测题（含答案）

<details>
<summary><b>1. 列举真核细胞除转录水平外的其他调控类型。是否存在真核特有而原核没有的？</b></summary>

其他类型：转录后水平（RNA 剪接、加帽、加尾）、RNA 稳定性与降解调控、翻译水平调控、翻译后水平（磷酸化、泛素化及蛋白质降解）调控。

真核特有：染色质结构重塑、RNA 可变剪接，以及非编码 RNA 介导的 RNA 干扰与基因沉默。
</details>

<details>
<summary><b>2. 比较细菌与真核细胞转录调控的 DNA 序列元件。</b></summary>

细菌依赖**操纵子**结构，主要元件为**启动子**和紧邻的**操纵基因（operator）**位点；阻遏蛋白或激活蛋白直接结合操纵基因，影响 RNA 聚合酶与启动子的结合。

真核元件更复杂：核心启动子（含 TATA 盒）、上游启动子元件、可位于数千碱基之外的**增强子**与**沉默子**。真核调控需要染色质结构参与，通过多种转录因子与辅因子形成复合体协同发挥作用，不像原核单凭简单阻遏即可完成。
</details>

<details>
<summary><b>3. 为什么 lacZ 常用作酿酒酵母的报告基因，却不在大肠杆菌中作报告基因？</b></summary>

酿酒酵母（真核）细胞中**不存在内源性 β-半乳糖苷酶**，外源引入的 LacZ 活性几乎零背景，可非常灵敏准确地通过显色反应（如 X-gal 染色）检测启动子活性。大肠杆菌菌株自身携带内源性 **lacZ** 基因，背景高，不适合做报告基因。
</details>

<details>
<summary><b>4. 为何仅凭通用转录因子与 RNA Pol Ⅱ，以基因组 DNA 为模板无法启动体外转录？</b></summary>

真核细胞的基因组 DNA 被组蛋白包装成**染色质（核小体）**，物理遮挡启动子区域，通用转录因子和 Pol Ⅱ 无法接近结合。PCR 产物是**裸露 DNA**，规避了染色质障碍，因此可启动体外转录。
</details>

<details>
<summary><b>5. 酵母双杂交检测相对于"必须发生诱饵-猎物相互作用才能激活报告基因"这一要求的潜在缺陷？</b></summary>

诱饵与猎物分别融合到 DNA 结合域和转录激活域，大标签融合可能改变蛋白三维构象或用空间位阻掩盖真正相互作用界面，使生理状态下能结合的蛋白在系统中无法结合（**假阴性**）。

其他缺陷：① 融合蛋白大量过量表达可能导致非特异性疏水聚集，产生**假阳性**；② 某些相互作用依赖特定翻译后修饰（磷酸化、糖基化），酵母可能缺乏对应的哺乳动物同源酶系；③ 融合蛋白可能对酵母有细胞毒性，导致宿主死亡无法筛选。
</details>

<details>
<summary><b>6. 染色质免疫沉淀（ChIP）步骤排序：a. 免疫沉淀 DNA-蛋白复合物 b. PCR 扩增 DNA c. 加特异性抗体 d. 蛋白质交联到 DNA 片段 e. 移除蛋白质</b></summary>

正确顺序：**d → c → a → e → b**。
</details>

<details>
<summary><b>7. 研究人员在 ChIP 中使用抗蛋白 X 抗体和基因 Y 区域的 PCR 引物，其可能提出的问题是什么？</b></summary>

例如："蛋白质 X 是否直接结合在基因 Y 的启动子区域，从而调控基因 Y 的表达？"
</details>

<details>
<summary><b>8. 给出影响基因表达的组蛋白共价修饰的例子。</b></summary>

组蛋白乙酰化、甲基化、磷酸化、泛素化以及 SUMO 化。
</details>

<details>
<summary><b>9. 为什么某种特定修饰的存在并不总是与激活或抑制唯一关联？</b></summary>

组蛋白修饰对表达的影响高度**依赖上下文**（组蛋白密码的组合）。例如 H3K4me3 通常与基因激活相关，而 H3K9me3、H3K27me3 通常与抑制相关；不同修饰位点间的拮抗/协同，以及修饰丰度（单/双/三甲基）都会影响最终结果。
</details>

<details>
<summary><b>10. 描述 DNA 甲基化在哺乳动物细胞基因表达中的作用。</b></summary>

主要发生在 **CpG 二核苷酸的胞嘧啶**上。启动子区（尤其 CpG 岛）高度甲基化通常与基因长期沉默相关，如基因组印记、X 染色体失活、抑制转座子活性；去甲基化则通常伴随基因重新激活。
</details>

<details>
<summary><b>11. 哺乳动物与大肠杆菌 DNA 甲基化的作用有何不同？</b></summary>

大肠杆菌主要是 **Dam 甲基转移酶介导的腺嘌呤甲基化**，用于错配修复中区分新合成链与模板链，并在复制起始中发挥作用——是维护序列完整性的辅助标记。哺乳动物甲基化则是一套**核心表观遗传调控机制**，决定特定基因是否表达。
</details>

<details>
<summary><b>12. 为什么印记会导致非孟德尔遗传？</b></summary>

孟德尔遗传中，子代从父母各继承一个等位基因，两者**等位表达、机会均等**。基因组印记中，某些位点发生**亲源依赖的 DNA 甲基化或组蛋白修饰**，使来自某一亲本一方的等位基因被永久表观沉默，因此性状分离不符合经典孟德尔模式。
</details>
