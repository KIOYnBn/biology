# 微生物学
## 一、绪论

### 1.1 微生物的定义与特点

**定义**：太小以至于肉眼无法看清的生物。

**特点**：

1. 小，比表面积大。
2. 代谢强，繁殖快。
3. 分布广，种类多。
4. 易变异，抗性强（耐寒、耐热、抗压力、耐渗透压）。

### 1.2 微生物的组成

| 类别 | 成员 |
| --- | --- |
| **原核** | 细菌（真细菌、古菌）、放线菌、蓝细菌、支原体、衣原体、立克次氏体 |
| **真核** | 真菌（酵母菌、霉菌、蕈菌）、原生动物、显微藻类 |
| **非细胞** | 病毒、亚病毒（类病毒、拟病毒、卫星病毒、卫星 RNA、朊病毒） |

![微生物三大类群](attachments/微生物三大类群.jpg)

![微生物分类思维导图](attachments/微生物分类思维导图.png)

### 1.3 微生物的大小

| 微生物 | 大小 |
| --- | --- |
| 原生动物 | 约 100 μm |
| 细菌 | 1～5 μm（有些长度远大于宽度） |
| 酵母 | 约 8 μm |
| 立克次氏体 | 约 0.4 μm |
| 衣原体、支原体 | 约 0.25 μm |
| 病毒 | 20～250 nm |

- 已知最小细菌：纳米细菌约 50 nm；最大细菌：硫细菌。

### 1.4 微生物学简史与科赫法则

- **巴斯德（Louis Pasteur）**：否定「自然发生学说」（生命体从非生物物质产生），确立「生源论」（生命体只能从已存在的生物中产生）。
- **科赫（Robert Koch）——科赫法则（Koch's postulate）**：
  1. **病原体存在**：在所有患病宿主体内都能找到特定微生物，健康宿主体内不存在。
  2. **病原体分离**：该微生物能从患病宿主体内分离并体外培养，得到纯培养物。
  3. **病原体致病性**：将纯培养物接种到健康宿主，应引起相同疾病。
  4. **病原体再分离**：从发病宿主体内再次分离出相同微生物，得到与原分离株相同的纯培养物。

### 1.5 微生物与人类

**有益应用**

- 工业：发酵。
- 农业：微生物肥料、微生物杀虫剂、促进增产、提高土壤肥力、虫害防治。
- 环境：净化污水、降解污染物（生物修复 bioremediation）。

**危害**

- 水华 water bloom（淡水）、赤潮（海水）。
- 传染病：鼠疫、天花、霍乱、流感、艾滋病等。

## 二、研究微生物的方法

### 2.1 纯培养与分离纯化

**混合培养 mixed culture** → 常见容器：试管、培养皿、锥形瓶等。
**纯培养 pure culture** → 由分离得到。

**固体培养基分离法**

| 方法 | 优点 | 缺点 |
| --- | --- | --- |
| 稀释倒平板法 pour plate | 适于分离和计数 | 操作繁琐；不适合热敏感菌；不适合专性需氧菌 |
| 涂布平板法 spread plate | 易操作、常规使用、快速方便 | 涂布不均；可能造成机械损伤 |
| 平板划线法 streak plate | 快速方便；可分区域划线或连续划线 | — |
| 稀释摇管法 shake tube | 可分离专性厌氧菌 | 不易观察和挑取菌落 |

**液体培养基分离法**

- 单细胞分离：显微操作仪、毛细管技术、小液滴法；适合少数菌的分离，操作难度与细胞大小成反比。
- 选择培养分离：影响因素包括温度、抗生素抗性、营养。

**菌落与菌苔**

- 菌落 colony：固体培养基上肉眼可见的、由某一种微生物繁衍形成的细菌团。
- 菌苔 lawn：固体培养基表面连续的菌落，常由多种微生物共同组成。

### 2.2 无菌技术

- **定义**：为使设备和区域远离所有微生物并保持无菌而执行的一套具体操作和程序。
- 要点：无菌容器、洁净空间、无杂菌群体。
- 维持无菌环境：压力蒸汽灭菌（最常用）、干热灭菌、棉塞、洁净工作台、无菌接种。

### 2.3 微生物的保藏

- 影响稳定性的因素：突变、污染、死亡。
- 基本要求：无杂乱（no clutter）、无腐败（no decay）。
- 方法：传代保藏法、低温贮藏法、干燥保藏法（冷冻真空、砂管、石蜡油、封藏）。

### 2.4 显微镜技术

**光学显微镜**

- 放大倍数 magnification；反差 contrast。
- 分辨率 resolution：最小可分辨距离 = 0.5λ / (n·sinθ)，其中 n·sinθ = NA（数值孔径）。
- 类别：明场显微镜、暗场显微镜、相差显微镜、荧光显微镜（紫外光激发荧光物质）。

**电子显微镜**

- 组成：电子束、电磁透镜、荧光屏；重金属盐染色；真空环境。
- 电子波长约为可见光的 1/100000。
- 分类：SEM 扫描电子显微镜、TEM 透射电子显微镜。

### 2.5 染色技术

**基本流程**：涂片 smear → 风干 → 热固定；染色目的在于提供反差。

- 碱性染料：阳离子型；酸性染料：阴离子型。

**染色类型**

| 类型 | 要点 |
| --- | --- |
| 简单染色 | 只用一种碱性染料 |
| 鉴别染色 | 不同细菌反应不同，如革兰氏染色、抗酸染色 |
| 负染色 | 染背景而非菌体（墨汁 india ink、苯胺黑 nigrosine） |
| 特殊染色 | 芽孢染色（加热使染料进入）、鞭毛染色（媒染剂加粗）、荚膜染色（负染 + 简单染色） |

**革兰氏染色 Gram stain**

- 流程：结晶紫（初染）→ 碘液（媒染）→ 乙醇（脱色）→ 番红/沙黄（复染）。
- 结果：G⁺ 保留结晶紫-碘复合物，呈紫色；G⁻ 脱色后被番红复染呈红色。
- 机制：G⁺ 细胞壁厚、肽聚糖层多且交联致密、不含类脂，乙醇使网孔缩小，复合物被留住；G⁻ 细胞壁薄、外膜类脂含量高、肽聚糖层薄且交联差，外膜被脱色剂溶解，复合物溶出而呈无色。
- 意义：细菌分类鉴定重要依据；辅助诊断感染与指导用药。

**抗酸染色 acid-fast stain**

- 流程：石炭酸复红 carbolfuchsin（加热）→ 盐酸乙醇脱色 → 美蓝 methylene blue 复染。
- 结果：抗酸菌呈红/粉色，非抗酸菌呈蓝色。
- 代表菌：分枝杆菌属、诺卡氏菌致病种；含约 60% 疏水蜡质脂质（分枝菌酸 mycolic acid），革兰氏染色呈阳性。

## 三、原核微生物

### 3.1 原核生物总论

**特征**

1. 一个或多个环状染色体，无核膜。
2. 无组蛋白。
3. 缺少细胞器。
4. 肽聚糖细胞壁。
5. 二分裂繁殖。

**分类**：细菌、古菌、放线菌、蓝细菌、支原体、立克次氏体、衣原体。

**三域系统**：古菌域 Archaea、细菌域 Bacteria、真核域 Eukarya（注意：细菌域包括细胞壁无肽聚糖的生物）。

![原核生物章节学习目标](attachments/原核生物章节学习目标.png)

### 3.2 细菌的形态

| 形态 | 特征与大小 |
| --- | --- |
| 球菌 coccus | 球形，0.5～1.0 μm |
| 杆菌 bacillus | 0.5～1.0 μm × 1～80 μm |
| 螺旋菌 spirillum | 0.3～1.0 μm × 1～50 μm |
| — 弧菌 vibrio | 弯曲的杆菌 |
| — 螺菌 spirillum | 螺旋形、刚硬 |
| — 螺旋体 spirochete | 螺旋形、柔软 |
| 其他 | 有柄细菌、星形细菌、方形细菌 |

**形态改变的原因**：代谢产物积累过多、营养缺乏、细胞衰老（培养时间过长）、物理化学因子刺激阻碍发育。

### 3.3 细菌细胞结构总览

- **一般构造**：细胞壁、细胞质膜、核区、间体、细胞质、内含物。
- **特殊构造**：鞭毛、菌毛、性毛、芽孢，以及糖被（微荚膜、荚膜、黏液层）。

### 3.4 细胞壁

**功能**：维持形态、防止渗透压变化导致的裂解或塌陷；环境屏障；参与生长与分裂；与致病性及抗生素作用位点有关；用于细菌大类鉴别。

#### 3.4.1 革兰氏阳性菌细胞壁

- 主要特征：厚的肽聚糖层 + 磷壁酸。
- **肽聚糖 peptidoglycan**（又称 murein）：由长糖链经短肽交联形成的唯一大分子。
  - 糖骨架：NAG（N-乙酰葡糖胺）与 NAM（N-乙酰胞壁酸）交替排列，10～65 个糖残基，β-1,4 糖苷键连接；溶菌酶水解该键使壁破裂。
  - 肽部分：四肽尾（四肽侧链，D-/L-氨基酸交替，附着于 NAM）与肽桥（短肽链；青霉素可干扰肽桥形成）。
  - 交联程度与糖链长度可变。

![革兰氏阳性细胞壁](attachments/革兰氏阳性细胞壁.png)

![肽聚糖网状结构](attachments/肽聚糖网状结构.png)

![肽聚糖单体](attachments/肽聚糖单体.png)

- **磷壁酸 teichoic acids**：甘油或核糖醇经磷酸基团连接的聚合物。
  - 脂磷壁酸 lipoteichoic acid：连于质膜并贯穿肽聚糖层；壁磷壁酸 wall teichoic acid：连于肽聚糖层。
  - 功能：因磷酸基负电荷调控阳离子进出；参与细胞生长、防止壁过度降解；作为重要抗原。
- **周质空间**：壁与质膜之间，蛋白质较少，含降解多聚营养物的胞外酶。

#### 3.4.2 革兰氏阴性菌细胞壁

- 主要特征：外膜 + 薄肽聚糖层 + 周质空间。
- **外膜 outer membrane**：脂多糖（O 多糖、核心多糖、脂质 A）、磷脂、脂蛋白。
  - 脂蛋白通过共价键使外膜牢固连接于肽聚糖。
  - 孔蛋白 porin：三聚体跨膜蛋白，分特异性与非特异性（允许一定分子量的亲水分子通过）。
  - **LPS 功能**：贡献表面负电荷；稳定外膜结构；形成渗透屏障；保护病原菌免受宿主防御；脂质 A 为内毒素。

![革兰氏阴性细胞壁](attachments/革兰氏阴性细胞壁.png)

![外膜脂多糖结构](attachments/外膜脂多糖结构.png)

![脂多糖化学结构](attachments/脂多糖化学结构.png)

- **周质空间**：宽约 30～70 nm，被称为「酶袋」。
  - 周质蛋白参与营养获取（水解酶、转运蛋白）、能量守恒（电子传递蛋白）、肽聚糖合成与毒素修饰。
  - 功能：降解大分子、抵御毒素、收集营养并递送给转运蛋白。

#### 3.4.3 两类细胞壁的比较

- G⁺ 约 50 层肽聚糖，G⁻ 仅 1～2 层；G⁻ 无肽桥。

#### 3.4.4 缺壁细菌

| 类型 | 成因与特点 |
| --- | --- |
| L 型细菌 | 变形杆菌等可自发失去细胞壁；形态多样；可通过细菌滤器（过滤型细菌）；对渗透压敏感；可恢复有壁状态 |
| 原生质体 protoplast | G⁺ 菌经溶菌酶或青霉素处理完全失去细胞壁；球形，仍能代谢；易裂解；对渗透压、震荡、离心敏感；易导入遗传物质 |
| 球状体 spheroplast | G⁻ 菌经溶菌酶处理仍残留部分外膜；由原生质体 + 剩余外膜构成 |
| 支原体 mycoplasma | 天然无壁；形态多样、对环境敏感；膜含固醇增强稳定性；可穿过滤菌器，最小 0.1～0.3 μm |

### 3.5 细胞壁内的结构

**细胞膜**

- 组成：磷脂双分子层（磷酸、甘油、脂肪酸）+ 蛋白（整合蛋白 integral、周边蛋白 peripheral）。
- 流动镶嵌模型：膜主体为具流动性的脂质双分子层；整合蛋白具疏水面嵌入内层；周边蛋白通过静电引力连于极性头；组分间无共价键。
- 功能：选择性透过屏障；呼吸、光合作用、脂质与细胞壁成分合成的场所。
- 间体 mesosome：质膜内不规则折叠，现多认为是电镜制样过程形成。

![细胞膜流动镶嵌模型](attachments/细胞膜流动镶嵌模型.png)

**细胞质**

- 约 80% 水，含蛋白质（酶）、糖类、脂质、无机离子及小分子；黏稠、半透明、有弹性。
- 核糖体：蛋白质合成场所，主要由 rRNA 组成。
- 细胞骨架：参与分裂、生长、DNA 移动、蛋白定位与形态决定。

**内含物 inclusion body**

- 特点：不同微生物内含物不同；是营养调节方式；贮藏物以多聚体存在，有利于维持渗透压与 pH 平衡。
- 类型：贮藏物、脂质内含物（PHB 聚-β-羟丁酸，可降解塑料）、异染粒（volutin，无机盐储备，美蓝染红）、糖原粒（碘液染褐色）、淀粉粒（碘液染深蓝）、硫粒。

**其他内含物**

- 磁小体 magnetosome：某些 G⁻ 菌形成，为氧化铁包裹体，由质膜内陷包围。
- 羧酶体 carboxysome：蓝细菌等固 CO₂ 菌中有，含 1,5-二磷酸核酮糖羧化酶/加氧酶。
- 气泡 gas vacuole：水生原核生物中，由圆柱形小空泡组成，外有 2 nm 蛋白膜，调节比重使细胞漂浮。

**核区 nuclear region**

- 不规则区域，含染色体与蛋白质；为单条长而连续的环状双链 DNA。

**芽孢 endospore**

- 营养缺乏时某些 G⁺ 菌形成的休眠体；由芽孢杆菌属 Bacillus、梭菌属 Clostridium、芽孢八叠球菌属 Sporosarcina 产生。
- 特点：细菌特有；高度脱水的耐久细胞；壁多层；在细胞膜内形成；耐高温、缺水、毒物与辐射。
- 染色：孔雀石绿加热染色 → 水洗 → 番红复染；营养细胞红/粉色，芽孢蓝绿色。
- 结构：孢外壁（脂蛋白）、芽孢衣（角蛋白）、皮层（肽聚糖）、核心（芽孢壁、芽孢质膜、芽孢质、核区）。
- 抗性机制：核心含水量低、含 Ca-DPA（吡啶二羧酸钙）、pH 略低；Ca-DPA 插入 DNA 碱基间稳定 DNA；小酸溶性 DNA 结合蛋白（SASPs）饱和孢子 DNA。
- 形成 sporulation：染色体复制分离 → 前孢子形成 → 孢子囊包裹前孢子 → 合成孢子层 → 皮层与芽孢衣形成 → 成熟 → 释放。
- 萌发 germination：激活（热或萌发剂触发）→ 萌发 → 长出 outgrowth。
- 伴孢晶体 parasporal crystal：苏云金芽孢杆菌 B. thuringiensis 等在形成芽孢时产生蛋白晶体；不溶于水、对蛋白酶不敏感、溶于碱性溶剂；幼虫中肠碱性环境溶解后穿孔致死，用于生物防治。

### 3.6 细胞壁外的结构

**糖萼 glycocalyx**

- 细胞壁外的糖衣，主要为多糖，也可含多肽。
- 两类：黏液层 slime layer（疏松附着）、荚膜 capsule（高度有序、紧密附着）。
- 染色：墨汁或苯胺黑负染背景，沙黄简单染色菌体。
- 功能：黏附环境、防止脱水与营养流失、增强毒力、抵抗宿主吞噬、形成生物膜、细胞间交流。
- 生物膜：作为屏障提供稳定内环境，承担物质转运、信息传递与能量转换；对杀菌剂与宿主免疫有很强抗性。

![生物膜形成过程](attachments/生物膜形成过程.png)

**鞭毛 flagella**

- 直径 10～20 nm，长 15～20 μm；光镜下不可见。
- 结构：鞭毛丝 filament（鞭毛蛋白 flagellin）、钩形鞘 hook（柔性连接）、基体 basal body（L 环连外膜、P 环连肽聚糖、MS 环连质膜；Mot 蛋白为动力、Fli 蛋白为开关）。
- 类型：单端生鞭毛 monotrichous、端生丛毛 lophotrichous、两端生鞭毛 amphitrichous、周生鞭毛 peritrichous。
- 染色：石炭酸品红 carbolfuchsin 加粗至光镜可见。
- 运动：基体旋转（顺/逆时针），成束推动液体前进；耗能。前进 run 为直行，翻转 tumble 为重新定向。

![鞭毛丝生长](attachments/鞭毛丝生长.png)

**菌毛 fimbriae**：部分 G⁻ 菌的短、直、细毛状附属物；介导黏附（彼此、表面、宿主组织），参与生物膜形成。

**性毛 pili**：比菌毛长，每细胞仅 1～2 根；参与运动与 DNA 转移（接合 conjugation）。

### 3.7 古菌

**特征**：生活在极端环境（极端嗜热菌、极端嗜盐菌、产甲烷菌等）；细胞壁无肽聚糖。

**细胞壁类型**

- S 层 S-layer：最普遍，由糖蛋白或蛋白质组成，厚可达 20～40 nm。
- 部分古菌在 S 层外还有蛋白鞘 protein sheath 或多糖层（如 methanochondroitin）。
- 假肽聚糖 pseudomurein 层位于 S 层与质膜之间：与肽聚糖的区别为 β-1,3 糖苷键（而非 β-1,4）、N-乙酰塔罗糖胺糖醛酸（而非 N-乙酰胞壁酸）、交联为 L-型氨基酸（而非 D-型）；对溶菌酶不敏感。
- 无 S 层者具单层而厚的化学组成多样的壁，常呈革兰氏阳性。

- 烃链来源于异戊二烯 units（五碳分支分子）；烃链与甘油以醚键连接（而非酯键），更耐热与化学攻击。
- 两类脂质：甘油二醚（C20，形成脂质双层）、二甘油四醚（C40，形成单层膜，更坚硬）。

### 3.8 其他原核微生物

**放线菌**：需氧；形成丝状细胞，分化为无性孢子；菌丝分气生菌丝与基质菌丝。

**蓝细菌**：G⁻；具类囊体 thylakoid，含叶绿素等光合色素；异形胞 heterocyst 可固氮；链丝段 hormogonium 具繁殖功能；厚壁孢子 akinete 为休眠细胞。

**支原体、立克次氏体、衣原体**（共同特征：G⁻、小、细胞内寄生）

- 支原体 mycoplasma：无细胞壁；质膜含固醇以抵抗渗透压；寄生于黏膜与关节，与呼吸道、泌尿生殖道疾病有关。
- 立克次氏体 rickettsia：缺乏糖酵解途径酶，不能自主代谢；经谷氨酸循环与 TCA 循环获能；无鞭毛。
- 衣原体 chlamydiae：球状、不运动；从宿主获取 ATP；生活史有网状体 RB（reticulate body）与具感染力的原体 EB（elementary body），EB 感染→RB→EB 再感染。

## 四、真核微生物

### 4.1 概述与细胞结构

**定义**：具有核膜、进行有丝分裂、具有线粒体或叶绿体等细胞器的一类生物。
**范围**：真菌 fungi、显微藻类 algae、原生动物 protozoa。

**细胞器**：线粒体、内质网、高尔基体、溶酶体、叶绿体。

**结构要点**

- 细胞壁：真菌主要为多糖 + 少量蛋白质和脂质；酵母为甘露聚糖与葡聚糖，低等真菌为纤维素，高等真菌为几丁质；藻类主要为纤维素。
- 糖被：部分真核生物形成富糖层，被蛋白质或脂质修饰。
- 纤毛/鞭毛：仅见于原生动物与动物；鞭杆由环状微管二联体 + 中央微管构成，另有基体与过渡区。
- 质膜：鞘脂类 + 甾醇 + 磷脂。

| 比较项 | 原核 | 真核 |
| --- | --- | --- |
| 甾醇 | 无 | 有 |
| 糖脂 | 无 | 有 |
| 电子传递链 | 有 | 无 |
| 基团转移运输 | 有 | 无 |
| 胞吞 | 无 | 有 |

**细胞质**

- 细胞基质：透明、黏性、持续流动的胶状物。
- 细胞骨架：微管 tubulin、肌动蛋白 actin、中间丝 intermediate filament。
- 内质网：粗面（有核糖体）、滑面（参与脂质与钙代谢）。
- 核糖体、高尔基体（4～8 个堆叠扁囊）、溶酶体（酸性水解酶）、微体（过氧化氢酶等，避免毒性过氧化氢损伤）。
- 线粒体：氧化磷酸化场所，外膜光滑、内膜折叠成嵴，有膜间隙。
- 叶绿体：叶绿体膜、类囊体、基质组成。
- 液泡。

### 4.2 真菌总论

**特征**：产生孢子；腐蚀性；缺少叶绿体；有性或无性繁殖；细胞壁为几丁质 / 甘露聚糖 / 半乳聚糖 / 纤维素。

**分类**：菌体 thallus、酵母 yeast（单细胞）、霉菌 mold（多细胞）、蘑菇 mushroom（大型真菌）。

**结构**

- 菌丝 hyphae：营养菌丝、气生菌丝。
- 孢子 spore：
  - 无性孢子：节孢子 arthroconidia、孢囊孢子 sporangiospore（孢子囊 sporangium）、分生孢子 conidiospore（顶端或侧端，不闭合）、芽生孢子 blastospore（出芽）。
  - 有性孢子：同宗配合 homothallic、异宗配合 heterothallic；阶段为单倍体 → 双核 → 二倍体。

### 4.3 酵母

- 特征：发酵糖类的单细胞真菌；芽殖或裂殖；细胞壁为葡聚糖（机械强度主要成分）或甘露聚糖；厌氧、喜酸、无鞭毛。
- 有性生殖：子囊孢子 ascospore；经质配 plasmogamy → 核配 karyogamy → 减数分裂 meiosis；营养体可为单倍体或二倍体。
- 无性生殖：出芽（芽痕 bud scar 多个、蒂痕 birth scar 一个）、二分裂、无性孢子（掷孢子、厚垣孢子、节孢子）。

### 4.4 霉菌

- 俗称丝状真菌 filamentous fungi。
- 菌丝：无隔菌丝 aseptate / coenocytic hyphae。
- 菌丝分化：
  - 营养菌丝：假根、吸器（吸取养料）；附着胞、附着枝（附着）；菌核、菌索（休眠；菌索为白色根状菌丝组织，促进蔓延与抵御不良环境）；匍匐枝（延伸）；菌环、菌网（捕食线虫）。
  - 气生菌丝：无性——分生孢子头、孢子囊、分生孢子器 pycnidium、分生孢子座 sporodochium；有性——担子、闭囊壳 cleistothecium、子囊壳 perithecium、子囊盘 apothecium。
- 细胞壁：纤维素/几丁质，蛋白质/甘露聚糖/葡聚糖。
- 生长：顶端生长；分顶端（几丁质 + 蛋白）、亚顶端（几丁质 + 蛋白 + 葡聚糖蛋白网）、成熟区（再加葡聚糖）、隔膜区。
- 菌落：大、质地疏松、干燥、不透明；中间颜色深，子实体与孢子颜色深。

![四大类微生物菌落比较](attachments/四大类微生物菌落比较.png)

### 4.5 蕈菌

- 一级菌丝：担孢子萌发形成单核细胞。
- 二级菌丝：通过锁状联合 clamp connection 形成双核细胞。
- 三级菌丝：进一步分化。
- 形成子实体并产生担孢子 basidiospore。

## 五、病毒与亚病毒

**结构**

- 二十面体 icosahedral；痘病毒 poxvirus 无衣壳但有脂蛋白；RNA 病毒遗传物质常为分段。

**复制阶段**：吸附 → 进入 → 脱壳 uncoating → 合成 → 组装 → 释放（出芽 budding 或裂解 lysis）。

**噬菌体**

- 大肠杆菌噬菌体（E. coli）为 DNA 病毒；只有遗传物质进入细胞，无需脱壳。
- 溶原性转化 lysogenic conversion：整合于细菌染色体的噬菌体基因产生毒素或病理性酶。

**病毒感染示例**

- 感染对象：乙肝 hepatitis B（人的活细胞）、脊灰 poliovirus（灵长类肠道与神经细胞）、狂犬病 rabies（哺乳动物）。
- 持续感染：麻疹病毒（脑细胞潜伏）、单纯疱疹病毒 HSV（唇疱疹、生殖器疱疹）、带状疱疹病毒 VZV（水痘、带状疱疹）。
- 肿瘤病毒 oncoviruses：乳头状瘤病毒（宫颈癌）、EB 病毒（Burkitt 淋巴瘤）。

**病毒培养**：细胞培养、鸡胚培养、活动物接种。

**病毒对宿主的破坏**：改变大小、形成包涵体、多核细胞、裂解、DNA 改变、癌变。

**亚病毒**：类病毒 viroid、拟病毒 virusoid、卫星病毒 satellite virus、卫星 RNA、朊病毒 prion（疯牛病 mad cow、羊瘙痒症 scrapie、慢性消耗病 CWD、库鲁病 kuru、克雅氏病 CJD）。

## 六、感染与免疫

### 6.1 免疫系统概述

- **定义**：机体识别和清除外来入侵抗原及体内突变或衰老细胞、维持内环境稳定的功能总称。
- **三大功能**：免疫防御（抵抗病原体侵入）、免疫监视（清除癌变和死亡细胞）、免疫平衡（维持稳定）。

### 6.2 正常菌群与致病菌

**正常菌群 normal flora**

- 正常人体体表及与外界相通腔道中存在的不同种类和数量的微生物，正常情况下无害而有益。
- 肠道微生物特点：数量大；功能多（营养、免疫、代谢、情绪等）；营养代谢（与肥胖相关的厚壁菌门 G⁺、拟杆菌门 G⁻）；降解有毒物质；保护与防御；维持胃肠道结构功能完整。

**致病菌 pathogen**：任何可能引发疾病的有机体。

- 机会致病菌 opportunistic pathogen：通常非致病，在定植部位改变、宿主免疫减弱、菌群失调等特定情况下致病。
- 完全致病菌 overt pathogen：较高可能性引发疾病。

**益生菌与益生元**

- 益生菌：细菌，与肠道害菌竞争，改善菌群平衡。
- 益生元：益生菌的「食物」，为无活性糖类。

### 6.3 感染与传染病

- **感染**：病原菌突破宿主三道防线后，在宿主特定部位定居、生长、繁殖、产生毒素，引起一系列病理生理反应的过程。
- **传染病**：由活病原体大量繁殖引起、可从宿主个体传播到另一活宿主的疾病。
- **全健康 One Health**：人类健康、动物健康、环境健康三者统一的整体。

**历史传染病**：鼠疫 plague（鼠疫耶尔森菌）、天花 smallpox（牛痘防治）、霍乱 cholera（霍乱弧菌，水传播）、流感 influenza、艾滋病 AIDS（HIV）。

**侵袭与扩散**

- 侵袭 invasion：侵入细胞并扩散，引起侵袭性感染；侵袭基因 inv 产生侵袭素。
- 扩散主要靠酶：血浆凝固酶 coagulase（形成纤维蛋白屏障）、透明质酸酶 hyaluronidase、链激酶 streptokinase、胶原酶 collagenase。

**内毒素与外毒素**

| 特性 | 内毒素 | 外毒素 |
| --- | --- | --- |
| 产生细菌 | 革兰氏阴性菌 | 都可以 |
| 位置 | 外膜组成部分 | 细胞质合成，分泌或不分泌 |
| 本质 | 脂多糖 | 蛋白质 |
| 热稳定 | 稳定 | 易失活 |
| 毒性 | 无（弱）毒性 | 强毒性 |
| 是否形成类毒素 | 不形成 | 形成 |

**微生物对控制措施的抵抗性**

- 高抵抗性：朊病毒、内生孢子。
- 低抵抗性：真菌孢子与菌丝、酵母、囊膜病毒、大部分细菌营养体、原虫滋养体。

### 6.4 先天性免疫：第一、二道防线

**第一道防线**

- 物理因素：表皮、黏膜、泪器、唾液、鼻毛、黏液-纤毛 escalator、咳嗽与喷嚏。
- 化学因素：皮脂中不饱和脂肪酸、低 pH（5～6）、抗菌肽、溶菌酶、胃液、阴道分泌物、尿液。
- 正常菌群。

**第二道防线**

- 吞噬细胞 phagocyte：巨噬细胞 macrophage、单核细胞 monocyte、粒细胞 granulocyte。
- 白细胞：中性粒细胞 neutrophil、淋巴细胞 lymphocyte、单核细胞、嗜酸性粒细胞 eosinophil、嗜碱性粒细胞 basophil。
- 吞噬作用五步：趋向 chemotaxis → 黏附 adherence → 摄入 ingest → 消化 digestion → 胞吐 exocytosis。
- 炎症 inflammation：症状 PRISH（痛 pain、红 redness、制动 immobility、肿 swell、热 heat）；阶段为血管扩张与通透性增强 → 吞噬细胞转移 → 组织修复；作用为破坏病原菌、限制传播、组织修复。
- 发热 fever：微生物被巨噬细胞吞入降解→释放内毒素→白细胞介素与 TNF-α→巨噬细胞释放细胞活类素→刺激下丘脑产生前列腺素→体温调定点升高；作用为抑制病原菌生长、增强代谢。
- 抗菌物质：
  - 干扰素 IFN：α/β 由被感染细胞产生，诱导未感染细胞产生抗病毒蛋白 AVPs；γ 由淋巴细胞产生，促进中性粒细胞与巨噬细胞吞噬。
  - 转铁蛋白 transferrin、抗菌肽（使细菌溶解）。
- 补体系统 complement system：体液中的酶活性蛋白；分固有成分（经典、旁路、凝集素三条途径）、调节蛋白、受体。
  - 命名：经典途径与终末成分按发现时间命名；旁路途径以字母称因子；凝集素按生物学特征；调节蛋白按功能。
  - 片段：大片段 a 作为级联反应酶，小片段 b 参与炎症反应（C2 相反）。
  - 性质：多数细胞可产生；血浆补体主要由肝细胞提供，局部炎症时由巨噬细胞提供；感染时含量升高；热敏感（50 ℃ 失活）。
  - 作用：增强炎症与吞噬、形成膜攻击复合物使细胞溶解。

### 6.5 适应性免疫：第三道防线

- 免疫器官：胸腺 thymus、骨髓 bone marrow、脾 spleen、淋巴结、黏膜相关淋巴组织。
- **定义**：机体对特定微生物感染进行反应的能力。免疫球蛋白 immunoglobulin（Ig）主要为 γ 球蛋白，分膜型与分泌型。

**体液免疫 humoral immunity**：发生于细胞外液，由抗体执行保护。

- 抗原 antigen：引发抗体产生的物质。
- 抗体：IgG、IgA、IgM、IgD、IgE。
- 表位 epitope（抗原决定簇 antigenic determinant）：抗体识别抗原上的表位。

![抗体结构](attachments/抗体结构.png)

**细胞免疫 cellular immunity**

- T 细胞表面 TCR 识别 APC 经 MHC 呈递的抗原。
- 抗原呈递细胞 APC：B 细胞（辅助 T 细胞→B 细胞产抗体）、巨噬细胞（辅助 T 细胞→活化巨噬细胞）、树突状细胞（初始 T 细胞→效应 T 细胞）。
- T 细胞分类：辅助性 T 细胞（CD4，被 MHC-Ⅱ 激活）、杀伤性 T 细胞（CD8，被 MHC-Ⅰ 激活）。
- 免疫反应阶段：感应阶段 → 增殖分化阶段 → 效应阶段。

**免疫记忆**：初次应答主要为 IgM；再次应答主要为 IgG。

**抗感染免疫**

- 病毒免疫逃避：抗原多样性、MHC-Ⅰ 表达下降、通过细胞桥转移、抑制先天与特异性免疫关键分子。
- 抗病毒感染：先天免疫（PAMP/PRR 识别、IFN-Ⅰ 诱导 AVPs 并促进 DC 成熟）、体液免疫（IgA/IgG/IgM 中和病毒、抑制吸附进入、促进溶解）、细胞免疫（感染细胞表面抗原改变，激活 NK 与 T 细胞，释放 IL、IFN、TNF）。
- 细菌感染：外毒素（组织破坏与功能紊乱，中和抗体 IgA/IgG/IgM）、内毒素（组织破坏与炎症，吞噬降解与免疫炎症反应）、细胞内感染（在宿主细胞内复制，依赖细胞免疫）。

## 七、微生物的营养、生态与生长

**营养与运输**

- 营养类型：腐生菌 saprobe。
- 运输：化学物质穿过膜的移动；胞吞 endocytosis 分吞噬 phagocytosis 与胞饮 pinocytosis。
- 生态位：生物在生态系统中与环境的关系的总和。

**环境因子**

- 温度：嗜冷菌 psychrophile、嗜温菌 mesophile、嗜热菌 thermophile。
- 其他：嗜二氧化碳菌 capnophile、嗜盐菌 halophile、嗜压菌 barophile。

**生态关系**

- 共生 symbiotic：互利共生 mutualism、共栖 commensalism、寄生 parasitism。
- 非共生 nonsymbiotic：协同 synergism、拮抗 antagonism。

**生长曲线**：延滞期 lag → 指数期 exponential → 稳定期 stationary → 衰亡期 death。

**计数方法**：浊度分析法 turbidometry、平板活菌计数 viable plate count。

## 八、微生物的控制

### 8.1 基本概念

| 术语 | 含义 |
| --- | --- |
| 消毒 decontamination | 用物理、化学、机械、生物方法破坏或减少不想要的微生物 |
| 腐败 spoilage | 目标微生物造成感染或腐败 |

| 抗菌剂 antiseptic | 直接用于体表的消毒剂 |
| 卫生处理 sanitization | 机械移除微生物的清洁技术 |
| 除菌 degermation | 通过机械方式减少微生物数量 |

- 微生物死亡：永久失去繁殖能力。

### 8.2 抗菌剂作用方式

1. **细胞壁**：使壁变脆弱或溶解（抗菌药物、洗涤剂、酒精）。
2. **细胞膜**：破坏膜完整性（表面活性剂 detergent/surfactant/soap）。
3. **蛋白与核酸合成**：氯霉素 chloramphenicol、紫外线、甲醛 formaldehyde。
4. **蛋白质**：醇、酚、酸、热。

### 8.3 物理控制

- **高温**
  - 湿热：高压蒸汽灭菌（使蛋白质、膜、DNA 变性）、间歇灭菌法 tyndallization（常压蒸汽，适用于不耐高温物品）、热水、巴氏消毒。
  - 干热：焚烧 incineration。
- **低温**：用于保存食物、培养基、培养物。
- **干燥 desiccation**：移除水分，效果有限；冷冻干燥 lyophilization。
- **辐射**：电离辐射（使电子脱离轨道、破坏 DNA，用于医疗器械与食品）、非电离辐射（紫外线形成嘧啶二聚体）。
- **过滤**。

## 十、思考题与简答题

**1. 益生菌和益生元的区别？**

- 益生元：益生菌的「食物」，无活性的糖类。
- 益生菌：细菌；与肠道害菌竞争，改善菌群平衡。

**2. 菌落与菌苔的区别（the difference between bacterial colony and bacterial lawn）？**

- 菌落：某一种微生物繁衍形成的、肉眼可见的菌体。
- 菌苔：多种微生物在固体培养基表面形成连续的菌落。

**3. 微生物的成员有哪些？**

- 原核：细菌、古菌；真核：真菌、原生动物、藻类、寄生虫；非细胞：病毒、类病毒、拟病毒、朊病毒。

**4. 微生物的特点有哪些？**：小且比表面积大；代谢强、繁殖快；分布广、种类多；易变异、抗性强。

**5. 分离纯化的方法？**

- 固体培养基：稀释倒平板法、涂布平板法、平板划线法、稀释摇管法。
- 液体培养基：单细胞分离法、选择培养法。

**6. 物种保护的基本原理与方法？**

- 影响因素：突变、污染、死亡；要求：无杂乱、无腐败。
- 方法：传代保藏、低温保藏、干燥保藏（冷冻真空、砂管、石蜡油、封藏）。

**7. 名词解释：菌落、菌苔、原核生物、真核生物**

- 菌落：固体培养基上肉眼可见的细菌团。
- 菌苔：固体培养基表面上连续的菌落。
- 原核生物：无细胞核的生物。
- 真核生物：有细胞核的生物。
