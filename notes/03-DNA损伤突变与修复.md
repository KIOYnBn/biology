# 03 · DNA 损伤、突变与修复

> [!abstract] 一句话定位
> **突变是序列永久改变，损伤是化学结构异常**；修复系统要在错误被"固定"成突变之前，把损伤可逆地抹掉——找不到模板时才会动用易错的容忍机制。

**导航**：[[分子生物学/02-基因组维持/02-DNA复制|← DNA 复制]] · [[分子生物学/00-复习总览|复习总览]] · [[分子生物学/02-基因组维持/04-重组与转座|重组与转座 →]]

---

## 0　三个关键问题

1. DNA 修复的速度如何快到足以避免错误被固定为永久突变？
2. 当 DNA 断裂或严重损伤、原始序列无法读取时，细胞如何恢复正确序列？
3. 细胞如何应对阻碍复制的 DNA 损伤？

---

## 1　概念辨析

| 概念 | 定义 |
| :--- | :--- |
| **突变** | 核苷酸替换、插入、缺失引起的**序列永久改变** |
| **损伤** | DNA **化学结构异常**，可被修复而不留痕迹 |
| **修复的核心依据** | 互补碱基配对（另一条链提供模板） |

> [!important] 三道防线
> ① 互补碱基配对（结构基础）　② DNA 聚合酶校对（见 [[分子生物学/02-基因组维持/02-DNA复制|DNA 复制]]）　③ 错配修复 + 损伤修复系统（本篇）

## 2　突变

### 2.1　类型

#### 点突变：仅改变单个核苷酸

**碱基替换**

| 类型 | 定义 |
| :--- | :--- |
| **转换** | 嘧啶↔嘧啶、嘌呤↔嘌呤 |
| **颠换** | 嘧啶↔嘌呤、嘌呤↔嘧啶 |

- 发生方式：**互变异构变换**
  - 酮式-烯醇式互变：G(烯醇)-T、G-T(烯醇)；T 突变：AT → GT。
  - 氨基-亚氨基互变：A(亚胺)-C、A-C(亚胺)。

**单个或少数核苷酸插入/缺失 → 移码突变**（阅读框改变）。

#### 更大尺度

片段插入、缺失、染色体重排。

### 2.2　按蛋白质效应分类

| 类型 | 后果 |
| :--- | :--- |
| **沉默突变** | 不影响功能，产生多态性；发生在基因间隔区、内含子、非翻译区或同义密码子 |
| **错义突变** | 编码不同氨基酸 |
| **无义突变** | 产生提前终止密码 |
| **移码突变** | 阅读框改变 |
| **逆转突变** | 恢复野生型表型 |

> 密码子与阅读框背景见 [[分子生物学/03-基因组表达/03-翻译|翻译]]；此处只讲突变的分子来源。

### 2.3　突变的来源

1. **DNA 复制的不准确性**：碱基互变异构。
2. **遗传物质受到化学损伤**：脱氨基、辐射。
3. **转座子造成的插入突变**（见 [[分子生物学/02-基因组维持/04-重组与转座|重组与转座]]）。
4. **诱发突变**：诱变剂处理。

### 2.4　突变的后果

1. 序列永久改变。
2. 阻碍复制或转录。

## 3　错配修复（MMR）

> **对象**：修复**新合成链**上的碱基错配。

### 3.1　大肠杆菌：MutS / MutL / MutH

1. **MutS 二聚体**沿 DNA 扫描：不直接识别碱基种类，而识别错配导致的**DNA 骨架扭曲**（错配无法形成正常氢键→双螺旋变形，易被 MutS 弯折捕获）；结合后构象变化招募 MutL。
2. **MutL** 作为衔接蛋白，将信号传递给 MutH，激活其内切酶活性。
3. **MutH** 在**半甲基化 GATC 位点**特异性切开**未甲基化的新链**，制造单链缺口。
4. **UvrD 解旋酶**从切口解开双链，对应方向的外切酶降解新链，一直切过错配位点。
5. **DNA Pol III** 以母链为模板填补缺口，**DNA 连接酶**封口。

### 3.2　真核生物

- **MSH**（MutS 同源）、**MLH、PMS**（MutL 同源）。
- **PCNA 招募 MSH**。
- **链识别**：
  - **后随链**：利用**冈崎片段**的切口。
  - **前导链**：通过复制叉上的滑动夹 **PCNA** 招募错配修复蛋白，利用 **3′ 延伸端**特征识别新链。

### 3.3　新链识别总结

| 生物 | 识别依据 |
| :--- | :--- |
| 原核 | **甲基化**状态（半甲基化 GATC，新链未甲基化） |
| 真核-后随链 | 冈崎片段 |
| 真核-前导链 | PCNA + 3′ 延伸端 |

## 4　DNA 损伤的类型

> [!tip] 学习框架
> 每一类都按 **"什么情况下造成 → 造成什么结果 → 如何修复"** 三步掌握。

### 4.1　环境因素

#### 烷化作用

- 甲基或乙基被转移到碱基反应活性位点及 DNA 骨架磷酸基团上。
- 烷化剂：亚硝胺、**EMS**（甲基磺酸乙酯）、**EES**（乙基磺酸乙酯）、芥子气。
- **O⁶-甲基鸟嘌呤**常与胸腺嘧啶错配 → 复制后 **G:C → A:T**。

#### 氧化损伤

- 活性氧攻击：超氧阴离子、过氧化氢、羟自由基。
- 来源：电离辐射、产自由基的化学物质。

#### 紫外线辐射损伤

- 同一条链相邻两个嘧啶发生光化学融合，产生**胸腺嘧啶二聚体（T-T）**；若 T 与 C 相邻则形成 T-C 加合物。
- 交联碱基无法正常配对 → 阻碍转录与复制。

#### 电离辐射损伤

- γ 射线、X 射线造成 **DSB**，引起缺失、易位、染色体片段化。
- 直接电离 DNA 骨架中的脱氧核糖，或先产生活性氧再间接攻击。
- **剂量效应（直接作用于染色体）**：ssDNA → dsDNA → 染色体畸变。

#### 诱变剂

| 类别 | 代表 | 机制 |
| :--- | :--- | :--- |
| 碱基类似物 | **5-溴尿嘧啶**（T 类似物，溴取代使其更易以烯醇式存在，与 G 错配）；**2-氨基嘌呤 2-AP**（A 类似物） | 复制时错配 |
| 嵌入剂 | 溴化乙锭、**吖啶染料**（能插入或楔入碱基对的小分子） | 插入突变：嵌入使聚合酶额外掺入 1 个核苷酸；缺失突变：构象扭曲使聚合酶跳过 1 个核苷酸 |

### 4.2　水解损伤

1. **脱氨基**
   - 单链状态时碱基暴露于水溶液，水分子易攻击碱基。
   - 胞嘧啶常被甲基转移酶修饰为 **5-甲基胞嘧啶**，脱氨基后生成**胸腺嘧啶**。
   - **C → U（CG → UA）**：最常见。
   - **A → 次黄嘌呤 Hx（= C）**；**G → 黄嘌呤（= C）**，但仅能形成 2 个氢键。
2. **脱嘌呤**：N-糖苷键自发水解，产生**无碱基位点（AP site）**。

## 5　修复与容忍机制

### 5.1　直接修复

由修复酶直接逆转、消除损伤。

| 靶标 | 机制 |
| :--- | :--- |
| 嘧啶二聚体 | **DNA 光解酶**捕获光能，用能量打断二聚体 |
| O⁶-甲基鸟嘌呤 | **甲基转移酶**将甲基转移到自身半胱氨酸上，随后被泛素-蛋白酶体降解 |

### 5.2　切除修复（单链损伤修复）

> 通用逻辑：**移除受损核苷酸 → 以未受损链为模板，由 DNA 聚合酶重新掺入正确核苷酸 → 连接酶封口**。

#### 碱基切除修复（BER）——切"一个碱基"

1. **识别并切除碱基**：特异性 **DNA 糖苷酶**识别受损碱基，水解糖苷键，产生 **AP 位点**（脱碱基位点）。
2. **切割骨架**：**AP 核酸内切酶**在 AP 位点切断 DNA 骨架。
3. **填补连接**：修复型 DNA 聚合酶（如 Pol β）以另一条链为模板填补**单个**核苷酸，DNA 连接酶封口。
- **机制**：碱基翻转。

#### 核苷酸切除修复（NER）——切"一段寡核苷酸"

> 通过识别**DNA 双螺旋的结构扭曲**发挥作用，最终移除包含损伤的一小段单链 DNA。

**大肠杆菌 UvrABCD**

1. **扫描识别**：UvrA-UvrB 复合物沿 DNA 移动，UvrA 识别螺旋扭曲。
2. **解链成泡**：UvrA 解离，UvrB 结合损伤位点并解开双链。
3. **双侧切口**：UvrC 被招募，在损伤 **5′ 侧与 3′ 侧**切割，释放含损伤的短单链。
4. **填补封口**：UvrD 解旋酶剥离损伤片段，DNA Pol I 填补，连接酶封闭。

**真核生物两条通路**（主要区别在于**损伤识别**机制）

| 通路 | 识别方式 | 对应原核组分 |
| :--- | :--- | :--- |
| **全基因组修复** | 特异蛋白识别损伤 | — |
| ↳ 损伤识别 | **XPC** | UvrA |
| ↳ 解链 | **XPA、XPD**（属于 TFIIH 复合物） | UvrB |
| ↳ 双侧切割 | **ERCC1-XPF** 切 5′ 端；**XPG** 切 3′ 端 | UvrC |
| ↳ 填补 | 修复型聚合酶 + 连接酶 | — |
| **转录偶联修复** | 转录时停滞的 RNA 聚合酶招募 NER 蛋白到损伤位点 | — |

> 转录偶联修复中 TRCF 的作用见 [[分子生物学/03-基因组表达/01-转录|转录]]。

### 5.3　双链断裂修复（DSB）

| 途径 | 原理 | 分布 |
| :--- | :--- | :--- |
| **同源重组修复（HR）** | 从另一条完整的同源染色体获取序列信息；机制为 **3′ 端入侵** | 主要存在于细胞中 |
| **非同源末端连接（NHEJ）** | 先保护并加工断裂末端，再将它们**直接连接**（易出错） | 真核生物中主要存在 |

**NHEJ 过程**：DSB → **Ku70/80** 识别结合末端 → 招募 **DNA-PKcs** 全酶 → 招募激活 **Artemis** 修剪加工末端 → **XRCC4、XLF、DNA 连接酶 IV** 连接末端。

> [!tip] 去重说明
> HR 的完整模型（Holliday、DSB 修复模型、RecBCD、Rad51、Spo11）统一在 [[分子生物学/02-基因组维持/04-重组与转座|重组与转座]] 中详讲；此处只保留"DSB 两条修复路线"的对照。

### 5.4　跨损伤修复 / 差错倾向修复（TLS）

> 当受损碱基**阻滞复制型 DNA 聚合酶**时，跨损伤聚合酶越过损伤位点完成复制。仍依赖模板，但掺入核苷酸**不依赖严格碱基配对**。

**调控机制**

| 生物 | 机制 |
| :--- | :--- |
| 原核（大肠杆菌） | **SOS 应答**：正常时 LexA 抑制 TLS 聚合酶基因；损伤产生的 ssDNA 激活 **RecA**，促进 LexA 降解 → 诱导 Pol IV / Pol V 合成 |
| 真核 | **PCNA 泛素化**触发聚合酶切换：复制叉停滞 → PCNA 泛素化 → 招募带泛素结合域的 TLS 聚合酶 → 越损伤后解离，复制聚合酶重新接管 |

**两种工作模型**

1. **聚合酶开关模型**：在停滞的复制叉处，TLS 酶直接替换复制酶，原位越过损伤。
2. **缺口填补模型**：复制酶跳过损伤，在下游重新起始，损伤位置留下单链缺口，后续由 TLS 聚合酶填补。

> 聚合酶"交接班"的视角见 [[分子生物学/02-基因组维持/02-DNA复制|DNA 复制 · 聚合酶转换]]。

- [ ] TLS：SOS 应答 vs PCNA 泛素化；两种工作模型

<details>
<summary><b>自测 1：转换与颠换如何区分？</b></summary>

嘌呤↔嘌呤或嘧啶↔嘧啶是**转换**；嘌呤↔嘧啶是**颠换**。
</details>

<details>
<summary><b>自测 2：BER 与 NER 的核心区别？</b></summary>

BER 切除**单个受损碱基**（糖苷酶先造 AP 位点，再切骨架）；NER 识别**螺旋扭曲**，直接切除含损伤的**一段寡核苷酸**（原核 UvrC 双侧切，真核 XPF/XPG 双侧切）。
</details>

<details>
<summary><b>自测 3：原核与真核错配修复如何区分新链？</b></summary>

原核靠**甲基化**状态——MutH 在半甲基化 GATC 处切开未甲基化的新链；真核后随链靠**冈崎片段**切口，前导链靠**PCNA** 招募 MMR 蛋白并识别 3′ 延伸端。
</details>

<details>
<summary><b>自测 4：HR 与 NHEJ 的差别？</b></summary>

HR 以同源染色体为模板、经 3′ 端入侵，修复**准确**；NHEJ 直接加工并连接末端，不需同源模板，但**易出错**（易造成插入/缺失）。
</details>
