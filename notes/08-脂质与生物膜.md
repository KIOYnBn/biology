# 08 脂质与生物膜

脂质是脂肪酸和醇形成的酯及其衍生物，核心特征是疏水性。本篇按贮存脂质、膜结构脂质、活性脂质展开，进而介绍血浆脂蛋白、生物膜及脂质的提取与分析。

## 一、绪论

- 元素组成：基本为 C、H、O，有的含 N、P、S。
- 特点：不溶或低溶于水，易溶于非极性溶剂。
- 分类：

| 依据 | 类型 | 说明 |
| --- | --- | --- |
| 组成 | 简单脂质 | 只含 C、H、O，由脂肪酸与甘油或长链醇形成酯，如三酰甘油和蜡 |
| 组成 | 复合脂质 | 含 N、P、S，包括甘油磷脂、鞘磷脂、甘油糖脂、鞘糖脂 |
| 组成 | 衍生脂质 | 由前两类衍生、具有脂质一般特性的物质 |
| 功能 | 贮存脂质 | 三酰甘油、蜡 |
| 功能 | 结构脂质 | 磷脂、胆固醇、糖脂 |
| 功能 | 活性脂质 | 类二十烷酸、胞内信使、类固醇激素等 |

## 二、脂肪酸（Fatty acid）

- 脂肪酸氧化形成 $CO_2$ 和 $H_2O$；结构为 $C_4$~$C_{36}$ 的羧酸。
- 生物中多为 12–24 C，一般为偶数碳（以二碳单位从头合成）；双键一般 1–4 个，多为顺式，分支较少。

### 1. 类型与命名

- **饱和脂肪酸**：无双键；细菌中大多为饱和脂肪酸。
- **不饱和脂肪酸**：含双键；植物中较多，通常为 $\Delta^9$、$\Delta^{12}$、$\Delta^{15}$；含多个双键者为多不饱和脂肪酸（PUFA）。

| 写法 | 含义 |
| --- | --- |
| 18:0 | 链长 18 C，无双键 |
| $18:2\Delta^{9,12}$ | $C_9$、$C_{12}$ 处有两个双键 |
| $18:2\Delta^{9c,12c}$ | $C_9$、$C_{12}$ 处有两个顺式双键 |

- **ω 命名法**：将 C1 命名为 ω，以 $\omega$-3 表示 C3 上有双键。
- **必需脂肪酸**：亚油酸 $18:2\Delta^{9,12}$ 和 α-亚麻酸 $18:2\Delta^{9,12,15}$；动物不能引入超过 $\omega^9$ 的双键。亚油酸可转化为花生四烯酸，进而生成类二十烷酸。

### 2. 物理性质

1. 链越长、双键越少，溶解度越低。
2. 双键越多，熔点越低。

### 3. 化学性质

1. 氧化与过氧化。
2. 双键的卤化和氢化。
3. **乳化作用**：脂肪酸是两亲化合物，是一种去污剂；在油滴表面聚集成层，使油滴变成亲水物质并在水中形成稳定乳胶。常见乳化剂如 SDS。

## 三、贮存脂质

### 1. 三酰甘油

- 油脂的化学本质就是三酰甘油：固态称脂，液态称油；植物主要是油，动物主要是脂（鱼油除外）。
- 结构：1 分子甘油 + 3 分子脂肪酸。
  - 简单三酰甘油：3 条烃链相同；混合三酰甘油：3 条烃链不同。
- 生物作用：**贮存能量与保温**，一般储存在脂肪细胞中（含脂酶）。
- 物理性质：无色无味、黏稠液体或固体，密度小于水。
- 化学性质：
  1. 可被乳化。
  2. 水解：酸、碱或脂酶；碱条件下水解称**皂化作用**，形成脂肪酸盐（皂）。
  3. 加成：氢化/卤化；**碘值**可衡量油脂不饱和度。
  4. 氧化（酸败）：双键氧化断裂，形成较短的易挥发醛或酸。
     - 过氧化是自由基链式反应，包括引发、增长、终止三阶段。
     - 自由基：含未配对电子的原子或原子团；活性氧：高反应性的氧。
     - 双键相连的亚甲基容易脱氢形成自由基，与氧形成 $LOO\cdot$。

### 2. 蜡

- 结构：长链脂肪酸 + 长链一元醇。
- 性质：完全不溶于水，极性头为酯基。
- 作用：储存（浮游生物）、防水（如蜂蜡）。

## 四、膜结构脂质

### 1. 磷脂

#### 甘油磷脂

- 结构：由 L-甘油-3-磷酸衍生，$C_1$、$C_2$ 与脂肪酸相连，$C_3$ 与磷酸相连，磷酸基再被 XOH 酯化。
- 物化性质：
  1. 溶于含少量水的非极性溶液，不溶于无水乙醇。
  2. 水解：弱碱 → 脂肪酸盐 + 3-磷酰醇甘油；强碱 → 脂肪酸盐 + 醇 + 3-磷酸甘油；脂肪酶水解其中一个脂肪酸；磷脂酶水解磷酸二酯键和酯键。

![[attachments/常见的甘油磷脂.jpg|700]]

**特殊甘油磷脂**：

1. **含醚键的脂肪酰链**：其中一个脂肪酸链以醚键而非酯键连接，如血小板活化因子。
2. **古菌的独特膜脂**：每个烃链都通过醚键与甘油连接。

![[attachments/古菌的膜脂.jpg|500]]

#### 鞘脂

- 组成：鞘氨醇（氨基醇）+ 长链脂肪酸 + 极性头基；极性头基通过糖苷键或磷酸二酯键连接。
- **神经酰胺**：脂肪酸与鞘氨醇 C2 的 $-NH_2$ 连接，是所有鞘脂的结构母体。
- 功能：提供胞外分子或相邻细胞识别位点。
- 类型：
  - **鞘磷脂**：极性头基为磷酸胆碱/磷酸乙醇胺，存在于动物细胞质膜，特别是髓鞘。
  - **鞘糖脂**：极性头基为单糖/寡糖。

### 2. 糖脂

脂质与寡糖共价连接形成糖脂（详见《07-糖类》）。

### 3. 类固醇

- **环戊烷多氢菲**：3 个六碳环 + 1 个五碳环；含角甲基者称**甾核**（A-B、C-D 环之间各有一个甲基）。
- 结构特点：
  1. C3 上常为羟基或酮基。
  2. C17 上具有侧链。
  3. C4–C5、C5–C6 之间常为双键。
  - 整体呈椅式构象。
- **固醇**：细菌不能合成固醇；C3 有 β 取向羟基，C17 有烃侧链。
  - **胆固醇**：参与动物细胞膜组成，是类固醇激素的前体；胆结石的主要成分即胆固醇，冠心病患者胆固醇含量常较高。

## 五、活性脂质

前体多为乙酰-CoA。

### 1. 类二十烷酸（二十碳多不饱和脂肪酸衍生物，原笔记称「类十二烷酸」）

- 作用：局部激素；由 20 碳 PUFA 衍生。
- 合成通路：
  1. 环加氧酶通路：生成前列腺素、凝血烷。
  2. 脂加氧酶通路：生成白三烯。
- 类型：
  - **前列腺素**：细胞接受信号时膜磷脂释放花生四烯酸，经环加氧酶（前列腺素 $H_2$ 合酶）产生；作用为平滑肌收缩、血压下降。PGE 溶于乙醚，可提高腺苷酸环化酶活性；PGF 溶于磷酸盐缓冲液，提高 cGMP 水平。
  - **凝血烷（TX，如 TXA₂）**：前列腺素类似物，含氧六元环；收缩动脉、促进血小板聚集、诱发血栓。
  - **白三烯（LT）**：含多个共轭双键，主要由白细胞合成；强效信号分子，收缩平滑肌、增加微血管通透性、收缩气管，过量可引发哮喘、过敏性休克。

### 2. 胞内信使

- **磷脂酰肌醇**：磷脂酶 C 水解磷脂酰肌醇 4,5-二磷酸，释放 $IP_3$（促 $Ca^{2+}$ 释放）和 DAG（激活蛋白激酶 C）。
- **鞘氨醇衍生物**：神经酰胺、鞘磷脂调控蛋白激酶活性。

### 3. 类固醇激素

胆固醇氧化衍生物，保留固醇核，包括性激素和肾上腺皮质激素。

### 4. 类萜

- 前体：异戊烯基焦磷酸 + 二甲丙烯基焦磷酸；结构上以**异戊二烯**为单位。
- 按异戊二烯数目分：单萜（2）、倍半萜（3）、双萜（4）等。
- 示例：
  - **植物挥发性脂质**。
  - **脂溶性维生素**：
    - 维生素 A（视黄醇）：通过视黄酸/视黄醛执行功能。
    - 维生素 D：在肝和肾转化为骨化三醇，促进小肠黏膜对钙磷的吸收及肾小管对钙磷的重吸收。
    - 维生素 E（生育酚）：定位于生物膜，是自由基清除剂，防止膜脂过氧化。
    - 维生素 K（凝血维生素）：作为羧化酶辅因子修饰凝血因子，参与凝血。
  - **氧化还原辅因子**：脂质醌（泛醌、质体醌）分别在线粒体和叶绿体驱动 ATP 合成。
  - **色素**：类胡萝卜素是共轭双烯脂质；叶绿素是脂质；花青素类不是脂质。
  - **多萜醇**。

### 5. 聚酮化合物

高活性天然次级代谢产物，由乙酰-CoA 经 Claisen 缩合生成，合成通路类似脂肪酸但缺少还原步骤。

## 六、血浆脂蛋白

- **脂蛋白**：脂质与蛋白质**非共价**结合；蛋白质部分称载脂蛋白。广泛存在于血浆，生物膜中与脂质融合者称细胞脂蛋白。

| 类型 | 合成部位 | 功能 |
| --- | --- | --- |
| 乳糜微粒 | 肠细胞内质网 | 最大、密度最小、脂质含量高；从小肠转运吸收的脂质，后被毛细血管壁脂蛋白脂酶水解；大量存在时血浆呈乳白色 |
| 极低密度脂蛋白（VLDL） | 肝细胞内质网 | 转运肝的脂质（三酰甘油和胆固醇）到靶组织；丢失三酰甘油后成 IDL |
| 低密度脂蛋白（LDL） | 由 IDL 转变 | 胆固醇的载体，转运胆固醇到肝外组织 |
| 高密度脂蛋白（HDL） | 肝和小肠 | 将肝外胆固醇运回肝 |

- 分离：电泳。
- 结构：球状颗粒，含疏水脂、极性脂和载脂蛋白。
- 载脂蛋白作用：作为疏水脂质的增溶剂；作为细胞膜脂蛋白的识别部位。

## 七、生物膜的组成和结构

- **膜脂**：磷脂、糖脂、固醇，以磷脂为主；磷脂中以甘油磷脂（磷脂酰胆碱、磷脂酰乙醇胺）为主。
- **糖萼（细胞外壳）**：质膜表面的寡糖–蛋白质复合体。

### 1. 膜蛋白与膜的结合方式

| 类型 | 结合方式 |
| --- | --- |
| 外周膜蛋白 | 分布在脂双层内外表面，通过静电相互作用和氢键与内在蛋白亲水结构域或膜脂极性头结合 |
| 内在膜蛋白 | 通过脂双层疏水相互作用与膜结合；需用去污剂、有机溶剂、变性剂提取；有些通过共价相连的脂质锚定 |
| 兼在蛋白质 | 有时在细胞溶胶，有时与膜结合 |

### 2. 生物膜的运动

| 状态 | 特点 | 促进因素 |
| --- | --- | --- |
| 有序液态 $L_a$ | 膜脂运动慢，低于正常生理温度 | 长链脂肪酸；固醇与不饱和脂肪酸磷脂相互作用（刚性环减少 C—C 旋转） |
| 无序液态 $L_d$ | 膜脂运动快，生理温度以上 | 不饱和脂肪酸、短链脂肪酸；固醇与长链饱和脂酰链磷脂及鞘脂结合（甾核阻扰有序装配） |

- **脂质的运动**：
  1. **翻转运动**：脂质从脂双层一层翻到另一层，需能；翻转酶催化氨基磷脂（磷脂酰乙醇胺、磷脂酰丝氨酸）向内层转位，鞘脂和磷脂酰胆碱位于外层。
  2. **侧向扩散**：磷脂在双层同一层与临近分子交换。
- 膜运动测定方法：**光漂白荧光恢复法**（膜蛋白荧光染色后强光漂白某一区域，观察恢复）。
- 某些膜蛋白形成聚集体（如乙酰胆碱受体）；某些膜蛋白通过细胞骨架锚定，不自由扩散。

## 八、脂质的提取、分离与分析

### 1. 有机溶剂提取

- 提取剂：氯仿 : 甲醇 : 水 = 1 : 2 : 0.8（体积比）。
  - 非极性脂质（三酰甘油、蜡、色素）用氯仿提取。
  - 膜脂（磷脂、糖脂、类固醇）用有机溶剂（甲醇）提取。
- 流程：组织在提取剂中匀浆 → 过滤 → 加过量水 → 取氯仿相 → 蒸发浓缩 → 干燥称重；脂质留在氯仿相（下相），蛋白质、多糖等极性大分子进入水/甲醇相。

### 2. 吸附层析分离

- 硅胶吸附层析：极性脂质按极性增加顺序被洗脱；极性脂质与极性硅酸结合，中性脂质直接流出。
- 硅胶薄层层析。

### 3. 气–液色谱

分析挥发性脂质混合物：将脂质转化为衍生物增加挥发性（如脂肪酸在甲醇/HCl 或 NaOH 中加热转酯为脂肪酸甲酯）；洗脱顺序取决于吸附剂性质和脂质沸点。

### 4. 专一性水解与质谱

- 专一性水解：利用酶对特定键的专一断裂测定脂质结构。
- 质谱：测定脂质结构。
